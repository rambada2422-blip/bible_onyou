# Gemini 열재앙 플레이테스트

## Gemini NEON에 전달할 프롬프트

> 바이블 온유의 8~10세용 출애굽기 탐험을 최대 3시간 동안 플레이테스트해 줘. GPT는 게임 코드를 맡고 Claude는 성경 본문과 그림 배치를 감수한다. 보고서 첫줄에 검토한 게임 커밋을 써 줘. 실제 플레이와 코드·사진 추론을 구분한 한국어 보고서를 만들어 줘.
>
> 1. 처음 45분에는 첫째 재앙을 세로 320×568과 가로 568×320에서 살펴봐. 강가부터 누르는 경로와 강물부터 누르는 경로에서 첫 행동을 무엇이 알려 주는지, 한 곳만 보고 나갔다 돌아오면 다음 행동이 보이는지 확인해.
> 2. 다음 75분에는 아홉 재앙과 유월절 준비를 이어서 살펴봐. 앞의 재앙에서 배운 조작이 파리와 흑암에서 어떻게 쓰이는지, 세 번째부터 어디에서 새로 발견할 것이 줄어드는지 기록해. 유월절 방에서는 단서 하나를 열고 설명 끝까지 읽은 다음 나머지 두 곳을 찾아봐.
> 3. 남은 시간에는 영향이 큰 문제 3개를 골라 ‘장면 / 한 행동 / 관찰한 결과 / 작은 개선안 / 다시 확인할 방법’으로 적어 줘. 해당하는 화면 크기와 근거 사진 또는 파일을 붙여 줘. 직접 실행한 범위와 사진·코드로만 검토한 범위를 밝혀 줘. 실제 어린이 관찰이 필요한 판단은 가설로 표시해. 마지막 밤의 경우는 본문을 조용히 읽을 수 있는지 살펴봐.
