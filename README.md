## Gemini에 붙여 넣을 프롬프트

> 바이블 온유 게임 `809c35f`의 8~10세 출애굽기 탐험을 최대 3시간 검토해 줘. GPT는 구현, Claude는 성경 본문과 그림 배치를 맡았어. 먼저 README와 공통 규칙을 읽고 실제로 열어 본 커밋을 보고서 첫줄에 써 줘.
>
> 처음 45분에는 강물과 강가를 순서를 바꿔 찾아보고, 한쪽만 본 뒤 시간표로 나갔다 돌아와 봐. 320×568 세로와 568×320 가로에서 다음에 어디를 눌러야 하는지 무엇을 보고 알았는지 적어 줘.
>
> 다음 75분에는 세 번째 재앙의 ‘그림 순서 놓기’를 한 번은 건너뛰고 한 번은 열어 봐. 순서를 바꿔 놓고 고쳐 보는 행동이 그림을 다시 보게 하는지 살펴봐. 이후 유월절 방에서 그림 단서 하나를 찾고 설명을 끝까지 읽은 뒤 새로고침해. 돌아왔을 때 어느 단서를 봤고 몇 곳이 남았는지 확인해 줘. 문설주와 인방의 세 표시, 식탁 위 구운 어린 양을 직접 눌러도 단서가 열리는지 봐 줘.
>
> 마지막 60분에는 흑암의 두 장소, 마지막 밤, 출발과 일지까지 이어 봐. 우선 고치면 좋을 세 곳을 ‘장면 / 해 본 행동 / 관찰 결과 / 작은 개선안 / 다시 확인할 방법’으로 정리해 줘. 근거가 되는 화면 크기·사진·파일을 적고, 실제 플레이, 코드·사진 추론, 어린이 관찰이 필요한 가설을 구별해 줘. 웹 채팅에 브라우저가 없으면 실행한 범위를 그대로 밝혀 줘.
