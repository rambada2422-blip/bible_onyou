# 샤론의 얼굴 그림

호렙 게임의 말풍선 옆에 쓰는 192×192 PNG 네 장이다. 원 밖은 투명하다. 3D 장면 안에서는 샤론을 그리지 않는다. 등장 기준은 [샤론 설정](../../../docs/11_샤론_설정.md) 4절과 7.1절을 따른다.

| 그림 | 등장할 때 |
| --- | --- |
| `sharon-avatar.png` | 평소 |
| `sharon-ask.png` | 묻는 중 |
| `sharon-joy.png` | 기뻐함 |
| `sharon-cheer.png` | 다시 해 보자 |

네 파일은 대표가 승인한 그-8 시안의 192픽셀 사본과 바이트 단위로 같다. ‘묻는 중’은 오른쪽 눈 둘레를 정리했고, ‘다시 해 보자’는 몸과 원형 테 사이를 넓혔다. ‘평소’와 ‘기뻐함’은 그-7과 같은 그림이다. [원본과 제작 기록](https://github.com/rambada2422-blip/bible_onyou/tree/0d6133df28294aad3a6cbe2971e8f9a6d0c4c2c5/docs/시안/길잡이/사이버3)

`node tools/build3d.js`가 그림을 게임과 한 파일 미리보기에 묶는다.

⚠️ GPT 그림 사용 조건의 약관 원문은 확인 전이다.
