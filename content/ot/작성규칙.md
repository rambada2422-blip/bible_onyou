# 구약 장면 자료 작성 규칙 (작성자와 검증자가 함께 읽는다)

장면 하나 = `content/ot/OT-NN.json` 파일 하나. 장면 목록과 본문 범위는 `docs/09_구약전체_장면표.md`, 상위 규칙은 `docs/00_공통규칙서.md`(충돌하면 규칙서가 우선). **본보기는 `content/ot/OT-09.json`** (독립 검증을 두 번 거친 호렙 산 장면)이다. 형식과 말투를 이 파일에 맞춘다.

## 1. 본문을 보는 방법 (이것만 쓴다)

```bash
node tools/bible_ref/ref.js "창 12:1-9"     # 개역한글과 KJV를 절마다 보여 준다
node tools/validate_ot.js OT-05             # 형식, 장절이 실제로 있는지, 본문과 지나치게 같은 문장을 검사
```
- 근거는 **성경 본문뿐**이다. 주석, 설교, 인터넷 자료, 기억에 있는 해설을 쓰지 않는다(규칙서 3.2). `sources`에는 "없음(성경 본문만 사용)"이라고 적는다.
- 쓰기 전에 장면의 본문 범위 전체를 반드시 위 명령으로 읽는다. 기억으로 쓰지 않는다. 대목과 물음의 장절은 그 내용이 실제로 적힌 절이어야 한다.

## 2. 반드시 지킬 것 (지난 검증에서 되풀이해 걸린 것들)

1. **본문에 없는 것을 쓰지 않는다.** 인물의 속마음, 표정, 날씨, 시간, 대사, 까닭을 지어내지 않는다. 본문이 말하지 않으면 "성경은 까닭을 말하지 않는다"로 둔다(규칙서 3.3).
2. **본문 문장을 그대로 옮기지 않는다.** 개역한글·개역개정의 문장을 베끼지 않고 자기 말로 풀어 쓴다(규칙서 7절). 검사기가 16글자 이상 같으면 경고한다. 경고가 나오면 고쳐 쓴다.
3. **하나님의 말씀은 간접으로만 적는다.** "하나님은 ~하겠다고 하셨어요"처럼 쓰고 따옴표 대사로 만들지 않는다. 실제 말씀은 아이가 성경책에서 읽는다. 하나님의 말씀이 나오는 대목에는 `open`에 그 장절을 적는다.
4. **세 단계의 사실은 같다.** t1(8~10세)·t2(11~13세)·t3(14~19세)는 깊이와 말투만 다르다. t1에만 있거나 t3에만 있는 사실은 괜찮지만 서로 어긋나면 안 된다.
   - t1: 1~3문장, "~했어요". t2: 2~4문장, "~했어요". t3: "~했다", 본문의 세부를 더 담는다.
5. **세 아이(최온 choeon, 휴 hyu, 온우 onwoo)는 목격자다.** `say`는 아이들끼리의 말이다. 성경 인물에게 말을 걸지 않고, 사건에 끼어들지 않고, 본문에 없는 사실을 말하지 않는다. 최온은 본 것을 말하고, 휴는 순서와 장소를 적고, 온우는 성경책에서 확인하자고 한다.
6. **쓰지 않는 표현**: 틀렸, 실패, 감점, 목숨(규칙서 4.2). 신앙을 점수로 매기는 말도 쓰지 않는다.
7. **심판과 죽음이 나오는 장면**은 본문이 말하는 만큼만, 자극적인 묘사 없이 적는다. 8~10세 문장은 특히 짧고 담담하게.
8. **신약과의 연결, "왜 하나님은 ~하셨을까"의 해석, 삶의 적용 물음은 넣지 않는다**(규칙서 3.5, 감수 전). t3의 "왜" 물음은 본문이 까닭을 직접 말하는 경우에만 묻고, 맞는 보기는 "성경이 말하는 만큼"이어야 한다. 적용은 `close`에만 둔다.
9. 인명과 지명은 개역한글·개역개정에 공통으로 쓰이는 표기를 따른다(예: 애굽, 바로, 여호수아).

## 3. 형식

```
{
  "id": "OT-05", "era": 2, "title": "…", "ref": "창 12:1-9",      // 범위가 둘 이상이면 첫 범위. 표기는 "책약어 장:절-절" 또는 "책약어 장:절-장:절"
  "place": "…",                                                  // 본문에 나오는 지명만. 없으면 "성경은 장소를 말하지 않는다"가 아니라 본문의 표현을 쓴다
  "review": { "required": true|false, "topics": ["…"], "status": "미감수" },   // 장면표의 "감수 필수"와 같게. topics는 규칙서 3.5의 주제
  "sources": "없음(성경 본문만 사용)",
  "beats": [                                                     // 5~7개(4~8 허용). 본문의 순서대로
    { "ref": "창 12:1", "open": "창 12:1", "focus": "abram",
      "text": { "t1": "…", "t2": "…", "t3": "…" },
      "say": { "who": "choeon|hyu|onwoo", "text": "…" } }
  ],
  "gates": {                                                     // 다음으로 가는 관문. 단계마다 물음 2개
    "t1": [ choice 또는 find ],                                   // 누가·어디서·무엇을
    "t2": [ order, choice(빈칸·인물 연결), find ],                // 사건 순서, 빈칸, 인물 연결
    "t3": [ findref, choice ]                                    // 스스로 본문 찾기, 본문이 말하는 까닭
  },
  "cards": [ { "ref": "창 12:2", "title": "…" } ],               // 말씀 카드 1~2개. 제목은 짧게, 본문의 표현으로
  "close": {
    "t1": { "kind": "prayer", "text": "한 문장 기도. …예수님의 이름으로 기도합니다. 아멘." },
    "t2": { "kind": "practice", "text": "이번 주에 ○○ ○장 ○절부터 ○절까지 소리 내어 읽어 보세요." },
    "t3": { "kind": "note", "prompt": "○○에서 새로 알게 된 사실을 한 가지 적어 보자." }
  },
  "design3d": {                                                  // 3D로 만들 사람이 읽는 설계. 모든 항목에 본문 근거 장절을 괄호로 붙인다
    "build": true|false,                                         // 장면표의 3D 표시와 같게
    "place": "…", "terrain": "…",
    "people": ["본문에 나오는 인물만 (장절)"], "props": ["본문에 나오는 물건·동물만 (장절)"],
    "god": "이 장면에서 하나님을 어떻게 나타내는지: 불·구름·빛·말씀 자막 가운데 본문에 있는 것만. 형상 없음",
    "epic": { "yes": true|false, "why": "압도 장면으로 만들 근거 장절" },
    "never": ["그리면 안 되는 것: 본문에 없는 행동, 하나님·천사의 형상, 잔인한 묘사 등"]
  },
  "quests": [ … 3개 … ]                                          // design3d.build가 true인 장면만. 아래 5절
}
```

### 물음의 네 가지 유형
- `choice`: `{ "type": "choice", "prompt": "…", "ref": "창 12:4", "options": [ { "label": "…", "ok": true }, { "label": "…", "basis": "본문에 없음" }, { "label": "…", "basis": "창 11:31" } ] }`
  보기 3개(많아야 4개), 맞는 보기는 정확히 1개. **맞지 않는 보기마다 `basis`**: 본문 어디에도 없는 내용이면 "본문에 없음", 성경의 다른 곳에 실제로 나오는 내용이면 그 장절. 맞지 않는 보기는 그럴듯하되 본문을 읽으면 분명히 가려지는 것으로 만든다. 본문 문장과 거의 같은 보기는 쓰지 않는다.
- `find`: `{ "type": "find", "ref": "창 12:7", "prompt": "성경책에서 창세기 12장 7절을 찾아 읽어 보세요.", "confirm": { "prompt": "…", "options": [ … ] } }`
  여러 곳을 함께 읽게 할 때는 `ref` 대신 `"refs": ["출 12:13", "출 12:23"]`(두 곳 이상). 14~19세에 쓴다(규칙서 13.5).
- `order`: `{ "type": "order", "prompt": "…순서대로 눌러 보세요.", "ref": "창 12:1-7", "items": ["…", "…", "…"] }` 항목 3~6개를 **본문 순서대로** 적는다(게임이 섞어서 보여 준다).
- `findref`: `{ "type": "findref", "prompt": "…이 적힌 절을 창세기 12장에서 찾아 장과 절을 적어 보자.", "book": "창세기", "accept": ["12:4"], "hint": "…" }` 답이 될 수 있는 절을 `accept`에 모두 적는다. 물음만 읽고 절을 하나로 좁힐 수 있어야 한다.

## 4. 감수와 기록
- 장면표에서 "감수 필수: 예"인 장면은 `review.required: true`와 해당 주제를 적는다. 그 주제를 풀이하는 문장은 쓰지 않고 본문의 사실만 적는다.
- 모든 장면의 `review.status`는 "미감수"다.

## 5. 부품 찾기 물음 (`design3d.build`가 true인 장면만)
탐험대 이야기: 타임머신에서 떨어진 부품 3개를 장면 안에서 찾아야 떠날 수 있다(성경 내용이 아니다). 부품마다 성경 물음을 풀면 탐지기가 다음 찾을 곳을 가리킨다.
```
{ "part": "영문 소문자 이름", "name": "부품 이름(톱니바퀴, 나침반 바늘, 나사, 렌즈, 안테나, 손잡이, 전구, 용수철, 건전지 등)",
  "line": "부품을 찾았을 때 하는 말(탐험대 이야기)", "found": "탐지기가 ○○ 쪽을 가리켜요.",   // ○○은 본문에 나오는 장소·물건
  "say": { "who": "…", "text": "…" },
  "q": { "t1": choice, "t2": choice 또는 order, "t3": findref 또는 choice } }
```
- 세 물음은 본문의 앞→뒤 순서로, 아이를 장면의 볼거리 쪽으로 이끈다. 부품이 놓인 곳은 사건의 자리에서 떨어진 곳이어야 한다(아이는 사건에 끼어들지 않는다).
- `findref`에는 본보기처럼 `after`(찾은 뒤 확인해 주는 한 문장)를 붙일 수 있다.

## 6. 끝내기 전에
`node tools/validate_ot.js OT-NN`이 오류 0이어야 한다. 경고(본문과 같은 문장, 8~10세 문장 수)는 고친다. 고칠 수 없는 경고는 까닭을 보고에 적는다.

## 7. 한 겹 더: 임무 (`mission`) — 규칙서 13절 (대표 결정 2026-11-15)

**이 절은 "임무(mission)를 쓰라"는 지시를 받은 작업자만 따른다. 장면 자료를 처음 쓰는 작성자와 그 검증자는 `mission`을 쓰지 않는다.**

대목·관문이 검증된 장면에 덧붙인다. 탐험대 이야기(비상 착륙, 최현 박사의 통신, 수리 재료)와 그 시대 사람과의 동행, 오늘의 물음이다. **먼저 `docs/00_공통규칙서.md` 13절을 읽는다.**

```
"mission": {
  "call": { "t1": "…", "t2": "…", "t3": "…" },          // 최현 박사의 통신(탐험대 이야기). 이 장면에서 무엇이 필요한지 1~3문장. 성경 사실을 새로 말하지 않는다
  "materials": [                                        // 3D 장면(design3d.build true)은 3개, 그 밖의 장면은 1개
    { "key": "horn", "name": "양의 뿔 조각", "basis": "출 3:1",     // basis: 그 물건(또는 그것이 나온 것)이 본문에 나오는 장절
      "use": "어느 부속을 대신하는지(탐험대 이야기)", "how": "아이들이 어떻게 얻는지. 떨어진 것을 줍는 등. 사건의 자리와 물건에는 손대지 않는다" }
  ],
  "companion": null 또는 {
    "who": "예레미야", "ref": "렘 7:1-2",                // 이 인물이 이 장면의 때와 곳에 있다는 근거 장절
    "talks": [                                          // 2~3개. 사건의 앞이나 뒤에 나누는 문답
      { "ask": { "who": "choeon|hyu|onwoo", "text": "아이의 물음(탐험대 이야기)" },
        "answer": { "t1": "…", "t2": "…", "t3": "…" },  // 그 인물이 본문에서 실제로 한 말을 풀어 쓴 간접 서술. "예레미야는 ~라고 전했어요."
        "ref": "렘 7:3-7", "open": "렘 7:3" }           // ref: 그 말이 적힌 절(그 인물이 말하는 절이어야 한다). open: 아이가 성경책에서 펼 절
    ]
  },
  "today": [                                            // 오늘의 물음 1~2개. 최현 박사가 답한다. 모두 감수 필수
    { "q": "지금 시대의 아이가 물을 만한 물음", "a": { "t1": "…", "t2": "…", "t3": "…" }, "refs": ["렘 29:11"] }
  ]
}
```

- **재료**: 본문에 나오는 평범한 것만. 기적이나 거룩한 것에 속한 것(불붙은 떨기나무, 만나, 언약궤와 성막·성전의 기구, 제물, 바다에 잠긴 병거, 무너진 여리고의 물건(수 6:18) 등)은 쓰지 않는다. 3D 장면은 `quests`의 부품 3개와 차례를 맞추고(재료 i가 부품 i를 대신한다), `quests[i].found`가 가리키는 곳에서 얻을 수 있는 것으로 한다.
- **동행 인물의 답**: 그 인물이 **그 본문에서 실제로 말한 것만** 쓴다(선지자는 그가 전한 말씀, "하나님이 ~라고 말씀하셨다고 전했어요"). 말한 사람이 그 인물인지 본문에서 확인한다. 본문에 없는 설명·속마음·요약을 그 인물의 말로 만들지 않는다. 아이의 물음에 꼭 맞는 기록된 말이 없으면 그 물음을 바꾼다. 장면에 말한 사람이 없으면 `companion`은 null.
- **오늘의 물음**: 답은 성경 장절이 말하는 만큼만. 장절은 그 책·그 시대에 가까운 구약 본문을 먼저 쓴다. 신약과의 연결은 넣지 않는다(감수 전). "성경은 여기까지 말한다"로 끝낼 수 있다. 7인의 글은 원문을 확인하지 못했으므로 인용하지 않는다.
- 나이 단계: t1은 1~3문장 "~해요", t2는 2~4문장, t3은 "~다". 사실은 세 단계가 같다.
- `node tools/validate_ot.js --mission OT-NN`으로 검사한다.

### 7.1 덧붙인 항목 (2026-11-15, 게임에 연결하며 더함)

- `materials[i].line`: 재료를 얻었을 때 아이(플레이어가 고른 아이)가 하는 말 한 문장(탐험대 이야기). 어디서 얻었는지 말한다. 3D 장면은 `quests[i].found`가 가리키는 곳과 같게 한다. 게임은 3D 장면에서 `quests[i].name`·`quests[i].line`(부품) 대신 `materials[i].name`·`materials[i].line`을 보여 준다.
- `materials[i].use`는 최현 박사가 통신으로 하는 말로 보여 준다. "~를 ~ 대신 쓸 수 있어요"처럼 한 문장으로 쓴다(탐험대 이야기).
- `companion.when`: `"before"` 또는 `"after"`. 문답을 사건(대목)의 앞에 둘지 뒤에 둘지. 그 인물의 말이 본문에서 사건보다 앞에 나오면 `before`, 사건 중이나 뒤에 나오면 `after`. 아이가 사건 전에 아직 일어나지 않은 일을 듣는 일이 없게 한다.
- 게임의 차례: 도착과 `call` → (`when: before`면 동행 문답) → 대목 → 관문 → (`when: after`면 동행 문답. 관문의 답을 미리 알려 주지 않게 관문 뒤에 둔다) → 재료를 얻음(3D가 아직 없는 3D 장면은 `quests`의 물음 3개를 풀며 재료 3개를 얻는다) → `today` → 말씀 카드 → 마무리.

### 7.2 물음의 세 단계와 현장 돕기 (대표 결정 2026-11-15, 규칙서 13.5·13.6. 유월절 OT-10이 본보기)

**물음(관문 `gates`, 탐지기 `quests[i].q`)** — 모두 `find`로 읽을 곳을 먼저 보여 주고, 찾아 읽은 뒤 `confirm`으로 묻는다.
- t1(8~10세): `ref`에 한 절. 그 절에 바로 나오는 사실(누가, 어디서, 어디로, 무엇을)을 묻는다. 예: 출 12:7 → 피를 어디에 바르라고 하셨나.
- t2(11~13세): `ref`에 범위(몇 절~몇 절). 읽은 뒤 답하는 "왜" 물음. 답의 까닭이 그 범위 안에 적혀 있어야 한다. 예: 출 12:21-23 → 아침까지 문밖에 나가지 말라고 한 까닭.
- t3(14~19세): `refs`에 떨어진 두 곳 이상. 한 곳만 읽어서는 답할 수 없고, 이어 읽어야 정황이 보이는 물음. 예: 출 11:7 + 12:23 → 이스라엘 집이 달랐던 까닭.
- 세 단계의 사실은 같다. 맞지 않는 보기의 `basis` 규칙은 3절 그대로다.

**현장 돕기 `mission.help`** — `{ "who": "이스라엘 자손의 한 집", "steps": [ … ] }`, 단계 2~8개. 각 단계:
- 공통: `kind`, `after`(이 대목 번호 뒤에 나옴. **첫 대목이 0**. 뜻을 묻는 단계는 `"gates"` — 관문과 사건 뒤 동행 문답 다음), `title`, `basis`(장절). 단계는 본문의 차례대로 놓는다.
- `do`: 본문에 그 사람들이 했다고 적힌 **평범한 일**을 돕는다. `text`(t1~t3), `tasks`(누르는 일 2~4개), `done`(다 누른 뒤 아이의 말 `{who, text}`).
- `watch`: 본문이 행위자를 정한 거룩한 행위(피를 바름, 제사 등)를 **곁에서 본다**. `text`, `say`(선택).
- `stay`: 함께 머물거나 기다린다. `text`, `wait`(버튼 글), `say`(선택).
- `ask`: 아이가 그 일의 뜻을 묻는다(`ask`). `answer`(t1~t3)는 본문이 그 사람들에게 하라고 한 말의 간접 서술, `by`(답하는 사람). `read`(t1~t3 물음, 위의 세 단계 규칙)로 성경을 펴서 뜻을 확인한다. `nt`(선택): 신약 연결 `{ref, text}` — 14~19세에만 보이고 "감수 전"으로 표시된다.
- 하지 않는 것: 아이가 거룩한 행위나 기적을 대신함, 사건의 결과를 바꿈, 본문에 없는 사건을 만듦, 돕는 사람에게 본문에 없는 말을 시킴.

### 7.3 놀이의 다양함·돕기 넓힘·8~10세의 글 (대표 결정 2026-11-16, 규칙서 13.7·13.8. 유월절 OT-10이 본보기)

**관문의 둘째 물음 `gates.tN[1]`**(첫째 물음은 find 그대로):
- t1 `multi`(여러 개 고르기): `{ "type": "multi", "ref": "출 12:8", "prompt": "성경책에서 출애굽기 12장 8절을 찾아 읽어 보세요.", "confirm": { "prompt": "…모두 고르세요.", "options": [ … ] } }` — 보기 4~5개, 맞는 보기 2개 이상(전부는 아니게). 맞는 보기는 모두 **그 한 절에 바로** 있어야 한다. 맞지 않는 보기의 basis 규칙은 3절 그대로.
- t2 `order`(순서 맞추기): `{ "type": "order", "ref": "출 12:29-34", "prompt": "성경책에서 … 읽고, 일어난 차례대로 눌러 보세요.", "items": [ … ] }` — 항목 3~5개를 **본문 순서대로** 적는다(게임이 섞는다). 모두 그 범위 안의 일이다.
- t3 `match`(잇기): `{ "type": "match", "refs": ["출 11:7", "출 12:28", "출 12:31"], "prompt": "… 찾아 읽고, 구절마다 맞는 내용을 이어 보자.", "pairs": [ { "ref": "출 11:7", "text": "…" }, … ], "after": "세 곳을 이으면 …" }` — 떨어진 2~4곳, 구절마다 내용 하나. 내용은 그 구절에만 있고 다른 구절과 헷갈리지 않게. `after`는 이어 읽은 정황 한 문장(본문이 말하는 만큼).
- 맞지 않는 보기를 고르면, basis가 장절이면 "타임머신 바늘이 엇나갔어요"(그 절로) 안내가 나온다. 그럴듯하되 다른 곳에 실제로 있는 보기를 하나쯤 두면 좋다(basis는 정확하게).

**8~10세 대목 글 `beats[i].text.t1`**: **1~2문장**. 그 대목의 핵심 사실만, 쉬운 말로. t2·t3과 사실이 어긋나지 않게(덜 말하는 것은 괜찮다).

**돕기 `mission.help`**: 장면마다 `do`가 **하나 이상**(규칙서 13.7).
- 13.6의 일(본문에 그 무리가 했다고 적힌 평범한 일)이 있으면 그것을.
- 없으면 **사건 곁의 평범한 준비·뒷일**: 그 자리의 이름 없는 사람들(무리, 한 집의 식구)을 돕는 일상의 일(물 긷기, 짐 나르기, 자리 정리, 길 비켜 주기 등). 이것은 성경 사건이 아니므로 `text`에 "탐험대 이야기"임이 드러나게 쓰고(예: "우리는 … 곁에서 …을 도왔어요"), `basis`는 그 사람들이 그 자리에 있었다는 절.
- 하지 않는 것: 거룩한 행위·기적·싸움·죄를 돕기, 이름 있는 성경 인물에게 본문에 없는 행동·말을 시키기, 결과를 바꾸기, 사건의 자리·거룩한 물건에 손대기.
- 검사: `node tools/validate_ot.js --v3 OT-NN` 오류 0, 경고 0.
