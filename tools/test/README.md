# 자동 점검 스크립트

휴대폰 크기 화면에서 게임을 처음부터 끝까지 조작하고 화면을 찍는다. Playwright와 Chromium이 필요하다.

- `walk2d.js <단계 0~2> <고를 이름> <저장 폴더>`: 2D 시범판 (`web/index.html`)
- `walk3d.js <단계 0~2> <저장 폴더> [화면 배율]`: 3D 호렙 산 전체 흐름 (`dist/preview3d.html`). 탐지기 물음 → 부품 3개 → 올려다보기 → (영상이 있으면 압도 장면) → 지켜보기 → 관문 → 타임머신 출발. 물음마다 먼저 다른 보기를 눌러 안내 문구도 확인한다
- `walkJ.js <단계 0~2> <저장 폴더> [화면 배율]`: 3D 요단 강 시대 추리
- `walkOT.js <단계 0~2> <저장 폴더> [첫 장면 번호] [마지막 장면 번호]`: 구약 40장면 이야기 카드 흐름(비상 착륙 → 시대 지도 → 장면 → 대목 → 관문 → 재료 → 오늘의 물음 → 마침 표시)
- `walk3dScene.js <OT-NN> <단계 0~2> <저장 폴더>`: 3D 장면 틀로 만든 장면 하나의 전체 흐름(탐험 → 재료 3개 → 올려다보기 → 지켜보기 → 관문 → 타임머신 → 시대 지도 마침 표시). 호렙 산(OT-09)은 `walk3d.js`로
- `view_person.js <이름> <저장 png> [동작]`: 인물 GLB를 네 방향에서 찍는다(인물 제작 라인 확인용)

3D 점검 전에 `node tools/build3d.js`로 미리보기 페이지를 다시 만든다. 스크립트 안의 주소는 `/home/user/bible_onyou` 기준이므로 다른 위치에서는 고쳐 쓴다.
