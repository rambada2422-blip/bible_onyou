## 지킨 것

세로 그림, 맑은 낮, 초록 잎, 가시, 연기와 재 없음, 머리쓰개를 쓴 모세의 완전한 뒷모습, 오른손 지팡이, 모세 얼굴 안 보임. 하나님·천사 형상, 하늘의 빛줄기, 후광, 다른 사람, 짐승, 신상, 폭력은 6장 어디에도 없다. E-1 시안에서 문제였던 날개 모양 불꽃과 귀·뺨 노출이 없다.

## 쓰지 않는 까닭

1. 불이 너무 작고 멀다. 덤불이 화면의 작은 부분이고 불꽃은 잎 사이로 비치는 정도다. 지시서 3.1의 1번 '아이들의 눈을 붙잡을 만큼'에 못 미친다. 제작 기록을 보면 요청문의 여백 규칙(좌우 6분의 1, 아래 8분의 1)과 '모세를 화면 앞에 크게 두지 않는다'를 맞추려고 카메라를 멀리 빼고 전체를 줄였다. 요청문이 그렇게 몰고 갔다.
2. 그림 3 (A, B 둘 다): 얼굴을 가리는 자세가 아니라 이마에 손을 얹고 멀리 내다보는 자세로 읽힌다 (출 3:6과 다르게 읽힌다).
3. 언덕 아래에서 올려다본 구도가 아니다.
4. 떨기나무가 모세보다 뒤에 있어 실제로는 사람 키만 하거나 더 커 보인다.
5. 누런 잎과 잎 테두리의 금빛 선이 남아 있다 (B가 더 많다).
