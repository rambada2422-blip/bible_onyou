## 3. 대표의 기대와 결정

### 3.1 대표가 말한 기대 (2026-11-13)

이전 세션의 결과물은 아래 기대에 못 미친다. 본 제작은 이 네 가지를 채워야 한다.

1. **불타는 떨기나무**: 아이들의 눈을 붙잡을 만큼 입체감 있고 황홀하게. 지금은 납작한 불꽃 여러 겹과 불티, 빛 번짐 수준이다.
2. **양 떼**: 모세가 이끄는 양 떼의 수가 훨씬 많아야 한다. 지금은 7마리다.
3. **부품 찾기**: 탐지기만 보고 찾는 것이 아니라 간단한 성경 퀴즈를 풀면서 찾는다.
4. **장면 연출 예시**: 부품(예: 나사)이 불타는 떨기나무가 보이는 곳 근처의 언덕 아래에 있다. 그것을 줍고 나면, 그 위쪽에서 모세가 불타는 떨기나무 앞에 서 있는 장면을 올려다보게 된다. 지금보다 실감 나게 묘사한다.

대표가 3.1의 네 가지를 맞다고 확인했다 (2026-11-13).

5. **대비의 원칙 (2026-11-13 추가)**: 평소 화면은 지금의 인형풍 그대로 둔다. 아이들이 "이 정도 그래픽이구나" 하고 익숙해질 때쯤, 성경의 압도적인 장면(하나님의 음성이 임하는 장면 등)에서만 어른의 눈으로 봐도 압도당하는, 경이롭고 황홀한 묘사를 쓴다. 사실적인 묘사는 이 장면들에만 넣는다. 자세한 것은 6절.

4번은 지형과 동선을 바꾸는 일이다. 떨기나무를 언덕 위에 두고, 아이들이 아래에서 올려다보는 자리를 만든다. 세 아이는 끝까지 목격자이고, 하나님의 말씀은 지어내지 않는다(규칙서 3.3).

### 4.7 검증하는 방법

- **자동 점검**: `tools/test/`의 스크립트가 휴대폰 크기 화면에서 처음부터 끝까지 조작하고 화면을 찍는다. 먼저 `node tools/build3d.js`로 묶은 뒤 실행한다. 찍은 화면은 반드시 직접 열어 본다.
  - `node tools/test/walk3d.js <단계 0~2> <화면 저장 폴더>`: 호렙 산 전체 흐름
  - `node tools/test/walkJ.js <단계 0~2> <화면 저장 폴더>`: 요단 강 시대 추리
- **본문 대조**: 대본, 퀴즈, 장면 배치를 새로 쓰면 작성 과정을 보지 않은 별도 에이전트에게 성경 본문과 대조하게 한다. 이전 세션에서 세 차례 했고 매번 고칠 곳이 나왔다.
- **실제 휴대폰**: 이전 세션은 한 번도 확인하지 못했다. 대표에게 링크를 열어 달라고 요청한다.

## 5. 이전 세션에서 배운 것

- 이 작업 환경에서 Blender는 `uv venv --python 3.13 venv && VIRTUAL_ENV=venv uv pip install bpy`로 설치해 화면 없이 쓸 수 있다.
- 3D 자료를 주는 외부 사이트 대부분과 성경 원문 사이트는 접속이 막혀 있다. 개역개정 원문 대조는 하지 못했다.
- 미리보기 페이지(`dist/preview3d.html`)에는 three.js를 함께 넣는다. 외부 주소를 이 환경에서 확인할 수 없어서다.
- 화면 없는 환경의 3D 점검은 느리다. 한 번에 5~10분이 걸린다.
- bpy 모듈에서 Cycles를 쓰려면 먼저 `addon_utils.enable('cycles')`를 불러야 한다. AgX 색 처리와 OIDN 잡음 제거는 된다.
- **유체 계산(Mantaflow)은 이 환경에서 쓸 수 없다** (2026-11-13 확인): bpy 5.3과 4.5 파이썬 모듈은 `LevelsetGrid.setConst` 오류로, Ubuntu의 Blender 4.0.2는 `PyImport_AppendInittab` 오류로 멈춘다. 불꽃은 잡음 무늬로 만든 절차적 부피(`bush_vision.py`)로 대신한다. 같은 방법을 다시 시도하지 않는다.
- Blender 점광원은 1m 거리에서도 매우 밝다(1000W가 햇빛의 수십 배). 불빛은 100W대로 둔다. 노출을 낮추면 하늘이 밤처럼 보이니 하늘 밝기를 따로 올린다(6.5: 시간이 바뀐 것처럼 그리지 않음).
- 사실적 장면을 매 프레임 통째로 그리면 540×960 한 장에 약 3분이라 30초 영상에 40시간쯤 걸린다(추정). 그래서 배경은 장면마다 한 번, 불과 모세만 매 프레임 그려 합친다(`vision_video.py`).
- 검증에서 반복해 나온 실수: 본문에 없는 인물의 행동을 그리는 것(신을 벗는 모세, 팔을 뻗는 여호수아), 본문 문장을 거의 그대로 옮기는 것, 장절이 내용을 실제로 담고 있지 않은 것, 장면의 방향과 거리.

## 6. 압도 장면

### 6.1 원칙

- 평소 화면은 인형풍이다. 사실적이고 압도적인 묘사는 성경의 압도적인 장면에만 쓴다. 평소와의 차이가 클수록 그 장면이 크게 느껴진다.
- 압도 장면을 만들기 시작하기 전에, 그 장면이 어떤 모습일지 글로 설명하고 대표의 승인을 받는다. 비용이 드는 경우 금액도 함께 확인받는다.
- 압도 장면도 신학 규칙을 그대로 지킨다. 압도하는 것은 불과 빛, 소리와 정적, 크기와 카메라이지, 하나님의 형상이나 지어낸 말씀이 아니다.

### 6.2 하나님의 음성 장면에서 지킬 것 (대표 동의 2026-11-13, 목회자 확인 필요)

- 하나님을 어떤 형상으로도 그리지 않는다. 불, 구름, 빛만 그린다. 불꽃이나 빛 속에 얼굴이나 사람처럼 보이는 모양이 한 장면이라도 생기면 쓰지 않는다. 영상은 모든 장면을 사람이 눈으로 확인한다.
- 하나님의 음성을 소리로 만들지 않는다. 성우의 목소리도, 꾸민 울림 소리도 쓰지 않는다.
- 말씀은 지어내지 않는다. 화면에는 "하나님이 떨기나무 가운데서 모세를 부르셨다"처럼 간접으로 적고 장절을 붙여, 아이가 성경책에서 직접 읽게 한다.
- 음성이 임하는 순간에는 바람과 불 소리를 포함한 모든 소리를 멎게 하고, 정적 속에서 빛만 남긴다. 그 뒤에 낮고 조용한 음악을 넣는다.
- 본문에 없는 일(하늘이 갑자기 어두워짐, 땅이 흔들림, 번개 등)을 사건처럼 넣지 않는다.

### 6.4 만드는 방법 후보

| 방법 | 내용 | 비용 | 상태 |
|---|---|---|---|
| Blender로 미리 그린 영상 | 이 작업 환경의 Blender로 사실적인 불과 빛을 계산해 짧은 영상으로 만들고, 그 순간에 게임에서 재생한다 | 없음. 계산 시간만 든다 | 미검증. 한 장면으로 시험한다 |
| 영상 생성 도구 | 글과 그림으로 영상을 만들어 내는 유료 도구를 쓴다 | 유료. 금액 확인 필요 | 미검증. 결과에 원하지 않은 형상이 섞일 수 있어 모든 장면 확인이 필요하다 |
| 3D 모델 생성 도구와 실시간 효과 | 사실적인 나무와 지형 모델을 만들어 게임 안에서 직접 보여 준다 | 유료. 금액 확인 필요 | 미검증. 휴대폰 성능의 제약을 받는다 |

미리 그린 영상은 휴대폰 성능과 무관하게 같은 품질로 보이고, 한 장면 한 장면을 확인할 수 있어 6.2를 지키기 쉽다. 첫 시험은 이 방법으로 한다.

### 6.5 첫 압도 장면 설명: 불붙은 떨기나무 (대표 승인 2026-11-13)

| 순서 | 화면 | 소리 |
|---|---|---|
| 1. 직전 | 인형풍 세계 그대로다. 아이들이 언덕 아래에서 부품을 줍는다. 위쪽 언덕에 불빛이 어른거린다 | 바람, 양 떼 소리 |
| 2. 올려다봄 | 카메라가 아이들 어깨 너머에서 천천히 위로 올라간다. 아이들은 화면 아래에 작게, 인형풍 그대로 남는다 | 바람이 잦아든다 |
| 3. 바뀜 | 화면이 미리 그린 사실적인 영상으로 넘어간다. 실제 같은 가시 관목이 실제 같은 불에 휩싸여 있다. 잎은 시들지도 검게 변하지도 않고, 연기와 재가 없다. 불티가 위로 솟고 열기로 공기가 일렁인다. 불빛이 바위와 모래를 물들인다 | 불 타는 소리가 커진다 |
| 4. 모세 | 모세가 불 앞에 선 뒷모습이 불빛에 어둡게 떠오른다. 얼굴은 보이지 않는다 | |
| 5. 부르심 | 화면 아래에 "하나님이 떨기나무 가운데서 모세를 부르셨다 (출 3:4)"가 뜬다. 불은 계속 타고 나무는 그대로다 | 모든 소리가 멎는다 |
| 6. 얼굴을 가림 | 모세가 얼굴을 가린다 (출 3:6). 신을 벗는 모습과 무릎 꿇는 모습은 넣지 않는다 | 낮고 조용한 음악이 시작된다 |
| 7. 돌아옴 | 화면이 다시 인형풍 세계로 돌아오고, 아이들에게 "성경책에서 직접 읽어 보세요" 안내가 나온다 | 음악이 이어진다 |

- 길이는 20~40초로 잡는다. 처음에는 끝까지 보고, 다시 볼 때는 건너뛸 수 있다.
- 영상 속 모세는 뒷모습과 윤곽만 나오므로 인형풍 모세와 생김새가 어긋나 보이지 않는다.
- 3번에서 주변이 어두워 보이는 것은 불이 밝아서 생기는 카메라 효과로만 표현하고, 날씨나 시간이 바뀐 것처럼 그리지 않는다.

## 7. 하지 말 것

- 감수 전 장면(장면목록에서 감수 필수인 10개)을 아이들에게 공개하지 않는다.
- 결제가 필요한 것을 대표 확인 없이 진행하지 않는다.
- 성경 본문을 게임에 싣지 않는다. 개역개정 사용 허락을 아직 받지 않았다.
- 한 번에 여러 장면을 만들지 않는다. 한 장면을 끝내 확인받고 넓힌다.
