## 3. 대표의 기대와 결정

### 3.1 대표가 말한 기대 (2026-11-13)

이전 세션의 결과물은 아래 기대에 못 미친다. 본 제작은 이 네 가지를 채워야 한다.

1. **불타는 떨기나무**: 아이들의 눈을 붙잡을 만큼 입체감 있고 황홀하게. 지금은 납작한 불꽃 여러 겹과 불티, 빛 번짐 수준이다.
2. **양 떼**: 모세가 이끄는 양 떼의 수가 훨씬 많아야 한다. 지금은 7마리다.
3. **부품 찾기**: 탐지기만 보고 찾는 것이 아니라 간단한 성경 퀴즈를 풀면서 찾는다.
4. **장면 연출 예시**: 부품(예: 나사)이 불타는 떨기나무가 보이는 곳 근처의 언덕 아래에 있다. 그것을 줍고 나면, 그 위쪽에서 모세가 불타는 떨기나무 앞에 서 있는 장면을 올려다보게 된다. 지금보다 실감 나게 묘사한다.

4번은 지형과 동선을 바꾸는 일이다. 떨기나무를 언덕 위에 두고, 아이들이 아래에서 올려다보는 자리를 만든다. 세 아이는 끝까지 목격자이고, 하나님의 말씀은 지어내지 않는다(규칙서 3.3).

### 3.3 대표가 아직 정하지 않은 것

| 항목 | 내용 | 권고 |
|---|---|---|
| 그래픽의 한계 | 대표는 "사실적인 3D"를 원했다. 코드와 Blender 스크립트만으로는 인형풍까지가 한계다 | 3D 모델 생성 도구를 모델 하나로 시험해 보고 결제 여부를 정한다 |
| 소리 | 지금은 합성음뿐이다 | 배경음악과 효과음 음원을 구하는 방법을 정한다 |
| 감수 | 목회자 감수를 아직 받지 못했다 | 감수 전에는 아이들에게 공개하지 않는다 |
| 아이 테스트 | 실제 아이들에게 시켜 본 적이 없다 | 본 제작을 크게 벌이기 전에 한다 |
| 세 주인공의 성격 | 제안만 있고 확정되지 않았다 (규칙서 11절) | |
| 회원가입과 서버 | 설계하지 않았다 | 장면이 늘어난 뒤에 한다 |

## 4. 다음 세션의 작업 순서

| 순서 | 작업 | 완료 기준 |
|---|---|---|
| 1 | 떨기나무 장면의 지형과 동선을 3.1의 4번대로 바꾼다 | 언덕 아래에서 올려다보는 구도가 휴대폰 화면에서 확인된다 |
| 2 | 떨기나무 효과를 끌어올린다 | 잎은 초록 그대로 보이고, 연기와 재는 없으며, 불꽃에 얼굴·사람 모양이 없다. 대표가 화면을 보고 승인한다 |

| 5 | 2D 그림 `alt02.svg`를 3D 설정에 맞게 다시 그린다 | 장면목록의 ALT-02 표와 일치한다 |
| 6 | 감수가 끝난 장면부터 3D로 늘린다 | 장면마다 독립 검증과 자동 점검을 통과한다 |

1~4번은 호렙 산 한 장면에서 끝낸 뒤 대표에게 보여 주고 다음으로 간다.

### 4.7 검증하는 방법

- **자동 점검**: `tools/test/`의 스크립트가 휴대폰 크기 화면에서 처음부터 끝까지 조작하고 화면을 찍는다. 먼저 `node tools/build3d.js`로 묶은 뒤 실행한다. 찍은 화면은 반드시 직접 열어 본다.
  - `node tools/test/walk3d.js <단계 0~2> <화면 저장 폴더>`: 호렙 산 전체 흐름
  - `node tools/test/walkJ.js <단계 0~2> <화면 저장 폴더>`: 요단 강 시대 추리
- **본문 대조**: 대본, 퀴즈, 장면 배치를 새로 쓰면 작성 과정을 보지 않은 별도 에이전트에게 성경 본문과 대조하게 한다. 이전 세션에서 세 차례 했고 매번 고칠 곳이 나왔다.
- **실제 휴대폰**: 이전 세션은 한 번도 확인하지 못했다. 대표에게 링크를 열어 달라고 요청한다.

## 5. 이전 세션에서 배운 것

- 이 작업 환경에서 Blender는 `uv venv --python 3.13 venv && VIRTUAL_ENV=venv uv pip install bpy`로 설치해 화면 없이 쓸 수 있다.
- 3D 자료를 주는 외부 사이트 대부분과 성경 원문 사이트는 접속이 막혀 있다. 개역개정 원문 대조는 하지 못했다.
- 미리보기 페이지(`dist/preview3d.html`)에는 three.js를 함께 넣는다. 외부 주소를 이 환경에서 확인할 수 없어서다.
- 화면 없는 환경의 3D 점검은 느리다. 한 번에 5~10분이 걸린다.
- 검증에서 반복해 나온 실수: 본문에 없는 인물의 행동을 그리는 것(신을 벗는 모세, 팔을 뻗는 여호수아), 본문 문장을 거의 그대로 옮기는 것, 장절이 내용을 실제로 담고 있지 않은 것, 장면의 방향과 거리.

## 6. 하지 말 것

- 감수 전 장면(장면목록에서 감수 필수인 10개)을 아이들에게 공개하지 않는다.
- 결제가 필요한 것을 대표 확인 없이 진행하지 않는다.
- 성경 본문을 게임에 싣지 않는다. 개역개정 사용 허락을 아직 받지 않았다.
- 한 번에 여러 장면을 만들지 않는다. 한 장면을 끝내 확인받고 넓힌다.
