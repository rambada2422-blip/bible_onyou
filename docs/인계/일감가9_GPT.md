일감 가-9를 맡았다. 화면이 끊기는 구간을 찾기 위해 호렙의 탐험 시작, 양 떼, 언덕, 압도 장면, 지켜보기를 같은 기기에서 측정한다.

최근 300개의 실제 화면 간격에서 평균과 최대를 구하는 `BO3D.debug.perf()`를 추가했다. 탭을 숨겼다가 돌아온 사이의 시간은 제외한다. 한 화면을 그릴 때 Three.js가 장면·그림자·빛 효과를 여러 번 그리므로 모두 합쳐 마지막 프레임의 그리기 횟수로 표시한다. `?perf=1`에서만 화면 아래에 숫자가 보인다.

`tools/test/walk3d.js`에서 다섯 구간마다 연속 12프레임을 측정하고 연령별 표와 `perf.json`을 남긴다. 기존 자동 진행과 바깥 검사 실행 경로를 그대로 둔다. 300개가 넘으면 오래된 최대값이 빠지는지, 최근 12프레임만 골랐을 때의 평균, 탭 복귀와 복수 그리기 합산을 별도로 확인했다. 실제 브라우저 화면과 전체 결과는 아래에 있다.
