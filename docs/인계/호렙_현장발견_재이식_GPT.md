# 호렙 현장 발견 기능 재이식

브랜치 `gpt/horeb-field-discovery-2` · 기준 `main`의 `7c9bc19` · 원본 `gpt/horeb-field-discovery`의 `1dda4e3` · 기능 이식 커밋 `9dee855`.

## 옮긴 기능

- 양 떼 곁에 굽이진 마른 물길과 자갈, 층이 진 사암 바위를 배치했다. 탐험자가 가까이 다가오면 양이 고개를 돌리고, 더 다가오면 조금 물러난다. 걸을 때는 발굽이 움직인다.
- 호렙 첫 물음에서 직접 찍은 사진을 다시 본다. 8~10세는 양을 사진에서 짚거나 보기에서 골라 답할 수 있다. 윗연령은 사진에서 찾은 뒤 양 떼의 주인을 고른다. 터치와 키보드를 지원하며, 이전 버전에서 저장한 사진에 양 좌표가 없어도 기존 보기로 풀 수 있다.
- `main`의 샤론 자기소개와 정답 뒤 ‘성경 표시 → 샤론의 안내 → 계속 탐험하기’ 순서를 보존했다. 첫 촬영에서 정답 이름을 미리 밝히지 않는 알림, 거리가 멀 때와 화면 가운데에 대상이 없을 때의 안내도 종전 문구를 쓴다.

## 모델 분할과 변경 파일

검수 도중 Gemini 가-12 분할(`ae02b08`)이 `main`에 병합됐다. 최종 브랜치는 분할을 포함한 최신 `main`의 `7c9bc19`에서 시작한다. 분할된 다섯 파일 중 호렙 기능으로 고친 것은 두 개다. `web3d/js/models-horeb-cast.js`에 양 모형과 움직임을 옮기고, `web3d/js/models.js`에는 `sheepWalk` 재질 한 줄을 반영했다.

| --- | --- |
| 지형과 양 떼 | `web3d/js/world.js`, `game-scene.js`, `models-horeb-cast.js`, `models.js` |

## 유월절 다섯 커밋의 위치

`gpt/night-mobile-play`와 `gpt/exodus-passover-preview`는 같은 `6194b8e`를 가리킨다. 두 브랜치 모두 아래 원본 다섯 커밋을 그대로 포함한다. 원격의 다른 GPT 브랜치 일곱 곳에서는 아래 대응 커밋을 모두 확인했다.

대응 커밋을 포함한 일곱 브랜치

- `gpt/exodus-field-notes`, `gpt/exodus-observation-journal`, `gpt/exodus-picture-choices`, `gpt/exodus-scripture-review`
- `gpt/film-delivery-qa`, `gpt/passover-roast-lamb`, `gpt/plague-films-01-04`

원격 브랜치별 커밋 포함 관계를 확인하고 `git range-diff`와 `git patch-id --stable`로 변경분을 대조했다. 네 쌍은 전체 패치가 일치한다. `3fe4125`의 Claude 작업 지시와 그 링크는 대응 브랜치에 앞선 커밋 `fc7f86c`로 이미 들어 있었다. 이 두 문서를 제외한 패치는 일치한다. `main`도 `7a65645`에서 `gpt/exodus-field-notes`를 병합해 대응 커밋 다섯 개를 모두 포함한다. 이번 호렙 브랜치는 이를 기준 커밋에서 물려받았고, 2D 게임의 파일 차이는 없다.

- `tools/test/full/horeb-field.js`로 390×844, 568×320, 320×568에서 세 연령의 첫 물음을 각각 끝까지 풀었다. 번들 미리보기와 개별 스크립트 진입점에서 실제 촬영, 빈 곳과 양 선택, 샤론 대화, 이어하기, 좌표가 없거나 잘못된 이전 저장의 보기를 확인했다. 320×568에서는 방향키와 Enter로 양을 찾았다.
