# 다윗 탐험 · 총괄 본문 검토 (Claude, 2026-11-23)

대상은 `antigravity/david-week` a897ea1의 `web/david/js/data.js`와 화면 문구(`app.js`, `index.html`)다. 작성 과정을 보지 않은 검증자가 개역개정 삼상 16·17·18·20·24장, 삼하 2·3·4·5·6·9·23장, 대상 29장과 대조했다. 사실 오류 셋은 총괄이 원문을 다시 열어 확인했다. 저장소 파일은 고치지 않았다.

## 결론

- 아직 합칠 수 없다. 아래 '꼭 고칠 것' 여덟 가지를 고친 뒤 목회자 감수에 넘긴다.
- D01과 D09는 문제 없다. 실패 표현, 하나님 형상, 아이가 사건을 바꾸는 조작은 없다.

## 고치면 좋은 것

- D03 "두 친구는 나중에 서로 인사하며 헤어졌어" → "서로 입 맞추고 함께 울며 헤어졌어" (삼상 20:41).
- D07 "친구 요나단을 기억하고" → "친구 요나단 때문에" (삼하 9:1, 7. 속마음을 단정하지 않음).
- 그림 설명
  - D07 '떡과 잔'에서 '잔'을 뺀다 (9장에 없음).
  - D03 '접어 건네는'을 뺀다.
  - D05 '왕관'은 기름 뿔로 바꾼다.
  - D06 '청색 천으로 덮인 궤'는 삼하 6장이 아니라 민 4:5–6에 근거한다. 그림의 근거를 적어 둔다.
- 첫 화면 '다윗의 일곱 관찰'은 장면이 아홉이므로 고치거나, D08·D09를 '더 보기'로 나눈다.
- 보충 hebron-elders의 fact 문장은 삼하 5:3과 어순과 어절이 비슷하다. 문장을 풀어 쓴다.

## 목회자 감수에 넣을 것

- D02: 아이를 삼상 17:45로 보낸다. 바로 뒤 46–51절에 골리앗을 죽이고 목을 벤 장면이 있다. 부모·교사가 함께 읽도록 안내하기를 권한다.
- D04: 사울이 다윗의 목숨을 노린 일, "원수를 네 손에 넘기리니"(삼상 24:4, 하나님의 주권).
- D06: 궤가 오벧에돔의 집에 머문 까닭이 바로 앞 웃사의 죽음이다(삼하 6:6–7).
- D08: 블레셋 진영을 뚫고 간 일, "목숨을 걸고 갔던 사람들의 피"(삼하 23:16–17).

## 규칙서와 부딪치는 것 (대표 판단)

- D03의 순서 놓기는 지시서가 요구했지만, 공통 규칙서 5절에서 '사건 순서'는 11~13세 유형이다.
- 공통 규칙서 8절의 필수 항목이 데이터와 인계에 없다: 장면별 나이 단계, 보기마다의 근거 장절, 감수 필수 여부, 감수 상태. 창세기 원고(`claude/genesis-week`)처럼 장면별 카드 정보를 문서로 남기기를 권한다.
