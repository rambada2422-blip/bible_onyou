# 창세기 본편 66회 편성 인계

기존 16개 시범 원고에서 건너뛴 사건을 확인하고, 창조부터 요셉의 죽음까지 이어지는 [집필용 회차표](../창세기/창세기_본편_회차표.md)를 작성했다. 대표가 제시한 최소 40편에 맞춰 구체적인 분량은 66편으로 제안했다. 이 커밋은 편성·배정 문서에 해당한다. 원고·실제 게임·독립 내용 검증·목회자 감수의 완성 수는 별도 관리한다.

- 변경 위치는 회차표, [클로드 작업 입구](../일감/claude-genesis.md), [놀이 작업표](../일감/창세기_연속제작.md), [창세기 인계](창세기_Claude.md)다. 동시에 올라온 C01~C03 진행 기록을 반영했다.
- 회차 번호가 01~66으로 이어지는지, 각 부의 수가 16·16·16·18인지, G01~G16이 관련 회차에 연결되는지 확인했다. 창세기의 장별 절 수와 대조해 1,533개의 장절 위치를 주 본문에 순서대로 한 번씩 배정했음을 확인했다. 이것은 범위 검사이며 장면의 본문 감수는 클로드와 감수자가 진행한다.
- 다음 집필자는 01회에서 G01을 대조해 둘째 날의 내용을 채우고 08회까지 쓴다. 공통규칙에 따라 문구와 장면 근거를 독립 검증한다. E번호 집필 상태와 C번호 놀이 진행은 따로 기록한다.
