## 어디까지 했는지

샤론 얼굴 PNG 네 장을 `BO3D.sharonData`로 묶어 3D 원본 페이지와 단일 HTML 미리보기에서 읽게 했다. 얼굴 파일이 없거나 읽히지 않아도 이름과 대사가 보인다.

승인 자료에서 동료 대사, 나이별 도입, 처음 목표, 물음 머리글, 부품 신호와 정답 뒤 안내를 읽는다. 물음 아홉 개는 첫 문장과 나머지로 나눠도 원래 글과 같다. 오답을 누르면 같은 물음에서 얼굴을 ‘다시 해 보자’로 바꾼다. 오답을 다시 눌러도 안내는 한 번만 표시된다. 세 나이 단계에서 정답 근거 장절이 먼저 나오고 다음 화면에 샤론의 안내가 나온다.

휴대폰에서 오답 안내가 물음 머리글을 밀어내는 경우를 줄이기 위해 물음 화면의 높이 한도를 화면의 64%로 늘렸다.
