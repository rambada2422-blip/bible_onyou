# 대표 결정 P1과 재대조 반영

작업 브랜치는 `gpt/exodus-field-notes`다. 요청한 `999ccf6`에서 시작해 총괄의 검토표가 있는 main `43be9f8`을 받아 작업했다.

- 아홉 재앙의 요약과 장절을 [검토표 6절](열재앙_배치재검토_Claude.md)과 글자 단위로 비교했다. 마지막 밤은 “밤중에 여호와께서 애굽 땅의 처음 난 것을 다 치셨어요.”로 시작한다. 현장과 일지 모두 같은 본문과 출 12:7, 23, 27, 29-30을 표시한다. 바로의 부름에는 출 12:31-32를 따로 붙였다.
- 둘째 묶음 이름은 ‘사람과 가축’이다. 목격 기록 2·8, 8~10세 기록 6 숨김, 식탁과 떠날 차림 장절도 반영했다. 짧은 재앙 여섯과 유월절 방의 그림에 화면 읽기용 설명을 넣었다.
- 첫 사진은 왼쪽 위부터 개구리 마당 뒤의 곡식·채소밭, 고센의 보리밭과 채소, 우박을 맞는 보리 이삭과 파란 삼꽃, 메뚜기가 앉은 가는 곡식과 채소·열매나무다. [작물 네 장 비교](사진/P1_밭_네장.jpg)
- 둘째 사진은 강 건너 신전과 애굽 집 너머 궁의 벽, 유월절 방, 마지막 밤이다. 벽에는 사람 형상이 없고 식탁에는 고기 대신 뚜껑을 덮은 그릇이 놓여 있다. 출 12:29 장면에는 한밤중의 닫힌 문이 보인다. [벽·방·마지막 밤 비교](사진/P1_벽과방.jpg)
- 총괄에게 일곱 그림의 최종 배치 재대조를 인계한다. P1은 대표 결정 반영 후 목회자 확인 단계이고 P2·P5·P6은 감수 대기다.

바뀐 게임 파일은 web/js/passover.js, web/js/art.js, web/assets/bg의 plague-frogs, plague-goshen, plague-hail, plague-locusts, plague-water, plague-flies, ex07-room 일곱 JPG다. tools/test/full/passover.js는 두 진입점에서 세 연령의 본문, 장절과 게임 진행을 확인한다.
