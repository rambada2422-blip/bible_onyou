# 홍해 바닷가의 대사와 설명 카드 배치

가로 820×570 화면에서 앞뒤를 이미 살펴본 저장을 열면 그림이 최온의 대사 영역과 94픽셀 겹쳤다. 그림이 ‘뒤쪽 길 보기’ 터치까지 가로막는 경우도 브라우저에서 재현했다. 창 높이에 맞춰 격자의 행이 줄어들어 그림의 실제 높이보다 작은 자리를 잡는 것이 원인이었다.

가로 레이아웃에서 각 행은 내용의 높이를 확보하고, 공간이 부족하면 아래로 스크롤한다. 그림과 설명에 반복되던 장소 이름은 설명 카드에 표시한다. 변경 파일은 `web/css/red-sea.css`와 `tools/test/red-sea.js`다.

배포용 단일 HTML에서 진영·앞바다·뒤쪽 길을 열고, 그림 경계와 대사·설명 카드·조작 단추의 좌표를 비교했다. 320~960픽셀 너비의 세로·가로 창 여섯 조건에 150%·200% 글자 크기를 포함했다. 각 조건에서 두 방향과 ‘모세가 전한 말 살피기’도 눌렀다. [960×708 실제 화면](사진/홍해_가로화면_대사배치.png)

[비공개 20판 · 저장 위치에서 열기](https://bible-onyou-moses-and-pharaoh.taupemast4.chatgpt.site/?v=20#redsea). Sites 임시 미리보기 중계는 시간 초과였다. 브라우저에서 점검한 단일 HTML과 배포 묶음의 내용이 일치했고, 비공개 배포가 성공했다.
