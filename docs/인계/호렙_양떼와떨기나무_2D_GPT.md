# EX-01 호렙에서 양 떼와 떨기나무 찾기

[2D 호렙 바로 플레이](https://bible-onyou-moses-and-pharaoh.taupemast4.chatgpt.site/#horeb) · [기능 커밋 7ac5506](https://github.com/rambada2422-blip/bible_onyou/commit/7ac550641a8e44aa0e216b6b348aa4411d828340)

첫 방문에는 연령과 대원을 고른다. 시간표의 ‘불붙은 떨기나무와 부르심’과 애굽 일터 다음 목적지의 ‘모세’에서도 들어간다. 호렙을 다시 열면 읽던 대목과 이미 찾은 이름들이 돌아온다. 끝에서는 ‘모세를 따라 왕궁으로’로 이어진다.

| 출애굽기 | 아이가 보는 일과 조작 | 소리 |
|---|---|---|
| 3:1 | 처음에는 양 떼가 보인다. 양 떼를 누르면 모세가 이드로의 양과 호렙에 이른 대목이 열린다. 휴와 함께 시선을 옮겨 그림 속 떨기나무를 찾는다. | 첫 조작에 여덟 마디 목관과 작은 방울. 첫 조작 전에는 무음 |

| 3:4–6 | 전체 그림에서 모세가 서 있는 자리, 이어서 팔로 얼굴을 가린 모습을 본다. 8세 단계는 관찰 안내 글에서 거룩한 땅과 조상의 이름들을 직접 찾는다. | 부르심부터 장면 소리를 멈춘다. 말씀과 인물의 반응에 귀를 기울이는 자리다. |

## 원고와 자산

- 호렙 원고와 세 연령의 퀴즈를 총괄 브랜치의 EX-01과 대조했다. 쉬운 단계의 세 곳 ‘글에서 찾기’는 main의 검토본을 가져왔다. 화면에서 이 놀이가 다루는 글과 읽기 전용 성경 원문을 구분한다. [원고·놀이 출처 6cb403f](https://github.com/rambada2422-blip/bible_onyou/commit/6cb403f)
- 두루마리 `web/js/horeb-scripture.js`는 기존 광야 두루마리와 같은 개역성경(KorRV, Public Domain)이다. 고정 판본의 CSV에서 출 3:1–12 열두 절을 뽑아 저장한 문자열과 글자 단위로 대조했다. [판본](https://github.com/scrollmapper/bible_databases/tree/59b18c5af5845728c275d5b7178ad0d024172b1f/sources/ko/KorRV)
- 양 떼는 기존 2D 호렙 삽화를 쓴다. 떨기나무는 대표가 선택한 E-2d 두 JPG를 그대로 가져왔다. 가까이 볼 때는 왼쪽 원본 가로 703픽셀 안에 불과 잎을 함께 담고, 얼굴을 가릴 때는 두 그림을 겹치지 않고 바꾼다. 기존 그림의 이용약관 원문 확인 상태는 원래 자산 기록에 따른다. [대표 선택 기록](../시안/선택.md) · [게임용 그림 이력](../../web3d/assets/awe/읽어보기.md)
- `tools/art-src/horeb-score.py`가 양 떼의 25.6초 음악과 10.5초 불씨 환경음을 합성한다. 두 음원 모두 외부 음원이나 표본을 사용하지 않았다. MP3를 디코딩해 길이·출력·반복 경계를 확인하고 재합성 결과도 대조했다.

## 자체 플레이

- 손가락으로 양 떼와 떨기나무를 찾아 시점을 왕복했다. 360×740에서 첫 터치 뒤 1초 안에 양 떼 음악의 실제 출력을 확인했다. 불씨 소리, 부르심의 무음, 낭독 시작·중단에 따른 음악 정지·복귀, 음소거 저장, 창 비활성화와 이탈 정지도 확인했다. 낭독 조작 검사는 음성 합성을 모의해 음악과의 간섭을 검사했다.
- 웹 원본과 오프라인 단일 파일에서 회전, 글자 125%, 새로고침, 세 이름 중 하나만 찾은 시점의 복원, 기존 카드 저장에서 여는 말씀 인장, 왕궁 진입을 시험했다. 세 연령 단계, 320×568·390×844·568×320·844×390, 키보드, 동작 줄이기도 점검했다.
- 2D 호렙의 전용 검사는 `tools/test/full/horeb-witness2d.js`에 있으며 전체 점검에서도 실행한다. 총괄의 낱말·그림 찾기 검사는 `tools/test/full/text-find2d.js`, `look-beats2d.js`에 있다. 보호 대상 파일 `web/js/content.js`의 EX-01 대목은 현재 main과 일치한다. 파일 전체에서 남는 차이는 앞선 작업에서 맞춘 최온 8세와 온우 17세다.
- 게임 진행·두루마리·소리는 `web/js/app-scene.js`, `app.js`, `horeb-field.js`, `horeb-scripture.js`, `bondage-field.js`에 연결했다. 두 2D 입구와 빌드는 `web/index.html`, `tools/build.js`, 화면 배치는 `web/css/app.css`를 사용한다.

## 플레이 판

기존 소유자 전용 Sites 33판을 게시했다. 게시 성공 응답과 저장된 33판에서 사이트 소스 커밋 `65b4c2867b4b23e04366451dce017b9fcc41cb96`을 확인했다. 게시용 HTML과 분리 자산 19개를 다시 한 파일로 조합해 오프라인 빌드와 일치하는지 확인했고 배포 묶음의 파일도 소스 체크아웃과 대조했다. 관리형 미리보기의 4173 포트 중계가 시간 초과되어 게시 주소에서의 직접 조작은 미확인이다. 실제 브라우저 플레이 검증은 웹 원본과 오프라인 빌드에서 했다.

## 다음 현장

기존 왕궁의 첫 방문부터 나일 강가의 첫 재앙까지 실제로 왕복한다. 특히 퀴즈 답에서 영상으로 넘어갈 때의 질문, 피해를 본 백성의 상황, 영상 종료 뒤 바로의 반응과 다음 목적지를 점검한다. 새 개별 본편은 출 17:8–16 아말렉, 이어 출 18장 이드로 순서다. 이번에 확인한 main과 작업 브랜치에는 두 사건에 대한 독립 검토를 마친 개별 원고가 없었다. 호렙의 새 2D 연출에 대한 대표·총괄 확인과 실제 어린이 플레이, 목회자 감수는 남아 있다.
