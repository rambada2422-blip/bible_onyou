# 아홉 재앙 기록판과 유월절 그림 단서

2D 시간표의 ‘열 가지 재앙과 유월절 · 감수용 미리보기’에서 확인한다. 첫째·넷째·아홉째 재앙은 두 장소를 살피면 한 칸이 차고, 나머지 여섯 장면은 목격 기록을 읽을 때 한 칸이 찬다. 재앙을 세 개씩 묶었으며, 각 기록에는 장절이 있는 한 줄 사실을 더했다. 같은 장소를 다시 눌러도 기록 수는 늘지 않는다.

유월절 방 그림에서 왼쪽 문기둥, 가운데 식탁, 오른쪽 신발과 지팡이를 찾는다. 처음에는 세 자리 모두 ‘미발견’으로 표시된다. 누른 물건의 이름과 장절·설명 전문을 열며, 재접속하면 마지막으로 열었던 카드를 보여 준다. 예전 판에서 찾은 단서도 이어진다. 그림의 세 단서는 손가락으로 누르거나 탭 키로 이동해 열 수 있다. 작은 가로 화면은 그림과 설명을 나란히 놓고 다음 버튼은 설명 아래에 둔다.

새 그림 ex07-room.jpg는 출애굽기 12장의 준비를 관찰하는 실내 시안이다. 세 단서가 같은 방에 놓인 구도와 물건의 위치는 미술 연출이다. 그림에는 신적 형상, 죽음 묘사, 아이의 예식 참여, 본문 인용이 없다. 목회자 검토와 대표의 그림 확인은 대기 중이다.
