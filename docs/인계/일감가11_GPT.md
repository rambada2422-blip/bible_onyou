## 어디까지 했는지

320×568과 568×320에서 수정 전 화면을 눌러 보았다. 호렙 도감과 요단 추리 수첩이 높이 40px, 깃발 색 단추가 40×40px, 모자 쓰기가 높이 40px였다. 호렙 첫 물음의 샤론 이름은 배경 대비 3.11:1, 세로 메뉴의 11~13세 표시는 4.01:1이었다. 수정 전 열 개 화면에서 화면 크기별로 13개 실패가 기록됐다.

도감·수첩과 꾸미기 단추의 최소 높이를 44px로, 깃발은 가로도 44px로 조정했다. 메뉴의 연령 색을 밝히고, 대화와 알림 칸의 인물 이름을 어두운 남색으로 표시했다. 샤론의 이름은 짙은 파란색이다. 화면 문구를 보존했다. 사진기와 소리 단추에는 이미 각각 ‘사진 찍기’, ‘소리 끄기’ 또는 ‘소리 켜기’가 있어 별도의 이름을 추가할 필요가 없었다.

새 시험은 양쪽 장소의 주요 화면을 실제로 열고, 세로·가로에서 누르는 크기와 이름, 글자만 숨겨 찍은 배경의 밝기를 확인한다. 조작할 수 있는 부분 뒤의 화면과 접힌 칸은 제외한다. 창이 길면 끝까지 스크롤해 확인한다. 바뀐 파일은 3D 화면 스타일, 새 검사 파일과 이 인계다. 빠른 점검 4/4. 수정 후 직접 검사와 전체 자동 조작을 진행한다.
