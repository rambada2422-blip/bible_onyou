## 한 일

2D 화면이 쓰는 글꼴 목록에 맑은 고딕·바탕의 한글 이름, 돋움, 노토 한글 고딕·명조 계열을 보강했다. 인터넷 글꼴 세 가지는 각 목록에서 맨 먼저 사용한다.

글꼴 주소를 막은 상태에서 320×568, 390×664, 844×390의 세 화면 크기로 나이 단계 셋을 시험했다. 첫 화면, 구성 안내, 단계 고르기, 시간표, 이야기, 물음, 말씀 카드, 마무리, 목적지까지 총 28화면에서 글이 잘리지 않았다. 윈도우 크롬이 실제로 사용한 기기 글꼴은 맑은 고딕과 바탕이었다. 인터넷 글꼴 세 가지를 실제로 받은 상태에서 움직이는 그림을 가리고 첫 화면·단계 고르기·시간표·물음·말씀 카드의 글자와 배치를 비교해 변경 전후 화면 사진이 같은 것을 확인했다.

시험 브라우저에서 제목의 높이를 일부러 줄였을 때 세 화면 크기 모두 잘림을 검출하고 종료값 1을 반환했다. 화면 사진 폴더를 생략해도 종료값 1을 확인했다.

```powershell
node tools/test/full/nofont2d.js dist/nofont2d
node tools/check.js --full
```
