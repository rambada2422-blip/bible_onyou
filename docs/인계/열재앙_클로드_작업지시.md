# Claude 총괄 작업 지시 · 출애굽기 7–12장

대표 요청으로 지금부터 GPT는 열 가지 재앙의 2D 조작과 저장을 담당하고, Claude 총괄은 아래 세 작업을 순서대로 진행한다. 기존 호렙 작업에서 대표 결정을 기다리는 동안 시작할 수 있다. 호렙의 미결정 사항은 기존 진행판에서 별도로 관리한다.

1. **재앙과 유월절의 순서를 검증한다.** 기준은 `docs/01_출애굽기_장면목록.md`의 EX-06~08이다. `gpt/exodus-passover-preview`의 `web/js/passover.js`에서 어린이에게 보이는 요약을 대조한다. 열 가지 재앙 각각과 문·식탁·떠날 차림, 출발에 대해 장절, 현재 표현, 유지하거나 고칠 근거를 남긴다. 유월절 준비가 열 번째 재앙보다 앞서는지, 흑암 때 빛이 있었던 장소 표현이 본문과 맞는지 특히 확인한다.
2. **세 장면의 어린이용 표현을 다듬는다.** 강물이 변함(출 7:14–25), 파리 떼와 고센(출 8:20–32), 흑암과 빛(출 10:21–29)을 대상으로 8~10세가 그림에서 볼 단서와 한 문장 안내를 짝지어 제안한다. 마지막 밤(출 12:29–32)은 아이들이 죽음을 점수나 보상으로 느끼지 않도록 표현을 검토한다. 제안마다 장절을 붙이고 사건을 관찰하는 아이의 시점을 유지한다.
3. **독립 검증 뒤 GPT에 회신한다.** 작성 과정을 보지 않은 검증자가 순서·장절·그림에서 확인 가능한 사실을 대조하도록 한다. 검증 전인 항목과 목회자 판단이 필요한 항목은 따로 표시한다. 먼저 끝난 항목부터 전달해도 된다.

결과 파일은 `docs/인계/열재앙_본문검토_Claude.md`이다. 각 항목을 ‘화면 / 장절 / 판단 근거 / 권장 문구’ 순으로 적고 마지막에 검증 상태를 적는다. Claude의 기존 작업 브랜치에 커밋해 결과 파일 경로와 커밋을 회신한다. GPT가 검토 결과를 받아 게임에 반영한다. 기존 호렙 결정이나 본편 공개 승인은 이 작업과 별도다.
