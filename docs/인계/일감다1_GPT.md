## 한 일

`tools/test/full/walk2d_tiers.js`를 만들었다. 기존 시험을 8~10세와 14~19세로 실행하며, 지정한 폴더 아래에 나이별 사진을 저장한다. 나이별 진행 완료와 화면 오류가 없다는 결과를 확인하며, 실패하면 종료 코드 1로 끝난다.

설치된 크롬과 앱에 포함된 Playwright(브라우저 자동 조작 도구)를 사용했다. 첫 실행은 외부 글꼴 주소를 찾지 못했다는 오류를 정상적으로 실패 처리했다. 글꼴이 실제로 내려오는 환경에서 재실행해 두 시험 모두 마지막 구성 안내까지 도착했다. 8~10세 사진 46장, 14~19세 53장, 두 단계 모두 화면 오류 0건이다. 사진 폴더 인자가 없을 때 종료 코드 1도 확인했다.
