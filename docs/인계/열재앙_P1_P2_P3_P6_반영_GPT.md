# 열 가지 재앙과 유월절 · 대표 결정 P1·P2·P3·P6 반영

총괄의 [검토표 3·6·7절](열재앙_배치재검토_Claude.md)을 반영했다. 기준은 Claude의 `47df154`, 작업 브랜치는 `gpt/exodus-field-notes`, 게임 커밋은 `5e6a096`이다. 이 브랜치는 요청한 `999ccf6`에서 이어진다.

## 본문과 연령별 화면

- 재앙 1~9의 요약과 장절은 6절 표의 아홉 행과 같다. 열 번째 재앙과 일지는 같은 글과 장절 ‘출 12:7, 12:23, 12:27, 12:29-30’을 보여 준다. 다음 ‘바로의 부름’은 출 12:31-32에 따로 둔다.
- 목격 기록 1~9의 글과 장절을 7.1절 표에서 그대로 옮겼다. 8~10세에게는 2·5·7·8·9번 다섯 기록을 보여 주고, 11~19세에게는 아홉 기록을 보여 준다. 자동 점검은 화면에 표시된 문장과 장절을 Claude 표와 직접 비교한다. [8~10세 화면의 메뚜기·흑암 목격 기록](사진/바로의마음_목격기록8과9.png)
- 묶음 이름 ‘사람과 가축’, ‘식탁’ 출 12:8, ‘떠날 차림’ 출 12:11, 28을 확인했다. 3절의 네 작물 그림, 두 신전 벽 수정, 짧은 재앙 여섯의 대체 설명은 [앞선 인계](열재앙_P1_배치재검토반영_GPT.md)에 있다.

## 그림과 직접 관찰

[유월절 준비와 한밤중의 실제 게임 화면](사진/유월절_문세곳과구운양.jpg)

| 총괄 확인 대상 | 적용 결과 |
|---|---|
| 유월절 방의 문 | 좌우 문설주와 위 인방에 짙은 붉은 자국 세 개. 문지방과 바닥은 깨끗하다. 제목과 단서 핀을 옮겨 세 자국이 미리보기에서 보이게 했다. |
| 유월절 식탁 | 뒤쪽 작은 접시 위에 머리와 다리가 몸에 붙은 구운 어린 양 한 마리가 옆으로 놓였다. 얼굴은 단순하게 그렸다. 앞쪽의 무교병과 나물도 보인다. |
| 한밤중 이스라엘 자손의 집 | 닫힌 문과 세 군데의 마른 자국. 문 그림 전체가 보이도록 제목을 그림 아래에 뒀다. |
| 그림 수위와 장소 | 두 그림 모두 흘러내림·고임·손자국·피 그릇이 없다. 절단된 다리, 날고기, 사람의 죽음, 하나님의 형상, 멸하는 자를 그리지 않았다. 애굽 집 세 그림(plague-flies, plague-darkness, ex08-door)은 이번 결정 전과 파일이 동일하다. |

방에서는 문 표시 세 곳 중 어느 곳을 직접 눌러도 ‘문’ 기록이 열린다. 구운 양을 누르면 ‘식탁’ 기록이 열린다. 기존 세 단서 핀과 동일한 저장을 써서 같은 단서를 거듭 보아도 한 번으로 센다. [방 그림 원본](../../web/assets/bg/ex07-room.jpg) · [한밤중 원본](../../web/assets/bg/plague-midnight.jpg)

바꾼 게임 파일은 web/js/passover.js, web/css/app.css, web/assets/bg/ex07-room.jpg, web/assets/bg/plague-midnight.jpg, 이를 묶은 web/js/art.js다. tools/test/full/passover.js에는 연령별 본문·장절, 표식을 직접 누르는 동작과 일지 장절 검증을 추가했다. 원본과 단일 파일 양쪽에서 연령 세 가지로 완주했다. 별도로 여섯 화면 크기에서 문 표시와 어린 양을 눌러 확인했다.

Claude 총괄은 두 그림의 배치와 수위를 다시 확인해 대표에게 합병 승인을 요청한다. P1·P2·P3·P6은 대표 결정 반영 후 목회자 확인 단계이며 P5는 감수 대기다.
