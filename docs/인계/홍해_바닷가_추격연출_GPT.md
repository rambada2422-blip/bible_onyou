# 홍해 앞에 갇히다 · EX-10 첫 화면 수정

[비공개 게임에서 바닷가 열기](https://bible-onyou-moses-and-pharaoh.taupemast4.chatgpt.site/?v=19#redsea-coast) · [휴대폰 첫 화면](사진/홍해_막힌해안.png) · [뒤를 돌아본 화면](사진/홍해_뒤따른병거.png)

첫 화면에 해안에 몰린 백성과 이집트 병거의 위치를 함께 그렸다. ‘앞바다 보기’는 인파 속에서 본 닫힌 바다, ‘뒤쪽 길 보기’는 말 두 마리가 끄는 선두 병거와 뒤따르는 행렬이다. 뒤를 돌아보면 화면이 살짝 가까워진다. 기기의 동작 줄이기 설정에서는 그림을 고정한다. [그림 세 장의 출처와 육안 확인 기록](../시안/홍해_바닷가/그림검토.md)

기존 `#redsea`는 탐험하던 위치를 연다. `#redsea-coast`는 진영에서 시작한다. 이미 건너는 중이거나 수첩을 마친 경우, 바닷가만 다시 둘러보고 ‘보던 탐험으로 돌아가기’를 누르면 원래 위치로 복귀한다. 새 그림은 단일 HTML에도 포함된다.

수정한 파일은 web/assets/red-sea 아래의 세 그림과 web/js/red-sea.js, web/js/app.js, web/css/red-sea.css, tools/build.js, tools/test/red-sea.js, tools/test/game-server.js다. 게임 원본과 배포용 단일 HTML을 Chromium에서 직접 조작했다. 두 방향 선택, 돌아보기 중 새로고침, 마른 길 40%에서 재관람 후 복귀, 장단과 수첩까지 확인했다.

320×480에서 1280×720까지 여덟 가로·세로 크기에서 버튼의 터치 면적과 스크롤을 확인했다. 단일 HTML을 연 뒤 네트워크를 끄고 양쪽을 돌아봤다. 기본 동작 설정에서는 선두 병거가 가까워지고, 동작 줄이기 설정에서는 고정됨을 확인했다. 비공개 사이트 19판으로 배포했다. Sites 임시 미리보기 중계는 시간 초과였으며, 원본과 배포 묶음의 브라우저 검사, 묶음 파일 일치, 배포 성공 응답을 확인했다.

EX-11의 마른 길과 EX-12의 미리암은 기존 2D 연출이다. 두 장면의 시각 품질을 같은 수준으로 다듬는 작업, 실제 아이가 첫 화면만 보고 상황을 읽는지 확인하는 일, 총괄 검토와 대표의 그림 승인이 남았다.
