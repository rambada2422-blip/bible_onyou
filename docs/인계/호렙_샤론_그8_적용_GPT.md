# 호렙에서 만나는 샤론의 그-8 얼굴

대표가 승인한 그-8 시안 기준으로 호렙 게임의 샤론 얼굴을 교체했다. 출발점은 `main`의 `74fb1cf`이고, 적용 브랜치는 `gpt/horeb-sharon-gr8`이다. [승인 시안](https://github.com/rambada2422-blip/bible_onyou/tree/0d6133df28294aad3a6cbe2971e8f9a6d0c4c2c5/docs/시안/길잡이/사이버3)

- **바뀐 파일**은 `web3d/assets/sharon/`의 묻는 표정과 격려하는 표정 PNG 두 장, 같은 폴더의 원본 안내, 빌드가 생성한 `web3d/js/sharondata.js`, 이 인계와 아래 사진 두 장이다.
- **원본 대조**에서 평소·묻는 중·기뻐함·다시 해 보자 네 표정 모두 승인본의 192×192 PNG와 게임 파일, 게임 데이터, 한 파일 미리보기에 담긴 바이트가 일치했다.
- **화면 확인**은 8~10세 단계의 320×568, 390×844 터치 화면에서 했다. 양 떼를 찍어 첫 물음을 열면 묻는 표정이 나오고, ‘낙타 떼’를 고르면 격려하는 표정으로 바뀐다. 두 표정 모두 말풍선 옆에 44×44로 표시됐다. 게임 원본과 `node tools/build3d.js`로 만든 한 파일 미리보기에서 같은 경로를 확인했다. 미리보기는 HTML 한 파일만 제공하고 외부 요청을 차단한 상태에서도 두 표정을 표시했다. [첫 물음](사진/호렙_샤론_첫물음.png) · [다시 고르기](사진/호렙_샤론_다시고르기.png)
- **남은 확인**은 실제 휴대폰에서의 가독성이다. 대표 확인 뒤 총괄이 병합한다.
