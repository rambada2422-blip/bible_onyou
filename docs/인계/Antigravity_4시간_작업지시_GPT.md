# Antigravity에 전달할 4시간 작업 지시

바이블 온유의 8~10세 보호자 플레이테스트 준비와 독립 회귀 검증을 맡아 줘. 최소 4시간 동안 실제 브라우저 조작과 테스트 구현을 진행해. 한국시간으로 시작 시각과 4시간 뒤 종료 예정 시각을 먼저 기록하고, 한 시간마다 새 발견·재현 조건·다음 검증을 짧게 기록한 뒤 계속해. 실행 한도로 조기 종료되면 실제 작업 시간, 마지막 커밋, 이어갈 지점을 정확히 남겨 줘.

- 저장소 [바이블 온유](https://github.com/rambada2422-blip/bible_onyou)
- 기준 브랜치 `gpt/exodus-observation-journal`
- 기준 게임 [809c35f](https://github.com/rambada2422-blip/bible_onyou/tree/809c35fea5b5704471f20a3f7af848c787f2f104)
- 작업 브랜치 `antigravity/exodus-guardian-playtest`

git fetch origin 후 기준 커밋에서 작업 브랜치를 만들고 git rev-parse HEAD를 기록해. AGENTS.md와 docs/00_공통규칙서.md를 먼저 읽어. GPT는 게임 구현, Claude는 성경 본문과 그림 감수를 맡고 있어. 네 산출물은 tools/test/full/guardian-passover.js, docs/인계/보호자_10분_플레이테스트_Antigravity.md, 근거 화면 사진 두 장이야.

첫 1시간. 이전 검토본 c3b676e와 기준 커밋을 각각 빌드해 실제 브라우저에서 열어. node tools/build.js를 실행하고 HTTP로 dist/preview.html을 열어 8~10세를 선택해. 넷째 재앙에서 한 장소만 본 상태로 ‘본 재앙 보기 → 1번째 · 물이 피가 됨 → 강가’를 찾아가. 강가 사진, ‘애굽 사람들은 마실 물을 찾으려고 강 둘레를 팠어요.’, ‘출 7:24’를 함께 읽을 수 있는지 확인해. 돌아가서 보던 장소, 기록 수, 다음 단추의 활성 상태를 대조해.

둘째 1시간. 320×480, 320×568, 390×844 세로와 568×320 가로에서 같은 과제를 해 봐. 책 단추의 위치와 대비, 강가 문장 끝까지 읽기, 닫기, 세로·가로 회전 후 복귀를 확인해. 발견한 회귀 위험을 정상 게임 진입점으로 재현하는 Playwright 점검을 작성해. tools/test/full/passover.js에서 이미 확인한 항목은 재사용하고 독립 점검에서는 실제로 빠진 조건을 우선해.

셋째 1시간. 강물부터 본 경우와 강가부터 본 경우, 넷째 재앙에서 나갔다 돌아온 경우, 흑암의 두 장소를 반대 순서로 연 경우를 점검해. 유월절 방에서는 문설주와 인방의 세 표시와 식탁 위 어린 양을 직접 눌러 봐. 단서 두 개에서 브라우저를 닫고 같은 프로필로 다시 열어 마지막 단서와 남은 수를 확인해. 중요한 문제는 가능한 다른 브라우저 엔진과 키보드로도 재현해.

넷째 1시간. 보호자가 그대로 읽을 수 있는 10분 안내서를 완성해. 과제는 첫 재앙의 두 곳 찾기, 넷째 재앙에서 강가 기록을 찾아 복귀하기, 흑암의 두 장소를 자기 말로 설명하기야. 과제마다 중립적인 말 한 문장, 20초 기다린 뒤의 첫 힌트 하나, 아이가 실제로 한 말과 도움 여부를 적을 빈칸을 둬. 실제 어린이 관찰과 자동 조작을 구별해. 참여자가 없는 칸은 비워 둬. 이번 검증은 기기 안에서 진행하며 Neon 설치나 어린이 행동 데이터 수집은 범위 밖이야.

새 테스트와 node tools/check.js --full을 실행하고, 한국시간 실제 시작·종료 시각, 테스트한 버전·화면 크기, 결과 파일, 재현된 문제 최대 세 개와 각 재검증 경로를 인계해. 작업 브랜치에 커밋·푸시하고 Claude가 열 수 있는 링크를 남겨. main 병합은 총괄과 대표가 맡아.
