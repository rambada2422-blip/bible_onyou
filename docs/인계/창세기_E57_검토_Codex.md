# E57 이후 목회자 검토본

[검토 화면](창세기_E57_목회자검토.html)은 휴대폰이나 컴퓨터에서 파일로 열 수 있다. E51~E57 재검증이 끝난 `claude/genesis-week`의 `1146e35`를 기준으로 만든 내부 검토본이다. 다음 집필은 E58(창 44:1–17)이다.

- **2026-11-25 대표 결정.** E46·E50·E51·E52는 8~10세 진행 순서에서 기본으로 건너뛴다. 감수를 마쳐 사용할 수 있는 회차 중 보호자가 고른 회만 포함한다. `web/genesis/reading-order.js`에 이 규칙을 구현했다. 검토 화면에서는 E45~E53이 감수를 마쳤다고 가정해 보호자 선택에 따라 순서가 어떻게 바뀌는지 확인한다. 선택은 현재 화면에서만 유효하다.
- **최종 목회자 검토 뒤 결정.** 회차표 51·54·56·57행과 G06의 E55 정답 선공개 문장을 현재안과 나란히 볼 수 있다. G06 수정안은 진행 대사와 녹음 대본에서 ‘서른 살에’만 덜어 낸다. 두 원본은 집필 브랜치의 상태를 유지한다. 검토 후 대표가 실제 적용 여부를 결정한다.
- **회신 대기.** 네 회차에 넣을 아동 보호 기관 연락처와 절차는 확인된 정보를 받아야 한다.

`node tools/build-genesis-review.js`는 현재 원고의 대상 문구를 확인한 뒤 `dist/genesis-e57-review.html`과 제안 차이 파일 `dist/genesis-e57-proposed.patch`를 만든다. 차이 파일은 `git apply --check`로 대조한다. 검토 화면을 갱신할 때에는 생성된 HTML을 이 폴더의 검토 화면에 복사한다.

Playwright가 설치된 환경에서 빌드 후 `node tools/test/genesis-review.js`를 실행한다. 보호자 선택 16가지, 감수를 마친 목록에 없는 회차 제외, 화면을 다시 열었을 때의 기본값, 키보드 조작, 오프라인 표시, 검토 문구 5건을 점검했다. 실물 성경의 가림 위치, 어린이 플레이와 목회자 감수는 남아 있다.
