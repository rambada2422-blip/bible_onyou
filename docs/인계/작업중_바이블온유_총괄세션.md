# 작업중_바이블온유_총괄세션

새 세션의 첫 작업 위치는 `rambada2422-blip/bible_onyou`의 **`antigravity/david-week`**다. 같은 환경에서는 `/workspace/antigravity-david`를 연다. 다른 환경이면 이 원격 브랜치를 체크아웃한다. 먼저 현재 브랜치 이름과 원격 최신 커밋을 확인하고 `AGENTS.md`와 담당 인계를 읽는다.

| 담당 | 인계 시점의 상태 | 새 세션의 첫 행동 |
|---|---|---|
| 안티그래비티 · 다윗 | A40까지 커밋되어 있다. 실제 아이 플레이 평가는 아직이다. | [A41~A48 제작표](../일감/다윗_현장탐사_A41_A48.md)를 열어 첫 미완료 카드부터 시작한다. A41 첫 행동은 기존 D02 시냇가에서 카메라를 한 칸 움직인 뒤 돌 사진 한 장을 찍는 것이다. |
| 클로드 · 창세기 | 전체 66회 편성. E26까지 별도 검증 반영, E27은 인계 당시 초안이다. | 11월 24일 16시(한국시간)부터 `claude/genesis-week`의 [고난도 연속 배정](https://github.com/rambada2422-blip/bible_onyou/blob/claude/genesis-week/docs/일감/창세기_고난도_연속배정.md)을 연다. E27 검증과 E28~E42 여섯 묶음 중 실제 첫 미완료 단계를 맡긴다. |
| GPT · 출애굽기 | 작업 브랜치는 `gpt/exodus-journey`이고 홍해 이후 마라·엘림·만나·반석의 물과 시내산·금송아지까지의 작업 기록이 있다. ‘엘림에서 찍은 한 장’은 설계안이다. | [출애굽기 작업 브랜치](https://github.com/rambada2422-blip/bible_onyou/tree/gpt/exodus-journey/docs/인계)에서 최신 원고·인계를 우선한다. 르비딤과 이드로는 원고 검토 여부를 확인한다. |

창세기 원고와 다윗 게임은 서로의 파일을 기다릴 필요가 없다. 각자 맡은 브랜치에 커밋·푸시하고 다음 미완료 카드와 첫 행동을 남긴다. 같은 카드를 진행 중인 세션이 있으면 중복 착수하지 않는다. main 병합은 대표 승인 뒤 총괄이 진행한다.
