## 작업 방식 (다음 세션도 같게)

- 본문 대조: 개역개정을 대한성서공회 누리집에서 열어 장절을 대조한다. 원고에는 개역개정 문장을 옮기지 않고 풀어 쓴 말과 장절만 쓴다 (공통 규칙서 7절).
- 아이 줄은 최온(10세)이 읽는다. 휴와 온우는 필요할 때만 짧게 나온다. 성경 인물의 대사는 본문에 있는 말만, 풀어서 쓴다.
- 한 편을 마칠 때마다 작성 과정을 보지 않은 검증자가 본문·규칙서와 대조한다. 결과는 위 표와 해당 원고의 '원고 자체 점검' 아래에 적는다.
