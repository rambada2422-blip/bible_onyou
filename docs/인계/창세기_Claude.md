## 총괄에게 보고할 것

- 지시서와 규칙서의 차이: 지시서 예시는 8~10세에게 "창세기 1장 5절"처럼 절까지 알려 준다. 공통 규칙서 5절은 8~10세에게 '책 이름과 장까지 안내, 부모·교사와 함께'다. AGENTS.md에 따라 규칙서를 따랐다. 아이에게는 장까지 말하고, 절은 '어른 도움말'로 어른만 본다. 일지에는 장절을 모두 적는다. 지시서처럼 절까지 말하기로 하면 원고의 '어른 도움말'을 어른의 줄로 옮기면 된다.

## 작업 방식 (다음 세션도 같게)

- 본문 대조: 개역개정을 대한성서공회 누리집에서 열어 장절을 대조한다. 원고에는 개역개정 문장을 옮기지 않고, 풀어 쓴 말과 장절만 쓴다 (공통 규칙서 7절). 작업자용 근거 표에도 원문을 따옴표로 옮기지 않는다.
- 원고 틀은 G01을 따른다: 카드 정보(질문과 보기, 정답 근거 포함), 읽는 법, 칸별 원고, 아이용 요약, 녹음용 읽기 원고, 작업자용 근거, 원고 자체 점검, 별도 내용 검증.
- 아이 줄은 최온(10세)이 읽는다. 성경 인물의 말은 본문에 있는 말만, 간접 화법으로 풀어 쓴다.
- 타임머신 이동, 일지 사진, 이름표처럼 탐험대의 도구가 나오는 줄에는 『탐험대 이야기』를 붙인다. 과거의 장면에 아무것도 붙이거나 남기지 않는다.
- 고르기 칸의 '보이는 것'에는 다른 장면의 물건을 장면 안에 두지 않고 '고르기 카드'로 둔다. 다른 장면에서 돌아왔을 때 다시 읽을 곳을 적는다.
- 한 편을 마칠 때마다 작성 과정을 보지 않은 검증자가 본문·규칙서와 대조한다. 결과는 위 표와 해당 원고 맨 아래에 적는다.
