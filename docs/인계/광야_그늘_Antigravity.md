# 광야 움직이는 그늘 인계 기록 (Antigravity)

- **브랜치**: `antigravity/exodus-desert-shade`
- **대상 현장**: 출애굽기 원정 5번째 현장 — `수르 광야 / 그늘이 사라지기 전에` (`map.id === 'desert'`, `출 15:22–27, 16:13–18`)
- **검증 대상**: 오프라인 묶음 `dist/expedition.html#road` (`360×640` 모바일 뷰포트, 터치·키보드, `prefers-reduced-motion: reduce`, 소리 꺼짐)

## 1. 구현 요약

1. **제자리에서 그늘 기다리기 (`web/expedition/road.js`, `web/expedition/road.css`)**
   - 광야 현장(`map.id === 'desert' && !game.finished`)에서만 행동 영역에 **`그늘 기다리기`** 버튼(`.rd-wait`)을 표시하고, 키보드 단축키 **`T` / `.`** 를 연결했다(조작 안내 문구에도 반영).
   - `waitInPlace()`는 이동(`move()`)과 동일한 `applyDesertTurn(x, y)` 규칙을 `spendTurn()` 전에 적용하여, 현재 칸이 그늘이면 열기 `-1`, 볕이면 열기 `+1`(3이 되면 물 `-1`)을 동일하게 계산한다.
   - 차양(`:`) 위에서 기다려도 물이 자동 보충되지 않으며, 기존 `물 보충`(`#rd-act`)으로만 보충된다.
   - 기다리기 전에 `snapshot()`을 저장하므로 `되돌리기(Z)`로 직전 턴 상태가 정확히 복원되며, 볕에서 물이 `0` 아래로 떨어지면 기존 탈진 안내(`발걸음이 멎었다`)와 되돌리기/다시 걷기가 그대로 동작한다.
   - `360×640` 작은 화면에서도 `#rd-act`와 `.rd-wait`가 2열로 나란히 배치되고 가로 넘침(`scrollWidth > innerWidth`)이 없도록 `.rd-actions` 및 `.rd-env` 반응형 규칙을 확장했다.

2. **태양 방향과 다음 그늘 예고 (`web/expedition/road.js`, `web/expedition/road-art.js`)**
   - 지도 바닥: 현재 그늘 칸의 음영 대비를 분명히 하고(`#365b6588`), 다음 태양 전환 시 그늘이 드리워질 이동 가능 칸에 점선 예고 윤곽을 표시했다(전환 직전 1턴에는 윤곽을 더 선명하게 강조).
   - 바위·하늘: 현재 해 방향(`sunSide`)에 맞춰 하늘의 해 위치와 바위의 햇빛 받는 면·그늘진 면을 반전시켜, 모션 축소(`prefers-reduced-motion: reduce`) 및 무음 상태에서도 해의 이동과 그림자 반전이 즉시 읽히게 했다.
   - 상태 문구(`#rd-env`): 물 잔량, 현재 `그늘`/`볕 n/3`, 다음 전환 시점과 방향(예: `물 4 · 볕 0/3 · 다음 턴 서쪽 그늘` → `물 4 · 그늘 · 4턴 뒤 동쪽 그늘`)을 쉬운 한국어로 표시한다.

## 2. 경로·장비별 실측 결과 (`dist/expedition.html`, `360×640`)

같은 장비에서 **짧은 볕 직행 경로**(12턴, 차양 미사용)와 **바위 그늘 대기 + 차양 경유 경로**(13턴, `(4,6)`에서 1턴 기다린 뒤 `(4,5)`·`(7,4)` 차양 보충)를 비교 측정했다.

| 장비 (시작 물) | 경로 | 총 턴 | 들른 차양 | 도착 여부 | 남은 물 | 도착 시 열기 |
|---|---|---:|---:|---|---:|---:|
| 관찰 렌즈 (`lens`, 3) | 짧은 볕 경로 | 12 | 0곳 | 도착 | **1** | 2/3 |
| 관찰 렌즈 (`lens`, 3) | 그늘·차양 경로 | 13 | 2곳 | 도착 | **3** | 0/3 |
| 여분 물병 (`flask`, 5) | 짧은 볕 경로 | 12 | 0곳 | 도착 | **3** | 2/3 |
| 여분 물병 (`flask`, 5) | 그늘·차양 경로 | 13 | 2곳 | 도착 | **5** | 0/3 |

- **동일 장비 비교**: `lens`(1 → 3)와 `flask`(3 → 5) 모두 그늘·차양 경로가 남은 물 `+2`, 열기 `0/3`으로 뚜렷하게 유리하다.
- **장비 비교**: 같은 짧은 볕 경로에서 `flask`(남은 물 3)가 `lens`(남은 물 1)보다 여유가 크며, `lens`는 볕에서 1걸음만 더 지체해도 물이 `0`으로 떨어진다.
- **예외·전환 검증**:
  - `(1,5)` 볕 칸에서 `lens` 상태로 계속 기다리면 탈진 안내(`발걸음이 멎었다`)가 열리고, `마지막 걸음 되돌리기`로 직전 상태(`물 0`)로 복구됨.
  - `(4,5)` 차양 위에서 `그늘 기다리기` 시 물 자동 보충 없음 확인, `물 보충` 탭 후 정상 보충 확인.
  - 메뉴 `이 현장 다시 시작` → `다시 시작`으로 출발점(`(1,6)`, 턴 0, 만수) 복구 확인.
  - `E(8,0)`(`엘림의 샘`)에서 `샘에 닿기` → `다음 현장으로` 클릭 시 6번째 현장(`시내 산기슭 / 산 위에서 들은 것`)으로 정상 이동하며 `그늘 기다리기` 버튼이 숨겨짐 확인.
