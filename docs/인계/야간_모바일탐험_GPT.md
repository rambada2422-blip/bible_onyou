# 바이블 온유 모바일 탐험 개선

2026-11-21 한국시간. 대표 요청으로 당분간 게임 코드는 GPT(Codex)가 맡는다. Claude 총괄이 검토할 브랜치는 `gpt/night-mobile-play`다. 이 브랜치에는 첫 발견 작업과 대기 중이던 2D 작업(`relay/web2d`의 `face3fc`), 호렙 연출 작업(`relay/horeb`의 `fd0dac2`)이 함께 들어 있다. 대표 승인 뒤 병합하는 절차는 진행판을 따른다.

## 플레이가 달라진 곳

- **시간표**를 열면 실제로 출발할 수 있는 세 장면을 바로 볼 수 있다. 원래 장면 번호를 유지했고 ‘전체 여정 보기’를 누르면 잠긴 장면까지 나온다. [휴대폰 시간표](사진/야간_열린시간표.png)
- **요셉의 단서**는 바로의 얼굴, 반지를 건네는 손, 금 사슬을 각각 눌러 찾는다. 단서마다 지름 44 CSS 픽셀을 확보했다. 세로 화면에서 하나를 찾고 가로로 돌려도 발견 표시가 남고 다른 두 단서를 그대로 누를 수 있다. [세로 화면](사진/야간_요셉단서.png) · [작은 가로 화면](사진/야간_요셉단서_가로.png)
- **호렙**에서는 양 떼 사진으로 첫 질문을 열고, 장소를 묻는 두 번째 질문을 해결하면 화면 위에 호렙이라는 이름이 나온다. 마지막 ‘지켜보기’에서 ‘다음으로 가는 관문’으로 바로 갈 수 있다. ‘샤론과 돌아보기’를 선택하면 원래 풀이를 읽을 수 있다.
- **휴대폰 미리보기**는 기기의 실제 너비로 열린다. 320픽셀 휴대폰에서 단일 파일이 980픽셀 페이지로 축소되던 문제를 고쳤다. 호렙 도감이나 요단 강 수첩을 읽을 때는 탐험 이동이 멈춘다. 창을 떠나면 누르고 있던 방향키와 조이스틱이 풀린다.

## 수정한 파일

2D는 `web/js/app.js`, `app-scene.js`, `app-questions.js`, `art.js`, `web/css/app.css`, `web/assets/bg/alt03.meta.json`을 고쳤다. 3D는 `web3d/js/`의 `game-story.js`, `game-travel.js`, `game-exploration.js`, `game-controls.js`, `game-jordan.js`, `game-loop.js`, `game-ui.js`를 고쳤다. 두 묶음 도구 `tools/build.js`, `tools/build3d.js`와 시험 서버 `tools/test/game-server.js`도 갱신했다. 자동 조작은 `tools/test/walk3d.js`와 `tools/test/full/`의 화면·저장·연출 시험을 갱신했다.

## 점검 기록

- 2D 화면 크기 320×568, 360×560, 390×664, 390×844, 568×320, 844×390에서 열린 시간표와 요셉·여호수아 단서를 확인했다. 요셉 경로는 8~10세로 엔딩과 탐험 일지까지 플레이해 58장을 기록했다.
- 모바일 Chromium에서 두 단일 파일이 320×568, 배율 1로 열리며, 도감이 열린 동안이나 창을 떠난 뒤에는 캐릭터 위치가 바뀌지 않는 것을 실제 입력으로 확인했다. 여섯 크기 모두에서 터치로 두 경로의 단서를 모두 찾았다.
- 글자 대비와 터치 영역, 움직임 줄이기, 글꼴 다운로드 실패 시 읽기, 저장·이어하기 예외 아홉 가지를 통과했다.
- 호렙 연출의 가까이 보기·전체 보기는 세로와 가로를 포함한 아홉 경우가 통과했다. 첫 상영과 재방문 건너뛰기, 창을 숨겼다가 복귀할 때 소리 재개, 움직임 줄이기, 그림을 불러오지 못한 경우의 진행도 통과했다.
- 전체 점검은 해당 기계의 Chromium 사용자 인증서 저장소를 쓸 수 있는 환경에서 실행한다. 한국어 글꼴 서버에 정상 인증서 검증으로 연결했다. 최종 전체 점검 결과는 실행이 끝나는 대로 이 기록에 추가한다.
