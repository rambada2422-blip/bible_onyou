# 바이블 온유 모바일 탐험 개선

2026-11-21 한국시간. 대표 요청으로 당분간 게임 코드는 GPT(Codex)가 맡는다. Claude 총괄이 검토할 브랜치는 `gpt/night-mobile-play`다. 이 브랜치에는 첫 발견 작업과 대기 중이던 2D 작업(`relay/web2d`의 `face3fc`), 호렙 연출과 기기 내 진행 저장 작업(`relay/horeb`)이 함께 들어 있다. 대표 승인 뒤 병합하는 절차는 진행판을 따른다.

## 플레이가 달라진 곳

- **시간표**를 열면 실제로 출발할 수 있는 세 장면을 바로 볼 수 있다. 원래 장면 번호를 유지했고 ‘전체 여정 보기’를 누르면 잠긴 장면까지 나온다. [휴대폰 시간표](사진/야간_열린시간표.png)
- **요셉의 단서**는 바로의 얼굴, 반지를 건네는 손, 금 사슬을 각각 눌러 찾는다. 단서마다 지름 44 CSS 픽셀을 확보했다. 세로 화면에서 하나를 찾고 가로로 돌려도 발견 표시가 남고 다른 두 단서를 그대로 누를 수 있다. [세로 화면](사진/야간_요셉단서.png) · [작은 가로 화면](사진/야간_요셉단서_가로.png)
- **2D 호렙**에서는 도착하자마자 그림 속 양을 직접 눌러 첫 이야기와 장절을 열 수 있다. 어느 양을 눌러도 되고, ‘둘러보기’ 단추로도 같은 대목을 읽는다. [도착 화면](사진/야간_2D호렙_양찾기.png)
- **3D 호렙**에서는 양 떼가 실제 촬영 거리에 들어오면 무리 위에 흰 초점 모서리가 나타나고 사진기 테두리가 밝아진다. 양 떼 사진으로 첫 질문을 열고, 장소를 묻는 두 번째 질문을 해결하면 화면 위에 호렙이라는 이름이 나온다. 마지막 ‘지켜보기’에서 ‘다음으로 가는 관문’으로 바로 갈 수 있다. ‘샤론과 돌아보기’를 선택하면 원래 풀이를 읽을 수 있다. [첫 촬영 화면](사진/야간_첫촬영.png)
- **11~13세 호렙 관문**에서는 여섯 장면 중 마지막 두 장면을 바꿔 놓아도 앞서 고른 번호가 남는다. 번호가 붙은 장면을 눌러 빼고 원하는 차례에 다시 넣는다. 2D와 3D 모두 터치와 키보드로 한 장면씩 고칠 수 있다. [순서를 다시 살피는 화면](사진/야간_호렙순서_다시놓기.png)
- **휴대폰 미리보기**는 기기의 실제 너비로 열린다. 320픽셀 휴대폰에서 단일 파일이 980픽셀 페이지로 축소되던 문제를 고쳤다. 호렙 도감이나 요단 강 수첩을 읽을 때는 탐험 이동이 멈춘다. 창을 떠나면 누르고 있던 방향키와 조이스틱이 풀린다.
- **첫 화면과 한글 글꼴**은 게임과 함께 열린다. 원래 사용한 주아·고운돋움·고운바탕을 게임에 포함했다. 웹에서는 기기 글꼴로 바로 시작할 수 있고, 한 파일 미리보기에는 글꼴까지 들어 있어 인터넷 요청이 없다. 글꼴 네 파일을 함께 담아 미리보기 하나당 약 2.35MiB 커진다. [출처와 사용 조건](../../web/assets/fonts/OFL.txt)
- **2D에서 쉬고 돌아오면** 읽던 대목이나 풀던 관문이 열린다. 요셉의 금 사슬을 찾고 나갔다가 돌아오면 찾은 표시가 남고, 나머지 두 단서만 찾으면 된다. 정답을 고른 뒤라면 다음 구간이 열린다. [다시 연 요셉 장면](사진/야간_요셉단서_이어하기.png)
- **3D에서 이어서 탐험하기**를 누르면 같은 기기·같은 브라우저 주소에서 주운 부품과 사진을 가지고 돌아온다. 양 떼를 촬영하기 전에 닫으면 양을 찾는 곳에서, 촬영한 뒤에 닫으면 첫 질문에서 이어진다. 도감 사진과 소리 설정도 복구한다. 아지트에서 고른 깃발 색과 획득한 탐험 모자의 착용 상태도 기억한다. 자료를 저장할 수 없는 기기에서도 탐험을 시작할 수 있다. [복귀 화면](사진/일감가6.png) · [저장 작업 기록](일감가6_GPT.md)
- 호렙 질문을 푸는 동안 소리 단추는 화면 위쪽에 있다. 568×320 휴대폰에서는 걷는 법이 탐험 목표를 가려 둘 다 읽기 어려웠다. 조작 안내를 오른쪽에 둬 두 문장을 함께 읽을 수 있다. 말씀 조각을 읽을 때는 직전에 완료한 목표와 글 뒤에 가려져 있던 사진기를 접고, 계속 탐험하면 탐험 도구가 다시 나타난다. [가로 화면 수정 전](사진/야간_3D가로_수정전.png) · [수정 후](사진/야간_3D가로_수정후.png)

- **3D에서 푼 관문과 내 탐험 기록**도 이어진다. 호렙 관문이나 요단 강 추리에서 답을 맞히고 바로 닫으면 다음 물음이 열린다. 마지막 관문을 맞혔으면 마무리 화면이 열린다. 14~19세 탐험대가 마무리에 쓴 글은 같은 기기에 남는다. 타임머신으로 귀환한 뒤 ‘내 탐험 기록’을 열면 다시 읽을 수 있다.

## 아직 살펴볼 재미 요소

2D에서 처음 풀 문제에 도착하기 전까지 애굽에서는 이야기 네 대목, 떨기나무에서는 일곱 대목, 구름 기둥에서는 다섯 대목을 순서대로 넘긴다. 요셉과 여호수아 길도 이야기 네 대목 뒤에 첫 단서 활동이 온다. 여기서 독자가 직접 하는 일은 주로 ‘다음’을 누르는 것이다. 떨기나무 장면에는 양을 직접 눌러 기존 첫 이야기를 여는 방식을 적용했다. 어린이가 그림을 살펴보는지, 글을 넘기는 속도만 바뀌는지를 보고 다른 장면에도 적용할지 결정할 수 있다.

아이와 처음 해 볼 때는 호렙 착륙 뒤 어른이 촬영법을 먼저 알려 주기 전에 스스로 양 떼에 다가가 사진을 찍는지, 2D 떨기나무에서 어느 대목부터 글을 읽기 전에 ‘다음’을 누르는지 보면 된다. 이번 기록은 모바일 브라우저 조작으로 확인한 것이며 실제 어린이 플레이 관찰은 남아 있다.

## 수정한 파일

2D는 `web/js/app.js`, `app-scene.js`, `app-questions.js`, `art.js`, `web/css/app.css`, `web/assets/bg/alt03.meta.json`을 고쳤다. 3D는 `web3d/js/`의 `game-story.js`, `game-travel.js`, `game-exploration.js`, `game-controls.js`, `game-jordan.js`, `game-loop.js`, `game-ui.js`, `game-save.js`와 `web3d/css/game.css`를 고쳤다. 두 묶음 도구 `tools/build.js`, `tools/build3d.js`와 시험 서버 `tools/test/game-server.js`, 2D와 3D의 `index.html`도 갱신했다. 자동 조작은 `tools/test/walk3d.js`와 `tools/test/full/`의 화면·저장·연출 시험을 갱신했다.

## 점검 기록

- 2D 화면 크기 320×568, 360×560, 390×664, 390×844, 568×320, 844×390에서 열린 시간표와 요셉·여호수아 단서를 확인했다. 요셉과 여호수아 길을 각각 세 연령으로 골라 엔딩과 탐험 일지까지 여섯 번 플레이했다. 각 길에서 연령 순서대로 화면 58장, 62장, 66장을 기록했다.
- 모바일 Chromium에서 두 단일 파일이 320×568, 배율 1로 열리며, 도감이 열린 동안이나 창을 떠난 뒤에는 캐릭터 위치가 바뀌지 않는 것을 실제 입력으로 확인했다. 여섯 크기 모두에서 터치로 두 경로의 단서를 모두 찾았다.
- 호렙 착륙 자리에서 터치 조이스틱을 밀어 세로 320×568과 가로 844×390에서 각각 양 떼까지 직접 걸었다. 초점이 생긴 자리에서 도감을 열고 닫은 뒤 촬영해 첫 질문이 나왔다.
- 2D·3D 웹 원본과 단일 파일 네 진입점 모두 외부 요청 0건으로 글꼴 네 개를 읽었다. 웹 원본은 글꼴 스타일 응답을 보류한 상태에서도 시작 단추가 작동했다. 게임 글꼴을 일부러 차단했을 때도 세 화면 크기에서 기기 글꼴로 읽고 진행했다.
- 글자 대비와 터치 영역, 움직임 줄이기, 글꼴 다운로드 실패 시 읽기, 기존 2D 저장 예외를 통과했다. 시간 이동 도중 닫기, 장면 중간 이어하기, 깨진 위치에서 기존 일지 보존, 오래된 탭의 덮어쓰기 방지까지 2D 저장 시험 11가지를 통과했다.
- 3D 메뉴·목적지·착륙·도움말·도감·탐지기·말씀 조각·지켜보기·관문·엔딩을 휴대폰 화면 여섯 크기로 열었다. 샤론 소개를 접고 편 상태까지 66장이다. 스크롤 가능한 글, 누를 수 있는 단추, 목표와 이동 안내의 겹침을 확인했다.
- 호렙 순서 관문에서 마지막 두 장면을 바꿔 놓았을 때 종전에는 선택한 번호가 6개에서 0개로 줄었다. 수정 후 2D·3D 각각 웹 원본과 한 파일에서 선택을 빼고 다시 넣어 다음 관문까지 갔다. 3D 호렙의 다음 관문과 요단의 다음 추리에서 재개하고, 직접 쓴 두 줄 기록을 새로고침·타임머신 귀환 뒤에 읽고 새 탐험에서 비우는 것도 확인했다.
- 3D에서 직접 주운 첫 부품과 양 사진을 새로고침 후 다시 확인했다. 호렙 뒤쪽 다섯 구간과 요단 강 수첩·추리·결과의 복원, 저장 공간 부족, 오래된 탭에서 다시 저장을 시도하는 경우, 손상된 저장, 기기 저장 차단 시험도 통과했다. 공간이 다시 생긴 뒤 호렙과 요단 강에서 이미 찾은 대상을 한 번 더 찍으면 도감 개수나 보상을 늘리지 않고 빈 사진을 복구했다.
- 호렙 연출의 가까이 보기·전체 보기는 세로와 가로를 포함한 아홉 경우가 통과했다. 첫 상영과 재방문 건너뛰기, 창을 숨겼다가 복귀할 때 소리 재개, 움직임 줄이기, 그림을 불러오지 못한 경우의 진행도 통과했다. 연령·화면·움직임 줄이기 13가지 조건의 화면 130장에서 그림 교체와 자막·무음 구간도 확인했다.
- 전체 점검은 해당 기계의 Chromium 사용자 인증서 저장소를 쓸 수 있는 환경에서 실행한다. 한국어 글꼴 서버에 정상 인증서 검증으로 연결했다. 호렙의 세 연령, 요단 강 복귀를 포함한 첫 묶음과 작은 가로 화면·지연 글꼴 수정본(`1827fa5`)이 각각 전체 8/8을 통과했다. 이후 3D 저장을 합친 검토본에서는 외부 글꼴 응답 한 건에 교차 출처 허용이 빠져 2D 점검이 실패했다. 여러 모바일 시험을 함께 돌리면서 호렙 세 연령의 마지막 관문에서 20분 제한에 걸려 이 실행은 6/8이었다. 요단 강 복귀는 통과했다. 위의 자체 글꼴 수정과 2D 장면 복귀를 합치고 가로 화면 안내와 목적지 이동 중 복귀까지 정리한 뒤, 2D 호렙에서 양을 찾는 방식까지 포함한 `555dd84`에서 다시 점검한다.
