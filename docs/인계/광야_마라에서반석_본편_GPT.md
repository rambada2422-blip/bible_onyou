# 광야 본편 · 마라에서 반석까지

## 1. 핵심 재미 루프와 플레이 위치

작업 브랜치는 `gpt/exodus-journey`이고, 플레이 주소는 기존 소유자 전용 Sites 버전 16이다.

홍해 일지에서 **마라로 떠나기**를 누르면 마라 → 엘림 → 만나 → 반석 순서로 답사한다. 각 장소는 새로고침하면 걷던 칸, 부른 동료, 장비 눈금, 찾은 지점에서 이어진다. 탐험 입구·시간표·광야 수첩에서도 들어간다. [광야 답사 시작](https://bible-onyou-moses-and-pharaoh.taupemast4.chatgpt.site/#wilderness)

| 장소 | 아이가 풍경에서 하는 일 | 사건의 앞뒤를 읽는 곳 |
|---|---|---|
| 마라 | 물가에 선 사람들과 물결 속 나무를 찾아 표시한다. | 사흘 동안 물을 얻지 못한 때부터 물이 달아진 경위까지 출 15:22–26 |
| 엘림 | 샘에서 종려나무를 거쳐 물가의 장막을 찾아간다. | 샘·종려나무와 그곳에 장막을 친 기록인 출 15:27 |
| 만나 | 이슬이 있던 자리의 기록을 살피고, 알갱이 → 거두는 사람 → 그릇 순으로 관찰한다. | 저녁과 아침, 양식을 거두는 기준과 실제 결과인 출 16:13–18 |
| 반석 | 마른 진영을 살핀 뒤 호렙의 물길을 거슬러 물이 나오는 바위를 찾는다. | 르비딤에서 물을 찾던 때와 모세가 호렙에서 행한 일을 담은 출 17:1–7. 요청된 출 17:5–6을 포함한다. |

**반석 한 판의 시간 흐름.** 시간은 처음 온 아이가 관찰하고 말씀을 읽는 경우의 설계 목표다. 실제 아이의 소요 시간은 측정 전이다. 익숙한 플레이어는 기다림 없이 진행한다.

| 목표 시간 | 아이 손에 맡기는 것 | 눈과 귀에 돌아오는 것 |
|---|---|---|
| 0:00–0:30 | 세 친구가 보이는 진영에서 표지를 누르거나 화살표로 한 칸 이동한다. | 첫 목표에 장소와 거리가 뜬다. 선두가 한 걸음 들썩이고 흙먼지와 발소리가 난다. |
| 0:30–1:10 | 최온을 불러 자갈길을 가까이 살핀다. 처음 기록의 장절을 눌러 사람들이 왜 물을 찾았는지 읽는다. | 접사 도구와 동료의 표정, 발견음이 반응한다. 원문은 두루마리 안에 그대로 남는다. |
| 1:10–2:00 | 휴와 관찰 장비의 방향을 조절한다. 확대창과 기준선을 보고 고정한다. | 눈금을 움직일 때마다 관찰창이 바뀐다. 장비가 준비되면 뒤의 기록을 볼 수 있다. |
| 2:00–3:20 | 온우를 부르고 물길을 끝에서부터 거슬러 굽이와 바위를 지도에 표시한다. | 찾은 위치가 하나씩 수첩에 남는다. 다른 곳을 누르면 다음으로 찾아볼 지점을 알려준다. |
| 3:20–4:00 | 말씀 기록과 현장 기록을 대조하고 맞는 이름표를 붙인다. | 즉시 짧은 완성음과 함께 관찰 카드·말씀 인장·고정 선반 기념품이 들어온다. |
| 4:00–5:00 | 처음·나중 풍경을 번갈아 보거나 관측대에서 인장을 열고, 시내산 수첩으로 이동한다. | 인장은 출 17:6을 펼친다. 답사 수에 따라 아지트의 전원등·정비대·선반 조명·항법 콘솔이 차례로 켜진다. |

## 2. 구현 우선순위와 확인 기준

| 단계 | 구현 순서 | 확인한 기준 |
|---|---|---|
| P0 | 홍해 → 광야 → 시내산 연결, 한 칸 이동, 저장, 원문 | 방향키 한 번에 한 칸 이동한다. 회전·새로고침 뒤 목표·위치·장비가 유지된다. 묶은 배포본과 원본 웹에서 4개 장소를 통과하고 수첩을 다시 열었다. |
| P1 | 세 동료 호출, 확대창, 풍경에서 지점 찾기, 연령별 힌트, 표정·이동·효과음 | 동료 셋이 풍경에 보인다. 휴의 잘못된 눈금, 온우의 다른 관찰 지점은 재시도할 수 있다. 소리를 끄고도 끝까지 간다. 8세 모드는 10/20/30초, 13세는 15/30/45초, 17세는 25초 뒤 첫 혼잣말만 자동으로 뜬다. 17세의 나머지 두 단계는 **동료에게 묻기**로 여는 것을 확인했다. |
| P2 | 관찰 카드·인장·고정 기념품, 아지트 복구, 기존 수첩 | 네 장소를 재답사해도 기념품이 늘지 않는다. 게임 일지에서 선반을 열고 인장을 눌러 해당 절로 이동한다. 엘림·만나·반석의 기록은 기존 수첩에 들어가고 조각판 최고 기록은 따로 유지된다. |

320×480부터 1280×720까지 여덟 크기에서 세 연령 모드와 동료 셋의 말풍선이 두 줄 안에 들어가는지, 버튼 높이가 44px 이상인지, 가로로 잘리는지 확인했다. 새로고침한 뒤에도 19개 절이 원자료와 일치하고 인장이 정확한 절에 초점을 주는지 자동 검사한다. 배포 파일을 열고 네트워크를 끊은 상태로도 네 장소와 시내산 수첩까지 조작했다. 이전 장면을 하지 않고 광야부터 시작한 저장에서도 네 번째 보상까지 복구등 두 개가 켜진다. 실제 아이와의 재미·난도 평가와 목회자 감수는 남아 있다.

## 3. 통합 JSON 데이터 구조 초안과 본문 출처

아래는 **반석 한 판을 배정할 때** 사용하는 데이터 예시다. 실제 전체 데이터에는 네 장소의 지도 좌표, 장비 눈금, 인장, 고정 슬롯, 아홉 가지 동료 대사, 음 높이, 연령별 힌트 시간, 복구 기준이 들어 있다. 편집 원본은 [wilderness.json](../../web/data/wilderness.json) 한 곳이다. 빌드가 원본 웹과 오프라인 묶음에서 사용할 스크립트를 만든다.

```json
{
  "stage": {
    "id": "rock",
    "sceneId": "BO-043",
    "range": "17:1–7",
    "evidence": [["물이 없던 진영", "17:1"], ["호렙 반석의 물", "17:6"]],
    "trail": [["아래쪽 물길", 31, 85], ["굽이진 물길", 50, 69], ["물이 나오는 바위", 58, 52]],
    "card": "반석 아래 물길",
    "seal": "17:6",
    "pin": "물방울 배지",
    "notes": ["바위에서 물이 흘러왔어.", "자갈 사이의 물길을 따라 바위 쪽을 살펴봤어.", "백성이 물을 찾던 때와 호렙 반석의 기록을 출 17:1–7에서 대조했어."]
  },
  "crew": [{
    "id": "onwoo",
    "name": "온우",
    "age": 17,
    "role": "마음 통역가",
    "lines": ["우리가 본 풍경의 이름표를 찾자.", "우리가 본 풍경을 다시 떠올려. 같은 이름표를 기록에 붙여 보자.", "우리가 본 풍경의 이름표를 찾자. 두루마리를 펴서 기록과 대조해 봐."]
  }],
  "hintSteps": ["혼잣말", "동료 아이콘", "관찰 대상"],
  "hintModes": [{"age": 8, "seconds": [10, 20, 30]}, {"age": 13, "seconds": [15, 30, 45]}, {"age": 17, "seconds": [25]}],
  "sounds": {"sand": [94], "dirt": [126], "stone": [310], "wood": [185], "tap": [410], "talk": [535, 480], "found": [494, 622, 740], "clear": [392, 494, 587, 784]},
  "restoration": [{"count": 1, "name": "전원등"}, {"count": 3, "name": "정비대"}, {"count": 6, "name": "기록 선반 조명"}, {"count": 10, "name": "항법 콘솔"}]
}
```

성경 본문은 출 15:22–27, 16:13–18, 17:1–7의 19절이다. 원자료가 **Public Domain**으로 표시한 **개역성경(KorRV)**을 사용했다. 고정 리비전의 CSV에서 절 문자열을 대조했고 테스트는 이 문자열 묶음의 SHA-256을 확인한다. 배지에는 장절만 저장하고, 누르면 같은 읽기 전용 두루마리를 연다. 세 친구의 안내는 『탐험대 이야기』로 표시한다. 장비 조작은 탐험대의 기록 시점과 돋보기만 바꾼다. [원문·사용 근거](https://github.com/scrollmapper/bible_databases/tree/59b18c5af5845728c275d5b7178ad0d024172b1f/sources/ko/KorRV)

기존 수첩의 현장 설명과 대표의 216장면 제작표에서 BO-190·041·042·043의 장절과 관찰 대상을 확인했다. 장면은 게임에서 2D로 그린다. 그림을 누르는 물음은 탐험대가 실제로 본 사물의 위치와 관찰 이름표에 한한다.

## 4. 개발 지시용 작업 카드와 다음 미구현 지점

한 에이전트는 한 카드의 쓰기 파일만 소유한다. 아래 역할은 후속 제작 때 배정하는 단위다. 창세기·다윗 담당자의 기존 파일을 사용하지 않는다.

| 카드 | 담당 범위와 쓰기 파일 | 입력 → 완료 조건 |
|---|---|---|
| 1 · 원문과 장면 근거 | Claude 원고·독립 검토, GPT는 확인된 원문만 연결. 이번 원문 모듈은 `web/js/wilderness-scripture.js` | 원문 출처·판본·허용 근거 및 검토된 원고 → 해당 절을 원문과 글자까지 대조 |
| 2 · 장소 데이터 | `web/data/wilderness.json` | 카드 1의 범위 → 좌표·두 기록·세 가지 보상을 한 장소 ID로 연결 |
| 3 · 풍경과 손맛 | `web/js/wilderness-landscape.js`, `web/js/wilderness-feel.js` | 카드 2의 ID·좌표 → 처음/나중 그림과 네 재질 발소리, 세 표정, 무음으로 조작 |
| 4 · 플레이와 저장 | `web/js/wilderness.js`, `web/css/wilderness.css` | 카드 2의 데이터 → 세 동료 호출, 중간 새로고침, 재답사와 선반 확인 |
| 5 · 본편과 수첩 연결 | `web/js/app.js`, `web/js/red-sea.js`, `web/js/exodus-trail.js`, `web/index.html`, `tools/build.js` | 카드 4의 진입 함수 → 홍해에서 진입, 시내산 수첩으로 복귀, 예전 저장 보존. 생성 파일 `web/js/wilderness-data.js`는 빌드로 갱신 |
| 6 · 실제 조작과 인계 | `tools/test/wilderness.js`, `tools/check.js`, 이번 인계·사진 | 배포할 묶음 → 터치·키보드·회전·복원·인장을 확인하고 전체 점검의 마지막 두 줄을 남김 |

다음 미구현 본편은 **르비딤에서 아말렉과 맞선 일(출 17:8–16)**, 이어 **이드로의 방문(출 18장)**이다. 확인한 main·작업 브랜치에서 두 사건의 검토된 개별 플레이 원고를 찾지 못했다. 원고와 독립 검토가 들어오면 이 순서로 진행한다. 시내산·성막의 기존 조각 수첩은 계속 이용할 수 있다.

전체 점검에서 분담 확인 대상으로 표시하는 `web/js/content.js`의 수정은 기본 캐릭터 선택에 쓰이는 최온과 온우의 나이 두 값이다. 각각 대표가 지정한 8세와 17세로 맞췄다. 전체 점검 결과는 아래 실행 로그 끝 두 줄이다.

```text
점검 종류: 전체 · 통과 11/12 · 확인 필요 1
점검 결과: 합격 (확인 필요 1건)
```
