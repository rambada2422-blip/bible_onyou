# 탐험 중 본 재앙을 다시 보기

브랜치 `gpt/exodus-field-notes`는 본문·그림 검토 브랜치의 e4a604b에서 시작했다. 재앙 화면과 유월절 준비 화면 위의 **본 재앙 보기**에서 지금까지 채운 기록을 최근 순으로 펼친다. 각 기록에는 해당 그림과 장절·요약이 나온다. 두 곳을 관찰한 재앙에는 두 그림과 장소 이름이 함께 나온다. 마지막 밤과 출발은 기존 흐름대로 읽는다.

기록은 현재 진행도로 즉석에서 만든다. 네 번째 재앙을 한 곳만 관찰했을 때는 앞의 세 기록만 열리며, 돌아가면 보던 장소에서 두 번째 장소를 마저 살펴볼 수 있다. 유월절 방에서도 열어 두었던 단서와 찾은 단서 수가 유지된다.

변경 파일은 web/js/passover.js, web/css/app.css, tools/test/full/passover.js이다. 모바일 검증에서는 세 연령으로 일반 웹과 단일 파일 미리보기를 각각 완주하고, 네 번째 재앙과 유월절 방에서 기록을 열어 저장 상태가 같은지 대조했다. 버튼과 Escape 키로 닫은 뒤의 키보드 초점도 확인했다. [실제 화면](사진/재앙_탐험중_다시보기.png)

구현 커밋은 `c3b676e`이다. 공유 미리보기에서 키보드로 기록을 펼치고 새로 고친 뒤 같은 탐험 지점으로 복원되는 것을 확인했다. 전체 점검 결과는 다음과 같다.

```
점검 종류: 전체 · 통과 8/8
점검 결과: 합격
```
