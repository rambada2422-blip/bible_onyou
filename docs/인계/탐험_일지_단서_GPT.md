# 탐험을 마친 뒤 다시 보는 그림 단서

2026년 11월 21일. GPT(Codex)가 구현한 게임 코드는 `7d84634`이고 검토 브랜치는 `gpt/night-mobile-play`다.

요셉의 그림에서 금 사슬을 발견하고 호렙으로 돌아온 뒤 일지를 열어 보니, 요셉의 말씀 카드만 남아 있었다. 이제 그림에서 단서를 누르는 순간 그 발견을 일지에 보관한다. 같은 단서를 다시 찾아도 기록은 하나이고, 나중에 다른 단서를 찾으면 해당 인물의 기록에 더해진다.

## 게임에서 확인하는 방법

1. 요셉의 도착 그림에서 금 사슬을 누르고 탐험을 마친다. 말씀 카드를 받으면 **단서 일지 보기**를 누른다. 요셉의 기록이 펼쳐져 금 사슬에 대한 설명과 창세기 41장 42절 표시를 볼 수 있다. 왼쪽 위 뒤로 가기 화살표를 누르면 같은 말씀 카드로 돌아온다. [요셉의 말씀 카드 화면](사진/말씀카드_단서일지.png)
2. **모세가 있는 곳으로**를 눌러 호렙에 돌아간다. 이후에도 **시간표 → 일지 → 요셉**에서 금 사슬을 볼 수 있다. 여호수아의 그림에서 언약궤를 발견하면 여호수아의 이름 아래 모인다. 시간표의 일지 숫자는 찾은 단서, 받은 말씀 카드, 직접 적어 둔 글의 합계다. [두 인물의 기록을 펼친 일지](사진/탐험일지_두인물_단서.png)

## 저장과 확인 범위

- 연령을 바꾸거나 게임을 다시 열어도 수집한 단서는 남는다. 같은 탐험을 다시 시작하면 그림을 새로 살펴볼 수 있다. **처음부터 다시**는 다른 탐험 기록과 함께 수집한 단서도 지운다.
- 예전 저장에 진행 중이거나 잠시 멈춘 탐험의 단서가 있으면 일지로 옮긴다. 이미 끝낸 탐험에 말씀 카드만 남아 있으면 어떤 단서를 눌렀는지 알 수 없어 그 카드만 표시한다.
- 웹 원본과 한 파일 미리보기에서 각각 390×844, 568×320, 320×568 화면으로 두 인물의 기록, 다시 발견, 새로고침과 초기화를 확인했다. 키보드로 각 인물의 기록을 펼치고 말씀 카드로 돌아갈 때 단서 일지 단추에 초점이 돌아오는 것도 확인했다.
- 기존 저장 시험 13가지, 휴대폰 화면 배치 6가지, 누르는 영역·이름·글자 대비 점검 3가지가 통과했다. 먼저 찾은 단서가 0~3개일 때 나이에 맞는 추리를 계속할 수 있는지도 두 인물과 두 실행 방식에서 모두 20번 확인했다.
- 공유 미리보기에서 요셉과 여호수아를 세 연령 단계로 한 번씩 플레이했다. 여섯 번 모두 애굽에서 출발해 말씀 카드의 단서 일지를 열고, 호렙과 광야를 지나 마지막 일지에서 금 사슬 또는 언약궤를 확인했다. 14~19세에서는 일지를 연 채 새로고침한 뒤 같은 말씀 카드에서 이어 갔다.
- 브라우저 저장이 막힌 경우에도 현재 탭에서 금 사슬을 찾아 일지를 열 수 있었다. 두 탭에서 같이 열었을 때 한쪽이 처음부터 다시 시작하면 오래된 탭이 지운 단서를 되살리지 않는 것도 확인했다.
