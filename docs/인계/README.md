# 인계 파일

총괄(Claude 29만 원 계정)이 아닌 세션이 일을 끝내거나 멈출 때 여기에 새 파일 하나를 만든다. 진행판은 고치지 않는다.

파일 이름: `카드이름_AI이름.md` (예: `카드A_GPT.md`). 같은 카드를 이어서 하면 같은 파일 맨 위에 덧붙인다.

적을 것:

- 날짜와 시각, AI 이름, 브랜치 이름
- 한 일 (끝냈는지, 어디까지 했는지)
- 바뀐 파일 목록
- 점검: `node tools/check.js --full` 결과의 마지막 두 줄. 못 돌렸으면 `자동 조작 미실행`
- 남은 일, 막힌 것, 대표에게 물을 것

화면 사진을 남겨야 하는 카드는 사진 한두 장을 `사진/` 폴더에 `카드이름.png`로 복사해 함께 커밋한다. `dist/` 폴더는 저장소에 올라가지 않는다.

끝나면 커밋하고 푸시한 뒤 대표에게 브랜치 이름을 알려 준다. main에는 합치지 않는다. 합치기는 총괄이 한다.
