## 한 일

판 번호가 맞아도 나이 단계, 진행 목록, 말씀 카드, 탐험 기록의 모양이 깨져 있으면 이어서 하기가 먼저 표시되는 것을 재현했다. 저장을 읽을 때 나이와 인물, 진행·카드·기록의 모양을 검사하게 했다. 읽을 수 없는 값은 메모리에서 처음 상태로 시작한다. 저장 키와 기록 항목은 기존 형식을 쓴다.

격리한 크롬에서 가짜 저장 값으로 아홉 가지를 실행했다. 끊어진 값, 옛 판 번호, 같은 판의 깨진 값 네 가지, 저장소 열기 차단, 저장 용량 부족, 정상 이어서 하기와 처음부터 다시가 모두 통과했다. 정상 저장에서는 첫 장면 완료·말씀 카드·가짜 탐험 기록이 새로고침 뒤에 복원됐고, 처음부터 다시 고른 뒤에는 새로고침해도 새 탐험 상태였다.

게임을 열기만 한 동안 시험용 원래 저장 값이 그대로인지 확인했다. 저장소 접근과 쓰기를 막은 두 시험에서도 첫 장면의 물음과 기록을 거쳐 다음 목적지까지 진행했다.

기존 자동 조작으로 8~10세와 14~19세 탐험도 함께 확인했다. 두 나이 단계 모두 화면 오류 없이 일지와 길잡이 화면까지 열었다.

```powershell
node tools/test/full/save2d.js dist/save2d
node tools/check.js --full
```
