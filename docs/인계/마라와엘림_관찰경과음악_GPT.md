# 마라와 엘림의 현장 관찰경과 음악

기능 커밋은 [84b5650](https://github.com/rambada2422-blip/bible_onyou/commit/84b5650f3e38d95630dae5de22d78a96176f8ae9)이다. 작업을 시작할 때 원격 main은 30763d9, gpt/exodus-journey는 e5aea7c였다. 마라·엘림·만나·안식일·반석과 시내산의 기존 본편, 수첩, 인장을 이어 썼다.

기존 소유자 전용 게임의 24판 배포가 성공했다. [마라에서 플레이](https://bible-onyou-moses-and-pharaoh.taupemast4.chatgpt.site/?v=24#marah) · [엘림에서 플레이](https://bible-onyou-moses-and-pharaoh.taupemast4.chatgpt.site/?v=24#elim)

## 직접 해 볼 길

홍해 일지에서 **마라로 떠나기**를 누르거나 마라로 바로 들어간다. 풍경 아래에서 **사흘 길 → 물가의 백성 → 물결 속 나무**를 누르면 세 친구의 관찰경으로 사흘 동안 물을 얻지 못한 길, 마시지 못한 물가에 멈춘 사람들, 나무 주위로 번진 파문을 확대해 본다. 각 시점에서 두루마리를 열면 출 15:22, 23, 25의 해당 절에 초점이 간다. 물이 달아진 경위는 출 15:25 원문에서 확인한다.

엘림에서는 **물샘 → 종려 그늘 → 물가의 장막**을 차례로 살핀다. 먼저 온 사람들 뒤로 그늘과 물가가 펼쳐지고, 나중 기록에는 샘 가까이에 자리 잡은 장막과 쉬는 사람들이 보인다. 샘과 종려의 수, 장막을 친 위치는 출 15:27 두루마리에서 확인한다. 게임의 조작은 탐험대의 관찰 대상과 장비를 바꾼다. [마라 관찰경](사진/마라_물이달아진뒤_관찰경.png) · [엘림 답사 화면](사진/엘림_샘과장막_답사.png)

## 소리와 자료

| 장면 | 귀로 구별하는 시점 |
| --- | --- |
| 마라 사흘 길 | 비어 있는 박 사이로 두 음씩 들리는 현과 성긴 목관. 첫 조작에서 시작한다. |
| 마시지 못한 물가 | 발걸음이 물가 표지에 닿거나 관찰경이 백성을 향하면 박이 끊기고 가까운 두 음이 겹친다. |
| 물이 달아진 뒤 | 첫 파문부터 밝은 현이 차례로 올라간다. 관찰경에서 나무를 선택하면 물방울 소리도 함께 난다. |
| 엘림의 샘과 종려 | 양옆에서 대답하는 세 박자의 발현음. 샘에는 물방울, 종려에는 짧은 잎 스침이 들린다. |
| 엘림 물가의 장막 | 걸음의 잔박이 멎고 긴 관악 선율이 이어진다. 앞 기록으로 돌아가면 샘의 음악이 다시 들린다. |

풍경 네 장은 자체 2D 그림이며 넓은 길·중경의 행렬·가까이 다가온 가족을 한 화폭에 그렸다. 처음과 나중 풍경 사이에서 마라의 물가 자세와 엘림의 장막 유무가 바뀐다. 현장 그림의 물결에는 동작 줄이기 설정이 적용된다. 탐험대 렌즈는 여섯 위치를 확대한다. 그림에 등장하는 인물은 백성과 탐험대 세 친구다. 대표 제작표 BO-190·041의 출 15:23–25, 15:27과 관찰 대상을 사용했다. 게임에는 확인된 개역성경(KorRV) 읽기 전용 두루마리와 기존 탐험대 대사가 들어 있다. 현장 캡션은 기존 관찰 이름과 근거에서 가져왔다. [판본과 사용 근거](광야_마라에서반석_본편_GPT.md)

음악 다섯 곡과 추가한 물방울·잎 소리를 직접 합성했다. 음색 원본은 제작 코드의 파형과 필터다. 두루마리에서는 음악과 환경음이 멎고, 닫으면 보고 있던 풍경의 음악이 돌아온다. [음악 제작 코드](../../tools/art-src/wilderness-score.py)

## 바뀐 파일과 실제 점검

- 관찰 지점과 자르는 범위는 [wilderness.json](../../web/data/wilderness.json)에 있고 빌드가 wilderness-data.js에 반영한다. 시점의 배치는 [wilderness-landscape.js](../../web/js/wilderness-landscape.js), 동작음은 [wilderness-feel.js](../../web/js/wilderness-feel.js)에 있다. 음악은 web/assets/audio/score/wild-*.mp3 다섯 파일이다.
- 관찰경·말씀 복귀·장비·저장은 [wilderness.js](../../web/js/wilderness.js), 장면 진입은 [app.js](../../web/js/app.js), 배치는 [wilderness.css](../../web/css/wilderness.css), 재생의 일시 정지는 [scene-music.js](../../web/js/scene-music.js)에 있다.
- 원본 웹과 단일 HTML에서 마라와 엘림의 시점을 앞뒤로 눌렀다. 브라우저에서 디코딩한 실제 출력으로 다섯 곡을 구별했다. 음악 끄기와 기존 소리 전체 끄기의 저장, 창 비활성화·복귀, 탐험 입구로 나갈 때 종료를 확인했다. 두루마리에서 새로고침한 뒤에도 같은 절이 열리고 닫으면 같은 확대 시점으로 돌아왔다. tools/test/scene-music.js의 측정기를 [광야 관찰경 검사](../../tools/test/wilderness-observation.js)에서도 사용하고 tools/test/wilderness.js에서 실행한다.
- 320×480~1280×720의 여덟 화면과 글자 100%·200%에서 앞뒤 시점과 탐험 도구의 버튼이 겹치거나 가로로 잘리지 않는지 검사했다. 첫 화면의 ‘사흘 길’ 터치에서 관찰경 표시까지 자동 조작으로 0.21초였다. 배포 묶음을 연 뒤 네트워크를 끊고도 엘림의 장막과 해당 말씀을 열었다.
- 배포용 단일 HTML을 확인한 뒤 왕궁 기본 시작 속성만 적용해 비공개 사이트에 올렸다. 검사한 HTML과 배포 보관본이 그 속성 외에 바이트 단위로 일치했다. Sites의 임시 미리보기는 중계 연결 시간 초과였다. 24판의 배포 성공은 Sites에서 확인했다.
- 자체 검증은 Chromium에서 진행했다. 실제 아이의 재미·난이도, 총괄의 연출 검토, 대표의 그림·음악 확인과 목회자 감수는 남아 있다.
