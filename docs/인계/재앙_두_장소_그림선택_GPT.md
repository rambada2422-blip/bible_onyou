# 첫째·넷째·아홉째 재앙의 그림 선택

작업 브랜치는 `gpt/exodus-picture-choices`다. 앞선 본문 검토 반영과 재앙 다시보기 작업을 포함한다. 총괄이 장면 배치와 목회자 감수 P1~P5의 상태를 확인한 뒤 합칠 수 있다.

첫째 재앙을 열면 물고기가 떠 있는 강물과 사람들이 땅을 파는 강가가 함께 보인다. 그림을 원하는 순서로 누르면 그 장소의 큰 그림과 성경 구절, 설명이 열린다. 먼저 본 그림에는 표시가 남고, 안내에는 남은 장소의 이름이 나온다. 같은 방식으로 넷째 재앙에서는 애굽의 집과 고센 땅, 아홉째 재앙에서는 애굽 땅과 이스라엘 자손이 사는 곳을 살펴본다. 세로 화면에서는 그림이 장면 제목 아래에, 짧은 가로 화면에서는 그림이 설명 왼쪽에 놓인다.

[세로 화면](사진/재앙_그림선택_세로.png) · [가로 화면](사진/재앙_그림선택_가로.png)

수정한 게임 파일은 `web/js/passover.js`, `web/css/app.css`다. 회귀 점검은 `tools/test/full/passover.js`에 있다. 그림의 실제 터치 좌표, 두 장소의 선택 순서, 다른 곳을 찾으라는 안내, 키보드 선택, 재입장 뒤 복원, 예전 저장의 호환성을 확인한다. 아이가 두 그림을 비교하고 싶어 하는지는 별도 플레이 관찰 과제다.
