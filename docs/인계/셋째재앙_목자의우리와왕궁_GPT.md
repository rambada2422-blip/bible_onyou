# 셋째 재앙 · 목자의 우리에서 왕궁까지

## 아이가 하는 일

기존 셋째 편에서 360px 화면의 사진 속 조작은 0개였다. 영상을 닫는 순간 요술사들이 바로에게 한 말과 결말이 한 문단에 나왔다. 이번에는 지팡이가 닿은 땅에서 출 8:16을 열고, 기존 예상 문제를 고른 뒤 41초 영상을 본다. 영상의 마지막 프레임에서 휴의 사진첩이 열린다. 왼쪽에서 목자가 어깨를 긁는 모습, 오른쪽에서 염소가 기둥에 몸을 비비는 모습을 짚으면 각각의 사진과 관찰 내용이 남는다. 두 곳은 어느 쪽부터든 찍을 수 있다.

‘왕궁으로 가기’를 누르면 온우와 요술사들의 손짓을 본다. ‘요술사들이 한 일’에서 출 8:18을 펼치고, ‘바로 돌아보기’로 시점을 바꿔 출 8:19에서 요술사들이 인정한 일과 바로가 듣지 않은 결말을 읽는다. 두 기록을 확인하면 탐험 일지에 말씀 인장이 남는다. 기존 감수본과 퀴즈·낭독을 그대로 사용했다. 말씀 두루마리에 쓰인 개역성경 KorRV 출 8:16–19 네 절은 고정된 배포본 CSV와 대조했다. [판본 출처](https://github.com/scrollmapper/bible_databases/blob/59b18c5af5845728c275d5b7178ad0d024172b1f/formats/csv/KorRV.csv)

## 그림과 소리

목자·염소, 요술사들의 사진과 관찰 문구는 기존 열 재앙 관찰 게임(`ff4f769`)에서 가져왔다. 첫 땅바닥과 마지막 바로의 얼굴은 프로젝트가 보관한 셋째 영상(`d46850e`, `videos/exodus-palace/03.mp4`)의 0.25초·36초 화면에서 자막을 피해 잘랐다. 박힌 지팡이나 성경 속 사건의 진행은 아이가 조작하는 대상과 구분했다.

흙을 살피는 입구는 고요하다. 영상이 끝나 우리로 시선이 바뀌면 낮은 현과 좌우로 스치는 솔질 소리가 다섯 박 단위로 되풀이된다. 사진을 찍을 때는 짧은 셔터음으로 발견을 알린다. 왕궁에 들어가면 기존 왕궁 곡으로 바뀌고 바로 쪽으로 돌아서면 그 곡이 멎는다. 출 8:19의 반응을 듣고 읽을 자리다. 요술사들 쪽으로 다시 돌아오면 왕궁 곡도 돌아온다. 영상 자체 소리, 낭독, 일지, 두루마리와 겹치는 동안 배경음악은 쉰다. 우리 곡 `palace-dust-pen.mp3`는 `tools/art-src/palace-dust-score.py`의 프로젝트 자체 합성음으로 다시 만들 수 있다. 20초를 두 바퀴 이어 디코딩했다.

## 실제 조작 검증

- Chromium에서 저장소 원본과 단일 파일판을 플레이했다. 첫 30초 안에 흙을 짚어 16절을 읽었다. 연속 재생한 영상에서 9초 221프레임, 22초 533프레임, 35초 845프레임을 확인했고, 마지막에 목자의 우리로 넘어갔다. 다른 재생에서는 영상 중 새로고침하고 저장된 시각에서 재개했다.
- 목자만 찍고 새로고침한 뒤에도 사진 한 장이 남았다. 키보드로 염소까지 찍으면 두 장이 됐다. 사진에서 왕궁으로 넘어가는 버튼과 영상 반복 버튼은 작은 화면에서도 한 줄에서 구별된다. 출 8:18·19의 초점, 두 시점 왕복과 새로고침, 일지 인장, 음악 끄기·복원, 낭독·화면 전환 때의 음악 정지를 확인했다.
- 320×568, 360×640, 390×844, 568×320, 740×360, 844×390, 768×1024, 1280×720에서 글자 150%로 사진 두 곳을 터치하고 왕궁의 원문을 열었다. 기존 왕궁 진행 중 셋째 편 링크에 들어가도 ‘하던 재앙으로 돌아가기’가 앞선 위치를 복원했다. 영상 오류 시 ‘우리 사진으로 확인하기’로 같은 놀이를 이어 갔다.
- 게임 변경은 `81093c0`이다. `web/js/palace-dust.js`가 우리·왕궁과 원문을 담당하고 `palace.js`·`palace-watch.js`·`app.js`가 영상·일지·저장을 연결한다. 회귀 검사는 `tools/test/full/palace-dust.js`다. 어린이·대표 플레이와 총괄·목회자의 최종 감수는 남아 있다.

## 다음 현장

개구리 편의 마지막 퀴즈에서 ‘다음 재앙으로’를 누르면 셋째 편에 들어간다. 셋째 편 왕궁의 ‘다음 재앙으로’는 네 번째 편 **왕궁까지 들어온 파리 떼**(출 8:20–32)를 연다. 애굽의 집과 고센에서 백성이 겪은 차이, 재앙이 거두어진 뒤의 바로를 살필 차례다. 원격의 1인칭 홍해 원정 변경(`9170bd6`)을 포함한 상태에서 작업했다. 아말렉(출 17:8–16), 이드로(출 18장)의 개별 본편은 독립 검토 원고를 기다린다.

## 비공개 플레이판과 검증 범위

기존 소유자 전용 왕궁 플레이판의 38판 게시 성공을 확인했다. 게시 소스 커밋은 `976ae3b52480d6c8d038b5c84b423a81be7e7db0`이다. 묶음의 파일 38개를 게시 소스와 대조했고, 허브에서 연결되는 기존 원정 단일 파일도 포함했다. 관리형 미리보기는 4173 포트 중계가 시간 초과되어 브라우저에서 확인하지 못했다. 위 실제 조작 결과는 저장소 원본과 단일 파일판을 사용했다.

셋째 편의 탭 숨김·복귀, 일지 열기·닫기, 입구로 나올 때 오디오 종료를 별도로 검증했다. 열 재앙의 기존 영상 열 편, 사건별 관찰 일지 열 장, 낭독 45개와 풀이 음성 6개를 원본·단일 파일판에서 확인했다.

## 전체 검사에서 바로잡은 실행 경로

관리형 Chromium은 원정 검사 세 개가 여는 로컬 파일 주소를 브라우저 정책으로 차단했다. 아홉 현장·일곱 현장·홍해 물벽 검사가 모두 게임 진입 전에 실패했다. 검사 커밋 `6db5cf8`은 이 오류일 때만 같은 배포 HTML 하나를 루프백에서 제공한다. 새로고침을 포함해 그 문서 탐색만 허용하고 다른 HTTP 요청은 차단한다. 파일 열기를 지원하는 환경에서는 기존 오프라인 파일 검사를 그대로 실행한다. 세 검사를 각각 다시 실행해 아홉 현장, 일곱 현장, 물벽 두 갈래의 마지막까지 통과했다.

추가로 시도한 Firefox 파일 직접 열기는 이 환경에서 브라우저가 준비되지 않아 이번 회차의 통과 항목에서 제외했다. 세 원정 검사의 이번 실행 결과는 Chromium 기준이다.

반복 검사에서 차단된 탭에 오류 페이지가 늦게 열려 다음 게임 탐색을 끊는 경우를 재현했다. `7937105`에서 차단된 탭을 닫고 같은 브라우저 컨텍스트의 새 탭으로 검사를 이어간다. 이 변경 뒤 양쪽 물벽 길의 직접 완주, 새로고침과 소고 응답을 네 번 연속 확인했다.
