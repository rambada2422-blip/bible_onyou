# 구름을 따라 · 출애굽기 원정

[오프라인 게임 ZIP](구름을_따라_출애굽기_게임.zip) · [수레에서 강둑까지 16초 실제 플레이](구름을_따라_플레이.mp4)

ZIP에서 `expedition.html`을 꺼내 열면 고센의 수레 옆에서 시작한다. 땅을 누르거나 방향키·WASD로 걷고, 가까이 가서 화면의 행동 단추나 스페이스를 누른다. Z는 한 수 되돌리기다. 같은 브라우저에서 같은 파일을 다시 열면 마지막 위치와 장비가 복원된다.

## 직접 탐험하는 일곱 현장

| 현장 | 플레이어가 결정할 일 |
|---|---|
| 고센 | 수레를 흙 작업대로 밀고, 흙을 누르다 때를 맞춰 손을 뗀다. 모퉁이에서 수레의 어느 쪽에 서야 말림터까지 갈지 판을 읽는다. 배달 후 이전 동선과 걸음 수를 보며 다시 풀 수 있다. 출 1:8–14 |
| 나일강 | 렌즈와 물병 중 하나를 가져간다. 렌즈를 고르면 더 먼 자리에서 낮은 발판과 높은 둑의 단서를 기록할 수 있다. 갈대 사이 상자, 누이, 바로의 딸, 아이를 기른 친어머니의 관계를 확인한다. 출 2:3–10 |
| 애굽의 강가와 집 | 서로 다른 두 개구리가 점프하는 자리를 찾아 셔터를 누른다. 직접 찍은 사진 두 장이 기록에 남는다. 출 8:1–15 |
| 홍해 | 갈라진 마른 길에 남은 두 동료의 흔적을 따라 합류하고 건너편에서 소고를 친다. 출 14:21–31, 15:20–21 |
| 광야 | 볕에서 걸으면 물이 줄고, 바위 그늘의 위치는 걸음에 따라 움직인다. 차양에서 물을 채울지, 샘까지 남은 물로 걸을지 정한다. 여분 물병을 가져오면 두 모금이 더 있다. 출 15:22–27, 16:13–18 |

수레의 동선과 탐험대 장비, 그늘에 따른 물 소비량, 야영지 두 곳에 압축한 행군은 게임을 위한 재구성이다. 본문의 장절은 현장과 기록에 표시한다. 직접 탐험의 저장 키는 `onyou.exodus.road.v1`이다. 수레를 다시 풀다가 **원정 복귀**를 누르면 원래 진행하던 현장으로 돌아간다. [고센의 수레](사진/출애굽기원정/고센_수레.jpg) · [광야의 물과 그늘](사진/출애굽기원정/광야_그늘.jpg)

독립 검토자 dot가 360×640 브라우저에서 0.9초간 눌렀다 떼는 동작, 앞을 가리던 건물의 투명도 변화, 서로 다른 두 배달 기록(9걸음과 11걸음), 연습에서 본편으로 돌아온 뒤의 렌즈와 진행 복원을 확인했다. DOT는 AI 검토자다. 17세 청소년이 도움 없이 두 번째 현장을 계속하는지, 선택을 바꿔 다시 오는지는 실제 플레이테스트가 남았다. 본문과 연출은 목회자 감수를 기다린다.

강둑의 두 갈래 길, 걷기 속도와 열기, 사십 년을 압축한 네 구간은 탐험대의 놀이로 설정했다. 이야기는 출애굽기의 주요 현장을 골라 이었으며, 출 40장의 성막 뒤에 사십 년 후일담을 따로 두었다. 본문 단서는 저장소의 다른 현장과 같은 공개 번역인 개역성경(KorRV)에서 필요한 절만 대조했다. 역본과 고정 출처는 `web/expedition/verses.js`에 있다.

## 구현과 확인

- 원본은 `web/expedition.html`과 `web/expedition/`에 있다. `node tools/build-expedition.js`로 다시 묶으면 `dist/expedition.html`이 나온다. 전체 2D 빌드에서도 같은 파일을 만든다. 나일강은 저장소 영상 1편의 갈대 강변 장면을 잘라 썼고, 엘림은 기존 광야 놀이의 엘림 그림을 재사용했다.
- ZIP에서 꺼낸 파일로 Chromium, Firefox, WebKit에서 각각 9/9를 완주했다. 세 개구리 사진, 돌아간 강둑, 햇볕 길의 멈춤과 물 나눔, 오답에서 재시도, 중간 재시작, 마지막 수첩 복원을 확인했다. Chromium은 오프라인 설정을 켰고 Firefox와 WebKit은 모든 HTTP 요청을 차단했다. 검사 명령은 `node tools/test/full/exodus-expedition.js`이다.
- dot가 작은 개구리를 찍을 때의 판정, 바구니 위치, 셔터와 행군 단추의 위치, 산 아래를 직접 보기 전후의 흐름을 독립 플레이했다. 그 결과를 반영해 무대 위에 셔터를 놓고 세 개구리의 실제 위치로 사진을 판정하며, 산길을 넘으면 진영을 가까이 보게 했다. [개구리 관찰창](사진/출애굽기원정/개구리_관찰창.png) · [산길에서 본 진영](사진/출애굽기원정/산길_진영확대.png)
- 실제 어린이와 실물 휴대폰에서의 조작·이해도, 목회자 감수와 공개 결정은 남아 있다.

직접 탐험의 자동 조작은 `node tools/test/full/exodus-road.js`이다. ZIP에서 꺼낸 HTML을 Chromium·Firefox·WebKit에서 각각 일곱 번째 현장까지 진행했다. Chromium은 오프라인으로 실행했고, 두 다른 브라우저에서는 HTTP·HTTPS 요청을 차단했다. 전달 ZIP의 기존 아홉 현장도 Chromium에서 다시 완주했다. 과거 저장과 현재 저장은 별도로 유지된다.

전체 회귀 검사는 기존 2D·3D·왕궁·광야·아홉 현장까지 통과했다. 전체 검사를 시작한 뒤 실행 목록에 추가된 직접 탐험 검사는 위 세 브라우저에서 별도로 돌렸다. 아래 확인 필요 항목은 브랜치와 main 사이의 기존 `web/js/content.js` 감수 표시다.

```text
점검 종류: 전체 · 통과 15/16 · 확인 필요 1
점검 결과: 합격 (확인 필요 1건)
```
