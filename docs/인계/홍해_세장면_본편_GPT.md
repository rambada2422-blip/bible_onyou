# 홍해 본편 세 장면

작업 브랜치는 `gpt/exodus-journey`다. `a4a5d9e`에서 세 장면과 진입 경로를, `88b83e0`에서 홍해 관찰 기록과 광야 수첩 연결을 추가했다. 소유자 전용 Sites 버전 14에 배포했다. [홍해 바닷가에서 시작](https://bible-onyou-moses-and-pharaoh.taupemast4.chatgpt.site/#redsea)

## 플레이 흐름

1. **EX-10 바다 앞에 갇히다** — 최온과 앞바다와 뒤쪽 길을 양쪽 순서로 살핀다. 바닷가에 장막을 친 백성을 바로의 병거가 따라잡았고 백성이 두려워한 이유를 확인한 뒤 모세가 전한 말을 읽는다. 출 14:2–14.
2. **EX-11 바다 사이의 마른 길** — 휴와 걷는 위치를 단추·슬라이더·키보드로 조절한다. 동풍이 분 밤과 물벽 사이의 마른 길을 보고, 건너편에서 바다를 돌아본다. 물이 되돌아온 장면과 하나님이 백성을 구원하신 결말을 확인한 뒤 노랫소리로 이동한다. 출 14:21–22, 26–30.
3. **EX-12 미리암의 소고** — 모세와 백성이 하나님께 노래하고 미리암과 여인들이 소고를 들고 춤추는 장면을 본다. 온우와 하는 탐험대 장단은 선택 놀이이며, 소리 없이도 노래의 이유를 읽고 일지를 열 수 있다. 출 15:1, 15:20–21.

유월절의 출발 화면 및 구름 기둥과 불 기둥 장면의 마지막에서 **홍해 본편으로**를 누른다. 기존 수첩 지름길은 **길 잇기 수첩 바로 열기**로 표시한다. 시간표와 수첩 상단에서도 본편으로 들어갈 수 있다. 같은 사이트에서 화면 링크의 끝부분만 바꿔 열 때도 해당 장면으로 이동한다.

홍해 일지를 마치면 광야에서 여정을 이어가고, 세 사건이 수첩에 기록된다. 조각판의 회전 기록과 최고 기록은 별도로 보존한다. 수첩 후반까지 진행한 저장은 해당 위치를 유지한다. 완료 후 다시 플레이해도 일지와 기록 수가 보존된다.

## 본문과 그림

근거는 `docs/01_출애굽기_장면목록.md` EX-10~12의 개별 사실·장절과 검토된 수첩 문구다. 성경 인물의 직접 대사를 추가하지 않았다. 세 친구의 안내와 장단은 『탐험대 이야기』다. 바닷가·병거·물벽·소고는 2D 게임 코드가 그린다. 성부·성자·성령 및 천사의 모습, 유혈 묘사는 없다. 장단은 탐험 도구의 효과음이다. 본편 문구와 화면의 목회자·총괄 감수, 실제 아이의 플레이 평가는 남아 있다.

## 확인한 동작

- 예전 저장과 새 저장, 수첩·유월절·광야·시간표·직접 주소에서의 진입, 도중 새로고침, 화면 회전, 앞뒤 이동과 키보드 도착, 건너온 바다 돌아보기, 장단 재시도와 무음 완료, 재관람과 수첩 복귀를 검사했다.
- 320×480부터 1280×720까지 여덟 화면에서 네 단계의 단추·펼침 항목을 끝까지 눌러볼 수 있는지 검사했다. 새 저장 세 개로 연령 단계별 출 1장 → 호렙 → 왕궁 열 재앙 → 유월절 → 구름·불 기둥 → 홍해 본편 세 장면 → 광야·시내산·성막 열두 기록을 확인했다.
- 왕궁 원본 영상 열 편의 마지막 재생, 유월절, 기존 나일강 조작도 따로 검사했다. Sites의 임시 미리보기 중계는 시간 초과였고, 게임의 원본과 배포에 사용한 묶음으로 브라우저 검사 후 비공개 배포 성공을 확인했다.
- 구현 파일은 `web/js/red-sea.js`, `web/js/red-sea-landscape.js`, `web/css/red-sea.css`다. 연결과 묶기는 `web/index.html`, `web/js/app.js`, `web/js/app-scene.js`, `web/js/passover.js`, `web/js/exodus-trail.js`, `tools/build.js`에 있다. `tools/test/red-sea.js`를 `tools/check.js --full`에 편입하고, `tools/test/exodus-trail.js`의 기존 경로 이름을 맞췄다.
