# 다윗 수정본 확인 · Claude 총괄 (2026-11-23)

대상: `antigravity/david-week`의 cfb2082 "본문 검토 8항목 반영 및 다윗 놀이 1~5 구현". 총괄은 코드를 다시 읽지 않고, 바뀐 화면 문구(`web/david/js/data.js`, `app.js`에 새로 들어간 한국어 줄)만 사무엘상·하, 역대상 개역개정과 공통 규칙서로 대조했다.

## 결론

- 지난 검토(`docs/인계/다윗_본문검토_Claude.md`)의 꼭 고칠 것 여덟은 모두 반영되었다.
- 새로 생긴 꼭 고칠 것 하나: D03 발견 문구 (아래 1).
- 고치면 좋은 것 하나: 놀이 1 '시냇물 아래' (아래 2).
- 고친 뒤 main에 합칠지는 대표가 정한다. 감수 필수 네 장면(D02, D04, D06, D08)은 '목회자 감수 전'으로 표시되어 있다.

## 새로 찾은 것

1. **꼭 고칠 것 · D03 발견 문구 (공통 규칙서 7절)**
   - 지금: "두 친구는 나중에 서로 입 맞추고 함께 울며 헤어졌어."
   - 삼상 20:41의 "서로 입 맞추고 같이 울되"와 문장 틀이 같다('같이'를 '함께'로만 바꿈).
   - 고칠 말 예: "두 친구는 나중에 눈물을 흘리며 작별 인사를 했어." 장절(삼상 20:41–42)은 그대로 둔다.
2. **고치면 좋은 것 · 놀이 1 '시냇물 아래 관찰 창' (공통 규칙서 3.4)**
   - 삼상 17:40은 다윗이 시내에서 매끄러운 돌 다섯을 골랐다고만 한다. 돌이 흐르는 물 아래에 있었는지는 말하지 않는다.
   - 화면의 '물결 아래', '물결이 걷히는'은 탐험대의 관찰 창이라는 표시(『탐험대 이야기』)를 붙이거나, '시냇가 돌밭'처럼 물을 단정하지 않는 말로 바꾸기를 권한다. 잔자갈 셋은 장면 속 자연물이라 그대로 두어도 된다.

## 함께 확인한 것

- 다윗 화면 코드에서 바깥으로 기록을 보내는 부분(fetch, XMLHttpRequest, sendBeacon, WebSocket)을 찾지 못했다. 놀이 5의 첫 선택·다시 놀기 기록(`telemetry`)은 이 기기 안에만 저장되는 것으로 보인다 (공통 규칙서 6절). ⚠️ 코드 전체를 읽은 것은 아니고 낱말로 찾은 결과다.
- 화면에 '구매'라는 말은 없다. 일감 제목의 '구매 전 체험'은 화면 문구로 쓰이지 않았다.
- D06의 '청색 덮개(민 4:5–6)' 그림 메모는 화면에 출처를 밝혔고, 목회자 감수 거리로 올라가 있다.
- 확인하지 못한 것: ⚠️ 그림과 화면 사진, 실제 휴대폰에서의 조작.
