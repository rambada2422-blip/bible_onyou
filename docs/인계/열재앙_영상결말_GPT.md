## 문구와 제작 자료

- 결말의 문장은 총괄이 검토한 `web/js/palace-story.js`와 `web/js/passover.js`에서 가져왔다. 자막에 해당 대목의 출애굽기 장절을 넣었다. 아이 눈높이에서 “무엇이 달라졌는가”를 보여 주고 바로의 마음은 절마다 행위 주체를 지켰다.
- `videos/exodus-palace/endings/`에 장별 장절·자막·내레이션 시점, 그림 16장, 음성 10개와 `render.py`를 두었다. 그림은 영화풍 정지 그림이고 편집할 때 확대·이동과 화면 전환을 더했다. 한국어 해설은 기존 Supertonic 3 배역을 썼고 마지막 밤 바로의 말은 바로 목소리다. 자막 서체는 기존 고운돋움 글꼴을 필요한 글자로 줄여 별도 이름으로 저장했다. 배포 조건은 같은 폴더의 `OFL.txt`에 있다.
- 영상 원본이 보관된 힉스필드 작업 공간에서 편집·출력했다. 이 브랜치의 게임은 확인된 편집본 주소를 사용한다. ZIP에는 외부 주소를 열지 않아도 되는 MP4 열 편이 들어 있다. 브랜치 `gpt/exodus-palace-dialogue`의 제작 자료 커밋은 `042d152`, 게임 연결 커밋은 `5b7877e`다.

## 확인

- 열 편의 전환 전·후와 결말을 추출해 확인했다. [1~5편](사진/재앙영상_결말_1.jpg) · [6~10편](사진/재앙영상_결말_2.jpg)
- 열 편은 각각 1920×1080, 초당 24프레임, 스테레오다. 합본은 6,205프레임으로 약 258.54초이며 열 장의 시작·끝과 음성 길이를 대조했다. 합본과 ZIP의 다운로드 주소에서 파일 시작과 전체 크기도 확인했다.
- 온라인 영상 주소를 쓰는 게임과 ZIP을 푼 오프라인 게임 양쪽에서, 390×844 브라우저로 열 편의 재생을 시작하고 결말 구간으로 이동해 끝나는 순간까지 재생했다. 기존 왕궁 시험은 장절·단서·영상 재시도와 51개 화면 낭독을 통과했다.
- 대표용 비공개 사이트는 나일강 급류를 포함한 기존 화면과 합쳐 배포했다. 통합본에서 나일강·왕궁 조작 시험을 통과했으며 Sites 배포 성공을 확인했다. Sites 내부 미리보기 릴레이는 시간 초과였다. 총괄의 새 결말 그림 감수와 실제 아이가 영상을 보고 결과를 설명하는지 확인하는 일은 남았다.
