# 나일강·왕궁·재앙 새 글 확인 · Claude 총괄 (2026-11-23 밤)

대상: `gpt/nile-skiff`의 `daa48ad` (`gpt/exodus-palace-dialogue` `5673474`를 품는다). 아이에게 보이거나 들리는 글을 개역개정 출 2·3·5·7~12장과 공통 규칙서에 대조했다. 작성 과정을 보지 않은 검증자가 대조했고 (왕궁 대목 45개, 물음 3개, 결말 자막 63개, 관찰 10장, 나일강 아이 글 전부), 총괄이 꼭 고칠 것 넷을 브랜치에서 직접 다시 찾아 확인했다. 코드는 다시 읽지 않았다.

## 결론

- **고치면 쓸 수 있다.** 왕궁 본문 고침 (`docs/인계/모세와바로_본문검토_Claude.md`의 고칠 것과 더할 것 11건)은 모두 글자까지 반영되었다. 바로의 마음 아홉 곳은 절마다 누가 굳게 했는지가 본문과 같다. 나일강 대표 결정 '가' (첫 화면 『탐험대 이야기』, 연꽃 → 갈대)도 반영되었다.
- 새로 꼭 고칠 것 넷 (아래). 고친 뒤 main에 합칠지는 대표가 정한다.
- main과 부딪히지 않는다. main과 합친 상태에서 빠른 점검 합격, GPT 시험 6개 (`nile-skiff`, `nile-locks`, `nile-rapids`, `palace-story`, `palace-narration`, `palace-watch`) 통과.

## 고치면 좋은 것

- 결말 자막 "보리와 삼이 우박에 꺾였어요" → 출 9:31은 '상하였다'. "우박에 상했어요".
- 결말 자막 "일어나지 못했어요" → 출 10:23은 '일어나는 자가 없었다'. "아무도 자리에서 일어나지 않았어요".
- 9장 첫 자막에 "여호와께서 말씀하신 대로"가 빠졌다 (출 10:21. 앞 검토의 고칠 것 7과 같은 뜻).
- 관찰 1장 "붉게 변한 강물의 빛깔" → 출 7:20은 '피로 변했다'. 자연 현상으로 읽히지 않게 "피로 변한 강물".
- 7장 "서둘러 피하게 한 이들" → 출 9:20은 '여호와의 말씀을 두려워하는 자들'. '서둘러'는 본문에 없다.
- 급류 도전 "갈대를 챙길까요", "갈대 우편을 챙겼어요" → 규칙서 12절 (과거에서 가져오는 것은 사진과 기록뿐). "갈대를 사진에 담을까요"처럼.

## 규칙서 7절 (네 어절 기준)에 걸리는 글 28곳 · 대표 결정을 기다린다

- 개역개정과 같은 낱말이 네 어절부터 이어지는 글이 왕궁 대목 13개, 결말 자막 13개, 한 문장을 낱말만 바꿔 옮긴 것이 셋 (자막 둘, 왕궁 7-3 바로의 말)이다. 가장 긴 것은 여덟 어절 (8:13).
- 대부분 총괄의 앞 검토가 "본문 그대로"를 권한 문구와 main에 이미 있는 `web/js/passover.js` 승인 문장에서 왔다 (7절 기준은 2026-11-23 15:20에 정해졌다). GPT의 잘못이 아니다.
- 바꿔 쓸 말은 검증자가 같은 방법으로 다시 대조했다 (같은 어절이 이어지는 것이 셋 이하). 대표 결정 P1 (여호와께서 치셨다), P3 (바로의 마음은 누가 굳게 했는지 본문대로)을 지킨다: 여호와께서 하신 곳은 "여호와께서 바로의 마음을 굳게 하셨어요", 바로 스스로 한 곳은 "스스로 마음을 굳게 하고", 누가 했는지 적지 않은 곳은 "마음이 굳어진 채".
- 고치면 왕궁 낭독 14개와 결말 영상 9편 (4장 빼고)의 자막·음성을 다시 만들어야 하고, main의 `passover.js`도 같이 맞춰야 한다.
- 전체 목록과 바꿔 쓸 말 예: 아래 부록.
