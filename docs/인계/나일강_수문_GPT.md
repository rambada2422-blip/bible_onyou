# 나일강 수문 탐험

[대표용 수문 체험판](https://bible-onyou-moses-and-pharaoh.taupemast4.chatgpt.site/nile.html?course=locks) · [휴대폰에서 본 두 수문](사진/나일강_엇갈린_두_수문.png)

기존 항해 일지에서 ‘수문 탐험으로’를 누르거나 직접 링크를 연다. 배가 구리 바퀴에 닿으면 멈춘다. 아이는 바퀴를 돌리거나 지금 열린 길을 따라간다. 황금 수문에는 마름모, 푸른 수문에는 둥근 표지가 있다. 열린 문은 양옆 말뚝과 물결, 닫힌 문은 널판으로 표시한다. 수문을 여닫는 조작은 탐험대의 지도 놀이다. 정박 후 여는 본문 기록 세 장은 기존 왕궁의 개구리 장면에서 그대로 가져왔다.

| 지도 | 새로 풀어 볼 것 | 최단 도착 | 연꽃을 거친 최단 도착 |
|---|---|---:|---:|
| 갈대 수문 | 배를 바퀴 옆에 대고 황금 문을 연다. | 4수 | 5수 |
| 엇갈린 두 문 | 황금 문이 열리면 푸른 문이 닫힌다. 바뀐 정지 위치를 이용한다. | 7수 | 12수 |
| 두 바퀴의 나루 | 서로 다른 두 바퀴를 찾아가며 문을 두 번 바꾼다. | 9수 | 12수 |

한 수는 노 한 번 또는 바퀴 한 번이다. 터치에서는 바퀴에 겹쳐 선 배나 ‘바퀴 돌리기’를 누른다. PC에서는 방향키와 G 또는 포커스를 둔 단추로 조작한다. ‘한 수 되돌리기’는 배·꽃·수문 상태를 함께 되감는다. 기존 네 물길의 일지와 중간 위치는 별도로 보존한다.

## 코드와 확인

- 게임 브랜치는 `gpt/nile-skiff`이며 기능 커밋은 `666e9cb`, 작은 화면 보강은 `0fa2b28`이다. `web/js/nile-routes.js`가 이동·수문·힌트, `nile-art.js`가 배경 캐시와 수문·바퀴 그림, `nile-game.js`가 입력·일지·저장, `web/css/nile.css`가 작은 화면의 조작 배치를 맡는다. `tools/test/full/nile-locks.js`가 새 퍼즐과 이전 저장을 검사한다.
- 세 지도의 도달 가능한 상태 34개·50개·61개에서 각각 나루로 가는 힌트가 끝나는지 확인했다. 나루 직행과 연꽃 경유의 최단 수를 각각 독립 탐색으로 대조했다.
- 휴대폰·PC 브라우저에서 바퀴를 터치하거나 키보드로 조작해 세 곳을 완주했다. 문을 연 다음 회전·새로고침·되돌리기, 두 항해 사이 중간 저장, 왕궁 복귀와 본문 열기를 점검했다. 320×568부터 1280×800까지 여덟 크기에서 첫 화면에 수문과 네 방향 단추가 모두 보이고 각 터치 영역이 44px 이상이었다.
- 레거시 네 물길 회귀 검사를 통과했다. 배포용 물길 파일(142,181바이트)과 선물용 단일 HTML을 Chromium과 WebKit에서 실제 터치 입력으로 실행해 첫 수문을 열고 나루의 성경 기록까지 확인했다. 두 파일 모두 해당 과정에서 추가 네트워크 요청이 없었다.
- Sites 내부 미리보기는 릴레이 연결 시간 초과였다. 위 브라우저 검사는 배포 파일 자체로 진행했다. 개인 비공개 배포에 사용한 사이트 소스 커밋은 `7869e78dc6a7d7b18088f05a9b14b509b8682010`이다. 본편 main 병합과 상점 출시는 별도다.
