## 대조와 조작 확인

- 검토표의 서술·대사 11곳과 게임 대목이 글자 단위로 일치했다. 개구리 장면의 물음과 정답 보기도 대조했다. 기존 44개 대목의 장절과 순서를 유지했고 33개 대목은 모든 필드가 이전과 같다. 출 7:22는 1장 끝에 추가해 기존 저장 위치를 보존했다.
- 화면·대사 45개와 풀이 6개에 대응하는 한국어 음원 51개 중 13개를 만들었다. 기존 해설·모세·바로의 목소리와 음량을 사용했다. 원고에 맞춰 13개 새 녹음을 음성 인식 결과와 대조했다. 열째 재앙의 ‘다 치셨어요’, ‘문 위에’는 쉼을 조정한 테이크로 바꿨다. 최종 MP3는 각각 다른 51개, 44.1 kHz 모노, 합계 약 7분 42초다. 실제 아이와 휴대폰 스피커로 듣는 확인은 남았다.
- `node tools/test/full/palace-story.js`에서 360×640, 320×568, 844×390으로 열 장면의 글·장절·세 퀴즈·복원·영상 오류 시 재시도를 확인했다. `node tools/test/full/palace-narration.js`는 소스 화면과 단일 HTML 양쪽에서 51개 음성의 실제 재생과 중단을 확인한다. [수정된 바로의 첫 대답](사진/모세와바로_본문수정_바로의대답.png)
- 바뀐 파일은 `web/js/palace-story.js`, `web/assets/audio/palace/`의 위 13개 음원, `tools/test/full/palace-narration.js`, 이 문서와 사진 한 장이다.

## 영상 이전과 총괄 확인

가로 1920×1080 영상 열 편의 게임 주소가 제작 당시 최종 목록에 있는 원본 주소와 일치한다. 현재 작업 환경의 허용 도메인 목록에 원본 두 호스트가 없어 HTTP 프록시가 접속을 403으로 거절했다. 로컬에 원본 MP4가 없어 게임은 기존 주소를 사용 중이다. 기존 왕궁 대화 오프라인 ZIP을 받거나 환경에서 `d8j0ntlcm91z4.cloudfront.net`과 `d2ol7oe51mr4n9.cloudfront.net` 접근이 허용되면 원본을 확인해 `videos/exodus-palace/`로 옮기고 파일 재생을 검사한다. main의 세로 영상 88초 합본은 별도로 승인된 제작물이다.

이번 전달 범위는 총괄 대조용 브랜치와 왕궁 감수용 HTML이다. 나일강 소재 처리는 대표 결정 대기이며 창세기·다윗 담당 브랜치와 운영 사이트 반영은 이 작업에 포함하지 않았다.
