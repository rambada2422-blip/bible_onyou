# 열 가지 재앙과 유월절 · Claude 배치 재검토 요청

검토 브랜치는 `gpt/exodus-scripture-review`이다. 총괄의 검토가 실린 main `120a6bf`에서 시작해 2D 미리보기와 수정분을 담았다. 기준은 [Claude 본문 검토](열재앙_본문검토_Claude.md) 1~3절이다. 2D 시간표의 ‘열 가지 재앙과 유월절 · 감수용 미리보기’에서 확인한다.

짧은 재앙의 배경은 티끌이 있는 마당, 빈 가축 우리, 화덕, 우박이 내리는 들, 메뚜기가 앉은 밭이다. 붉은 강물은 첫 재앙에만 나온다. 기존 강가·식탁 그림은 시안 폴더에 보관했다. 아이에게 시신, 신적 형상, 멸하는 자를 보여 주는 그림은 없다. 그림을 대조한 뒤 본편 반영 여부를 총괄이 결정한다.

## 문구와 조작

재앙 2·5·7 요약, 준비 화면의 첫 안내, ‘문’ 단서를 검토 원문의 권장 문구로 교체했다. 마지막 밤 두 번째 문장은 ‘피를 바른 이스라엘 자손의 집에는 재앙이 내려 멸하는 일이 없었어요.’이며 같은 글을 일지에서 다시 읽는다. 마지막 밤과 출발 화면에는 진행 칸이나 완료 표시, 효과음이 없다. 출발 뒤 단추는 ‘탐험 기록 다시 읽기’이다.

8~10세는 여섯 관찰 지점을 선택하면 2절의 해당 한 문장 안내를 본다. 흑암의 밝은 곳 이름은 ‘이스라엘 자손이 사는 곳’이다. 11세 이상은 그림과 본문 설명을 읽는다. P1~P5는 목회자 판단 전이며, 가축의 죽음은 P5 감수용 권장 문구로 표시한 미리보기다.

수정한 실행 파일은 web/js/passover.js, web/css/app.css, web/assets/bg의 새 배경, tools/build.js, 생성된 web/js/art.js이다. tools/test/full/passover.js가 실제 로드된 배경, 연령별 안내, 저장 후 복원, 마지막 밤과 일지의 연결, 준비 그림의 단서 좌표를 두 진입점에서 점검한다.

게임 구현 커밋은 `8db1fb6`이다. 감수 회신의 본문 문구 여섯 개와 8~10세 관찰 안내 여섯 개를 원문과 대조했다. 일반 웹과 단일 파일 미리보기에서 세 연령 설정으로 여섯 번 완주했다. 3D 호렙·요단을 포함한 전체 자동 점검도 통과했다. 새 식탁에 담긴 고기의 모습(출 12:9)은 총괄의 그림 재대조 항목으로 남긴다.
