# 모세와 바로의 한국어 낭독

대표가 지적한 기계적인 ‘읽어 줘’를 대화 탐험의 열 재앙 전체에서 고쳤다. 이전 판은 화면 표지와 본문을 합쳐 기기의 기본 음성으로 읽었다. 게임 커밋은 `a233085`, 작업 브랜치는 `gpt/exodus-palace-dialogue`다.

[같은 주소의 비공개 게임](https://bible-onyou-moses-and-pharaoh.taupemast4.chatgpt.site) · [새 낭독과 재앙 영상 10편을 담은 오프라인 ZIP](https://d2ol7oe51mr4n9.cloudfront.net/user_3BUlkqr62Kq073dmR6GRokxkB9P/a6477f37-13f7-4a37-b276-c5ce91e54649.zip)

## 낭독 방식

해설은 차분한 한국어 목소리, 모세와 아론이 함께 전하는 말과 모세의 대답은 부드러운 목소리, 바로의 대답은 또렷하고 단호한 목소리로 제작했다. 기기별 기본 음성과 배역 이름 읽기를 없앴다. 성경 대사와 장절 표시는 이전 판과 같다. 문장이 바뀌는 곳에 쉼을 넣고, 개구리 재앙의 짧은 대답과 마지막 밤의 호흡을 따로 점검했다.

- 대목 44개에는 대사·서술·질문이 들어 있다. 질문 음성은 보기 두 개도 읽는다. 풀이 6개는 아이가 답을 고른 뒤 ‘풀이 듣기’로 들을 수 있다.
- `web/assets/audio/palace/`의 MP3 50개는 확정된 대본으로 미리 만든 한국어 합성음이다. 오픈웨이트 Supertonic 3의 기본 목소리 세 개를 사용했다. 실제 사람의 음성 복제와 서비스 크레딧 결제는 없었다. 모델 배포 조건은 OpenRAIL-M, 추론은 sherpa-onnx다. [모델과 이용 조건](https://github.com/supertone-inc/supertonic#license) · [사용한 한국어 지원 ONNX 모델](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models)
- `web/js/palace.js`와 `web/css/app.css`는 재생·중단·다시 듣기를 처리한다. 영상의 재생 버튼, 다음 대목, 탐험 나가기, 화면 숨김은 현재 낭독을 끊는다. 읽던 도중 다른 목소리를 틀거나 영상 위에서 듣기를 누르면 앞소리가 멈춘다.
- `tools/build.js`는 단일 HTML 안에 음성 50개를 묶는다. 개별 웹 파일은 누른 대목만 불러온다. `tools/test/game-server.js`가 시험 중 MP3의 형식을 알린다. 대본을 수정하면 같은 장·대목 번호의 음성과 해당 질문의 hint/evidence 파일도 함께 교체한다. 오프라인 묶음은 압축을 모두 풀고 `게임_시작.html`을 연다.

## 검증

- 같은 대본의 음성을 다른 한국어 음성인식 모델로 받아써 대조했다. 제10재앙의 ‘처음 난 자들을’이 더 잘 구분되는 테이크로 교체했다. 음성인식 결과는 사람의 연기·발음 감수를 대신하지 않는다.
- 최종 50개 파일은 총 약 6분 37초이며 44.1 kHz 모노 MP3다. 통합 음량은 −18.0~−15.9 LUFS이며 최대 트루피크는 −1.5 dBTP다.
- `tools/test/full/palace-narration.js`로 360×640 휴대폰 브라우저에서 원본과 단일 HTML의 각 50개 음성이 실제로 디코딩되고 재생 시간이 흐르는 것을 확인했다. 기기 음성 엔진이 없는 경우, 듣기 중단, 자연 종료, 다음 대목으로 이동, 다른 앱으로 전환, 영상과 낭독의 교대, 답을 바꾼 뒤 다른 풀이 듣기를 포함한다. 배포한 ZIP을 풀어 해설·모세·바로가 실제 내장 음원으로 차례로 재생되는 것과 다운로드 파일의 서명도 확인했다. 실물 휴대폰 스피커로 듣는 확인은 남아 있다.
