# 재앙의 두 장소를 관찰하는 탐험

시간표의 ‘열 가지 재앙과 유월절 · 감수용 미리보기’에서 연다. 강물과 강가(출 7장), 애굽의 집과 고센(출 8장), 흑암과 빛(출 10장)은 두 장소를 눌러 그림과 기록을 비교한다. 나머지 여섯 재앙은 장절이 붙은 짧은 목격 장면이다. 유월절의 세 단서를 찾은 뒤 열 번째 재앙과 바로의 부름을 두 대목으로 읽고 출발한다.

첫 판에서 이름을 맞힌 기록은 그대로 이어지며, 비교하던 중 나갔다 돌아와도 마지막 장소를 다시 연다. 이미 마친 아이는 시간표에서 탐험 기록 맨 아래 ‘처음부터 다시 둘러보기’를 눌러 다시 시작한다. 다시 탐험하는 도중에도 일지에서 끝낸 기록 14개를 읽을 수 있다.

조작과 저장은 web/js/passover.js, 일지 연결은 web/js/app.js, 장소의 모습과 움직임은 web/css/app.css에 있다. 실제 화면은 [애굽](사진/흑암_애굽.png)과 [이스라엘 자손이 사는 곳](사진/흑암_빛.png)을 참고한다. 휴대폰의 동작 줄이기 설정을 사용하면 파리 떼가 움직이지 않는다.

Claude 총괄의 작업 브랜치에 fc7f86c로 본문 검증 지시를 전달했다. 응답 파일은 docs/인계/열재앙_본문검토_Claude.md이다. 장절과 그림의 해석, 열 번째 재앙의 어린이용 표현은 목회자 감수 대상이다.

휴대폰 브라우저 세 크기와 세 연령으로 일반 페이지와 단일 파일 미리보기를 총 여섯 번 완주했다. 두 장소를 반대 순서로 누르기, 한 곳을 여러 번 누르기, 중단·복원, 마지막 밤 다시 열기, 재탐험 중 일지 보기, 구버전 저장 읽기를 확인했다. 자동 조작은 tools/test/full/passover.js로 다시 실행할 수 있다.
