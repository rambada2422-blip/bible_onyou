# 일감 다-3 · 2D 화면의 단추 크기와 이름

- 줄: 코드 줄 다 · 2D 시범판 · 브랜치: `relay/web2d` · 맡을 수 있는 AI: GPT, Gemini
- 먼저 끝나 있어야 하는 것: 다-2
- 인계 파일: `docs/인계/일감다3_AI이름.md`
- 함께 지킬 규칙: `docs/08_작업줄.md`의 '모든 줄에 함께 쓰는 규칙'

## 왜

8세 아이의 손가락으로 누르기 쉬워야 하고, 화면을 읽어 주는 기능이 단추 이름을 읽을 수 있어야 한다.

## 할 일

1. 새 시험 `tools/test/full/a11y2d.js`: 주요 화면에서 누르는 것이 가로세로 44 이상인지, 글자가 없는 단추에 이름(`aria-label`)이 있는지, 글자가 바탕과 충분히 다른지(밝기 견줌 4.5 이상) 본다.
2. 걸리는 곳을 고친다. 모습이 크게 달라지는 곳은 고치지 말고 인계 파일에 적는다.
3. 새 시험 파일은 `tools/test/full/` 폴더에 둔다. 첫 인자로 화면 사진을 둘 폴더를 받고, 실패하면 `exit 1`로 끝난다. `tools/check.js`는 고치지 않는다 (일감 나-1이 끝나면 전체 점검이 이 폴더를 스스로 찾아 돌린다). 그 전에는 `node tools/test/full/파일.js dist/check/이름`으로 직접 돌려 결과를 인계 파일에 적는다.

## 건드릴 파일

`web/css/app.css`, `web/js/app.js` (단추 이름을 더하는 곳만), `tools/test/full/a11y2d.js` (새 파일), 묶은 결과 파일, 그리고 인계 파일.

## 하지 말 것

- 문구를 바꾸지 않는다.

## 완료 기준

- 시험이 통과한다.
- `node tools/check.js --full` 합격.
