# 안티그래비티 · 다윗 현장 탐사 A41~A48

`antigravity/david-week`에서 [다윗 인계](../인계/다윗_Antigravity.md)와 기존 플레이 화면 `web/david/index.html`을 먼저 연다. A01~A40 다음에 이어지는 4일 분량이다. 완료 카드를 지나쳐 첫 미완료를 맡고, 작업 중인 사람이 있으면 다른 장면 묶음부터 진행한다. 새 역사 대본이나 외부 그림 없이 다윗 브랜치에서 완주할 수 있다.

| 묶음 | 작업 | 아이가 해 보면 드러날 완료 기준 |
|---|---|---|
| 1 · A41 시냇가 사진기 | D02 관찰 창 옆에 탐험대의 작은 사진기를 놓는다. 기존 돌 그림을 재사용한다. 최온과 한 자리씩 좌우로 움직여 물결 사이에 돌의 윤곽을 담고 셔터를 누른다. | 첫 화면에서 돌의 반짝임이 시선을 이끈다. 짧은 탭 한 번은 한 자리만 옮긴다. 셔터를 누른 바로 그 구도가 사진에 남고 키보드로도 찍힌다. |
| 1 · A42 사진을 골라 기록 | 방금 찍은 두 구도를 나란히 열고 아이가 한 장을 수첩에 끼운다. 다시 찍을 때는 앞서 고른 구도를 보고 바꿀 수 있다. | 어느 사진이든 선택할 수 있다. 촬영 뒤 회전·새로고침해도 후보와 선택이 복원된다. 두 번째 사진을 골라도 D02 원래 장절·수집 수가 유지된다. |
| 2 · A43 행렬을 보는 두 자리 | D06의 기존 궤·장막 그림을 사용해 관찰자가 서는 두 지점을 한 화면에 만든다. 시점을 옮기면 가까운 천막 가장자리와 먼 장면의 겹침이 달라져 다음 단서가 보인다. | 양쪽에서 같은 사건을 본다. 아이가 움직이는 것은 탐험대와 관찰 창뿐이다. 화면을 두드리거나 방향키를 눌렀을 때 어느 자리인지 소리 없이도 알아본다. |
| 2 · A44 두 자리의 기록 대조 | A43에서 담은 두 기록을 온우와 반투명 종이처럼 겹쳐 본다. 한 손으로도 표식을 맞추면 기존 궤·장막 근거가 해당 장절로 열린다. | 끌기와 두 번 탭 모두 된다. 중간 복귀 시 관찰 위치와 겹침이 남고 D06 기존 입구 둘에서도 일지가 열린다. |
| 3 · A45 휴의 관찰등 | D09 예물 기록 카드 옆에 휴의 탐험대 관찰등을 둔다. 선이 끊긴 부분에 맞는 연결 조각을 돌려 끼우면 수첩 아래쪽에 비스듬한 빛이 들어온다. | 잘못 돌려도 한 동작만 되돌릴 수 있다. 색을 꺼도 선·홈 모양으로 연결된다. 수리는 탐험대 장비 안에서 끝난다. |
| 3 · A46 빛의 방향 선택 | D09 수첩의 기존 대상 그림 두 곳에 빛을 비춰 다른 윤곽을 살핀다. 아이가 마음에 드는 관찰 순서로 두 그림을 기록하고 기존 장절을 연다. | 서로 반대 순서로 두 판을 마친다. 밝기나 예물 값으로 점수를 매기지 않는다. 회전·복귀 후 마지막 빛 방향이 남는다. |
| 4 · A47 첫 30초와 동료 힌트 | 위 세 장면의 새 입구에서 막힌 구간을 실제로 측정하고 가장 오래 걸린 한 곳을 고친다. 연령 모드별 힌트는 8세 10/20/30초, 13세 15/30/45초, 17세 25초에 첫 혼잣말 후 수동으로 요청한다. | 320×568 세로·640×360 가로·PC 키보드에서 첫 조작 가능, 힌트가 터치를 가로채지 않음, 조작 직후 오래된 타이머 취소를 확인한다. 첫 행동과 화면 반응을 사진으로 남긴다. |
| 4 · A48 두 번째 판과 이전 저장 | 기존 9/9 일지와 새 저장에서 D02·D06·D09의 새 놀이를 각각 연다. 두 번째 판에는 지난 사진·관찰 결과에서 새 선택을 할 수 있게 한다. | 중간 저장→새로고침→돌아오기와 두 번 연속 완주를 실제 조작한다. 기존 카드·장절·일지 개수를 대조하고 다윗 회귀 검사와 전체 점검 결과를 남긴다. |

작업 파일은 `web/david/` 아래 해당 장면과 [다윗 인계](../인계/다윗_Antigravity.md)다. 기존 그림·장절·다윗 전용 저장 키를 재사용한다. 한 묶음마다 모바일·키보드 완주, 짧은 탭과 길게 누르기, 새로고침을 확인하고 같은 브랜치에 올린다. 자동 조작과 실제 아이 관찰은 인계에 별도로 적는다.
