# 일감 다-7 · `app.js` 나누기

- 줄: 코드 줄 다 · 2D 시범판 · 브랜치: `relay/web2d` · 맡을 수 있는 AI: GPT, Gemini
- 먼저 끝나 있어야 하는 것: 다-6
- 인계 파일: `docs/인계/일감다7_AI이름.md`
- 함께 지킬 규칙: `docs/08_작업줄.md`의 '모든 줄에 함께 쓰는 규칙'

## 왜

`web/js/app.js`가 약 600줄이다. 화면마다 파일을 나누면 고칠 때 읽을 양이 준다.

## 할 일

1. 뜻이 통하는 묶음으로 3~5개 파일로 나눈다 (예: 저장과 공통, 첫 화면과 시간표, 장면, 물음과 시대 추리). 동작과 모습은 한 점도 바꾸지 않는다.
2. `tools/build.js`와 `web/index.html`의 불러오는 순서를 맞춘다. `README.md`의 시범 화면 표에서 `app.js` 줄만 새 파일 이름으로 고친다.
3. 나누기 전과 뒤에 자동 조작이 찍은 사진을 견준다 (일감 나-11의 도구가 main에 있으면 쓴다).

## 건드릴 파일

`web/js/app.js`와 나눈 새 파일, `web/index.html`, `tools/build.js`, `README.md` (그 한 줄만), 묶은 결과 파일, 그리고 인계 파일.

## 하지 말 것

- 화면의 모습과 동작을 바꾸지 않는다. `web/js/content.js`를 고치지 않는다.

## 완료 기준

- 나누기 전과 뒤의 사진이 같다는 것을 인계 파일에 적었다.
- `node tools/check.js --full` 합격.
