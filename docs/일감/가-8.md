# 일감 가-8 · 3D를 열 수 없는 기기에 안내 보여 주기

- 줄: 코드 줄 가 · 3D 게임 · 브랜치: `relay/horeb` · 맡을 수 있는 AI: GPT, Gemini
- 먼저 끝나 있어야 하는 것: 없음 (가-1~5와 같은 파일을 고치지 않으므로 순서만 지키면 된다)
- 인계 파일: `docs/인계/일감가8_AI이름.md` · 화면 사진: `docs/인계/사진/일감가8.png` (한두 장)
- 함께 지킬 규칙: `docs/08_작업줄.md`의 '모든 줄에 함께 쓰는 규칙'

## 왜

오래된 기기에서는 3D 그림 기능(WebGL)을 쓸 수 없다. 지금은 그런 기기에서 무엇이 보이는지 확인한 적이 없다.

## 할 일

1. 3D 화면을 만들지 못하면 빈 화면 대신 안내를 보여 준다. 문구는 아래 둘뿐이다.
  - 제목: "이 기기에서는 3D 탐험을 열 수 없어요"
  - 본문: "다른 휴대폰이나 컴퓨터에서 다시 열어 주세요."
2. 새 시험 `tools/test/full/nowebgl.js`: 3D 그림 기능을 못 쓰게 만든 화면에서 안내가 보이고 오류로 멈추지 않는지 본다.
3. 새 시험 파일은 `tools/test/full/` 폴더에 둔다. 첫 인자로 화면 사진을 둘 폴더를 받고, 실패하면 `exit 1`로 끝난다. `tools/check.js`는 고치지 않는다 (일감 나-1이 끝나면 전체 점검이 이 폴더를 스스로 찾아 돌린다). 그 전에는 `node tools/test/full/파일.js dist/check/이름`으로 직접 돌려 결과를 인계 파일에 적는다.

## 건드릴 파일

`web3d/js/game-scene.js`, `web3d/js/game-ui.js`, `web3d/css/game.css`, `tools/test/full/nowebgl.js` (새 파일), 묶은 결과 파일, 그리고 인계 파일.

## 하지 말 것

- 위 두 문구 말고 다른 문구를 쓰지 않는다.

## 완료 기준

- 시험이 통과한다.
- `node tools/check.js --full` 합격.
