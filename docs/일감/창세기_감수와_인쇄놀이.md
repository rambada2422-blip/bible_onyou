# 클로드 · 창세기 본편 다음 작업

작업 브랜치는 `claude/genesis-week`다. E01~E66 원고와 독립 검증 기록을 바탕으로 아래 순서대로 진행한다. 첫 산출물이 나오면 같은 브랜치에 저장하고 다음 항목으로 이어간다.

## 1. 목회자가 결정할 안건을 한 곳에서 열 수 있게 만들기

먼저 E46·E50·E51·E52와 이 회들을 건너뛴 뒤의 E53 첫 줄을 펼쳐 한 묶음을 완성한다. 결과 파일은 `docs/참고/감수_묶음_창세기본편.md`다. 네 회의 8~10세 기본 건너뛰기는 대표의 확정 사항으로 표시한다. 기관 연락처·절차는 확인 대기다.

이어서 E01~E66 전 편을 색인으로 연결한다. 회차별로 현재 원고에서 근거를 찾아 **회차·장절 / 검토할 실제 표현 또는 가릴 범위 / 결정할 질문 / 원고 링크**를 적는다. 여러 회의 쟁점이 같으면 질문을 합치고 해당 회차 링크를 함께 둔다. 명시적인 결정 항목이 없는 회는 원고의 감수 상태만 연결한다. 기존 E57 문구 비교와 Codex의 E58 플레이 검토본은 참조 대상으로 둔다. 목회자가 아직 답하지 않은 칸은 비워 둔다. 완료 기준은 66개 회차 링크가 모두 열리고, 이미 결정된 내용과 회신이 필요한 질문을 구별해 사용할 수 있는 것이다.

## 2. C29 · E59와 E60을 이어 보는 인쇄 놀이

감수 답을 기다리는 동안 `docs/창세기/연속/C29.md`와 같은 폴더에 바로 인쇄할 PDF를 만든다. E59와 E60의 기존 고르기·일지 문구를 사용해, 한 장에는 단서 카드와 기록 칸을, 별도 면에는 진행자용 답과 장절을 둔다. 자르거나 접기 전 아이가 보는 면에 다음 답이 드러나는지 확인한다. 두 선택 경로를 끝까지 따라가고 PDF를 실제 크기로 열어 잘리는 칸과 한글 글리프를 점검한다. 새로 쓴 대사가 있다면 기존 독립 검증 절차를 따른다. 실물 시험과 목회자 감수 상태는 확인한 범위만 기록한다.

각 작업을 마치면 [담당 인계](../인계/창세기_Claude.md) 맨 위에서 결과 파일과 다음 미완료 항목을 찾을 수 있게 갱신한다.
