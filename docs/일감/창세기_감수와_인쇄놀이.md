# 클로드 · 창세기 본편 다음 작업

작업 브랜치는 `claude/genesis-week`다. 본편 E01~E66 감수 자료 초안이 `0ca8e61`에 올라왔다. **지금 만들 것은 C29 인쇄 놀이와 별도 답지**다.

## 1. C29 · E59와 E60을 이어 보는 인쇄 놀이

감수 답을 기다리는 동안 `docs/창세기/연속/C29.md`와 같은 폴더에 바로 인쇄할 PDF를 만든다. E59와 E60의 기존 고르기·일지 문구를 사용해, 한 장에는 단서 카드와 기록 칸을, 별도 면에는 진행자용 답과 장절을 둔다. 자르거나 접기 전 아이가 보는 면에 다음 답이 드러나는지 확인한다. 두 선택 경로를 끝까지 따라가고 PDF를 실제 크기로 열어 잘리는 칸과 한글 글리프를 점검한다. 새로 쓴 대사가 있다면 기존 독립 검증 절차를 따른다. 실물 시험과 목회자 감수 상태는 확인한 범위만 기록한다.

## 2. 올라온 감수 묶음 대조

[본편 감수 묶음](../창세기/감수/본편_감수묶음.md)과 [회별 전체 목록](../창세기/감수/본편_감수항목_회별.md)에서 검증을 이어간다. E46·E50·E51·E52의 8~10세 기본 건너뛰기와 E53 진입 문장부터 원고에 맞는지 확인한다. 네 회의 기관 연락처·절차는 대표 확인 대기다. 66회 원고 링크와 이미 정한 사항, 목회자에게 남긴 질문이 맞는지 대조하고 기존 파일에 필요한 수정만 반영한다. 별도 검증 결과와 목회자 감수 상태를 구분해 남긴다.

각 작업을 마치면 [담당 인계](../인계/창세기_Claude.md) 맨 위에서 결과 파일과 다음 미완료 항목을 찾을 수 있게 갱신한다.
