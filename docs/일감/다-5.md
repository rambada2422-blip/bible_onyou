# 일감 다-5 · 2D 저장이 깨져도 게임이 되는지 시험

- 줄: 코드 줄 다 · 2D 시범판 · 브랜치: `relay/web2d` · 맡을 수 있는 AI: GPT, Gemini
- 먼저 끝나 있어야 하는 것: 다-4
- 인계 파일: `docs/인계/일감다5_AI이름.md`
- 함께 지킬 규칙: `docs/08_작업줄.md`의 '모든 줄에 함께 쓰는 규칙'

## 왜

2D 시범판은 진행을 기기에 저장한다. 저장된 값이 깨졌거나 저장할 수 없는 환경에서 어떻게 되는지 시험한 적이 없다.

## 할 일

1. 새 시험 `tools/test/full/save2d.js`: 깨진 저장 값, 옛 꼴의 저장 값(판 번호가 다른 것), 저장할 수 없는 환경, 정상 저장 뒤 "이어서 탐험하기"와 "처음부터 다시".
2. 게임이 멈추는 경우가 있으면 `web/js/app.js`의 저장을 읽는 곳에서 고친다 (못 읽으면 처음부터 시작).
3. 새 시험 파일은 `tools/test/full/` 폴더에 둔다. 첫 인자로 화면 사진을 둘 폴더를 받고, 실패하면 `exit 1`로 끝난다. `tools/check.js`는 고치지 않는다 (일감 나-1이 끝나면 전체 점검이 이 폴더를 스스로 찾아 돌린다). 그 전에는 `node tools/test/full/파일.js dist/check/이름`으로 직접 돌려 결과를 인계 파일에 적는다.

## 건드릴 파일

`web/js/app.js` (저장을 읽고 쓰는 곳만), `tools/test/full/save2d.js` (새 파일), 묶은 결과 파일, 그리고 인계 파일.

## 하지 말 것

- 저장하는 것을 늘리지 않는다. 개인 정보를 저장하지 않는다.

## 완료 기준

- 시험이 통과한다.
- `node tools/check.js --full` 합격.
