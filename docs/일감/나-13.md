# 일감 나-13 · 미리보기 파일 크기 검사

- 줄: 코드 줄 나 · 점검 도구 · 브랜치: `relay/tools` · 맡을 수 있는 AI: GPT, Gemini
- 먼저 끝나 있어야 하는 것: 나-12
- 인계 파일: `docs/인계/일감나13_AI이름.md`
- 함께 지킬 규칙: `docs/08_작업줄.md`의 '모든 줄에 함께 쓰는 규칙'

## 왜

한 파일 미리보기가 커지면 휴대폰에서 여는 시간이 길어진다. 지금 2D는 약 0.5MB, 3D는 약 2.4MB다.

## 할 일

1. `tools/lint/size.js`: `dist/preview.html`과 `dist/preview3d.html`이 있으면 크기를 찍고, 무엇이 큰지 (그림, 인물 모델, 코드) 어림 표를 찍는다. 2D가 1.5MB, 3D가 6MB를 넘으면 경고(`exit 2`)로 낸다. 파일이 없으면 넘어간다.
2. 검사 파일은 `tools/lint/`에 둔다. 인자 없이 `node tools/lint/파일.js`로 돌고, 통과하면 `exit 0`, 불합격이면 `exit 1`, 사람이 봐야 하는 경고만 있으면 `exit 2`로 끝난다. 걸린 곳은 파일 이름과 줄 번호, 까닭을 한국어로 한 줄씩 찍는다. 새 패키지를 설치하지 않는다.

## 건드릴 파일

`tools/lint/size.js` (새 파일), 그리고 인계 파일.

## 하지 말 것

- 크기를 줄이려고 그림이나 모델을 고치지 않는다 (재기만 한다).

## 완료 기준

- 지금 main에서 돌린 표가 인계 파일에 있다.
- `node tools/check.js` 합격.
