# 일감 다-8 · 카드 5-나 · 요단 강 새 그림의 화면 확인

- 줄: 코드 줄 다 · 2D 시범판 · 브랜치: `relay/web2d` · 맡을 수 있는 AI: GPT, Gemini
- 먼저 끝나 있어야 하는 것: 다-1. 문은 열려 있다 (총괄이 2026-11-20에 새 그림을 main에 넣었다)
- 인계 파일: `docs/인계/일감다8_AI이름.md` · 화면 사진: `docs/인계/사진/일감다8_*.png`
- 함께 지킬 규칙: `docs/08_작업줄.md`의 '모든 줄에 함께 쓰는 규칙'

## 왜

2D 시범판의 요단 강 그림을 대표가 고른 새 그림으로 바꿨다 (2026-11-20. 총괄이 `web/assets/bg/alt02.jpg`와 `alt02.meta.json`을 넣고 옛 `alt02.svg`를 뺐으며 `web/js/content.js`의 문구 네 곳을 그림에 맞췄다. `docs/시안/요단강/총괄_검토.md`의 맨 뒤 절). 총괄은 8~10세의 길만 화면 사진으로 보았다. 나머지 나이 단계와 영역마다의 확인이 남았다.

## 할 일

1. 묶은 뒤 2D 시범판에서 요단 강 장면 (ALT-02. 갈림길에서 '여호수아'를 고르면 나온다)을 나이 단계 셋 (8~10세, 11~13세, 14~19세)으로 끝까지 걷는다 (`node tools/test/walk2d.js 0 여호수아 폴더`, `1`, `2`도 같다).
2. 나이 단계마다 말씀 네 개의 화면을 열어, 화면이 비추는 곳이 글이 말하는 대상과 맞는지 본다 (여호수아, 궤, 궤 오른쪽 위의 빈 강바닥, 행렬과 제사장 사이의 마른 강바닥).
3. 8~10세의 '다른 점 찾기' 화면에서 고리 셋이 서로 겹치지 않고, 아래 글 상자에 가리지 않으며, 답 세 줄이 한 화면에 다 보이는지 본다. 화면 크기 360×640과 390×844 둘 다에서 본다.
4. `web/js/content.js`가 쓰는 영역 이름이 `web/assets/bg/alt02.meta.json`에 모두 있는지 본다.
5. 어긋난 것이 있으면 고치지 말고 인계 파일에 적는다 (어느 나이 단계, 어느 화면, 무엇이 어긋나는지).

## 건드릴 파일

`docs/인계/사진/` (나이 단계마다 두세 장), 그리고 인계 파일. 그 밖에는 고치지 않는다.

## 하지 말 것

- 그림, `alt02.meta.json`, `web/js/content.js`를 고치지 않는다. `tools/art-src/gen_alt02.js`는 그대로 둔다 (기록).

## 완료 기준

- 나이 단계 셋의 화면 사진을 열어 보았고 인계 사진으로 남겼다.
- `node tools/check.js --full` 합격.
