# Antigravity · 광야에서 움직이는 그늘 기다리기

2026-11-28 배정. `antigravity/exodus-desert-shade`에서 시작한다. 출발 커밋은 `d9ed09a`이다. 17세 플레이어가 뜨거운 모래를 바로 건널지, 바위 그림자가 돌아오기까지 기다릴지 지형을 보고 결정하는 장면을 구현한다.

## 게임에서 바꿀 일

- 일곱 현장 원정(`expedition.html#road`)의 다섯 번째 현장 **그늘이 사라지기 전에**가 대상이다. `web/expedition/road.js`의 `cellShade`, 이동의 열기·물 계산, `snapshot`과 `undo`부터 본다. 이미 있는 그늘·우물·물병을 그대로 활용한다.
- **그늘 기다리기**를 누르면 자리를 지키고 한 턴을 보낸다. 기다림도 같은 턴에 같은 칸으로 이동한 경우와 같은 볕·그늘 비용을 치른 뒤 해가 움직인다. 차양의 물을 자동 보충하지 않는다. 햇볕에 오래 서서 물이 바닥나면 기존 탈진과 되돌리기가 작동해야 한다.
- 다음 그림자가 어느 쪽에 생길지 바위 가장자리나 모래 위 빛으로 읽을 수 있게 한다. 기다리기 전후가 지도에서 보이고, 쉬운 글자 단서도 제공한다. 움직임 줄이기 설정 및 소리 끔에서도 보이게 한다. 숫자만 더하는 방식은 완료 조건을 충족하지 않는다.
- 짧은 볕길과 차양을 거치는 길을 같은 장비로 실제 걸어 비용을 비교한다. 한 턴 되돌리기, 중간 재시작, 물병과 렌즈의 차이, 샘에 도착해 다음 현장으로 넘어가는 흐름을 확인한다.

## 제출과 확인

수정 범위는 `web/expedition/road.js`, `road-art.js`, `road.css`(모두 같은 폴더), `tools/test/full/exodus-desert-shade.js`, `docs/인계/광야_그늘_Antigravity.md`, `docs/인계/사진/출애굽기원정/광야_태양전환_전.png`과 `광야_태양전환_후.png`다. 두 사진은 같은 작은 화면, 같은 바위, 해가 바뀌는 바로 전후를 담는다. `node tools/build-expedition.js` 후 오프라인 실행본을 360×640 터치와 키보드로 확인하고 `node tools/test/full/exodus-road.js`를 실행한다. 인계에는 두 경로에서 측정한 남은 물·도착 여부와 재현 방법을 남긴다.

새 기능 검사 명령은 `node tools/test/full/exodus-desert-shade.js 검사결과폴더 dist/expedition.html`로 실행할 수 있게 한다.

앱에서 직접 맡으면 이 작업 브랜치에만 커밋·푸시한다. 자동 실행기 안에서는 현재 작업 폴더에 결과를 남기면 실행기가 독립 검증 후 로컬 결과 브랜치에 보관한다. 새 API·유료 그림이나 음원 없이 기존 자산으로 만든다.
