# 일감 가-3 · 압도 장면 ③ 소리

- 줄: 코드 줄 가 · 3D 게임 · 브랜치: `relay/horeb` · 맡을 수 있는 AI: GPT, Gemini
- 먼저 끝나 있어야 하는 것: 가-2
- 인계 파일: `docs/인계/일감가3_AI이름.md`
- 함께 지킬 규칙: `docs/08_작업줄.md`의 '모든 줄에 함께 쓰는 규칙'

## 왜

장면의 중심은 하나님이 부르시는 순간에 모든 소리가 멎는 것이다 (지시서 6.2).

## 할 일

1. `docs/09_떨기나무_압도장면.md`의 5절 표와 10절의 소리 줄을 그대로 만든다.
2. 장면 동안에는 떨기나무와의 거리로 불 소리를 정하는 지금의 계산을 멈추고, 끝나면 되돌린다.
3. 시험용 값: `BO3D.debug.audioLevels()`가 전체 소리 크기와 바람, 불, 음악의 크기를 돌려준다.
4. `tools/test/walk3d.js`에 더한다: 2번이 끝났을 때 불 소리가 1번이 끝났을 때보다 크다, 4번에서 0.5초 뒤 전체 소리 크기가 평소의 100분의 1 이하다, 5번에서 음악이 나고 불과 바람은 없다, 6번 뒤 지켜보기가 시작될 때 음악이 처음부터 다시 시작되지 않는다. 소리 끄기 단추를 누른 채로도 한 번 지나간다.

## 건드릴 파일

`web3d/js/fx.js`, `web3d/js/game-awe.js`, `web3d/js/game-loop.js`, `web3d/js/game-story.js`, `web3d/js/game-debug.js`, `tools/test/walk3d.js`, 묶은 결과 파일, 그리고 인계 파일.

## 하지 말 것

- 새 소리 파일을 넣지 않는다. 지금 있는 바람, 불, 낮은 음악만 쓴다.
- 하나님의 음성을 소리로 만들지 않는다. 목소리, 울림, 천둥, 종소리, 합창 같은 소리를 넣지 않는다.
- 불 소리를 지금 게임에서 가장 클 때(넘지 못하는 선에 섰을 때)보다 크게 하지 않는다.

## 완료 기준

- 위 시험이 통과한다.
- `node tools/check.js --full` 합격.
