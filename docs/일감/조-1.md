# 일감 조-1 · 3D 코드 지도

- 줄: 조사 줄 · 참고 문서 · 브랜치: `relay/docs` · 맡을 수 있는 AI: GPT, Gemini
- 먼저 끝나 있어야 하는 것: 없음
- 인계 파일: `docs/인계/일감조1_AI이름.md`
- 함께 지킬 규칙: `docs/08_작업줄.md`의 '모든 줄에 함께 쓰는 규칙'

## 왜

다른 AI가 큰 파일을 통째로 읽지 않고도 고칠 곳을 찾게 한다 (AGENTS.md: 저장소 전체를 훑지 않는다).

## 할 일

1. `docs/참고/코드지도_3D.md`: `web3d/js/`의 파일마다 무엇을 하는지 두세 줄, 밖에서 부르는 이름(함수와 값)의 목록과 한 줄 풀이, 파일끼리 누가 누구를 부르는지.
2. 게임의 흐름(첫 화면 → 이동 → 호렙 산 탐험 → 물음 → 지켜보기 → 관문 → 돌아감 → 요단 강)을 따라 어느 파일의 어느 함수가 맡는지 표로 적는다.
3. 코드를 고치지 않는다. 문서 하나만 새로 만든다. 문서 첫머리에 만든 날짜, 기준으로 삼은 커밋, 만든 AI를 적는다. 쉬운 한국어로 쓴다.

## 건드릴 파일

`docs/참고/코드지도_3D.md` (새 파일), 그리고 인계 파일.

## 하지 말 것

- 짐작으로 쓰지 않는다. 코드를 읽어 확인한 것만 쓰고, 확인하지 못한 것은 ⚠️로 표시한다.

## 완료 기준

- 문서에 적은 함수 이름 열 개를 골라 실제로 그 파일에 있는지 다시 찾아보았다 (인계 파일에 적는다).
- `node tools/check.js` 합격.
