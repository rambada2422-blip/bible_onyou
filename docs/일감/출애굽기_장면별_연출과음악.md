# 출애굽기 장면별 연출과 음악

출애굽기 게임 이어 만들기 자동 작업이 매번 여는 제작표다. 새로 만드는 장면과 이미 플레이 가능한 장면에 같은 기준을 적용한다. 첫 점검에서 부족한 부분이 나오면 그 실행에서 실제 게임을 고치고 재검증한다. 대표에게 같은 제작 지시를 다시 받기 위해 멈출 필요가 없다.

## 이번 작업을 고르는 법

최신 작업 브랜치와 인계부터 확인한다. 아래 ‘다음’ 또는 이후 인계가 지정한 첫 미완료 장면을 고른다. 다른 실행이 맡았으면 겹치지 않는 장면을 고른다. 새 본편의 검토 원고가 도착하면 본문 순서로 제작하고, 원고가 필요한 동안에는 이미 구현된 장면을 개선한다. 직전 장면을 다시 작업할 근거는 새 결함, 새 자료, 대표 피드백이다.

## 한 장면의 완료 기준

- **화면과 영상**. 첫 시점에서 장소·규모·직면한 일이 보이고, 아이의 시선과 조작을 따라 원인, 벌어진 일, 결말로 이어진다. 사건에 필요한 순간과 인물의 반응을 실제 화면에 담는다. 기존 영상을 쓰면 모바일에서 마지막 프레임과 다음 게임 화면까지 재생한다. 경량 2D 장면은 시점 전환·움직임·아이의 직접 탐사로 구현할 수 있다.
- **게임과 말씀**. 첫 30초 안에 관찰·이동·장비 조작·소통 중 의미 있는 행동과 피드백이 있다. 성경 사건과 결말은 본문대로 진행한다. 탐험대의 창작 행동, 사용 근거와 판본이 확인된 읽기 전용 말씀, 탐험대 게임 음악을 구별한다.
- **소리**. 도입과 전환, 결말에 맞는 배경음악을 실제 게임에서 재생한다. 같은 장소에서도 위험과 관찰 대상이 바뀌면 리듬·악기·시작 시점을 다시 정한다. 앞바다에서 뒤따르는 병거로 돌아볼 때와 같이 핵심 시점을 왕복하며 실제 게임에서 확인한다. 환경과 조작에는 구별되는 소리를 쓴다. 자체 영상 음성·낭독·리듬 놀이와 겹치는 구간은 음악을 낮추거나 멈춘다. 의도된 정적과 음악이 다시 들어올 지점을 기록한다. 첫 조작, 음악 끄기·기억, 탭 숨김·이탈 정지, 무음 플레이를 확인한다. 홍해의 재생기 `BO.sceneMusic.create()`와 사용 예제는 `web/js/scene-music.js`, `web/js/red-sea.js`에 있다. 다른 화면은 기존 소리 설정과 함께 동작하게 연결한다.
- **작은 화면과 저장**. 터치와 키보드, 화면 회전, 글자 확대, 새로고침과 다음 장면으로의 복귀를 점검한다. 그림·자막·대사·버튼의 겹침을 실제 화면에서 확인한다.
- **인계**. 해당 장면 행에 확인한 시점·놀이·곡이나 정적·권리 근거·검증 결과와 다음 한 곳을 적는다. `node tools/check.js --full`의 실제 마지막 두 줄과 브랜치 커밋, 플레이 위치를 남긴다. 실제 아이·대표·목회자의 검토는 진행 상태를 그대로 표시한다.

그림·음악·영상은 사용 근거를 기록한다. 유료 생성, 공개 범위 변경, 다른 팀 브랜치 편집은 이 자동 작업 범위 밖이다. 유료 자산이나 감수가 필요한 장면은 필요한 항목만 대기로 남기고 독립적인 다음 장면을 진행한다. 대기만 남으면 후속 실행에서 변경 사항을 확인하고 같은 알림은 생략한다. 전체 대상의 제작과 점검을 마치면 최종 결과를 남기고 반복 예약을 일시 중지한다. main 병합은 대표 승인 뒤 총괄이 진행한다.
