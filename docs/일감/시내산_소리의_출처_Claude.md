# Claude · 시내산에서 들은 소리와 직접 본 일

2026-11-28 배정. `claude/exodus-sinai-witness`에서 시작한다. 출발 커밋은 `d9ed09a`이다. 17세 플레이어가 산 너머 소리를 듣고 자기 추측을 남긴 뒤 실제 광경으로 확인하는 장면 하나를 구현한다.

## 게임에서 바꿀 일

- 기존 아홉 현장(`expedition.html#guided`)의 일곱 번째 현장 **산 위의 말, 산 아래의 소리**에서 작업한다. `web/expedition/play.js`의 `mountain()` 3/4 지점이 입구다. 지금은 **먼 진영 소리 듣기**를 누르면 두 사람의 해석을 곧바로 알려 준다. 소리를 들은 뒤 **내 추측 남기기**를 열 수 있게 하고 **싸움 소리 같다**와 **노랫소리 같다** 중 하나를 남기게 한다. 청각을 쓰지 않아도 상황을 이해할 짧은 자막을 둔다.
- 능선을 열기 전에는 본 장면의 결말을 알려 주지 않는다. 기존 밀기 및 **진영을 내려다보기**로 확인하면 화면에서 **내 추측**과 방금 **직접 본 것**을 함께 읽게 한다. 내 추측에는 선택한 버튼의 문구를 보존한다. 두 선택 모두 진행할 수 있고, 추측을 건너뛴 예전 저장도 이어진다. 선택한 직후 앱을 다시 열어도 같은 추측이 남아야 한다.
- 출 32:1–6은 백성이 한 말과 행동, 32:7–14는 하나님의 진노와 산 위에서의 첫 간구, 32:17–19는 여호수아와 모세가 소리를 해석한 말과 뒤에 본 송아지·춤, 32:30–32는 이튿날의 간구다. 화자의 말과 플레이어의 추측을 구별한다. 심리를 단정하거나 하나님과 모세의 대사를 지어내지 않는다. 기존 `verses.js`의 인용과 장절을 대조한다.

## 제출과 확인

수정 범위는 `web/expedition/play.js`, 필요시 `chapters.js`(같은 폴더의 해당 장면), `tools/test/full/exodus-sinai-witness.js`, `docs/인계/시내산_소리_Claude.md`다. 새 상태는 기존 진행 저장을 이용한다. `node tools/build-expedition.js`로 만든 실행본에서 두 해석, 중간 재시작, 기존 선택 생략 경로를 직접 조작한다. `node tools/test/full/exodus-expedition.js`로 기존 아홉 현장도 확인한다. 인계에는 실행한 명령, 두 경로에서 확인한 실제 문구, 장절 대조와 감수 대기 항목을 남긴다. 내용은 별도 검증을 거치며 목회자 적용 승인은 대표에게 남긴다.
