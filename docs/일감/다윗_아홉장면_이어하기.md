# 안티그래비티 · 다윗 아홉 장면 이어하기

작업 브랜치는 `antigravity/david-week`다. 첫 작업은 `web/david/js/app.js`에서 **D01 들판 망원경의 완료 단추를 누른 새 플레이어가 D02 카메라로, D02에서 D03 겉옷 퍼즐로 실제 진입하는지** 재현하는 것이다. 이후 D09까지 일반 ‘다음 장면’만 따라가며 현재 구현을 확인한다. D01~D09 그림 놀이와 영상은 이미 있으므로 이를 연결해서 사용한다.

## 1. 첫 화면에서 시작하는 아홉 장면

첫 화면에서 한 번 눌러 D01부터 D09까지 그림 놀이를 순서대로 진행할 수 있게 한다. 이미 연결된 구간은 기존 진입 함수를 재사용하고, 기본 물음으로 빠지는 구간만 고친다. 마지막 D09에서는 모은 탐험 일지를 연다. 기존 세 장면 선택 코스와 개별 장면 바로 가기는 각자의 방식으로 계속 동작해야 한다. 산출물은 실제 게임 코드와 갱신된 오프라인 실행본이다.

## 2. 중간에 멈춘 장면부터 이어하기

첫 화면에서 아홉 장면을 떠난 자리를 알아볼 수 있게 하고, 이어할 때 해당 그림 놀이의 조작 상태까지 복원한다. 기존 9/9 일지가 있는 저장본에서 새 여정을 시작해도 모아 둔 일지를 보존한다. 여러 장면을 건너뛰어 체험한 사람의 일지 개수를 연속 여정의 현재 위치로 간주하지 않는다.

## 3. 실제 조작으로 완주 확인

처음 시작해 목록에서 장면을 다시 고르지 않고 아홉 장면을 완주한다. 중간 장면 새로고침·브라우저 재시작, 기존 9/9 저장본, 세 장면 코스도 점검한다. 실제로 끊어진 곳을 고치고 그 경로를 자동 조작 검사에 남긴다. 완주한 일지와 이어하기 화면 사진, 단일 HTML 실행본을 준비하고 [다윗 인계](../인계/다윗_Antigravity.md)에 실행 방법과 점검 결과를 남긴다.
