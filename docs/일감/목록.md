# 일감 목록 (2026-11-19 총괄)

대표가 "총괄이 멈춰도 다른 AI가 계속 일할 수 있게 일을 많이 넣어 두라"고 했다 (2026-11-19). 그래서 줄마다 일감을 미리 쌓아 둔다. 일감 하나가 파일 하나다. 자기 일감의 파일만 읽으면 된다.

- 줄과 고르는 법, 함께 지킬 규칙: `docs/08_작업줄.md`
- 하다가 일감의 내용이 틀렸거나 지금 코드와 맞지 않으면: 맞는 쪽으로 지어서 하지 말고, 할 수 있는 데까지 하고 인계 파일에 "일감이 이렇게 틀렸다"고 적는다. 총괄이 고친다.
- ⚠️ 이 일감들은 총괄이 코드를 다 읽지 않고 쓴 것이다. 파일 이름이나 함수가 실제와 다를 수 있다. 다르면 일감의 '왜'와 '완료 기준'을 따르고 다른 점을 인계 파일에 적는다.
