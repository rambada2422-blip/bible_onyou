# 일감 가-2 · 압도 장면 ② 순서와 글자

- 줄: 코드 줄 가 · 3D 게임 · 브랜치: `relay/horeb` · 맡을 수 있는 AI: GPT, Gemini
- 먼저 끝나 있어야 하는 것: 가-1
- 인계 파일: `docs/인계/일감가2_AI이름.md` · 화면 사진: `docs/인계/사진/일감가2.png` (한두 장)
- 함께 지킬 규칙: `docs/08_작업줄.md`의 '모든 줄에 함께 쓰는 규칙'

## 왜

그림판 위에서 장면의 순서 0~6번을 차례로 보여 주고 글자 두 줄을 띄운다.

## 할 일

1. `docs/09_떨기나무_압도장면.md`의 1절 표, 3.1절, 4절, 7절, 10절(0번, 물러나는 움직임, 글자의 때, 그림을 바꾸는 때)을 읽고 그대로 만든다.
2. 끼워 넣는 자리: 부품 3을 주운 뒤 최온의 말에서 '다음'을 누른 뒤, 지켜보기 1 / 5 창이 뜨기 전이다. 6번이 끝나면 지금 게임이 하던 대로 지켜보기 1 / 5로 간다.
3. 글자는 `web3d/js/content3d.js`의 `horeb` 안에 아래 자료를 **글자 그대로** 붙여 넣고 거기서 읽는다. 문구를 코드에 직접 쓰지 않는다.

```js
awe: {
  call: { ref: '출 3:4', t1: '하나님이 떨기나무 가운데서 모세의 이름을 부르셨어요.', t2: '하나님이 떨기나무 가운데서 모세를 부르셨어요.', t3: '하나님이 떨기나무 가운데서 모세를 부르셨다.' },
  hide: { ref: '출 3:6', t1: '모세는 얼굴을 가렸어요.', t2: '모세는 하나님 뵙기를 두려워해서 얼굴을 가렸어요.', t3: '모세는 하나님 뵙기를 두려워하여 얼굴을 가렸다.' }
}
```
4. 장면 동안 위쪽 표시줄, 목표 문구, 도감·사진기·소리 단추, 조종 막대를 숨기고 끝나면 되돌린다.
5. 시험용 값: 자동 조작 때는 순서마다 멈췄다가 `BO3D.debug.aweNext()`를 받으면 다음 순서로 간다. `BO3D.debug.aweState()`는 지금 순서 번호와 떠 있는 글자를 돌려준다.
6. `tools/test/walk3d.js`가 이 장면을 지나가게 고친다. 나이 단계 셋에서 4번과 5번의 글자가 위 자료와 같은지 맞춰 보고, 5번에서 그림을 바꾸기 직전과 직후의 화면을 찍어 그림의 가로 0~719에 해당하는 곳이 같은지 비교한다.
7. 가-1에서 총괄이 본 것 하나를 함께 고친다: 전체 보기에서 위쪽 하늘 띠와 그림 윗변이 만나는 곳에 가로선이 옅게 보인다 (390×844 화면 사진). 띠의 색을 그림 맨 윗줄과 똑같이 맞추거나, 그림 윗부분 40줄에 걸쳐 띠의 색으로 부드럽게 이어지게 해서 선이 보이지 않게 한다. 고친 뒤 사진을 열어 본다.
8. 소리는 다음 일감(가-3)에서 한다. 이 일감에서는 지금 소리가 깨지지 않게만 둔다. 건너뛰기와 움직임 줄이기는 가-4에서 한다.

## 건드릴 파일

`web3d/js/game-awe.js`, `web3d/js/game-story.js`, `web3d/js/game-ui.js`, `web3d/js/content3d.js` (위 자료 붙여 넣기만), `web3d/js/game-debug.js`, `web3d/css/game.css`, `tools/test/walk3d.js`, 묶은 결과 파일, 그리고 인계 파일.

## 하지 말 것

- 위 자료의 글자를 한 글자도 바꾸지 않는다. 다른 문구를 새로 쓰지 않는다.
- 지켜보기와 관문의 문구, 순서를 바꾸지 않는다.
- 두 그림을 겹쳐서(반투명하게) 바꾸지 않는다. 인형풍 화면과 그림을 직접 겹치지 않는다 (모래색을 거친다).
- 화면이 떨기나무 쪽으로 다가가는 움직임을 넣지 않는다 (물러나는 움직임 한 번뿐이다).

## 완료 기준

- 나이 단계 셋에서 자동 조작이 이 장면을 지나 끝까지 간다.
- 4번과 5번의 화면 사진을 열어 보았다: 글자가 떨기나무, 모세, 바위를 가리지 않는다.
- `node tools/check.js --full` 합격. `content3d.js`가 바뀌어 '확인 필요 1건'이 나오는 것은 맞다 (총괄이 글자를 대조한다).
