# 일감 다-1 · 2D 자동 조작을 나이 단계 셋 모두로

- 줄: 코드 줄 다 · 2D 시범판 · 브랜치: `relay/web2d` · 맡을 수 있는 AI: GPT, Gemini
- 먼저 끝나 있어야 하는 것: 없음
- 인계 파일: `docs/인계/일감다1_AI이름.md`
- 함께 지킬 규칙: `docs/08_작업줄.md`의 '모든 줄에 함께 쓰는 규칙'

## 왜

전체 점검은 2D 시범판을 11~13세 한 단계로만 지나간다.

## 할 일

1. 새 시험 `tools/test/full/walk2d_tiers.js`: `tools/test/walk2d.js`를 8~10세와 14~19세로도 끝까지 돌린다.
2. 통과하지 못하면 까닭을 본다. 시험 쪽의 문제면 `tools/test/walk2d.js`를 고치고, 게임 쪽의 문제면 고치지 말고 인계 파일에 적는다.
3. 새 시험 파일은 `tools/test/full/` 폴더에 둔다. 첫 인자로 화면 사진을 둘 폴더를 받고, 실패하면 `exit 1`로 끝난다. `tools/check.js`는 고치지 않는다 (일감 나-1이 끝나면 전체 점검이 이 폴더를 스스로 찾아 돌린다). 그 전에는 `node tools/test/full/파일.js dist/check/이름`으로 직접 돌려 결과를 인계 파일에 적는다.

## 건드릴 파일

`tools/test/full/walk2d_tiers.js` (새 파일), `tools/test/walk2d.js`, 그리고 인계 파일.

## 하지 말 것

- 대본, 물음, 정답을 고치지 않는다.

## 완료 기준

- 두 단계 모두 끝까지 가거나, 못 간 까닭이 인계 파일에 있다 (그때는 `상태: 하는 중`).
- `node tools/check.js --full` 합격.
