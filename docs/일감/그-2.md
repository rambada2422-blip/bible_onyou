## 왜

8~10세의 탐지기 물음은 그림 보기로 하기로 했는데 그림이 아직 없어 글자 보기로 두었다 (`docs/07_호렙_퀴즈와_동선.md` 2절).

## 할 일

1. 아래 아홉 가지를 작은 그림으로 만든다. 물음 하나에 보기 그림 셋이다.
  - 물음 1: 낙타 떼 / 양 떼 / 소 떼
  - 물음 2: 바닷가 / 큰 성읍 / 산 (하나님의 산 호렙)
  - 물음 3: 불이 붙은 떨기나무 / 장막 안 / 우물가
2. 그림체: 아이 그림책 삽화. 따뜻하고 단순하다. 평면 채색에 한 단계 어두운 그림자, 윤곽선 없음 (`docs/02_그림_스타일가이드.md` 2~4절의 색과 금지 사항을 따른다). 정사각형. 글자 없음. 사람 없음.
3. 한눈에 무엇인지 알 수 있어야 하고, 같은 물음의 세 그림은 크기, 밝기, 정성이 같아야 한다 (맞는 답만 눈에 띄면 안 된다).
4. 지킬 것: 떨기나무 그림은 잎이 초록이고 연기와 재가 없으며 불꽃 속에 얼굴이나 사람 모양이 없다. 산 그림에 건물, 십자가, 하늘의 빛줄기, 후광을 넣지 않는다. 성읍 그림에 신상이나 신전을 넣지 않는다.
5. 그림은 `docs/시안/그림보기_호렙/`에 `q1_a.png`처럼 이름 붙여 두고 같은 폴더에 제작 기록을 쓴다.
6. 카드 E의 여섯 줄(진행판 '작업 카드 E')을 그림마다 확인해 제작 기록에 한 줄씩 적는다. 만든 도구와 날짜, 넣은 요청문 전문을 제작 기록에 적는다. 그림을 다 만든 뒤 `node tools/check.js`(빠른 점검)를 돌린다.
