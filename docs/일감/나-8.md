## 왜

이 저장소는 누구나 볼 수 있는 공개 저장소다 (대표 2026-11-19). 비밀값이나 개인 정보가 실수로 올라가면 안 된다.

## 할 일

1. `tools/lint/secrets.js`: 저장소의 글 파일에서 찾는다. 이메일 주소, 전화번호(010으로 시작하는 꼴), 주민등록번호 꼴, 열쇠 꼴(`sk-`, `ghp_`, `AKIA`, `AIza`로 시작하는 긴 글자열, `-----BEGIN` 으로 시작하는 줄).
2. 넘어가는 것: `noreply@anthropic.com`, 그림을 글자로 바꾼 긴 자료 (묶은 결과 파일 `web/js/art.js`, `web3d/js/glbdata.js` 등), `web3d/vendor/`.
3. 찾으면 불합격(`exit 1`)으로 내되, **찾은 값 자체는 화면에 찍지 않는다** (파일 이름과 줄 번호, 무슨 종류인지만 찍는다).
4. 검사 파일은 `tools/lint/`에 둔다. 인자 없이 `node tools/lint/파일.js`로 돌고, 통과하면 `exit 0`, 불합격이면 `exit 1`, 사람이 봐야 하는 경고만 있으면 `exit 2`로 끝난다. 걸린 곳은 파일 이름과 줄 번호, 까닭을 한국어로 한 줄씩 찍는다. 새 패키지를 설치하지 않는다.

## 건드릴 파일

`tools/lint/secrets.js` (새 파일), 그리고 인계 파일.

## 하지 말 것

- 찾은 값을 인계 파일, 커밋 글, 화면에 옮겨 적지 않는다.
