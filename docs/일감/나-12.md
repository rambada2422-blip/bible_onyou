# 일감 나-12 · 전체 점검을 더 빨리 끝내기

- 줄: 코드 줄 나 · 점검 도구 · 브랜치: `relay/tools` · 맡을 수 있는 AI: GPT, Gemini
- 먼저 끝나 있어야 하는 것: 나-11
- 인계 파일: `docs/인계/일감나12_AI이름.md`
- 함께 지킬 규칙: `docs/08_작업줄.md`의 '모든 줄에 함께 쓰는 규칙'

## 왜

전체 점검이 15분쯤 걸린다 (호렙 산 자동 조작이 약 10분). 사용 한도가 작은 계정에 부담이다.

## 할 일

1. `node tools/check.js --full --parallel`: 자동 조작들을 동시에 돌린다. 기본(옵션 없음)은 지금처럼 차례로 돈다.
2. 동시에 돌려도 결과가 같은지 본다: 옵션을 주고 세 번 이어서 돌려 세 번 모두 합격하는지, 걸린 시간이 얼마나 줄었는지 표로 인계 파일에 적는다.
3. 세 번 가운데 한 번이라도 불합격이면 그 까닭(시간 초과인지 등)을 적고, 옵션은 남기되 "아직 믿을 수 없음"이라고 `tools/test/README.md`에 적는다.

## 건드릴 파일

`tools/check.js`, `tools/test/README.md`, 그리고 인계 파일.

## 하지 말 것

- 자동 조작 안의 기다리는 시간을 줄이거나 확인 항목을 빼서 빠르게 하지 않는다.
- 기본 동작을 바꾸지 않는다.

## 완료 기준

- 세 번 돌린 표가 인계 파일에 있다.
- 옵션 없이 `node tools/check.js --full` 합격.
