# 그래픽 제작 협업과 첫 시범(OT-12 시내 산)

- 작성: 2026-11-18. 근거: 대표의 "Claude × GPT × Gemini 그래픽 제작 협업 프로토콜"(2026-11-18).
- 상태: **무대의 틀과 산 그림 1장까지 구현하고 자동 시험을 통과했다. 광야·백성·모세 그림은 아직 임시 도형이다(완성 아님).** 아이 시험 전, 목회자 감수 전.

## 1. 일하는 방식(대표 결정)

| 맡는 이 | 하는 일 |
|---|---|
| Claude | 장면 분석, 화면 연출 설계, GPT 요청서 작성, 받은 그림 검수, 코드 구현과 통합, 실행 검증 |
| GPT | 그림 제작(요청서대로) |
| Gemini | GPT가 거듭 못 맞출 때만 대안 |
| 대표 | 요청서를 GPT에 전달하고, 나온 그림(공유 링크나 파일)을 Claude에게 전달 |

- 한 장면씩 돈다: 분석 → 요청서 → 그림 전달 → 검수 → 통합 → 시험 → 다음 장면. 한 장면이 검증되기 전에 다른 장면의 그림을 많이 만들지 않는다.
- 움직여야 하는 것은 배경 그림에 합치지 않는다. 하늘·구름·연기·불·번개·화면 단추는 코드로 만든다. 그림 안에 글자와 단추를 넣지 않는다.
- 성경 표현 규칙은 `docs/00_공통규칙서.md`와 같다(하나님·천사의 형상 없음, 하나님의 음성 없음, 본문에 없는 것을 지어내지 않음, 아이들은 목격자).

## 2. 왜 시내 산을 먼저 했나(분석)

- 이야기 카드 28장면의 배경은 장면별이 아니라 **시대별 10장**이다. 시내 산 장면에는 "출애굽" 시대 그림(노을 진 바다와 야자수)이 나와 장면과 맞지 않았다.
- 화면 20개가 모두 글과 [다음]이었다. 우레·번개·구름·연기·흔들리는 산은 글로만 나왔다. "돕기"는 체크 3개 누르기, 단추 1개 누르기였다.
- 게임 안에 그림 파일은 한 장도 없었다(코드로 그린 그림, 3D 인물 모형 14개, 영상 1개뿐).
- 본문이 보여 줄 것을 분명히 적어 둔 장면이다(출 19:16-18의 구름·불·연기·번개·나팔 소리·흔들림). 자리가 한 곳이라 그림 4장으로 된다.

## 6. 대표가 정할 것·확인할 것

1. ⚠️ **나팔 소리**(출 19:16)를 합성음으로 넣었다(감수 ★★★). 부는 이는 그리지 않고, 하나님의 음성은 만들지 않는다. 빼라고 하시면 뺀다.
2. ⚠️ 본문에 없어 조심해서 정한 것: 옷을 빤 물(그릇 하나만), 경계의 표시(화면 점선으로만), 이틀을 넘기는 것(탐험대의 가상 장치로 표시).
3. ⚠️ 소리(우레·나팔)는 귀로 확인하지 못했다. 휴대폰에서의 속도도 재지 못했다.
4. 구름과 불이 얼굴이나 사람처럼 보이지 않는지는 화면을 열어 확인했다(그렇게 보이는 곳 없음). 감수 때 다시 본다.
