# 3D 코드 지도 (`web3d/js/`)

- 만든 날짜: 2026-11-20
- 기준 커밋: `8d15dda` (`main`)
- 만든 AI: Gemini (안티그래비티)

3D 게임(`web3d/index.html`, 미리보기 묶음 `dist/preview3d.html`)을 이루는 `web3d/js/`의 파일 19개를 정리한 지도다. 큰 파일을 통째로 읽지 않고도 고칠 자리를 찾는 데 쓴다.

---

## 1. 한눈에 보는 구조와 불러오는 순서

`web3d/index.html`은 아래 순서대로 스크립트를 읽는다.

1. 외부 라이브러리·공용 자료: `vendor/three.min.js`, `vendor/GLTFLoader.js`, `../web/js/content.js`(`BO.content`), `../web/js/icons.js`(`BO.icons`)
2. 3D 자료·모델·세계·효과: `content3d.js` → `avatars.js` → `models.js` → `models_jordan.js` → `glbdata.js` → `world.js` → `jordan.js` → `fx.js`
3. 게임 모듈 (`BO3D.gameModules.*`): `game-scene.js` → `game-ui.js` → `game-awe.js` → `game-exploration.js` → `game-travel.js` → `game-jordan.js` → `game-story.js` → `game-controls.js` → `game-loop.js` → `game-debug.js`
4. 진입점: `game.js` — 비공개 공유 객체 `G`를 만들어 위 10개 모듈을 순서대로 등록·초기화하고, `G.resize()`, `G.menu()`, `requestAnimationFrame(G.frame)`을 부른다.

> **파일끼리 연결하는 방식**: `game-*.js` 모듈 10개는 모두 `G`를 통해 함수와 상태를 주고받는다. 바깥 파일(`world.js`, `jordan.js`, `models.js`, `models_jordan.js`, `fx.js`, `avatars.js`, `glbdata.js`)은 전역 `BO3D.*`에, 3D 전용 문구(`content3d.js`)는 `BO.content3d`에 걸린다.

## 2. 자료·모델·세계·효과 파일 (8개)

### `content3d.js` (195줄)
- **하는 일**: 3D 전용 문구와 퀴즈 자료를 담는다. 시간 나침반 이동 화면 문구, 호렙 산 탐지기 물음 3개와 압도 장면 글자, 요단 강 시대 추리 단서·증거·결론 문구가 들어 있다. ⚠️ 내용 파일이므로 Claude만 쓰고 별도 검증을 거쳐야 한다.
- **밖에서 부르는 이름**:
  - `BO.content3d.route`: 시간 나침반 이름 고르기 화면의 제목·안내·이동 문구.
  - `BO.content3d.horeb`: 호렙 산 탐험 안내(`intro`, `objective`, `kicker`, `bookHint`, `lastPart`, `lookUp`), 압도 장면 글자(`awe.call`, `awe.hide`), 탐지기 물음 3개(`quiz`).
  - `BO.content3d.jordan`: 요단 강 시대 추리 안내(`unknownPlace`, `place`, `ref`, `story`, `objective`, `need`, `edgeRiver`, `edgeCrowd`), 단서 5개(`clues`), 증거 고르기(`evidence`), 강 이름 확인(`river`), 추리 결과(`conclusion`).
- **누가 부르는가**: `game-scene.js`가 `G.C3`, `G.JD`로 받아 두고 `game-ui.js`, `game-awe.js`, `game-exploration.js`, `game-travel.js`, `game-jordan.js`, `game-story.js`가 읽는다.

### `avatars.js` (4줄, 자동 생성)
- **하는 일**: `tools/build3d.js`가 만드는 파일이다(직접 고치지 않는다). 주인공 세 아이의 얼굴 SVG 그림 문자열을 담는다.
- **밖에서 부르는 이름**:
  - `BO3D.avatars`: `{ choeon, hyu, onwoo }` 키로 SVG 문자열을 꺼낸다.
- **누가 부르는가**: `game-scene.js`(`avatar`)가 읽고, `game-ui.js`, `game-story.js`, `game-jordan.js`가 대화 말풍선과 메뉴에 쓴다.

### `glbdata.js` (5줄, 자동 생성)
- **하는 일**: `tools/build3d.js`가 만드는 파일이다(직접 고치지 않는다). Blender로 만든 3D 인물 파일(GLB)과 압도 장면 정지 그림(JPG)을 Base64 문자열로 묶어 단일 HTML 미리보기에서도 열리게 한다.
- **밖에서 부르는 이름**:
  - `BO3D.glbData`: `{ joshua, moses, priest }` 키로 GLB Base64 데이터를 꺼낸다.
  - `BO3D.aweData`: `{ bush_2, bush_3 }` 키로 압도 장면 그림 Base64 데이터를 꺼낸다.
- **누가 부르는가**: `game-scene.js`(모세 GLB), `game-travel.js`(여호수아·제사장 GLB), `game-awe.js`(압도 장면 그림).

### `models.js` (1,331줄)
- **하는 일**: 외부 파일 없이 Three.js 도형과 정점 색으로 호렙 산의 인물·동물·사물 3D 모델을 만든다. 단위는 미터, 발이 `y=0`, 정면이 `+Z`다. ⚠️ 내부 도형 조립 함수 하나하나는 끝까지 읽지 않았고, 바깥에 내놓는 `BO3D.models` 목록만 확인했다.
- **밖에서 부르는 이름 (`BO3D.models`)**:
  - `config`: 모델 공통 치수·설정 값.
  - `kid(key)`: 주인공 아이(`choeon`, `hyu`, `onwoo`) 모델과 걷기 갱신 함수(`{ group, update }`).
  - `moses()`: 모세 기본 모델(`{ group, setPose, update }`). GLB가 있으면 `game-scene.js`가 바꿔 끼운다.
  - `sheep(seed)`: 양 한 마리 모델(`{ group, update }`).
  - `bush()`: 불붙은 떨기나무 기본 모델(`{ group, update }`).
  - `timeMachine()`: 놋쇠 타임머신 모델(`{ group, update }`).
  - `scrap()`: 빛나는 말씀 조각 모델(`{ group, update }`).
  - `rock(seed)`, `shrub(seed)`, `acacia(seed)`: 광야 바위·덤불·아카시아 나무 소품 모델.
- **누가 부르는가**: `game-scene.js`, `world.js`, `jordan.js`(바위·타임머신), `game-exploration.js`(부품 옆 바위).

### `models_jordan.js` (1,219줄)
- **하는 일**: 요단 강 장면(수 3:1-17)의 인물·궤·성읍·자연물 3D 모델을 만든다. `models.js`와 같은 도형 조립 방식이다. ⚠️ 내부 도형 조립 함수는 끝까지 읽지 않았고, 바깥에 내놓는 `BO3D.models2` 목록만 확인했다.
- **밖에서 부르는 이름 (`BO3D.models2`)**:
  - `israelite(seed)`: 강을 건너는 백성 한 사람 모델(`{ group, update }`).
  - `priestSimple(side)`: 궤를 메는 제사장 기본 모델(`side`: `'L'` 또는 `'R'`). GLB가 있으면 `game-travel.js`가 바꿔 끼운다.
  - `leaderSimple()`: 백성을 이끄는 사람(여호수아) 기본 모델. GLB가 있으면 바꿔 끼운다.
  - `arkCovered()`: 청색 덮개로 덮은 언약궤와 채 모델(`userData`에 채 위치 포함).
  - `waterWall()`, `waterSurface()`: 물 모델 함수(요단 강 본문 규칙상 `jordan.js`에서는 현재 쓰지 않는다).
  - `jericho()`: 강 건너편 여리고 성읍 모델.
  - `palm(seed)`, `reeds(seed)`, `grain(seed)`: 종려나무, 강가 풀, 추수 때 곡식밭 소품 모델.
- **누가 부르는가**: `jordan.js`(`build`).

### `world.js` (202줄)
- **하는 일**: 호렙 산 광야의 지형 높이, 걸을 수 있는 범위, 하늘·구름·먼 산, 햇빛, 바위·덤불·나무 흩뿌리기를 만든다.
- **밖에서 부르는 이름 (`BO3D.world`)**:
  - `P`: 주요 좌표 모음(`start`, `machine`, `flock`, `mosesStart`, `mosesEnd`, `bush`, `scraps`, `witnessRadius`, `mountain`).
  - `height(x, z)`: `(x, z)` 자리의 땅 높이(떨기나무 언덕과 호렙 산 포함).
  - `walkable(x, z)`: 아이들이 걸어 다닐 수 있는 땅인지 여부.
  - `build(scene)`: 장면에 하늘·지형·빛·소품을 채우고 `{ sun, hemi }`를 돌려준다.
  - `rng(seed)`: 같은 씨앗이면 늘 같은 난수를 내는 함수.
- **누가 부르는가**: `game-scene.js`(호렙 산 구성 및 `G.H`, `G.WALK`, `G.P`), `jordan.js`(`rng`), `tools/test/walk3d.js`(`P.scraps`).

### `jordan.js` (179줄)
- **하는 일**: 두 번째 장소인 요단 강(수 3:1-17)의 지형, 마른 강바닥, 제사장 넷과 덮인 궤, 지도자, 건너는 백성 46명 행렬, 멀리 여리고 성읍, 사진 단서 목표 지점을 만든다.
- **밖에서 부르는 이름 (`BO3D.jordan`)**:

## 3. 게임 모듈 파일 (`game-*.js`, 10개)과 진입점 (`game.js`)

### `game.js` (26줄)
- **하는 일**: 3D 게임의 시작점이다. 공유 객체 `G`를 만들고 `BO3D.gameModules`의 10개 모듈을 정해진 순서대로 등록·초기화한 뒤 첫 화면과 프레임 루프를 시작한다.
- **밖에서 부르는 이름**: 없음(즉시 실행 함수).
- **부르는 대상**: `BO3D.gameModules`의 `scene`, `ui`, `awe`, `exploration`, `travel`, `jordan`, `story`, `controls`, `loop`, `debug`, 그리고 `G.resize`, `G.menu`, `G.frame`.

### `game-scene.js` (246줄)
- **하는 일**: Three.js 렌더러·카메라·호렙 산 장면을 만들고, 타임머신·떨기나무·모세(GLB 포함)·양 떼 32마리·말씀 조각·경계선을 배치한다. DOM 만들기와 수학 보조 도구도 제공한다.
- **밖에서 부르는 이름 (`G.*`)**:
  - 지형·수학·DOM 도구: `H`, `WALK`, `el`, `add`, `tx`, `icon`, `refChip`, `avatar`, `bookName`, `dist2`, `lerpAngle`, `place`.
  - 인물·동물: `spawnKids`(선택한 아이와 동료 둘을 현재 장소에 배치), `updateSheep`(양 떼 32마리 무리 움직임).
  - 주요 상태·객체: `T`, `C`, `C3`, `JD`, `ALT`, `P`, `SC`, `S`, `cur`, `JL`, `M`, `FX`, `root`, `canvas`, `ui`, `renderer`, `scene`, `camera`, `env`, `post`, `machine`, `bush`, `bushFx`, `moses`, `sheep`, `scraps`, `ring`, `kids`, `player`, `followers`.
- **누가 부르는가**: 사실상 모든 `game-*.js` 모듈이 `G.el`, `G.tx`, `G.H`, `G.place` 등을 부른다. `updateSheep`은 `game-loop.js`가, `spawnKids`는 `game-story.js`와 `game-jordan.js`가 부른다.

### `game-ui.js` (114줄)
- **하는 일**: 게임 상태 초깃값(`state`, `step`, 카메라·조이스틱 변수)과 화면 위 UI 요소(상단 표시줄, 조종 막대, 안내 문구, 토스트, 하단 시트, 오버레이, 소리·도감·사진기·아지트·추리 단추)를 만든다. 탐지기 물음과 말씀 카드 조립도 맡는다.
- **밖에서 부르는 이름 (`G.*`)**:
  - 함수: `setObjective`, `toast`, `showPanel`, `hidePanel`, `btn`, `detectorQuestion`(호렙 산 탐지기 3지선다 물음 화면), `beatNodes`(성경 장절·이야기·대화 말풍선 묶음).
  - 상태·UI 요소: `state`, `step`, `camYaw`, `camPitchH`, `camDist`, `lastDrag`, `now`, `camPos`, `camLook`, `camLookT`, `stick`, `drag`, `keys`, `trail`, `mosesWalking`, `mosesArrived`, `lastToast`, `evIdx`, `pspeed`, `baseFov`, `viewShift`, `hud`, `place_`, `count`, `partCount`, `clueCount`, `hudRef`, `track`, `trackArrow`, `trackText`, `base`, `knob`, `hint`, `overlay`, `touch`, `snd`, `dexBtn`, `dexLabel`, `camBtn`, `flash`, `denBtn`, `dedBtn`.
- **누가 부르는가**: UI 단추 클릭 시 `G.FX.audio.mute`, `G.openDex`, `G.openClues`, `G.openDen`, `G.startDeduce`를 부른다. `showPanel`·`toast`·`btn` 등은 `story`, `exploration`, `travel`, `jordan`이 부른다.

### `game-awe.js` (524줄)
- **하는 일**: 불붙은 떨기나무 압도 장면(순서 0~6, 정지 그림 2장, 위쪽 하늘 띠, 가까이 보기·전체 보기, 글자 자리, 모래색 덮개)을 계산하고 진행한다.
- **밖에서 부르는 이름 (`G.*`)**:
  - `startAwe(onDone)`: 압도 장면 순서 0~6을 시작하고 끝나면 `onDone`을 부른다.
  - `stopAwe()`: 압도 장면을 멈추고 화면을 닫는다.
  - `aweNext(arg)`: 시험 모드(`BO3D_TEST`)에서 다음 순서나 그림 교체 직전·직후(`'beforeSwap'`, `'afterSwap'`)로 넘긴다.
  - `aweState()`: 현재 순서, 글자, 장절, 그림 번호, 보기 상태 등을 돌려준다.
  - `showAwe(view, pic)`: 시험용으로 가까이 보기(`'near'`)·전체 보기(`'wide'`)를 바로 띄우거나 닫는다(`'off'`).
  - `aweRect()`, `layoutAwe()`, `computeAweLayout(viewMode, W, H)`: 그림판 위치·크기 계산과 조회.
- **누가 부르는가**: `game-story.js`(`startEvent`가 `startAwe`, `menu`·`begin`이 `stopAwe`), `game-debug.js`(`awe`, `aweRect`, `aweNext`, `aweState`).

### `game-exploration.js` (156줄)
- **하는 일**: 호렙 산에서 사진 찍기와 탐험 도감(5장), 타임머신 부품 3개의 3D 모형과 탐지기 물음 열기, 부품 줍기, 방향·거리 탐지기 갱신을 맡는다.
- **밖에서 부르는 이름 (`G.*`)**:
  - 함수: `dexCount`, `updateDexBtn`, `takeShot`(호렙 산 사진 촬영·도감 저장), `openDex`(탐험 도감 보기), `showDetector(i)`(i번째 탐지기 물음 열기), `takePart(i)`(i번째 부품 줍고 `G.collect(i)` 호출), `updateTracker`(탐지기 화살표·거리와 '타임머신에 타기' 단추 표시).
  - 데이터: `DEX`, `dex`, `wantShot`, `PARTS`, `partsFound`, `sceneDone`, `detectorPart`, `brass`, `partObjs`.
- **누가 부르는가**: `game-loop.js`(`takePart`, `updateTracker`, `takeShot`), `game-story.js`(`showDetector`, `updateDexBtn`, `dexCount`), `game-ui.js`(`openDex`), `game-travel.js`(`dexCount`, `DEX`, `PARTS`).

### `game-travel.js` (185줄)
- **하는 일**: 타임머신 아지트(부품 수리·사진 벽·깃발·탐험 모자 꾸미기), 다음 시대로 출발 연출과 완료 카드, 이름 고르기(시간 나침반) 화면, 시간 이동 전환, 요단 강 GLB 인물 교체를 맡는다.
- **밖에서 부르는 이름 (`G.*`)**:
  - 함수: `openDen`(타임머신 아지트 열기), `updateDepart(dt)`(타임머신 상승 연출), `hudMode`(호렙 산·요단 강에 맞게 상단 표시줄 전환), `route`(시간 나침반 이름 고르기 화면), `warpTo(title, fn)`(1.5초 시간 이동 화면 뒤 `fn` 실행), `loadJordanGlb`(여호수아·제사장 GLB 교체).
  - 객체·상태: `flagColor`, `flag`, `hatOn`, `departGlow`.
- **누가 부르는가**: `game-ui.js`(`openDen`), `game-loop.js`(`updateDepart`), `game-story.js`(`route`, `hudMode`), `game-jordan.js`(`hudMode`, `loadJordanGlb`, `warpTo`).

### `game-jordan.js` (163줄)
- **하는 일**: 요단 강 입장, 사진으로 단서 5개 모으기, 추리 수첩 보기, 증거 고르기·성경 확인·마지막 추리, 추리 결과와 호렙 산으로 돌아가는 흐름을 맡는다.
- **밖에서 부르는 이름 (`G.*`)**:
  - 함수: `enterJordan`(요단 강 장면 생성·입장), `takeClue`(사진 찍어 단서 수집), `openClues`(추리 수첩 열기), `startDeduce`(단서가 모이면 추리 단계 시작).
  - 상태: `clue`(수집한 단서 사진 맵).
- **누가 부르는가**: `game-travel.js`(`route`에서 '여호수아'를 고르면 `enterJordan`), `game-loop.js`(`takeClue`), `game-ui.js`(`openClues`, `startDeduce`).

### `game-story.js` (268줄)
- **하는 일**: 처음 화면(나이 단계·주인공 고르기), 호렙 산 시작과 도입 대화, 말씀 조각 줍기, 사건 목격(압도 장면 → 지켜보기 1/5~5/5), 관문 4종(`choice`, `find`, `findref`, `order`), 마무리 말씀 카드와 탐험 모자 착용을 맡는다.
- **밖에서 부르는 이름 (`G.*`)**:
  - 흐름 함수: `menu`(처음 화면), `begin`(호렙 산 시작), `collect(i)`(i번째 말씀 조각 처리, 3번째면 `startEvent` → `startAwe` → `showBeat`).
  - 공용 UI 조각: `goodNote`, `lookNote`, `findBlock`, `findrefBlock`, `sheetOverlay`, `wearHat`, `hat`.
- **누가 부르는가**: `game.js`(`menu`), `game-travel.js`(`begin`, `menu`, `wearHat`), `game-exploration.js`(`collect`), `game-loop.js`(`collect`), `game-ui.js`(`goodNote`, `lookNote`), `game-jordan.js`(`goodNote`, `findBlock`, `findrefBlock`, `sheetOverlay`, `begin`).

### `game-controls.js` (155줄)
- **하는 일**: 터치 조이스틱·화면 드래그·키보드(WASD/화살표) 입력을 받고, 주인공과 동료 둘의 이동, 호렙 산·요단 강 경계 막기, 모세 걷기, 상황별 카메라 추적(탐험·사건 올려다보기·출발)을 맡는다.
- **밖에서 부르는 이름 (`G.*`)**:
  - `snapCamera()`: 카메라를 주인공 뒤로 즉시 맞춘다.
  - `movePlayer(dt)`: 입력대로 주인공을 이동시키고 모세·떨기나무·요단 강 경계를 지킨다.
  - `moveFollowers(dt)`: 동료 아이 둘이 주인공 발자취(`G.trail`)를 따라오게 한다.
  - `moveMoses(dt)`: 말씀 조각 2 이후 모세가 떨기나무 앞까지 걸어가게 한다.
  - `updateCamera(dt)`: 현재 `G.state`에 맞춰 카메라 위치·시선·화면 올림(`viewShift`)을 부드럽게 갱신한다.
- **누가 부르는가**: `game-loop.js`(`movePlayer`, `moveFollowers`, `moveMoses`, `updateCamera`), `game-story.js`·`game-jordan.js`(`snapCamera`).

### `game-loop.js` (67줄)
- **하는 일**: 화면 크기 변경 대응(`resize`)과 매 프레임 갱신(`frame`)을 맡는다. 현재 장소(호렙 산/요단 강)에 맞춰 애니메이션·이동·부품/조각 줍기·탐지기·카메라·태양 그림자·불 소리·렌더링·사진 촬영을 순서대로 돌린다.
- **밖에서 부르는 이름 (`G.*`)**:
  - `resize()`: 렌더러 크기와 카메라 비율·시야각을 화면 크기에 맞춘다.
  - `frame(t)`: `requestAnimationFrame`으로 매 프레임 실행되는 주 루프.
- **누가 부르는가**: `game.js`(최초 실행), `window` `resize` 이벤트.

### `game-debug.js` (27줄)
- **하는 일**: 자동 점검 스크립트(`walk3d.js`, `walkJ.js`, `awe_layout.js`)가 게임 상태를 읽고 조종할 수 있게 `BO3D.debug`를 열어 준다. 실제 화면에는 영향을 주지 않는다.
- **밖에서 부르는 이름 (`BO3D.debug`)**:
  - 조회: `level`, `clues`, `jordan`, `parts`, `dex`, `sheep`, `aweRect`, `aweState`, `state`.
  - 조종: `awe(view, pic)`, `aweNext(arg)`, `stick(x, y)`, `yaw(v)`, `goto(x, z)`.
- **누가 부르는가**: `tools/test/walk3d.js`, `tools/test/walkJ.js`, `tools/test/full/awe_layout.js`.
