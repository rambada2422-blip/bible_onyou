# 창세기 본편 감수 묶음 (E01~E66)

목회자 감수와 대표 결재를 한 번에 받으려고 만든 문서다. 본편 원고 66편은 모두 별도 검증을 반영했지만 **한 편도 감수를 받지 않았다.** 감수 필수로 표시한 55편은 감수 전에는 확정하지 않고 아이에게 쓰지 않는다. 기준은 `claude/genesis-week`의 `7fe1ecc`(2026-11-25)이다.

원고마다 감수에서 확인받을 것을 적어 두었는데, 모으면 735줄이다. 한 줄씩 보면 끝이 없다. 그런데 대부분은 **같은 쟁점 열네 가지**를 회마다 되풀이해 적은 것이다. 그래서 이 문서는 같은 쟁점의 질문을 하나로 합치고, 합쳐지지 않는 것만 회마다 따로 보게 했다. 목회자와 대표가 아직 답하지 않은 칸은 비워 두었다.

## 2-가. 먼저 볼 묶음: E46·E50·E51·E52와 E53의 첫 줄

대표가 8~10세 이용 방식을 정한 네 회다. 네 회 모두 감수 전이고, 아래의 문장과 가릴 범위는 목회자의 답을 기다린다. 표의 '답' 칸은 비워 두었다.

### 이미 정해진 것과 기다리는 것

| 항목 | 상태 | 내용 |
|---|---|---|
| 네 회의 8~10세 이용 방식 | **결정됨** (대표 2026-11-25) | 8~10세 진행 순서에서 기본으로 건너뛴다. 감수를 마친 뒤 보호자가 고른 회만 한다. 네 원고의 머리말, 나이 단계, 건너뛰는 길에 반영했다 |
| 아동 보호 기관 연락처와 절차 | **확인 대기** | 네 원고의 자리가 비어 있다. 확인된 정보를 받아야 채울 수 있다 |
| 네 회의 문장, 가릴 범위, 답 문장 | **회신 필요** (목회자) | 아래 회마다의 표 |
| 반에서 해도 되는지, 녹음을 쓸지 | **회신 필요** (대표) | 원고는 보호자와 아이 둘이서 하기를 권하고, 녹음과 요약을 아이 혼자 듣거나 읽게 두지 않는다고 적었다 |
| 11~13세 판, 14~19세 판 | 쓰지 않았다 | 네 원고에 연령별 읽기 안내 표만 있다. 8~10세 판의 감수 뒤에 정한다 |

## 3. 여러 회에 걸친 질문 열네 가지

같은 쟁점이 여러 회에 되풀이되어 질문을 하나로 합쳤다. '해당 회차'는 그 쟁점에 닿는 확인 거리가 있는 회다(낱말로 자동 분류한 것이라 어림이다). '검토할 실제 표현'은 원고에 적힌 확인 거리를 옮긴 것이다. **답 칸은 비워 두었다.**

### ① 본문이 적지 않은 까닭과 속마음은 채우지 않는다

- **결정할 질문**: 본문이 까닭을 적지 않은 곳에서 "성경은 까닭을 적지 않아요"라고 답하고 속마음을 채우지 않는 방식을 그대로 둘까요?
- **원고가 한 방식**: 본문이 까닭을 적지 않으면 "성경은 까닭을 적지 않아요"라고 답한다. 인물의 속마음과 본문에 없는 대사를 쓰지 않는다.

## 9. ⚠️ 이 묶음의 한계

- 질문 번호 표시와 '해당 회차'는 낱말을 보고 자동으로 붙였다. 어림이다. 어느 질문에도 들지 않은 줄은 42줄이고 회별 목록에 〔기타〕로 표시했다.
- 확인 거리와 '정할 것'의 문장은 원고에 적힌 그대로 옮겼다. 원고가 바뀌면 다시 뽑아야 한다.
- 가림 종이와 창을 낸 종이가 실물 성경에서 되는지, 실제 아이와 했을 때 어떤지는 어느 회도 확인하지 못했다.
- 이 문서는 감수를 대신하지 않는다. '추천'은 원고를 쓴 쪽의 의견이고, 답 칸이 빈 것은 아직 정해지지 않은 것이다.
