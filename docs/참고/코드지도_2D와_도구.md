## 2D 화면이 열리는 순서

[web/index.html](../../web/index.html)이 `#app`에 게임을 연다. [app.css](../../web/css/app.css)를 읽고, 스크립트를 `content.js` → `icons.js` → `art.js` → `app.js` 순서로 불러온다. 브라우저에서 `web/index.html`을 열거나, `node tools/build.js`를 실행하고 `dist/preview.html`을 열면 된다.

| 파일 | 하는 일과 찾아갈 곳 |
|---|---|
| [web/js/content.js](../../web/js/content.js) | `BO.content`에 나이 단계(`tiers`), 주인공(`chars`), 시간표(`timeline`), 목적지 보기(`route`), 장면 대화·질문·카드(`scenes`)를 담는다. `EX-00`·`EX-01`·`EX-09`는 시간표에서 플레이할 수 있는 장면이고, `ALT-02`·`ALT-03`은 목적지 선택에서 이동하는 장면이다. 3D도 일부 자료를 읽는다. 내용 변경의 담당과 검증은 [AGENTS.md](../../AGENTS.md)의 업무 분담을 따른다. |
| [web/js/icons.js](../../web/js/icons.js) | `BO.icons`에 작은 SVG 그림을 담는다. 8~10세의 그림 보기와 책·일지·읽어 주기 같은 버튼 그림을 찾을 수 있다. 2D와 3D가 함께 읽는다. |
| [web/js/art.js](../../web/js/art.js) | `tools/build.js`의 결과물. `BO.art`에 배경과 주인공 그림, `BO.artMeta`에 배경 상태와 눌러 찾을 영역을 담는다. 그림을 바꿀 때는 `web/assets/bg/`와 `web/assets/char/`에서 원본을 찾은 뒤 다시 묶는다. |
| [web/js/app.js](../../web/js/app.js) | 위 세 자료를 읽어 게임 화면을 만든다. `renderTitle` → `renderSetup` → `renderHub`가 시작·선택·시간표다. `renderRoute`는 목적지 선택, `runScene`은 도착·대화·관문·카드 같은 장면 진행을 맡는다. `renderJournal`과 `renderGuide`는 일지와 구성 안내다. |
| [web/css/app.css](../../web/css/app.css) | `:root`의 색과 글꼴, 시작·선택·시간표 화면, 위쪽 그림 무대(`.stage`)와 아래쪽 대화 영역(`.sheet`), 보기 버튼(`.opt`)의 배치를 맡는다. 끝부분에 움직임 줄이기와 높이 640px 이하 화면의 규칙이 있다. 3D 미리보기에도 이 파일이 들어간다. |

`app.js`에서 진행 저장은 `fresh`·`load`·`save`, 저장 키는 `bo_demo_v1`이다. 배경 상태를 바꾸는 곳은 `runScene` 안의 `setState`다. `region`과 `mapRect`가 배경의 900×1200 좌표를 화면 위치로 바꾸고, `hotspotBlock`이 눌러 찾는 보기를 다룬다. 요단 강은 `web/assets/bg/alt02.jpg`와 `alt02.meta.json`을 읽는다.

## 미리보기와 점검 도구

명령은 저장소 루트에서 실행한다. 묶기와 빠른 점검에는 Node.js가 필요하다. 브라우저 자동 조작에는 Playwright와 Chromium도 필요하다. 자동 조작의 기본 인자는 [자동 점검 안내](../../tools/test/README.md)에도 있다.

| 파일 | 하는 일 | 실행 예 |
|---|---|---|
| [tools/build.js](../../tools/build.js) | 배경·캐릭터 그림과 배경 위치 자료를 `web/js/art.js`로 묶고 `dist/preview.html`을 만든다. 손으로 쓴 SVG의 금지 요소와 같은 이름의 배경 중복을 검사한다. JPG·PNG는 900×1200, 한 장 300KB(300×1024바이트), 사진형 배경 합계 1.5MB의 제한을 확인한다. | `node tools/build.js` |
| [tools/build3d.js](../../tools/build3d.js) | 얼굴 SVG를 `web3d/js/avatars.js`로, 인물 GLB와 압도 장면 JPG를 `web3d/js/glbdata.js`로 묶는다. Three.js 사본과 화면 코드를 넣은 `dist/preview3d.html`을 만든다. | `node tools/build3d.js` |
| [tools/check.js](../../tools/check.js) | 빠른 점검은 JS 문법, 두 미리보기 묶기, 바뀐 파일 목록을 확인한다. 지정된 내용 파일의 변경에는 별도 경고를 붙인다. `--full`은 빠른 점검에 2D 흐름, 사진형 배경, 3D 호렙 산, 3D 요단 강의 네 자동 조작을 더한다. | `node tools/check.js` / `node tools/check.js --full` |
| [tools/test/README.md](../../tools/test/README.md) | 브라우저 자동 조작의 준비물과 기본 인자를 안내한다. 아래 표는 스크립트에서 확인한 현재 인자와 범위다. | 문서 |
| [tools/test/walk2d.js](../../tools/test/walk2d.js) | 한 나이 단계로 시작해 목적지를 고르고 2D 장면·일지·안내를 조작한다. 기본 주소는 `web/index.html`이다. 나이 번호(0~2), 목적지 이름, 사진 폴더 뒤에 주소와 배율을 선택해서 넣을 수 있다. | `node tools/test/walk2d.js 1 모세 dist/check/2d` |
| [tools/test/bgraster.js](../../tools/test/bgraster.js) | 시험용 JPG를 화면에 띄우고 가운데 픽셀을 확인한다. 배경 파일 중복, 한 장과 전체 용량, 치수를 벗어난 경우 빌드가 거절하는지 본다. 시험용 배경을 정리하고 다시 묶는다. | `node tools/test/bgraster.js dist/check/bgraster` |
| [tools/test/walk3d.js](../../tools/test/walk3d.js) | 호렙 산의 물음 세 개, 탐험 흐름, 재시작 리셋을 세 나이 단계 모두에서 확인한다. 첫 번호(0~2)는 어느 나이 단계부터 돌릴지 정한다. 사진 폴더 뒤에 배율을 넣을 수 있다. | `node tools/test/walk3d.js 1 dist/check/horeb` |
| [tools/test/walkJ.js](../../tools/test/walkJ.js) | 지정한 한 나이 단계(0~2)로 요단 강에서 단서와 강 이름을 확인하고 호렙 산으로 돌아온다. 사진 폴더 뒤에 배율과 주소를 선택해서 넣을 수 있다. | `node tools/test/walkJ.js 1 dist/check/jordan` |
| [tools/test/full/awe_layout.js](../../tools/test/full/awe_layout.js) | 압도 장면의 가까이 보기·전체 보기에서 그림 범위와 글을 얹을 자리를 여러 세로·가로 화면 크기로 확인한다. 기준 커밋의 전체 점검은 네 자동 조작을 고정 목록으로 불러오므로 이 검사는 별도로 실행한다. | `node tools/test/full/awe_layout.js dist/check/awe_layout` |

3D 자동 조작 전에 `node tools/build3d.js`로 `dist/preview3d.html`을 만든다. 전체 점검은 `dist/check/`를 새로 만들고 각 실행의 사진을 넣는다. Playwright가 빠진 환경의 전체 점검은 자동 조작을 생략한 경고를 남긴다. 점검의 마지막 두 줄에서 종류, 통과 수, 확인 필요 여부를 함께 본다.

## Blender로 3D 인물을 만드는 도구

`bpy`가 설치된 Python으로 저장소 루트에서 실행한다. 설치 환경에 대한 기록은 [common.py](../../tools/blender/common.py) 머리말에 있다. 인물 스크립트의 기본 출력은 `web3d/assets/`다. 검토용 모델은 `--out`으로 별도 위치에 쓸 수 있다. 게임 미리보기에 사용할 원본 GLB를 갱신하면 `node tools/build3d.js`로 다시 묶는다.

| 파일 | 만드는 것과 실행 방법 |
|---|---|
| [tools/blender/common.py](../../tools/blender/common.py) | 여호수아와 제사장이 함께 쓰는 몸·옷·뼈대·동작·GLB 내보내기 코드다. 두 인물 스크립트가 불러 쓴다. 내보낼 때 삼각형 수, 뼈 수, 파일 크기와 발밑 높이를 기록한다. |
| [tools/blender/moses.py](../../tools/blender/moses.py) | `python tools/blender/moses.py`로 `moses.glb`를 만든다. 서 있기(`Idle`), 걷기(`Walk`), 얼굴 가리기(`HideFace`)를 넣는다. |
| [tools/blender/joshua.py](../../tools/blender/joshua.py) | `python tools/blender/joshua.py`로 `joshua.glb`를 만든다. 서 있기와 걷기가 들어간다. `--check`를 주면 몸을 움직일 때 표면이 늘어나는 정도도 확인한다. |
| [tools/blender/priest.py](../../tools/blender/priest.py) | `python tools/blender/priest.py`로 `priest.glb`를 만든다. 채를 메고 서 있는 `Carry` 동작을 넣는다. `--check`와 `--meta 경로`를 받으며, 후자는 채와 손의 위치 등을 JSON으로도 쓴다. |
