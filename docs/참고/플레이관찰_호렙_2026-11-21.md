# 호렙 플레이 관찰 기록 (2026-11-21, 총괄)

- 누가: Claude 29만 원 (총괄). 대표 지시 (2026-11-21): "휴대폰에서 호렙을 처음 하는 아이가 스스로 발견하고 다음 행동을 고를 수 있는 시범판."
- 무엇으로: 최신 main (`fb62ec5`)에 GPT 검토 브랜치 `gpt/night-mobile-play` (`152092d`)를 합친 작업 브랜치. 휴대폰 크기 390×844, 손가락 입력 (Playwright의 터치), 8~10세, 최온.
- 방법: 아이처럼 화면에 보이는 것만 보고 눌렀다. 코드를 보고 답을 미리 알지 않았다. 아래 '걸린 시간'의 기계 시간은 잰 값이고, 아이가 읽는 시간은 **추정**이다 (실제 아이 관찰은 하지 못했다).
- ⚠️ 실제 아이가 해 볼 기회는 없었다. 이 기록은 대표가 아이와 해 볼 때 볼 자리를 정하는 데 쓴다.

## 2. 3D 호렙 · 착륙에서 샤론의 첫 물음까지 (8~10세)

| 차례 | 화면 | 아이가 한 일 | 본 것 |
|---|---|---|---|
| 1 | 첫 화면 | 8~10세, 최온, 탐험 시작 | |
| 2 | 시간 나침반 | '모세' | 바로 착륙 (이동 그림 없이 1.5초 안에 탐험 화면) |
| 3 | 착륙 | 양 떼가 화면 가운데 멀리 보인다. 목표 "멀리 움직이는 무리를 사진에 담아 보세요". **사진기를 바로 눌렀다** | **"사진에 담긴 것이 없어요. 찍고 싶은 것을 화면 가운데에 놓고 다시 찍어 보세요."** 양 떼는 이미 가운데에 있다. 실제 까닭은 거리 (멀다)인데 말은 '가운데가 아니다'로 들린다 → **망설인 화면 ①** |
| 4 | 착륙 | 아래 안내 "왼쪽 아래를 누른 채 밀면 걸어요"를 읽고 왼쪽 아래를 눌러 위로 밀었다 | 누른 자리에 조이스틱이 나타난다. 누르기 전에는 조이스틱이 보이지 않는다 |
| 5 | 걷기 | 계속 밀었다 (13.9초) | 양 떼 위에 흰 초점 모서리, 사진기 단추에 흰 테두리 |
| 6 | 초점 | 사진기를 눌렀다 | 0.7초 안에 '샤론의 물음 1 / 3' (모세는 무엇을 돌보고 있었나요? 낙타 떼 / 양 떼 / 소 떼). "도감에 새로 담았어요: 양 떼, 모세" |

- 다른 길: 착륙에서 '샤론에게 물어보기' → "양 떼 쪽으로 걸어가요. 양들을 화면 가운데에 놓고 사진기 버튼을 눌러 보세요." (거리를 말해 준다. 아이가 이 단추를 먼저 누르면 막히지 않는다.)
- 처음 내 손으로 발견하기까지 (착륙 → 양 떼 사진): 걷는 시간만 13.9초 (잰 값). 읽고 한 번 실패하는 시간을 더해 **35~50초 (추정)**.
- '다음'만 연속으로 누른 횟수: **0번** (착륙에서 물음 1까지 '다음' 단추가 없다).
- 망설인 화면: ① 먼 데서 찍었을 때의 안내 (위 3번). ② 샤론이 누구인지 모르는 채 물음 1에서 처음 말한다 (소개는 접는 칸 안). ③ '말씀 조각 0 / 3'이 무엇인지 화면에 풀이가 없다 (작다).

## 3. 2D 떨기나무 · 이야기 일곱 대목 (8~10세)

| 차례 | 화면 | 아이가 한 일 | 본 것 |
|---|---|---|---|
| 1 | 시간표 | '2 불붙은 떨기나무와 부르심' 출발 | |
| 2 | 다음 목적지 | '모세' | |
| 3 | 도착 | 그림에서 가장 눈에 띄는 **불붙은 떨기나무를 먼저 눌렀다. 다음에 모세를 눌렀다** | **아무 반응이 없다** → **망설인 화면 ③**. 안내 "그림에서 양 떼를 찾아 눌러 보세요."를 읽고 양을 눌렀다 |
| 4 | 대목 1 (출 3:1) | 양 떼를 눌러 열었다 (첫 발견) | |
| 5 | 대목 2~7 (출 3:2-12) | **'다음' 6번, 이어 '다음으로 가는 관문' 1번. 모두 같은 자리의 같은 단추** | 그림은 대목마다 조금씩 당겨지지만 누를 것은 없다. 대목 3과 7은 "성경책에서 직접 읽어요" 카드가 붙는다 |
| 6 | 관문 1 / 2 | 보기 셋 (그림 단추) | |

- 처음 내 손으로 발견하기까지 (도착 → 양 떼): 안내 한 줄을 읽고 누르면 **5~15초 (추정)**. 떨기나무와 모세를 먼저 누르는 아이는 반응이 없어 더 걸린다.
- '다음'만 연속으로 누른 횟수: **7번** (양을 누른 뒤 관문까지 '다음' 6번 + '다음으로 가는 관문' 1번).
- 읽을 양: 8~10세 일곱 대목의 글과 동료 말 합해 484자 (빈칸 뺌). 8~10세가 눈으로 읽으면 2~3분쯤 (추정). 그 동안 할 수 있는 다른 행동이 없다.
- 이 장면에서 가장 놀라운 대목 ("어? 떨기나무에 불이 붙었어요. 그런데 나무가 타서 없어지지 않아요!", 출 3:2-3)도 '다음'을 눌러 읽는다. 도착 그림에 이미 불이 보이고, 그 나무를 눌러도 반응이 없다.
- 그 밖에: 시간표에 어른에게 하는 말 "시범판에는 목사님 감수가 필요 없는 세 장면만 열려 있습니다."가 아이 화면에 나온다 (작다).

## 4. 고칠 곳 고르기

| 후보 | 아이가 겪는 것 | 무게 |
|---|---|---|
| 가. 2D 떨기나무의 '다음' 7번 | 장면의 가장 큰 순간을 글로만 넘긴다. 가장 눈에 띄는 떨기나무가 눌러도 반응이 없다. 2~3분 동안 고를 행동이 없다 | **크다.** 지루함이 쌓이고 '읽지 않고 누르기' 버릇이 든다 |
| 나. 3D 먼 데서 찍었을 때의 안내 | 맞게 한 것 같은데 '없다'는 말을 듣는다. 아래 안내를 읽으면 걸어서 풀린다 | 중간. 한 번 헤매고 풀린다 (막히지는 않는다) |
| 다. 3D 샤론 소개가 접는 칸에 있음 | 샤론이 누구인지 모르고 물음을 받는다 | 작다. 다만 `docs/11` 7.1절의 차례와 다르다 (대표 결정 필요) |

→ **가를 고친다.** 출 3:3 ("내가 돌이켜 가서 이 큰 광경을 보리라")대로 아이가 그림에서 떨기나무를 눌러 '가까이 가서 보는' 행동을 하게 한다. 나는 대표에게 묻는 항목으로 넘긴다.

- 처음에는 출 3:6 (모세가 얼굴을 가렸다)도 아이가 모세를 눌러 그림이 바뀌는 것을 보게 했다. 별도 검증의 지적으로 뺐다: 출 3:5 (신을 벗으라) 바로 뒤라 본문에 없는 '신을 벗음'을 기대하게 하고, 아이 손짓에 성경 인물이 반응하는 모양이 된다 (규칙서 3.3, 11절). 하나님이 말씀하시는 대목 (출 3:4-12)은 그림을 눌러 열지 않는다. 감수 묶음 7.1절 p3.

## 5. 고친 뒤 같은 출발점에서 다시 플레이 (2026-11-21)

출발점: 8~10세, 2D 시간표 → '2 불붙은 떨기나무와 부르심' → '모세' → 도착 화면.

| 차례 | 고치기 전 | 고친 뒤 |
|---|---|---|
| 도착에서 떨기나무를 누름 | 반응 없음 | 양 떼에 노란 고리가 뜬다 (찾을 것을 알려 줌) |
| 양 떼를 누름 | 대목 1 (출 3:1) | 같다 |
| 대목 1의 아래 단추 | '다음' | "그림에서 놀라운 떨기나무를 찾아 눌러 보세요." 누르면 떨기나무에 고리가 뜬다. 그림의 다른 곳을 눌러도 같다 |
| 떨기나무를 누름 | (없음) | 대목 2 (출 3:2-3) "어? 떨기나무에 불이 붙었어요…" |

- 11~13세, 14~19세도 같은 자리에서 그림의 떨기나무를 눌러 연다 (안내 글은 세 나이 단계가 같다).

- 한계: 아래 단추만 이어 누르는 것은 1번 줄었을 뿐이다. 장면에서 가장 놀라운 순간을 아이가 직접 여는 것이 이번 고침의 몫이다.
