# 진행판

어느 AI, 어느 계정, 어느 컴퓨터에서 열어도 이 파일 하나로 이어받는다. 위쪽 '지금 상태'는 고쳐 쓰고, 맨 아래 '작업 기록'은 지우지 않고 맨 위에 새 기록을 더한다. 이 파일은 총괄만 고친다. 다른 세션은 `docs/인계/`에 인계 파일을 쓴다.

## 지금 상태

### 작업 카드 A · `game.js` 나누기

- 왜: `web3d/js/game.js`가 1,102줄, 72KB로 한 파일에 몰려 있다. 고칠 때마다 통째로 읽게 되어 모든 AI의 사용량이 늘어난다.
- 할 일: 역할별로 여러 파일로 나눈다 (예: 조작, 카메라, 진행, 화면 안내, 점검용 `BO3D.debug`). 나눈 파일은 `web3d/js/` 아래에 둔다.
- 건드릴 파일: `web3d/js/game.js`와 거기서 나온 새 파일, `web3d/index.html`의 script 줄, `tools/build3d.js`의 `scripts` 목록.
- 하지 말 것: 동작, 문구, 숫자를 바꾸지 않는다. 옮기기만 한다. `content.js`, `content3d.js`, `models*.js`는 건드리지 않는다.
- 완료 기준: 나눈 파일이 각각 400줄 이하. `node tools/check.js --full` 합격.

### 작업 카드 B · 양 떼 30마리 이상 (지시서 4절 3번)

- 할 일: 모세가 이끄는 양 떼를 30마리 이상으로 늘리고 무리 지어 움직이게 한다. 지금은 7마리이고 `web3d/js/game-scene.js`의 `G.sheep = []` 부분에서 `P.flock` 둘레에 놓는다. 양 모델은 `models.js`의 `makeSheep`이다.
- 건드릴 파일: `web3d/js/game-scene.js` (양 떼를 놓는 곳), `web3d/js/game-loop.js` (양 떼 움직임을 부르는 줄), `web3d/js/game-debug.js` (양의 수 값 한 줄만), `web3d/js/models.js`의 `makeSheep`, `tools/test/walk3d.js` (양의 수를 확인하는 줄만).
- 자리: 양 떼는 `P.flock` 가운데에서 9 안쪽에 퍼진다. 언덕(떨기나무에서 15 안쪽)에는 오르지 않는다 (`docs/07_호렙_퀴즈와_동선.md` 4.1절).
- 완료 기준: `BO3D.debug`에 양의 수를 알려 주는 값을 더하고, `walk3d.js`가 30 이상인지 확인해 아니면 실패하게 한다. `node tools/check.js --full` 합격. 양 떼가 보이는 화면 사진 한 장을 `docs/인계/사진/카드B.png`로 복사해 함께 커밋한다.
- 대표 확인: 실제 휴대폰에서 끊기지 않는지는 대표가 링크를 열어 확인한다.
- 지킬 것: 양 떼는 출 3:1의 배경이다. 본문에 없는 사건을 더하지 않는다.

### 작업 카드 C · `alt02.svg` 다시 그리기 (지시서 4절 5번)

- **멈춤 (2026-11-18 대표 결정)**: 요단 강 그림도 GPT가 생성한 그림으로 진행한다 (카드 E). 아래 내용은 기록으로 남긴다. 다시 그릴 때 지킬 장면 설정은 그대로 쓴다.
- 왜: 2D 시범판의 요단 강 그림이 3D 설정과 다르다. 멈춰 쌓인 물을 건너는 곳 바로 옆에 그렸고 좌우 방향도 확인하지 않았다 (장면목록 3절 'ALT-02의 3D 장면 설정' 아래 '고쳐야 할 것').
- 할 일: `tools/art-src/gen_alt02.js`를 고쳐 그림을 다시 만든다. 장면목록의 'ALT-02의 3D 장면 설정' 표 다섯 항목(방향, 쌓인 물, 백성과 궤의 거리, 궤, 지도자)과 하나씩 맞춘다.
- 건드릴 파일: `tools/art-src/gen_alt02.js`, `web/assets/bg/alt02.svg`, `web/assets/bg/alt02.meta.json`. `web3d/` 아래 파일은 읽기만 한다.
- 쌓인 물: 그리지 않는다. 그림 영역 `water`는 이름을 그대로 두고 물이 끊어져 드러난 강바닥 자리로 옮긴다. 그러면 `web/js/content.js`는 고칠 필요가 없다. 영역 이름을 꼭 바꿔야 하면 `content.js`에서 그 이름을 쓰는 두 곳의 이름만 바꾼다.
- 아이에게 보이는 문구는 고치지 않는다. 새 그림과 어긋나는 문구를 찾으면 인계 파일에 적어 총괄에게 넘긴다.
- 목회자 판단이 필요하다고 적힌 설정은 장면목록에 적힌 값(제사장 넷, 흰 세마포, 백성은 하류 쪽으로 건넘)을 그대로 그린다. 값이 적혀 있지 않은 것(지도자가 선 자리)은 지금 그림의 자리를 그대로 둔다. 바꿔야 할 것 같으면 그리지 않고 인계 파일에 적는다.
- 하지 말 것: 금빛 궤를 드러내지 않는다. 지도자가 강을 가리키거나 손을 내밀게 그리지 않는다.
- 완료 기준: 표 다섯 항목과 그림을 하나씩 대조한 표가 인계 파일에 있다. 다시 그린 그림의 화면 사진을 열어 봤고, 한 장을 `docs/인계/사진/카드C.png`로 복사해 함께 커밋했다. `node tools/check.js --full` 합격.
