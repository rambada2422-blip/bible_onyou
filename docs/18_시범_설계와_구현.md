## 3. 대표께 알릴 내 판단(바꿀 수 있다)

1. 감수 태그는 **기본으로 보이게** 했다(지금은 잡아 가는 때이므로). 아이 시험 때는 지도 아래 "감수 태그 숨기기".
2. **신약 장절(요 1:29, 고전 5:7)은 유월절 장면(OT-10)을 마치면** "어린 양의 기록" 끝에 열린다(모든 나이). 맨 끝(OT-40)으로 미루면 대부분의 아이가 보지 못한다고 보았다. 감수 태그 ★★★.
3. 날아간 양털은 **처음 한 번만** 나온다(같은 일을 되풀이시키지 않으려고). 양털이 있는 다른 장면(OT-08·25·31)에서 먼저 얻어도 같다.
4. 설계도 2는 잔가지를 꽂은 뒤에 도착한다(양털을 먼저 얻었으면 바로).
5. 온실의 나무는 꽂은 뒤 다녀온 장면 수 0·1·2·4·8·12·16에서 한 단계씩 자란다. 실제 날짜는 쓰지 않는다. 두 장면마다 창 쪽으로 기울고, 화분을 돌려 주면 곧아진다(어느 쪽이든 잘못되는 일은 없다).
6. 기존 장비 1~3단계(모자·깃발·손목 탐지기)는 **그대로 두었다.** "만든 도구"는 매듭 줄 하나만 더했다. 7단계를 다시 짜는 것은 시범 뒤에 정한다(`docs/17` 6.2).
7. 지도 맨 위의 점선 타임머신 그림은 덜컹이 그림으로 바꿨다(고친 시대 수만큼 계기판 불이 켜진다).
