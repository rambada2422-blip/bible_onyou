# 아이 시험 자료 (20분, 흥미 개선 확인용)

`docs/12_아이시험_계획.md`를 그대로 따라 만든 자료입니다. **아직 하지 않은 시험입니다.** 아이의 이름·사진·연락처는 어디에도 받지 않습니다(규칙서 6절).

## 파일
| 파일 | 누가 | 쓰임 |
|---|---|---|
| `부모안내문.html` · `.md` | 부모 | 시험 전에 드리는 한 장. 무엇을 하고 무엇을 받지 않는지 |
| `진행순서카드.html` | 진행하는 사람 | 준비물, 번갈아 보는 순서(홀수 번째 아이는 앞 판 먼저, 짝수 번째는 개선 판 먼저), 한 아이의 20분, 오려 쓰는 카드 10장 |
| `관찰지.html` | 관찰하는 사람 | 구간(10분) 하나에 한 장. 아이 한 명에 두 장 인쇄 |
| `집계도구.html` | 집계하는 사람 | 인터넷 없이 열리는 한 파일. 놀이 기록(JSON)을 붙여 넣고 관찰지의 수를 넣으면 5개 항목의 통과 여부와 판정이 나옵니다 |
| `교사부모_한장안내.html` · `.md` | 교사·부모 | 이 게임이 무엇이고 아이 곁에서 어떻게 함께 하는지(공개할 때 쓸 안내. 지금은 감수 전) |

인쇄는 각 HTML을 열어 브라우저의 인쇄(A4)로 합니다. 관찰지 1쪽, 진행 순서 카드 2쪽, 부모 안내문 1쪽, 교사·부모 안내 1쪽입니다.

## 시험 날의 흐름
1. 부모 안내문을 드리고 말로 동의를 받습니다(서명·이름을 받지 않습니다).
2. 진행 순서 카드대로 아이마다 20분. 구간마다 **새 시크릿 창**으로 열고, 진행하는 사람이 이야기 카드 첫 화면까지 열어 건넵니다. **이야기 카드 5분 → 같은 장면 3D 5분**(진행하는 사람이 바꿔 줌).
3. 관찰하는 사람은 구간마다 관찰지 한 장을 채웁니다. 돕기·마무리 시간과 마친 장면 수는 초시계와 눈으로 적습니다.
4. 끝난 뒤 `집계도구.html`에 구간을 하나씩 넣습니다. 결과 표와 판정이 바로 나옵니다. "내보내기"의 글을 복사해 총괄에게 보냅니다.
5. **끝난 뒤 지우기**(부모 안내문의 약속): 집계를 맡은 사람이 결과를 정리한 뒤, 시험한 날부터 한 달 안에 ① 관찰지 종이를 없애고 ② 메모 앱에 복사해 둔 놀이 기록을 지우고 ③ 집계 도구의 "모두 지우기"를 누릅니다. 총괄에게 보낸 글에는 번호와 수만 있습니다. 시험에 쓴 휴대폰은 시크릿 창을 닫으면 게임 진행·놀이 기록·14~19세가 적은 기록 글이 함께 지워집니다(보통 창으로 했으면 브라우저의 "사이트 데이터 지우기").

## 집계 도구가 계산하는 것
- 같은 판의 구간을 모두 합쳐(분자끼리, 분모끼리) 5개 항목을 계획서의 통과 기준으로 판정합니다.
- 판정: 개선 판이 5개 가운데 4개 이상 통과하고 2초 안에 넘긴 비율이 앞 판의 절반 이하이면 "진단이 맞았다". 개선 판에서 물음마다 평균 60초를 넘고 포기의 절반 이상이 성경을 찾던 순간이면 "반대 가설". 둘 다 아니면 "아직 판정하지 않는다", 둘 다이면 "사람이 정한다".
- 표본이 계획(6명 이상, 나이 단계마다 2명 이상, 한 아이가 두 판 모두, 번갈아 보는 순서)에 못 미치면 경고를 보여 줍니다.
- 놀이 기록에서 자동으로 채우는 칸: 본 화면 수, 2초 안에 넘긴 수, 돕기 단계 수, 장절 물음 수와 걸린 초(이야기 카드의 관문·뜻 묻기), 재료를 얻은 횟수. 돕기 15초·마무리·마친 장면은 참고값만 보여 주고 관찰지의 수를 넣습니다.
- 앞뒤가 안 맞는 수("그중" 칸이 전체보다 큼)는 받지 않고, 같은 아이의 같은 판을 두 번 넣으면 묻습니다.
- 계산은 꾸민 자료로 시험했습니다: `node tools/test/check_kidtest.js`(44가지, 경계값 포함), 화면은 `node tools/test/shot_kidtest.js`.

## ⚠️ 시험 전에 정하거나 준비할 것
- **앞 판(11/15, `fff0535`)에는 놀이 기록 기능이 없습니다.** 앞 판의 "2초 안에 넘긴 화면"은 관찰하는 사람이 손으로 셉니다(관찰지 항목 3). 손으로 센 수는 놀이 기록보다 거칠어 판정의 "앞 판의 절반 이하" 비교가 흔들릴 수 있습니다. 앞 판에도 놀이 기록을 넣은 시험용 판을 총괄에게 부탁했습니다(대표 결재지 가3).
- **앞 판과 개선 판의 주소 두 개**가 있어야 합니다. 지금 미리보기 주소는 하나(늘 최신 판)입니다.
- **놀이 기록의 한계**(게임 코드 `story.js`를 읽어 확인. 독립 검증의 지적):
  - 화면의 시간은 "다음 화면이 뜰 때" 닫힙니다. 그래서 마무리 화면이나 3D로 넘어가기 직전 화면의 시간에는 지도·3D를 걷는 시간이 섞입니다. → **마무리에 머문 초, 돕기 15초, 마친 장면 수, 10분 안에 마친 장면은 놀이 기록 값을 쓰지 않고 관찰지에 적은 수를 넣습니다**(도구는 이 칸들을 자동으로 채우지 않고 참고값만 보여 줍니다).
  - 3D 장면 안의 동행 문답·돕기·오늘의 물음 화면도 이야기 카드와 같은 이름으로 기록됩니다. 3D의 관문과 탐지기 물음은 기록되지 않습니다(초시계로 잽니다).
  - 보고 있던 마지막 화면은 기록에 들어가지 않고, "기록 지우기"를 눌러도 다음 기록 맨 앞에 섞입니다. → 구간마다 새 시크릿 창을 쓰면 섞이지 않습니다.
  - "이전" 단추로 돌아가 다시 본 화면은 한 번 더 세어집니다. 재료를 찾은 순간의 표시(`seek-found`)는 도구가 화면 수에서 뺍니다.
- **게임에 진행(마친 장면, 얻은 재료)을 지우는 단추가 없습니다.** 지우지 않으면 둘째 아이부터 숨은 재료 찾기가 나오지 않고 수리 막대가 차 있습니다. → 구간마다 새 시크릿 창. 시험용 "진행 지우기" 단추를 총괄에게 부탁했습니다.
- 3D 절정 화면에는 "건너뛰기·끝내기" 단추가 없습니다(호렙 영상을 두 번째 볼 때만 있음). 관찰지 항목 4는 "끝까지 보지 않고 그만둔 횟수"(화면 닫기, 휴대폰 내려놓기 포함)로 셉니다.
- 계획서가 정하지 않아 **기본값으로 둔 것**(대표 결재지 가4): ① "기회 없음"인 항목은 통과로 세지 않는다 ② 돕기 단계가 한 번도 없었던 판(앞 판에 흔함)은 항목 3을 2초 넘김만으로 본다(기준 하나가 빠지는 너그러운 쪽) ③ 절정 화면과 마무리 가운데 하나만 있었으면 있는 쪽만으로 항목 4를 본다(너그러운 쪽) ④ 두 판정 조건이 함께 맞으면 사람이 정한다 ⑤ 같은 판의 구간을 **모두 합쳐서** 본다. 그래서 "스스로 1회 이상 엶", "10분 안에 1장면 이상", "오답 2회 이상"은 아이 한 명만 채워도 됩니다(도구가 "아이별로 보면 통과 몇 명"을 함께 보여 줍니다) ⑥ 재료를 얻었는데 마친 장면이 0이면 항목 2는 미달 ⑦ 한 구간은 이야기 카드 5분 → 3D 5분, 바꾸는 것은 진행하는 사람이 한다 ⑧ 절정의 "건너뛰기·끝내기"는 "끝까지 보지 않고 그만둠"으로 센다.
- 부모 안내문의 "인터넷으로 보내지 않습니다"는 놀이 기록에 대한 말입니다. 게임을 열 때 화면 글꼴을 구글 서버에서 불러오므로(`docs/감수/공개전_점검표.md`) "게임이 아무 데도 접속하지 않는다"고는 말하지 않습니다.
- ⚠️ 실제 휴대폰에서 확인하지 못한 것: 집계 도구, 시크릿 창에서 놀이 기록이 남는지, 새로 고침 뒤 `#log`가 남는지. 시험 전날 어른끼리 한 번 해 보세요.
