# 부모님께 드리는 안내 (바이블 온유 아이 시험)

안녕하세요. 교회와 가정에서 쓰려고 만들고 있는 성경 탐험 게임 **"바이블 온유"**를 아이들이 실제로 해 보는 짧은 시험에 자녀가 함께해 주기를 부탁드립니다.

## 무엇을 하나요
- 자녀가 휴대폰으로 게임을 **20분**(10분씩 두 번) 해 봅니다. 같은 장면의 두 가지 판을 번갈아 봅니다.
- 게임은 구약의 한 장면을 보고, **자기 성경책을 펴서** 답을 찾는 방식입니다. 실물 성경책을 곁에 둡니다.
- 어른 한 사람이 곁에서 **어디서 재미있어하고 어디서 막히는지**만 종이에 적습니다. 자녀를 평가하는 시험이 아닙니다. 점수도 없습니다.

## 받지 않는 것
- 자녀의 **이름, 사진, 연락처, 주소를 받지 않습니다.** 종이에는 번호(1, 2, 3…)와 나이 단계(8~10세 / 11~13세 / 14~19세)만 적습니다.
- 사진이나 영상을 찍지 않고, 화면을 녹화하지 않습니다.
- 게임이 남기는 놀이 기록(어느 화면에 몇 초 머물렀는지)은 **그 휴대폰에만** 있고, 시험이 끝나면 지웁니다. 인터넷으로 보내지 않습니다.

## 알아 두실 것
- 이 게임은 **아직 목사님의 감수를 받기 전**입니다. 그래서 시험에 온 아이에게만, 어른이 곁에 있는 자리에서만 보여 줍니다. 게임 주소는 나누어 드리지 않습니다.
- 게임에는 광고, 결제, 채팅이 없습니다.
- 자녀가 하다가 그만하고 싶어 하면 바로 멈춥니다. 참여하지 않으셔도 아무 불이익이 없습니다.
- 적은 종이와 놀이 기록은 게임을 고치는 데에만 쓰고, 결과를 정리한 뒤(시험한 날부터 한 달 안에) 없앱니다.

## 여쭙니다
자녀가 이 시험에 함께해도 괜찮으신지 **말로 알려 주세요.** 이름을 받지 않기 위해 서명은 받지 않습니다.

궁금하신 것은 시험을 진행하는 분께 물어 주세요. 고맙습니다.
