## 시작할 때
1. `git log --oneline -3`, `git branch --show-current`로 네 브랜치를 확인한다. 결과는 **네 브랜치에만** 올린다. `main`, `claude/inspiring-bardeen-vflaqn`, `claude/auto-base`, 다른 갈래의 브랜치에는 올리지 않는다. PR을 만들지 않는다. force push를 하지 않는다.
2. 읽는다(이 순서): `docs/00_공통규칙서.md` 전체(특히 3절·13절) → `docs/11_구약전체_진행표.md` → `docs/10_구약전체_3일작업_지시서.md`의 4.1·5·6·7·8·9절 → `docs/08_협업운영지침.md` 2·4·5절 → 네 갈래의 지시서 → 지시서가 가리키는 문서.
3. `bash tools/setup_env.sh` → `node tools/validate_ot.js --v3` → `node tools/build3d.js` → 네 갈래와 관련된 시험을 한 번 돌려 **지금 상태가 통과하는지** 확인하고 시작한다. 안 되면 원인을 진행 파일에 적고, 네 갈래 범위 안이면 먼저 고친다.
4. 네 진행 파일 `docs/auto/<갈래>_진행.md`를 만들고 바로 커밋·푸시한다(아래 형식).

## 반드시 지킬 것
- **규칙서가 가장 위다.** 하나님과 천사를 형상으로 만들지 않는다. 하나님의 음성을 소리로 만들지 않는다. 성경에 없는 사건·대사·속마음을 지어내지 않는다. 성경 본문(개역개정·개역한글)을 저장소에 싣지 않는다(장절만, `ref/`는 .gitignore). 폭력 장면을 만들지 않는다. 세 아이는 끝까지 목격자다. 신학 판단이 필요한 것은 네가 확정하지 말고 "감수 항목"에 적는다. 감수 상태를 "감수 완료"로 쓰지 않는다.
- **파일 주인.** 네 지시서의 "네 파일"만 고친다. 다른 갈래의 파일을 고쳐야 일이 되면, 고치지 말고 진행 파일의 "다른 갈래·총괄에 부탁"에 적고 그 일을 빼고 계속한다. `docs/11_구약전체_진행표.md`와 `docs/00`~`docs/12`는 고치지 않는다(다른 세션의 것. 읽기만). 지시서에 "더하기만"이라고 적힌 공용 파일은 기존 동작을 바꾸지 않는 줄 더하기만 한다.
- **만든 사람과 검증하는 사람을 나눈다.** 글·물음·배치·그림은 작성 과정을 보지 않은 별도 하위 에이전트가 본문(`node tools/bible_ref/ref.js`)과 대조해 틀린 곳만 찾게 한다. 높음·중간 지적을 모두 고친 뒤에야 끝난 것으로 친다. 지적 수와 반영 수를 진행 파일에 적는다.
- **하위 에이전트는 동시에 4개까지.** 3D 시험은 느리고(한 번에 5~10분) 여러 개를 한꺼번에 돌리면 서로 느려진다. 시험은 한 번에 1~2개만.
- **멈춤에 대비한다.** 의미 있는 단위(장면 하나, 수정 묶음 하나)가 끝날 때마다 커밋하고 바로 푸시한다(`git push -u origin <네 브랜치>`, 네트워크 오류면 2·4·8·16초 뒤 다시). 그때마다 진행 파일을 고친다. 한도에 걸려 끊겼다가 "이어서 하라"는 말을 받으면 진행 파일부터 읽고 "▶ 다음"부터 한다. 컨테이너가 바뀌었으면 `tools/setup_env.sh`를 다시 실행한다.
- **"됐다"는 실제로 돌려 본 것만 쓴다.** 시험이 실패하면 실패했다고 쓴다. 통과시키려고 시험을 끄거나 느슨하게 고치지 않는다. 찍은 화면은 직접 열어 본다.
- 생성 파일(`web3d/js/otdata.js`, `glbdata.js`, `avatars.js`)은 스크립트로만 만든다. 손으로 고치지 않는다.
- 돈이 드는 것, 새 외부 서비스 가입, 외부로 보내기(메일·메시지), 아이들에게 공개는 하지 않는다.
- 기존 파일을 통째로 지우거나 처음부터 다시 쓰지 않는다. 2D 시범판(`web/`)과 지금 통과하는 시험을 깨뜨리지 않는다.
- 한국어로, 비개발자가 읽을 수 있게 쓴다. 커밋 메시지도 기존처럼 한국어 한 줄.

## 진행 파일 형식 (`docs/auto/<갈래>_진행.md`)
```
# <갈래> 진행 (자동 작업)
## 최종 보고            ← 끝날 때 채운다: 한 일 / 시험 결과(통과 수/전체) / 안 된 것 / 합칠 때 주의
## ▶ 다음               ← 지금 이어서 할 일 한 줄
## 끝난 것              ← 단위마다 한 줄(커밋 번호, 시험, 독립 검증 지적 수와 반영)
## 하는 중
## 대표 결정 대기        ← 무엇 / 왜 대표가 정해야 하나 / 그동안 쓴 기본값
## 감수 항목             ← 목회자가 봐야 할 것(장면, 장절, 무엇)
## 다른 갈래·총괄에 부탁  ← 남의 파일을 고쳐야 하는 일
## 실패·주의             ← 안 된 방법과 원인 한 줄(같은 방법을 다시 하지 않는다)
```
