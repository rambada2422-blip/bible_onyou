# 갈래 pack: 목회자 감수 자료, 아이 시험 자료, 대표 결재지

먼저 `00_공통지시.md`를 읽는다. 브랜치는 `claude/auto-pack`.

## 목표
게임이 아이들에게 나가지 못하게 막고 있는 것은 코드가 아니라 **사람이 해야 하는 세 가지**다: 목회자 감수, 아이 시험, 대표 결정. 이 세 가지를 **받는 사람이 가장 적은 시간으로 끝낼 수 있게** 자료를 만든다. 게임 코드와 장면 자료는 고치지 않는다(읽기만).

## 만들 것
1. **목회자 감수 자료** (`docs/감수/`)
   - `tools/make_review_pack.js`가 `content/ot/*.json`, `eras.json`, `_verify/era-N.md`, 3D 장면 설정 파일 머리말의 "감수가 필요한 설정"에서 뽑아 **다시 만들 수 있게** 한다(내용이 바뀌면 다시 돌리면 된다).
   - 구성: 한 장 안내(무엇을 봐 주시면 되는지, 양과 걸리는 시간 어림, 표시 방법) → 규칙서 3절·13절의 대표 결정 요약(목회자가 원칙부터 볼 수 있게) → 시대별 10묶음. 장면마다: 본문 범위, 감수 필수 까닭, 항목 번호 · 장절 · **게임에 나오는 문장 그대로** · 표시 칸(그대로 / 고침 / 뺌) · 적을 칸. 항목: 오늘의 물음(40), 뜻 묻기(40), 신약 연결(16), 손으로 하는 돕기(42), 14~19세 적용 물음, 동행 인물 문답, 미해결, 3D 설정.
   - 나오는 형식: 휴대폰·컴퓨터에서 읽는 HTML 한 파일(표시한 것을 그 기기에 저장하고 글로 내보내기) + 인쇄용(A4) + md. 성경 본문은 싣지 않는다(장절만).
   - 뽑은 항목 수가 진행표의 수(오늘의 물음 40, 뜻 묻기 40, 신약 연결 16, 돕기 42 등)와 맞는지 대조하고, 안 맞으면 까닭을 적는다.
   - 급한 순서(감수 필수 장면 먼저, 높음 지적이 있었던 곳 먼저)로 "먼저 볼 30항목"을 따로 뽑는다.
2. **대표 결재지** (`docs/감수/대표_결재지.md` + HTML): 진행표 "대표 결정 대기"의 모든 줄과 다른 갈래 진행 파일의 "대표 결정 대기"(마감 무렵 `git fetch origin 'refs/heads/claude/auto-*:refs/remotes/origin/claude/auto-*'`로 읽는다)를 예/아니오로 답할 수 있게, 추천 1번과 까닭을 붙여 한 장으로. 신학 판단이 섞인 것은 "목회자에게" 칸으로 옮긴다.
3. **아이 시험 자료** (`docs/아이시험/`, `docs/12_아이시험_계획.md`를 그대로 따른다): 인쇄용 관찰지(구간당 한 장), 진행 순서 카드(앞 판·개선 판 번갈아 보기), 부모 안내문(이름·사진·연락처를 받지 않는다는 것 포함), 결과 집계 도구(오프라인 HTML 한 파일: `#log`의 JSON을 붙여 넣고 관찰 수치를 넣으면 5개 항목 통과 여부와 판정이 나온다. 계산은 꾸민 자료로 시험한다).
4. **교사·부모 한 장 안내**: 이 게임이 무엇이고, 아이 곁에서 어떻게 함께 하는지(성경책 준비, 나이 단계, 모든 시대 열기, 놀이 기록).
5. **개역개정 사용 허락 신청 준비**(`docs/감수/개역개정_신청_준비.md`): 규칙서 10절의 "아직 정하지 않은 것". 신청에 넣을 내용의 초안과 대표가 채울 빈칸. 신청 절차·주소처럼 확인하지 못한 것은 ⚠️ 미확인으로 적는다. **보내지 않는다.**

## 네 파일
`docs/감수/`, `docs/아이시험/`, `tools/make_review_pack.js`, `tools/test/`의 새 파일. 그 밖은 읽기만.

## 검증
- 자료의 문장이 게임 자료와 글자 그대로 같은지 스크립트로 대조(바꿔 쓰지 않는다).
- 작성 과정을 보지 않은 에이전트가 "목회자라면 이 자료만 보고 감수할 수 있는가, 빠진 항목은 없는가"를 따진다.
- HTML은 390×844와 A4 인쇄 화면을 찍어 직접 본다.

## 여력이 남으면
- 감수 결과를 받아 반영하는 순서 문서(표시 → 누가 → 어떤 파일 → 어떤 시험).
- 공개 전 점검표(규칙서 6절 아동 보호, 7절 저작권, 9절 4단계): 지금 채워진 것과 빈 것.
- 그림·소리·글꼴·코드의 출처와 사용 조건 목록(규칙서 7절).
