## 그리는 법 요약 (이어서 하는 사람에게)
- 그림판 900×600, 휴대폰에서 보이는 곳은 x 110~790, y 100~470. 사람·하나님·천사·글자·폭력 없음. 심판·죽음은 앞뒤의 풍경만. 우상은 본문에 있어도 그리지 않음.
- `SA.reg('OT-NN', { beats: [대목마다 그림 함수], arrive: 0, end: 마지막 })`. 붓은 `SA.kit`.
- 찍어 보기: `node tools/test/shotArt.js <폴더> OT-NN [--big]` → 한 장에 도착·대목·끝. 실제 화면: `node tools/build3d.js && node tools/test/shotArtPlay.js <폴더> OT-NN`.
