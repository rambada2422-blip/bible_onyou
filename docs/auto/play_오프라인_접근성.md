# 오프라인·홈 화면 설치 준비와 접근성 점검 (play 갈래, 2026-11-16)

"여력이 남으면" 목록의 둘째·셋째다. 잰 것만 적었다. 고친 것은 "고침"에, 못 한 것은 "안 됨·남은 일"에 있다.

## 1. 오프라인으로 열기 (`node tools/test/offlineCheck.js`)

| 물음 | 잰 결과 |
|---|---|
| 미리보기 한 파일의 크기 | 8.2MB (`dist/preview3d.html`. three.js, 인물 모형, 장면 자료가 모두 들어 있다) |
| 페이지가 인터넷에서 가져오는 것 | 글꼴 하나뿐(Google Fonts의 Jua·고운돋움·고운바탕) |

### 안 됨·남은 일
- **홈 화면에 설치(앱처럼 열기)**: 지금은 준비가 없다(manifest, 아이콘, 서비스 워커 모두 없음). 설치와 "한 번 받아 두면 인터넷 없이 열림"을 제대로 하려면 **자기 주소(https)에 올려야** 한다. 지금 대표가 보는 미리보기 주소(Claude 미리보기)에는 서비스 워커를 둘 수 없고, 주소 끝의 `#...`도 전달되지 않는다. → 올릴 곳을 정하는 것은 "대표 결정 대기"(운영비·서비스 가입).
- 올릴 곳이 정해지면 할 일(코드 반나절): `manifest.json`(이름, 아이콘 192·512, `display: standalone`), 아이콘 그림, 서비스 워커(미리보기 한 파일과 영상을 저장), 글꼴 파일을 같이 싣기(지금은 Google Fonts에 기대고 있어 오프라인이면 글꼴이 바뀐다. Jua·고운돋움·고운바탕은 SIL 오픈 폰트 라이선스라 같이 실을 수 있다. ⚠️ 라이선스 글은 싣기 전에 다시 확인).
- 저장 한도: 진행·기록은 수십 KB, 사진 도감은 사진 한 장에 5~8KB(40장면을 다 3D로 찍어도 2MB 아래로 어림). 브라우저의 "사이트 데이터 지우기"를 하면 진행이 사라진다 → 부모·교사 화면의 "진행 옮기기"로 글을 따로 적어 두면 되살릴 수 있다.
- ⚠️ 아이폰 Safari에서는 재 보지 못했다(이 작업 환경은 Chromium뿐).

## 2. 접근성 점검표 (`node tools/test/a11yCheck.js <폴더> <단계>` → `python3 tools/test/a11yContrast.py <폴더>`)

처음 화면, 처음 안내, 시대 지도, 유월절 장면(OT-10)의 모든 화면 종류, 탐험 일지, 수리 현황, 설정, 부모·교사 화면 = 23화면, 글 조각 약 400개를 8~10세와 14~19세로 쟀다(390×844).

| 항목 | 기준 | 처음 | 고친 뒤 | 고침 |
|---|---|---|---|---|
| 글자와 바탕의 색 대비 | 작은 글 4.5 이상, 큰 글 3 이상(WCAG AA) | 모자란 종류 16 | 실제로 모자란 것 0(아래 주) | 아이 이름표(최온 2.2, 휴 2.7 → 5 이상), 동행 인물 이름(3.6 → 6 이상), 작은 머리글 "탐험대 이야기"·"지켜보기 1 / 7"(4.2~4.4 → 4.5 이상), 시대 지도의 "시대 1"(그림 위, 그림자와 밝은 색) |
| 가장 작은 글자 | 12px 이상 | 11.5px 2종류(시대 지도의 "3D"·"감수 필수" 표시) | 0 | 12px로 |
| 누를 곳의 크기 | 44×44px 이상 | 돌아가기 단추 36px, 마무리 펼치기 26px, 3D의 깃발 색 40px·모자 단추 40px·도감 단추 40px·탐지기 단추 34px쯤 | 이야기 카드 0(전수 점검), 3D는 CSS로 44px 이상 | `story.css`, `game.css` |
| 이름표 없는 단추(화면 읽기 프로그램용) | 0 | 0 | 0 | 새 단추에도 `aria-label` |
| 움직임 줄이기 설정 | 켜면 되풀이 움직임이 없어야 | 0 | 0 | 새로 넣은 움직임 없음 |
| 글자 크기 고르기 | 사용자가 키울 수 있어야 | 없음 | 보통·크게(1.12배)·아주 크게(1.25배) | 설정 화면. 320 폭 "아주 크게"에서도 옆 넘침 0(`walkPlay.js`) |
| 읽어 주기 | 8~10세 | 대목 글만 | 모든 글 화면(시트 아래 왼쪽), 다른 나이는 설정에서 | 기기의 한국어 음성이 있어야 한다 |
| 소리에만 기대는 정보 | 없어야 | 탐지기 "삐삐삐"는 글로도 나옴 | 그대로 | — |
| 색에만 기대는 정보 | 없어야 | 맞힌 보기는 색 + "성경에 그렇게 기록되어 있어요" 글, 잠긴 시대는 흐림 + 🔒 + "잠김" 글 | 그대로 | — |

주: 대비 계산은 글자색(CSS)과 찍은 화면의 바탕색으로 한다. 고친 뒤에도 표에 남는 5줄 가운데 2줄(처음 화면의 큰 제목, 시대 이름)은 굵고 큰 글자라 바탕색을 글자색으로 잘못 읽은 것이고, 2줄(아이 이름표)은 CSS 거르개로 진하게 한 것이 계산에 잡히지 않은 것이다(찍은 화면에서 진해진 것을 눈으로 확인). 1줄(그림 위의 "시대 1")은 고쳤다.

### 안 됨·남은 일
- 3D 화면(걸어 다니는 화면의 위쪽 안내, 말풍선) 위의 글은 뒤가 3D 그림이라 대비를 재지 못했다. 어두운 반투명 바탕을 깔고 있다.
- 화면 읽기 프로그램(TalkBack, VoiceOver)으로 실제로 써 보지 못했다. 3D 탐험은 눈으로 보고 걷는 놀이라 이야기 카드 쪽("이야기 카드로" 단추)이 대신하는 길이다.
- 색각 이상 시뮬레이션은 하지 않았다.
