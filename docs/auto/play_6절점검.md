# 6절 점검: 과몰입을 유도하는 장치인가 (play 갈래, 2026-11-16)

규칙서 6절은 "광고, 유료 결제, 뽑기, 접속 보상처럼 과몰입을 유도하는 장치를 넣지 않는다"고 하고, 2절은 "개인 순위표 없음", 3.3절은 "신앙을 점수·등급·순위로 매기지 않는다"고 한다.
아래는 놀이 장치마다(독립 검증이 코드와 맞춰 보고 빠진 장치 넷을 더했다) 그 기준에 걸리는지 코드를 읽고 따진 표다. 신학 판단이 아니라 놀이 설계 점검이다. 최종 판단은 대표와 감수자가 한다.

## 따진 기준 (일곱 가지)

| 번호 | 과몰입 장치의 모습 | 이 게임 코드에 있나 |
|---|---|---|
| ① | 운으로 갈리는 보상(뽑기, 무작위 상자) | 없음. 보상이 무작위로 정해지는 곳이 없다(`Math.random`은 어른 확인 곱셈, 화면 흔들림, 불티·소리의 잔떨림에만 쓰이고 보상과 이어진 곳에는 쓰이지 않는다) |
| ② | 접속·시간 보상(출석, 연속 접속, 기다리면 차오르는 것) | 없음. 날짜·시각은 "마친 날"과 "걸린 시간" 기록에만 쓰고 보상과 이어지지 않는다 |
| ③ | 남과 견주기(순위표, 등수) | 없음. 다른 사람의 기록을 받거나 보내는 곳이 없다 |
| ④ | 잃을까 봐 하게 만들기(기간 한정, 안 하면 사라짐, 목숨) | 없음. 모은 것은 사라지지 않고 기한이 없다 |
| ⑤ | 돈(결제, 광고) | 없음 |
| ⑥ | 끝이 없는 되풀이(무한 단계, 날마다 새 과제) | 없음. 40장면·재료 64개·말씀 카드 80장으로 끝이 정해져 있다 |
| ⑦ | 불러들이기(알림, 푸시) | 없음. 알림을 보내는 코드가 없다 |

## 장치별 판단

| 장치 | 하는 일 | 걸리는가 | 근거 | 바꾼 것 |
|---|---|---|---|---|
| 시대 잠금 | 앞 시대의 장면 하나를 마치면 다음 시대가 열림 | 아니오 | 시간·접속과 상관없이 장면 하나로 열린다(②④ 아님). 차례대로 읽게 하는 안내에 가깝다. 어른이 "모든 시대 열기"로 풀 수 있다 | "모든 시대 열기" 단추를 아이 화면(시대 지도)에서 어른 확인 뒤의 부모·교사 화면으로 옮김 |
| 수리 막대(시대 지도) | 시대마다 모은 재료의 비율을 열 칸으로 보여 줌 | 아니오 | 끝이 정해진 진행 표시(⑥ 아님). 운·시간·남과 견주기가 없다. "탐험대 이야기"로 표시해 믿음의 점수로 읽히지 않게 했다 | 없음 |
| 깃발 색 해금(3D 아지트) | 시대 부속을 고칠 때마다 깃발 색이 하나씩 열림 | 아니오 | 정해진 차례로 열리는 꾸미기(① 아님, 뽑기가 아니다). 12절의 "다녀온 곳을 기념하는 물건"에 해당. 잠긴 색은 🔒로만 보이고 재촉하는 글이 없다 | 없음 |
| 탐지기 소리·숨은 재료 찾기(이야기 카드) | 여섯 땅 가운데 한 곳을 눌러 재료를 찾음. 가까우면 "삐삐삐" | **약하게 걸릴 수 있었음** | 숨은 곳은 장면마다 정해져 있고(무작위 아님) 여섯 번 안에 반드시 찾으며 얻는 것도 같다(① 아님). 다만 "한 번에 찾았어요!", "N번 만에 찾았어요!"가 운을 칭찬하고 횟수를 점수처럼 보이게 했다 | **두 글을 "찾았어요!" 하나로 바꿈**(`story.js` seekNodes) |
| 탐지기(3D의 방향 화살표·물음 단추) | 성경 물음을 풀면 재료가 있는 쪽을 가리킴. 물음 단추가 천천히 커졌다 작아짐 | 아니오 | 길 안내다. 움직임 줄이기 설정이면 멈춘다 | 없음 |
| 말씀 카드·탐험 일지(새로 만든 화면) | 마친 장면의 카드(장절·제목)를 다시 봄. "말씀 카드 2 / 80" | 아니오. 다만 감수 때 확인 | 끝이 정해져 있고 운·시간이 없다. 수는 "다녀온 장면"의 수이지 믿음의 크기가 아니다. 그래도 말씀을 "모으는 물건"처럼 느끼게 할 수 있어 감수 항목에 적음 | 카드에 장절과 제목만 두고 "성경책에서 직접 읽어 보세요"를 붙임 |
| 사진 도감 | 3D에서 찍은 사진을 모음. "도감을 모두 채웠어요!" | 아니오 | 장면마다 4~6장으로 끝이 있다 | 없음 |
| 탐험 모자 | 첫 장면을 마치면 쓸 수 있음 | 아니오 | 한 번 열리면 끝. "믿음의 점수가 아니라 다녀온 곳을 기념하는 물건"이라고 화면에 적혀 있다 | 없음 |
| 엇나간 횟수·걸린 시간(새로 만든 기록) | 물음에서 다른 보기를 고른 횟수, 장면에 머문 시간 | 아니오 | 아이 화면에는 보이지 않고 어른 확인 뒤의 부모·교사 화면에만 보인다. 그 화면에 "점수나 순위가 아니다"라고 적었다. 기기 밖으로 나가지 않는다(③ 아님) | 없음 |
| 엇나간 바늘(틀린 보기) | 성경의 다른 곳으로 잠깐 엇나갔다 돌아옴 | 아니오 | 잃는 것이 없고 횟수를 아이에게 보여 주지 않는다(④ 아님, 4.2절) | 없음 |
| 소리(새로 넣은 분위기 소리·단추 소리) | 물·바람·밤·무리의 웅성임, 단추의 "톡" | 아니오 | 얻었을 때 나는 소리가 아니다. 끌 수 있다 | 없음 |
| 얻을 때의 짧은 소리와 튀는 숫자(전부터 있던 것) | 사진·재료를 얻을 때 맑은 소리 세 음(`chime`), 숫자가 한 번 커졌다 돌아옴 | 약함. 그대로 둠 | 얻은 것을 알려 주는 한 번의 표시이고, 운·시간과 이어지지 않으며 되풀이해 얻을 수 없다. 움직임 줄이기 설정이면 튀지 않고 소리는 끌 수 있다 | 없음 |
| 마침 화면의 "다음 장면"·"다음 시대로" 단추 | 장면을 마치면 으뜸 단추가 다음 장면으로 이어짐 | **약하게 걸릴 수 있음** | 저절로 넘어가지는 않지만(누르지 않으면 그대로) 쉬어 갈 자리를 말해 주지 않았다 | **마침 화면에 "오늘은 여기까지 해도 좋아요. 진행은 이 기기에 저장돼요."를 더함**. 단추 차례는 그대로(대표 결정 대기) |
| 빈칸·남은 수 표시("아직 못 찍었어요", "남은 재료 N개", 수리 현황의 "?", "N / 64") | 아직 얻지 못한 것을 빈칸과 수로 보여 줌 | 약함. 그대로 둠 | 다 채우고 싶게 하는 표시이지만 끝이 정해져 있고 기한·잃는 것이 없다. 3D에서는 남은 재료를 찾아야 타임머신이 떠나므로(12절 "과거에 아무것도 남기지 않는다") 길 안내이기도 하다 | 없음(대표 결정 대기에 묶음) |
| 놀이 기록 `#log` | 화면마다 머문 시간, 2초 안에 넘긴 화면, 나간 곳을 이 기기에 적음 | 아니오 | 아이 시험(`docs/12`)에서 어디가 지루한지 보려는 도구다. 기기 밖으로 나가지 않고, 아이를 더 붙잡아 두는 조정에 쓰지 않는다. 어른 확인 뒤에만 부모·교사 화면으로 이어진다 | `#log` 화면에서 부모·교사 화면으로 갈 때도 어른 확인을 거치게 함 |

## 남긴 것 (대표·감수자가 볼 것)

- 수 표시(말씀 카드 "N / 80", 모은 재료 "N / 64", 시대별 "부속 N / N · 수리 끝!", 깃발 색 "N / 11")를 아이 화면에 보여 줄지: 지금은 보여 준다(다녀온 장면의 수와 같은 뜻). 빼는 쪽이 더 좁다.
- 마침 화면의 으뜸 단추를 "다음 장면"으로 둘지 "시대 지도"로 둘지: 지금은 "다음 장면"이고 쉬어 가도 된다는 글을 더했다. → `play_진행.md`의 대표 결정 대기.
- 시대 잠금을 처음부터 풀어 둘지(반에서 한 시대만 볼 때 번거로움): 지금은 잠금이 기본값이고 부모·교사 화면에서 푼다.
