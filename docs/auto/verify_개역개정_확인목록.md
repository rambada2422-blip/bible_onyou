# 8~10세 물음 156개: 개역개정 성경으로 답이 찾아지는지 확인 목록

- 만든 때: 2026-11-16, 자동 작업 verify 갈래. 장면 자료(`content/ot/OT-*.json`)에서 기계로 뽑았다. 성경 본문은 싣지 않았다(물음과 정답 보기는 게임 글이다).
- **왜 필요한가**: 8~10세 물음은 "성경책에서 ○장 ○절을 찾아 읽고 고르기"다. 글과 정답은 개역한글에 맞춰 대조했다(이 작업 환경에서는 개역개정을 열 수 없었다). 아이들은 대부분 개역개정을 펴므로, 개역개정의 낱말이 다르면 답을 찾지 못할 수 있다.
- **보는 법**: 개역개정을 펴서 장절을 읽고, 정답 보기가 그 절에서 찾아지면 확인 칸에 ✓, 찾기 어려우면 ✗와 개역개정의 낱말을 적는다. 156개, 한 개에 30초쯤(어림) 걸린다.
- "개역한글 낱말 그대로" 칸: 정답 보기의 낱말 가운데 개역한글 절에 글자 그대로 있는 것(기계가 뽑음, 헛짚음 있음). 아이가 이 낱말을 절에서 찾아 맞추게 되므로, 개역개정에서 이 낱말이 바뀌었으면 ✗일 가능성이 크다. 비어 있으면 정답을 풀어 쓴 것이다(숫자를 한글로 쓴 것 등).
- **먼저 볼 곳**(앞선 대조에서 개역한글과 KJV가 다르게 읽힌 곳): OT-02 창 2:15 "동산을 다스리기"(KJV는 가꾸다) / OT-04 창 11:2 동방으로, 11:4 대(탑) / OT-07 창 28:17 / OT-09 출 3:1 / OT-22 삿 16:13 / OT-25 삼상 10:19 / OT-26 삼상 17:6, 17:45 / OT-29 왕상 12:18 / OT-32 왕하 17:6 / OT-34 왕하 23:3 / OT-35 왕하 25:4 / OT-36 단 6:2 (`verify_진행.md` 감수 항목과 같음. 8~10세 물음이 아닌 곳도 있다).
- ✗가 나온 물음은 고치기 전에 이 갈래(또는 이어받는 세션)에 알려 주면, 개역개정과 개역한글 두 쪽에서 다 찾아지는 보기로 고치고 다시 대조한다.
