- 분위기 소리를 까는 대목과 근거(`web3d/js/story.js`의 AMB 표, 독립 대조 뒤 10장면): OT-01 물(창 1:2, 대목 1~5), OT-03 물(창 7:17-18, 물이 불고 주는 두 대목), OT-07 밤(창 28:11, 아침 전까지), OT-11 물(출 14장 바닷가)·센 바람(출 14:21 대목만), OT-17 밤(수 2:2-5), OT-18 물(수 3:15, 물이 그치기 전 두 대목), OT-20 무리(수 24:1 첫 대목만), OT-21 밤(삿 7:9, 싸움 전 두 대목), OT-29 무리(왕상 12:3, 처음 두 대목), OT-31 물·센 바람(욘 1:4). 넣지 않은 것: 시내 산의 우레·나팔(출 19:16), 금송아지 잔치 소리, 유월절 밤, 싸움 소리, 본문에 없는 광야 바람, 율법책 낭독 자리의 무리(느 8장), 성전 봉헌(왕상 8장)·언약책 낭독(왕하 23장)의 회중, 찬송과 통곡(스 3:11-13). OT-20의 무리 소리는 회중이 "하나님 앞에" 선 자리라 감수 때 확인.
- 읽어 주기: 화면의 풀어 쓴 글과 장절 이름만 기기 음성으로 읽는다. 성경 본문은 화면에 없어 읽지 않는다. 그래도 동행 인물의 대답(간접 서술)과 "하나님이 ~라고 말씀하셨어요" 같은 풀어 쓴 문장을 기계 음성이 읽는 것이 괜찮은지.

## 실패·주의
- 독립 검증 ①에서 고치지 않은 것(낮음): 저장 공간이 모자라면 사진 도감의 사진을 모두 버리고 이름·설명만 남기는 것(계산으로는 사진 200장에도 한도에 닿지 않음) / 사진 설명을 찍을 때 복사해 두어 나중에 감수로 설명이 바뀌어도 기기에는 옛 글이 남는 것(설명이 3D 장면 설정 안에만 있어 일지에서 다시 읽을 수 없다) / 글자 크기가 시트 아래 단추·3D 말풍선·처음 화면에는 적용되지 않는 것(설정 글에 밝힘) / 빠른 연타 때 읽어 주기 단추의 눌림 표시가 어긋날 수 있다는 추측(확인 못 함).
- ⚠️ Safari(아이폰)에서 글자 크기(CSS zoom)와 한국어 읽어 주기는 확인하지 못했다(이 환경은 Chromium뿐).
- 화면 전수 점검과 3D 시험을 함께 돌리면 3D 시험이 아주 느려진다(호렙 한 번에 40분 넘게). 3D 시험은 다른 시험이 없을 때 돌린다.
- 장면이 긴 표(`.otmap`)는 세로로 쌓는 틀이라, 안의 글 상자·표가 눌려 줄어든다. `.otmap > * { flex-shrink: 0 }`으로 막았다.
