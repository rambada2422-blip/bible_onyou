# 그림 스타일 가이드 v0.1

게임의 모든 그림은 이 문서를 따른다. 신학 규칙은 [00_공통규칙서.md](00_공통규칙서.md)가 우선한다.

## 1. 방향

- 아이 그림책의 삽화. 따뜻하고 차분하며, 8세가 봐도 무섭지 않고 19세가 봐도 유치하지 않다.
- 평면 채색(flat) 위에 겹겹의 원근을 쌓는다: 하늘 → 먼 산 → 중간 지형 → 주인공이 되는 대상 → 앞쪽 풀·돌.
- 먼 것은 흐리고 푸르게, 가까운 것은 진하고 따뜻하게(공기 원근).
- 윤곽선은 쓰지 않는다. 형태는 색면과, 한 단계 어두운 그림자 면으로 구분한다.
- 빛의 방향은 장면마다 하나로 정하고 모든 그림자가 그 방향을 따른다.
- 도형 몇 개를 늘어놓은 아이콘처럼 보이면 미완성이다. 돌, 풀, 옷 주름, 지형의 굴곡 같은 작은 디테일로 삽화의 밀도를 만든다.

## 2. 절대 지키는 것

- 하나님(성부·성자·성령)을 사람, 얼굴, 손, 눈, 빛나는 인물 실루엣 등 어떤 형상으로도 그리지 않는다. 불, 구름, 빛만 그린다. 불꽃이나 구름 안에 얼굴·인물처럼 보이는 모양이 우연히라도 생기지 않게 한다.
- 천사(여호와의 사자)도 그리지 않는다.
- 애굽의 신상·신 벽화를 그리지 않는다. 장식은 기하 무늬와 식물 무늬만 쓴다.
- 폭력 장면(매질, 피, 죽음)을 그리지 않는다.
- 그림 안에 글자를 넣지 않는다.
- 세 주인공(최온, 휴, 온우)은 배경 그림에 넣지 않는다. 그들은 목격자이며 화면 UI에 따로 나온다.

## 3. 사람 그리기

- 성경 인물은 고대 근동의 옷차림: 무릎 아래까지 오는 통옷, 겉옷, 허리띠, 머리쓰개, 샌들.
- 피부는 올리브~갈색 계열. 얼굴은 단순하게(점 눈, 작은 입). 표정보다 자세로 감정을 전한다.
- 작은 군중은 실루엣에 가깝게, 두세 가지 옷 색으로 변화를 준다.

## 5. 파일 규격 (배경 그림)

- SVG 한 파일. 루트는 `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 900 1200" preserveAspectRatio="xMidYMid slice">`. width·height 속성은 넣지 않는다.
- 세로 3:4 화면에 꽉 차게 쓰인다. 아래쪽 150px(y 1050 이상)은 대화창에 가려질 수 있으니 땅만 둔다. 중요한 대상은 x 80~820, y 150~950 안에 둔다.
- 이 SVG는 웹 페이지 안에 그대로 끼워 넣는다(inline). 그래서:
  - 모든 `id`와 `class` 이름 앞에 파일 키를 붙인다. 예: 키가 `ex01`이면 `ex01-sky`, `ex01-flame`.
  - `<style>` 안의 선택자는 접두어가 붙은 class·id만 쓴다. `path { }` 같은 태그 선택자, `*` 선택자는 금지.
  - `@keyframes` 이름에도 접두어를 붙인다.
- `<script>`, `<image>`, `<text>`, `<foreignObject>`, 외부 주소 참조, 글꼴은 쓰지 않는다.
- 필터는 빛 번짐용 `feGaussianBlur` 정도만, 한 그림에 3개 이하. `feTurbulence`는 쓰지 않는다(휴대폰에서 느리다).
- 파일 크기 90KB 이하.
- 움직임: 불꽃 흔들림, 구름 흐름, 별 반짝임 같은 잔잔한 반복만. CSS `@keyframes`로 만들고 전체를 `@media (prefers-reduced-motion: no-preference) { }` 안에 넣는다. 움직임이 꺼져도 그림이 완성돼 보여야 한다.
- 상태가 여러 개인 그림은 상태마다 `<g id="키-state-이름">`으로 묶는다. 기본 상태만 보이게 하고 나머지는 `style="display:none"`을 붙인다. 게임이 상태를 바꿀 때 이 묶음의 display를 켜고 끈다.

## 6. 함께 내는 정보 파일

그림마다 `키.meta.json`을 같은 폴더에 둔다.

```json
{
  "key": "ex01",
  "states": ["approach", "hideface"],
  "regions": [
    { "id": "bush", "label": "떨기나무", "x": 380, "y": 420, "w": 220, "h": 260 }
  ]
}
```

- `regions`는 그림 속 주요 대상의 위치(viewBox 좌표의 사각형). 게임이 그 부분을 확대하거나 누를 수 있는 영역으로 쓴다.

## 7. 스스로 확인하는 방법

그림을 다 그렸다고 판단하기 전에 반드시 화면으로 본다.

1. SVG를 끼워 넣은 HTML을 만들어 Chromium으로 390×520 크기(deviceScaleFactor 2)로 찍는다. 이 환경에는 Playwright가 설치돼 있다(`require('playwright')`, `chromium.launch()`에 옵션 불필요. 새로 설치하지 말 것).
2. 찍은 PNG를 직접 열어 본다.
3. 아래를 점검하고 고친 뒤 다시 찍는다. 최소 두 번 반복한다.
   - 그림책 삽화처럼 보이는가, 도형 나열처럼 보이는가
   - 주요 대상이 한눈에 무엇인지 알아볼 수 있는가
   - 2절의 금지 사항에 걸리는 모양이 없는가
   - 상태가 여러 개면 상태마다 찍어 확인했는가
   - 아래쪽 150px에 중요한 것이 없는가
