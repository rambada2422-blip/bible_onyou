# 구약 전체 장면표 v0.1

- 작성일: 2026-11-15
- 대표 결정(2026-11-15): 출애굽기 시범판에서 **구약 전체의 흐름**으로 넓힌다. 40장면. 대본·퀴즈는 40장면 모두, 3D는 시대마다 대표 장면(아래 "3D" 표시 12개), 나머지는 이야기 카드로 잇는다. 대표 확인 없이 진행하되 별도 검증자의 본문 대조(규칙서 9절 2단계)는 유지한다.
- 상태: 장면 선정은 Claude 초안이다. 목회자 감수 전이며 모든 장면의 감수 상태는 **미감수**다. "감수 필수"는 규칙서 3.5의 주제(주권과 책임, 재앙과 심판, 구약 사건의 신약적 의미)가 걸리는 장면이다.
- 장면 자료: `content/ot/OT-NN.json` (형식과 규칙은 `content/ot/작성규칙.md`, 검사는 `node tools/validate_ot.js`)
- 기준: `00_공통규칙서.md`. 출애굽기 13장면(`01_출애굽기_장면목록.md`)은 그대로 두고, 이 표의 시대 3은 그중 핵심을 다시 묶은 것이다.
