# 감수 결과를 받아 반영하는 순서

목사님이 표시해 주신 것(화면용의 "내보내기" 글, 또는 종이)을 받아 게임에 반영할 때의 순서입니다. 만드는 사람(총괄·작업 세션)이 봅니다.

## 0. 받기
1. 내보낸 글의 첫머리 **"자료 판"**을 봅니다. `docs/감수/README.md`의 자료 판과 같아야 항목 번호가 맞습니다. 다르면 그 판의 커밋에서 `항목목록.json`을 꺼내 번호를 맞춥니다(`git log -S"<자료 판>" -- docs/감수/항목목록.json`).
2. 받은 글을 **그대로** `docs/감수/받은것/YYYY-MM-DD_감수표시.txt`로 저장합니다(고치지 않음). 종이로 받았으면 `감수자료.html`을 열어 같은 표시를 넣고 "내보내기"로 만든 글을 저장합니다. 이름은 "감수 목사님"이라고만 적고, 개인 연락처는 저장소에 넣지 않습니다.
3. 뜻이 분명하지 않은 표시(메모만 있고 표시가 없는 것, "의논 필요")는 대표를 통해 다시 여쭙니다. **짐작으로 고치지 않습니다.**

## 1. 표시별로 누가, 어느 파일을
| 항목 번호의 꼴 | 표시 | 누가 | 어느 파일 | 뒤에 돌릴 것 |

## 2. 장면 자료를 고친 뒤 (장면마다)
1. 고친 사람과 **다른** 검증자가 본문과 다시 대조합니다(`node tools/bible_ref/ref.js "장절"`). 감수에서 고친 문장도 사실관계는 대조합니다(규칙서 9절).
2. `node tools/validate_ot.js --v3 OT-NN` 오류 0, 경고 0.
3. `node tools/build3d.js` → `node tools/test/walkOT.js 0|1|2 <폴더> NN NN`(세 나이 단계). 3D 장면이면 `walk3dScene.js OT-NN 0|1|2`.
4. 장면 자료의 감수 상태를 고칩니다: 그 장면의 **모든** 표시 항목이 "그대로"이거나 반영이 끝났을 때만 `"status": "감수 완료(YYYY-MM-DD, 감수자)"`. 일부만 끝났으면 `"감수 중"`. 이 문서를 쓰는 지금은 40장면 모두 `미감수`입니다.
5. `node tools/make_review_pack.js` → `node tools/test/check_review_pack.js`. 자료 판이 바뀝니다. 고친 항목만 다시 여쭐 때는 `항목목록.json`에서 그 번호를 골라 드립니다.

## 3. 끝내기
- `docs/11_구약전체_진행표.md`의 "감수 때 확인할 것"과 장면표의 감수 상태를 고칩니다(총괄).
- 화면의 "감수 전" 글(`공통·화면글` 항목에 모두 실려 있음)을 감수가 끝난 범위만큼 바꿉니다. 일부 장면만 끝났으면 끝난 장면만 열고 나머지는 닫아 둡니다.
- 규칙서 9절의 마지막 단계(실제 휴대폰에서 끝까지 해 본 뒤 공개)는 감수와 따로 남아 있습니다. `공개전_점검표.md`를 봅니다.
- 공개는 대표가 정합니다.
