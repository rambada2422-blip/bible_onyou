# 대표 결재지 (바이블 온유)

> **🟡 내부 결정 · 대표가 정할 것 28가지** (모두 예/아니오로 답할 수 있게 썼고, 추천과 까닭을 붙였습니다.)
> - 급한 것은 **"가" 묶음 7가지**입니다. 나머지는 모두 지금대로 두기를 추천하므로, 다르게 하실 것만 표시하셔도 됩니다.
> - 신학 판단이 섞인 것은 여기서 정하지 않고 **목회자 감수 자료로 옮겼습니다**("목회자에게" 칸).
> - 돈이 드는 결정은 없습니다. 밖으로 나가는 일(목사님께 자료 드리기, 공회 문의, 아이 시험)은 대표가 직접 하시는 일로 적었습니다.

자료 판 `a22c750c` · `docs/감수/대표_결재_자료.json`을 고치고 `node tools/make_review_pack.js`를 돌리면 다시 만들어집니다. 휴대폰에서는 `대표_결재지.html`을 열어 표시하고 "내보내기"로 글을 뽑을 수 있습니다.
