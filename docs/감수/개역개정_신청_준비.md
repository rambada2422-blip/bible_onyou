# 개역개정 사용 허락 신청 준비 (초안 · 보내지 않음)

- 작성: 2026-11-16, 자동 작업 pack 갈래. 규칙서 10절 "아직 정하지 않은 것"의 "개역개정 사용 허락 신청"을 준비한 것입니다.
- **이 문서는 준비 자료입니다. 어디에도 보내지 않았습니다.** 보내는 것은 대표가 정합니다.
- 지금 게임은 성경 본문을 한 줄도 싣지 않습니다(장절만 보여 주고 아이가 자기 성경책을 폅니다). 이 상태는 규칙서 7절대로 허락을 받을 때까지 그대로입니다.

## 3. 전화로 물을 것 (문의 대본)

> 안녕하세요. 교회와 가정에서 쓰려고 어린이·청소년용 성경 학습 게임을 만들고 있습니다. 아직 공개 전입니다. 저작권 사용에 대해 몇 가지 여쭙니다.

1. 게임 화면에 **성경 본문은 싣지 않고 장절만**("출애굽기 12장 7절을 찾아 읽어 보세요") 보여 줍니다. 이 경우에도 허가가 필요한가요?
2. 사건을 **우리 말로 풀어 쓴 글**(본문을 그대로 옮기지 않음)을 싣습니다. 이것도 허가 대상인가요?
3. 나중에 **한 절씩, 모두 80절**을 "말씀 카드"로 화면에 싣고 싶습니다. 이 경우의 분류(앱·전자책 등)와 사용료, 허가 기간은 어떻게 되나요? 광고·결제가 없는 비영리, 교회 안 사용이면 달라지나요?
4. 신청서 양식과 보낼 곳, 걸리는 기간을 알려 주세요.
5. 허가를 받으면 화면에 넣어야 하는 **표시 문구**가 있나요?

## 4. 신청서에 넣을 내용 (초안, [ ]는 대표가 채울 빈칸)

**신청인**
- 단체·이름: [ 교회 이름 또는 개인 이름 ]
- 담당자·연락처: [ 이름 / 전화 / 전자우편 ]
- 주소: [ ]

**쓰려는 곳**
- 이름: 바이블 온유 ([ 정식 이름이 정해지면 고침 ]. 규칙서 10절: 게임 이름은 아직 정하지 않음)
- 종류: 휴대폰 웹으로 여는 어린이·청소년(8~19세) 성경 학습 게임. 앱스토어 출시는 하지 않음(나중에 정함)
- 쓰는 사람: 우리 교회와 가정의 아이들부터. [ 예상 인원: 명 ]
- 공개 방식: 주소를 아는 사람만 여는 웹 페이지. [ 공개 예정일: 목회자 감수와 아이 시험 뒤 ]
- 영리 여부: 무료. 광고·유료 결제·뽑기가 없음(규칙서 6절)
- 신학 기준과 감수: 웨스트민스터 표준문서, 담임 목회자 감수 [ 감수자 이름·교회 ]

**쓰려는 본문**
- 번역본: 성경전서 개역개정판
- 범위(가장 좁은 안): 말씀 카드 80장 × 한 절 = **80절**. 구약 17권(창세기, 출애굽기, 민수기, 신명기, 여호수아, 사사기, 룻기, 사무엘상, 사무엘하, 열왕기상, 요나, 열왕기하, 다니엘, 에스라, 에스더, 느헤미야, 말라기). 장절 목록은 `docs/감수/md/시대01.md`~`시대10.md`의 "말씀 카드" 줄에 있습니다
- 쓰는 방법: 아이가 **자기 성경책에서 그 절을 찾아 읽은 뒤에** 카드에 그 절이 나타남. 본문을 고치거나 줄이지 않고, 장절과 번역본 이름을 함께 표시
- 쓰지 않는 것: 본문 전체 싣기, 검색, 내려받기, 본문을 소리로 읽어 주기
- 기간: [ 1년 / 공회 기준에 따름 ]

**함께 보낼 자료**
- 게임 소개 한 장(`docs/아이시험/교사부모_한장안내.md`를 고쳐 쓰면 됩니다)
- 화면 예시 2~3장 [ 총괄이 미리보기에서 찍음 ]
- 80절 장절 목록

## 5. 허락을 받은 뒤에 할 일 (지금은 하지 않음)
- 규칙서 7절의 "싣지 않는다"를 허락 범위만큼 푸는 대표 결정 → 규칙서에 기록.
- 본문은 허락받은 절만, 따로 떨어진 자료 파일로(장면 자료와 섞지 않음). 표시 문구를 화면에 넣음.
- 허가 기간이 끝나는 날을 달력에 적어 둠(갱신).
