# 창세기 놀이 5 · 조카에게 건네는 한 판

놀이 1~4 가운데 가장 잘 작동한 한 판을, 처음 보는 어른과 아이가 바로 할 수 있게 석 장으로 정리했다.
- 1장: 아이 앞에 두는 놀이판과 카드
- 2장: 진행자용 순서와 정답·근거
- 3장: 해 본 뒤 적는 기록표

인쇄본은 같은 폴더의 `놀이5_인쇄본.pdf`(A4 석 장)다.

- 놀이 1의 전체 원고는 `놀이1_방주창가.md`다. 이 판은 그 원고를 줄인 것이다. 아이가 듣는 어른의 말은 놀이 1에서 글자 그대로 가져왔다. 최온의 줄(아이가 원고를 함께 볼 때 읽는 줄)과 쉼의 자세한 안내는 줄였다.

## 2장 · 진행자용 (아이에게 보여 주지 않는다)

### 준비 (5분, 아이가 보기 전에)

1. 1장을 인쇄해 자른다. 시간 창 카드는 세로 한 줄이 한 장이다. 앞면과 안쪽 사이 가로줄에서 뒤로 접어 붙인다. 앞면은 앞에, 안쪽은 뒤에 온다.
2. 카드 세 장을 앞면이 위로 오게 창 ①②③ 자리에 놓는다. 창을 연다는 것은 카드를 위아래로 뒤집는 것이다 (좌우로 뒤집으면 글이 거꾸로 보인다).
3. 새 잎 카드 한 장과 칩 여섯 개는 어른이 갖고 있다가 진행 3번에서 건넨다.

### 진행 (읽을 말은 굵게. 놀이 1 원고의 칸 번호를 괄호에 적었다)

1. (칸 1) **산 위에 멈춘 방주가 보여요. 방주의 창이 열렸어요.** 『탐험대 이야기』 **아래의 시간 창 세 개는 탐험대가 만든 종이 창이에요. 노아가 비둘기를 날려 보낸 날이 하나씩 숨어 있어요.**
2. (칸 2) 앞면 세 장을 차례대로 읽어 준다. 『탐험대 이야기』 **시간 창 안쪽에는 그때 비둘기가 어떻게 되었는지 적혀 있어요.**
3. (칸 3) 『탐험대 이야기』 **탐험대가 단서 카드를 만들어 왔어요. 감람나무 새 잎 카드 한 장과 돌아옴 칩이에요.** 새 잎 카드와 칩을 아이 앞으로 밀어 준다. **세 번 가운데 비둘기가 감람나무 새 잎을 물고 온 때는 딱 한 번이에요. 돌아옴 칩은 '돌아왔어요'와 '돌아오지 않았어요' 두 가지예요. 필요한 만큼 써요.**
4. (칸 4) **먼저 열어 볼 창 두 개를 골라 봐요. 하나는 끝까지 닫아 둬요.** 아이가 고를 때까지 기다린다.
5. (칸 5) 아이가 고른 두 창을 뒤집어 안쪽을 같이 읽는다. 창 아래에 맞는 칩을 놓고, 새 잎이 나오면 새 잎 카드도 놓게 한다.
6. 닫아 둔 창에 따라 아래 세 묶음 가운데 한 묶음만 고른다. 물음마다 아이가 말할 때까지 기다린다.
    - 셋째를 닫았으면 (칸 6-가): **새 잎 카드는 벌써 둘째 창에 있어요. 셋째 창에도 새 잎 카드를 놓을 수 있을까요?** / **첫째 창과 둘째 창을 견주어 봐요. 무엇이 달라졌나요?** / **셋째 창은 앞면만 보고는 딱 알 수 없어요. 내 생각을 말하고 칩을 놓아 봐요.**
    - 둘째를 닫았으면 (칸 6-나): **새 잎 카드는 아직 어느 창에도 없어요. 새 잎은 세 번 가운데 한 번 나와요. 어느 창에 놓을까요?** / **탐험대가 새 잎 카드를 줄 때, 비둘기가 새 잎을 어떻게 했다고 했지요?** / **그렇다면 둘째 창의 비둘기는 노아에게 돌아왔을까요, 돌아오지 않았을까요?**
    - 첫째를 닫았으면 (칸 6-다): **둘째 시간 창 앞면을 다시 읽어 봐요. 노아가 비둘기를 '한 번 더' 날려 보냈대요.** / **그렇다면 첫째 창의 비둘기는 노아에게 돌아왔을까요, 돌아오지 않았을까요?** / **새 잎 카드는 벌써 둘째 창에 있어요. 첫째 창에도 놓을 수 있을까요?**
7. (칸 7) **이제 닫아 둔 창 카드를 뒤집어 봐요.** **놓은 칩과 새 잎 카드가 안쪽 글과 같은가요? 다르면 안쪽 글에 맞게 바꿔 놓아요.** 셋째 창을 마지막에 열었으면 이어서 읽는다: **성경은 이번에는 비둘기가 돌아오지 않았다고만 말해요. 왜 돌아오지 않았는지는 적혀 있지 않아요.**
8. (칸 8) **창세기 8장을 펴 볼까요? 비둘기를 날려 보낸 세 번을 찾아서 시간 창과 하나씩 맞춰 봐요.** (8~12절) **비둘기보다 먼저 날아간 새도 나와요. 까마귀예요. 시간 창은 비둘기만 담았어요.** (7절의 까마귀에 대해서는 돌아왔다는 말이 없다. 8절의 '또'는 까마귀에 이어 비둘기도 보냈다는 뜻이다) 아이가 세 번을 찾으면: **무엇을 보니 알 수 있었나요? 8장에 첫째는 앉을 곳이 없어 돌아오고, 둘째는 새 잎을 물고 돌아왔다고 나와요.** **셋째는 돌아오지 않았다고 나와요.**
9. (칸 9) 『탐험대 이야기』 **일지에 세 번을 일어난 차례대로 적어요.** 첫째 돌아왔어요 8:9 · 둘째 감람나무 새 잎 8:11 · 셋째 돌아오지 않았어요 8:12. (원하면) 한 문장 기도: **노아를 기억하신 하나님, 고맙습니다.**

### 정답과 근거

| 창 | 안쪽 | 근거 | 닫아 두었을 때 아이가 찾는 길 |
|---|---|---|---|
| 첫째 | 돌아옴. 앉을 곳이 없었음 | 창 8:8–9 | 둘째 앞면의 '한 번 더'(8:10의 '다시') → 돌아왔음. 새 잎은 둘째에 이미 있음 |
| 둘째 | 저녁에 돌아옴. 감람나무 새 잎 | 창 8:10–11 | 새 잎이 첫째·셋째에 없음 → 둘째. 새 잎을 '물고 왔다' → 돌아왔음 |
| 셋째 | 돌아오지 않음 | 창 8:12 | 앞면으로는 정할 수 없다. 두 창을 견주어 예상하고 뒤집어 확인한다. 까닭은 본문에 없다 |

### 지킬 것

- 예상이 달라도 "틀렸어요"라고 하지 않는다. 칩을 안쪽 글에 맞게 바꾸고 8장으로 확인한다.
- 셋째 비둘기가 왜 돌아오지 않았는지 단정하지 않는다 (공통 규칙서 3.3).
- 이 장과 정답은 처음 하는 아이에게 보여 주지 않는다. 아이가 오래 막히면 창세기 8장을 함께 편다.

## 3장 · 해 본 뒤 적는 기록표

혼자 두 역할로 시험한 칸은 채워 두었다. 실제 아이와 한 칸은 비워 두었고, 진행한 어른이 적는다. 아이를 알아볼 수 있는 것(이름, 학교, 사는 곳, 아이를 부른 말)은 적지 않는다 (공통 규칙서 6절).

| 적을 것 | 혼자 두 역할로 시험 (2026-11-23, Claude) | 실제 아이와 (날짜, 아이 나이만. 이름은 적지 않는다) |
|---|---|---|
| 먼저 연 두 창 | ①②, ①③, ②③ 세 가지 모두 | |
| 준비를 마치고 아이가 첫 창을 열 때까지 걸린 시간 | 약 2분 (⚠️ 소리 내어 읽은 분량으로 잡은 추정) | |
| 막힌 자리 (몇째 칸, 그때 아이가 한 말) | 고친 뒤에는 없음. 고치기 전에 찾은 곳: 칸 6-가(최온의 줄이 답을 먼저 말함), 칸 6-나·6-다(어느 때를 묻는지 흐림), 칸 6-나(물음이 답을 짚어 줌), 칸 7(새 잎 카드를 바꾸라는 말이 없음), 화면으로 볼 때 답이 보임 | |
| 닫아 둔 창의 단서를 아이가 스스로 찾았는지, 어른이 짚어 줬는지 | (혼자 시험이라 알 수 없음) | |
| 닫아 둔 창의 예상이 맞았는지 | 첫째를 닫으면 '한 번 더'와 새 잎으로, 둘째를 닫으면 새 잎과 '물고 왔다'로 끝까지 이끌어 냄. 셋째를 닫으면 예상한 뒤 뒤집어 확인 | |
| 아이가 성경 8장에서 세 번을 찾았는지 | (혼자 시험이라 알 수 없음. 시험한 사람이 8장 8~12절에서 세 번을 찾을 수 있는 것은 확인함) | |
| 끝까지 걸린 시간 | 10~15분 (⚠️ 추정) | |
| 아이가 다시 하고 싶어 했는지 | (혼자 시험이라 알 수 없음) | |
| 두 번째 판에서 고른 것 (아래 선택 가운데) | (혼자 시험이라 없음) | |

두 번째 판에서 바꿀 수 있는 선택: 닫아 둘 창 바꾸기(처음 만나는 아이와) · 역할 바꾸기(아이가 진행자, 어른이 곁에서 물음을 불러 줌) · 화면판(`놀이1_화면판.md`) · 다음 놀이(놀이 2, 3)로 가기.

## 별도 내용 검증 (2026-11-23)

작성 과정을 보지 않은 검증자가 놀이 1 원고, 창 8장 원문, 공통 규칙서, 일감 표, 인쇄본과 대조했다. 결과는 수정 필요 3건, 권장 7건이었다. 정답표가 창 8:8–12와 맞는 것, 굵은 글씨와 카드 글이 놀이 1과 글자까지 같은 것, 인쇄본이 석 장인 것, 아이 이름을 받지 않는 것은 문제없었다. 아래처럼 반영했다.

- 필수 (반영)
  - 6-나의 물음("탐험대가 새 잎 카드를 줄 때…")이 가리키는 놀이 1 칸 3의 줄이 빠져 있었다. 진행 3번에 그 줄을 되살리고, 카드는 그 줄과 함께 건네게 했다.
  - 놀이 3·4의 검증과 다시 시험한 상태를 사실대로 고쳐 적었다(⚠️ 수정본 재검증 전).
  - 인쇄본에서 6-가·6-나·6-다가 차례대로 하는 단계처럼 찍혔다. 한 묶음만 고르는 것이 보이게 한 줄씩 묶고 인쇄본을 다시 만들었다.
- 권장 (반영)
  - '한 글자도 다르지 않다'는 말을 '어른의 말은 글자 그대로, 최온의 줄과 쉼 안내는 줄임'으로 고쳤다. 놀이 1 칸 2의 『탐험대 이야기』 줄과 칸 8 끝의 두 줄도 되살렸다. 대조한 문장 수를 다시 세어 적었다.
  - 기록표의 추리 길 설명을 고치고, 막힌 자리를 칸 번호로 적었다. '아이가 스스로 찾았는지, 어른이 짚어 줬는지'와 '두 번째 판에서 고른 것' 줄을 더했다. 혼자 시험 칸의 '찾음'은 아이의 결과처럼 읽혀서 고쳤다.
  - '두 번째 판'의 '분명하다'는 말을 낮추고, 역할 바꾸기는 어른이 곁에서 물음을 불러 주게 해 '2장은 처음 하는 아이에게 보여 주지 않는다'와 맞췄다.
  - 놀이 3의 걸리는 때를 15~20분으로 맞췄다.
  - 인쇄본 3장에 두 번째 판의 선택을 넣었다.
  - 기록표에 아이를 알아볼 수 있는 것은 적지 않는다는 줄을 넣었다.

### 수정본 재검증 (2026-11-23)

작성 과정을 보지 않은 다른 검증자가 놀이 3~5를 함께 다시 대조했다. 놀이 5는 2장만 따라가도 세 경우가 끝까지 가고, 어른의 말과 카드 글이 놀이 1과 글자까지 같고, 인쇄본이 석 장이라는 것을 확인했다. 새로 나온 지적을 반영했다.
- 필수: 첫째·둘째 창 안쪽이 창 8:9, 8:11 한 절의 차례를 그대로 따랐다. 놀이 1과 함께 고쳤다(놀이 1 맨 아래).
- 권장: 칸 1의 "방주는 산 위에 멈춰 있어요. 노아가 방주의 창을 열었어요."(8:4, 8:6 틀)를 놀이 1과 함께 고쳤다. 진행 6번의 '한 묶음만'에서 굵은 글씨를 뺐다(굵은 글씨는 읽을 말이다). 놀이 4의 준비물에 자물쇠 쪽지와 그림 카드를 넣었다.
