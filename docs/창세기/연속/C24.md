# C24 · 두 이름의 반쪽 카드 (므낫세와 에브라임)

창세기 41:50–52에서 요셉이 두 아들에게 붙인 이름과, 이름마다 요셉이 덧붙인 말을 **반쪽 카드**로 맞추는 판이다. 카드 한 장을 반으로 나눠, 왼쪽 반쪽에는 이름, 오른쪽 반쪽에는 그 이름을 붙이며 한 말이 있다. 반쪽은 모두 같은 크기의 네모라 모양으로는 짝을 알 수 없다. 이름 반쪽 셋(므낫세, 에브라임, 요셉)과 설명 반쪽 셋 가운데 한 짝은 다른 날(창 30:24, 라헬이 요셉에게 이름을 붙인 날)의 것이다. 아이는 성경을 펴기 전에 여섯 반쪽을 짝판의 세 자리에 내 생각대로 먼저 놓고, 첫째 아들과 둘째 아들 가운데 어느 쪽부터 41장으로 확인할지 고른다. 짝이 다르면 반쪽 한 장만 바꾼다.

## 카드 정보

| 항목 | 내용 |
|---|---|
| 카드 번호 | C24 (바탕 원고 없음, 새 판) |
| 근거 장절 | 창 41:50–52 (중심), 30:22–24 (다른 장면) |
| 나이 단계 | 8~10세 (어른과 함께) |
| 사람 수 | 두 사람 (어른 한 명은 진행, 아이 한 명은 반쪽을 놓는다) |
| 걸리는 때 | ⚠️ 추정 8~10분 (잰 시간이 아니다) |
| 질문과 보기 | 이름 반쪽 셋과 설명 반쪽 셋을 짝판의 세 자리(요셉의 첫째 아들 / 요셉의 둘째 아들 / 다른 날)에 어떻게 놓을까요? 먼저 내 생각대로 놓고 성경으로 확인한다(공통 규칙서 4.1). 첫 선택: ㉠ 첫째 아들부터 확인 / ㉡ 둘째 아들부터 확인 |
| 정답 근거 | 첫째 아들: 므낫세 + 아버지 집의 일도 고생도 잊게 하셨다 · 창 41:51 / 둘째 아들: 에브라임 + 고생하며 일한 땅에서 잘되게 하셨다 · 창 41:52 / 다른 날: 요셉 + 아들을 하나 더 주시기를 바란다 · 창 30:24 (이름을 붙인 사람은 라헬) |
| 성경 찾기 안내 | 아이에게는 책과 장(창세기 41장, 30장)과 '41장 끝 무렵', '바로 뒤', '30장 가운데쯤'까지 안내한다. 절은 어른 도움말로만 둔다 (공통 규칙서 5절). 일지에는 장절을 함께 적는다 |
| 다른 장면 | 라헬이 아들을 낳고 요셉이라는 이름을 붙인 날 (창 30:22–24) 한 곳. 설명 반쪽 '아들을 하나 더 주시기를 바란다'를 첫째나 둘째 아들 자리에 놓으면 다녀온다 |
| 준비물 | 아래 '인쇄용 짝판과 반쪽 카드'(인쇄하거나 손으로 옮겨 쓴다), 아이의 성경책, 탐험 일지(종이)와 연필. 자르지 않으려면 짝판의 자리에 반쪽의 기호를 연필로 쓴다 |
| 참고 출처 | 성경 본문만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음. 확인 권함: 41:51의 '고난'(37–40장의 일)을 풀어 말하지 않은 것, 30:23의 '부끄러움'을 다루지 않은 것, 기도 문장 |
| 감수 상태 | 미감수 |

읽는 법
- **어른**은 어른이 읽는 줄이고, **최온**은 아이가 읽는 줄이다(최온은 탐험대의 10살 아이). 한 줄이 한 화면이다.
- **쉼**에서는 다음 줄로 넘어가지 말고 아이를 기다린다.
- 『탐험대 이야기』가 붙은 줄은 성경 본문이 아니다. 짝판, 반쪽 카드, 다른 날 카드, 탐험 일지는 탐험대가 만든 종이 도구다.
- 괄호 안의 장절과 '어른 도움말'은 소리 내어 읽지 않는다.
- 이 문서에는 답이 적혀 있어서 어른만 본다. 아이 앞에는 인쇄한 짝판과 반쪽 카드만 둔다.

## 놀이 준비 (⚠️ 추정 3분)

1. 어른이 아래 '인쇄용 짝판과 반쪽 카드'를 인쇄한다. 이 문서의 다른 쪽에는 답이 있으니 어른이 갖는다.
2. 반쪽 카드 여섯 장을 잘라, 이름 반쪽과 설명 반쪽을 따로 섞어 글이 보이게 펼친다. 반쪽은 모두 같은 크기의 네모로 자른다(모양으로 짝을 알 수 없게). 자르지 않을 때는 목록을 판 옆에 두고, 자리마다 반쪽의 기호를 연필로 쓴다.
3. 다른 날 카드는 글이 안쪽으로 가게 접어 둔다.
4. 아이의 성경은 덮어 둔다. 반쪽을 다 놓은 뒤에 편다.

## 아이에게 알려 줄 규칙 (세 줄)

- 성경을 펴기 전에 반쪽 여섯 장을 **내 생각대로** 세 자리에 놓는다. 자리마다 이름 반쪽 하나, 설명 반쪽 하나다.
- 첫째 아들과 둘째 아들 가운데 **어느 쪽부터** 41장으로 확인할지 고른다.
- 짝이 다르면 **반쪽 한 장만** 바꾼다.

## 플레이 원고

### 칸 1 · 도착 (창 41:46–50)

- 보이는 것: 곡식을 쌓아 둔 성읍과 일하는 사람들 (멀리서 작게). 탐험대 쪽에는 짝판(요셉의 첫째 아들, 요셉의 둘째 아들, 다른 날)과 반쪽 카드 여섯 장
- **최온** 『탐험대 이야기』: 카드가 반으로 나뉘어 있어! 이름 반쪽이랑 말 반쪽이야.
- **어른**: 풍년이 든 일곱 해 동안, 남는 곡식은 요셉이 모아 두었어요. 그 무렵 요셉에게 두 아들이 태어났어요. (어른 도움말: 47–50절. 언제 태어났는지는 50절에 있다)
- **어른** 『탐험대 이야기』: 요셉은 두 아들에게 이름을 붙이며, 이름마다 말을 덧붙였어요. 그 이름과 말을 반쪽 카드로 맞춰 봐요.
- → 칸 2로 간다.

### 칸 2 · 먼저 놓기 (성경을 펴기 전)

- 보이는 것: 짝판, 반쪽 카드 여섯 장
- **어른** 『탐험대 이야기』: 반쪽을 같이 읽어요. (어른은 이름 반쪽과 설명 반쪽을 인쇄한 차례대로 읽어 준다)
- **어른** 『탐험대 이야기』: 성경을 펴기 전에 먼저 놓아요. 자리마다 이름 반쪽 하나와 설명 반쪽 하나를 내 생각대로 짝지어 놓아요.
- **쉼**: 아이가 여섯 장을 다 놓을 때까지 기다린다.
- **어른** 『탐험대 이야기』: 이제 창세기 41장을 펴요. 첫째 아들과 둘째 아들 가운데 어느 쪽부터 확인할까요?
- **쉼**: 아이가 고를 때까지 기다린다.
- 고르기
  - **㉠ 첫째 아들부터** → 칸 3으로 간다.
  - **㉡ 둘째 아들부터** → 칸 4로 간다.

### 칸 3 · 첫째 아들 (창 41:50–51)

- 보이는 것: 짝판의 '요셉의 첫째 아들' 자리, 펼친 성경
- 칸 다른-날에서 돌아왔으면 '이름을 찾았으면' 줄부터 다시 읽는다.
- **어른**: 41장 끝 무렵에서 요셉의 첫째 아들 이름을 찾아봐요. (어른 도움말: 51절. 개역개정은 '장남'이라고 쓴다)
- **쉼**: 아이가 '므낫세'를 찾을 때까지 기다린다.
- **어른** 『탐험대 이야기』: 이름을 찾았으면, 같은 절에서 요셉이 덧붙인 말을 읽어요. 첫째 아들 자리의 설명 반쪽과 같은 뜻인가요?
- **쉼**: 아이가 견줄 때까지 기다린다.
- **어른** 『탐험대 이야기』: 지금 첫째 아들 자리에 '아들을 하나 더 주시기를 바란다'는 반쪽이 있나요?
- 고르기
  - **있어요** → 칸 다른-날로 간다.
  - **없어요** → 이 칸의 아래 줄을 이어 읽는다.
- **어른** 『탐험대 이야기』: 이름 반쪽이나 설명 반쪽이 다르면, 맞는 반쪽과 한 장만 바꿔요.
- **쉼**: 아이가 바꿀 때까지 기다린다.
- 고르기 (다음 칸)
  - **둘째 아들을 아직 확인하지 않았어요** → 칸 4로 간다.
  - **둘째 아들도 확인했어요** → 칸 5로 간다.

### 칸 4 · 둘째 아들 (창 41:52)

- 보이는 것: 짝판의 '요셉의 둘째 아들' 자리, 펼친 성경
- 칸 다른-날에서 돌아왔으면 '이름을 찾았으면' 줄부터 다시 읽는다.
- **어른**: 41장 끝 무렵에서 요셉의 둘째 아들 이름을 찾아봐요. 첫째 아들 이야기 바로 뒤예요. (어른 도움말: 52절. 개역개정은 '차남'이라고 쓴다)
- **쉼**: 아이가 '에브라임'을 찾을 때까지 기다린다.
- **어른** 『탐험대 이야기』: 이름을 찾았으면, 같은 절에서 요셉이 덧붙인 말을 읽어요. 둘째 아들 자리의 설명 반쪽과 같은 뜻인가요?
- **쉼**: 아이가 견줄 때까지 기다린다.
- **어른** 『탐험대 이야기』: 지금 둘째 아들 자리에 '아들을 하나 더 주시기를 바란다'는 반쪽이 있나요?
- 고르기
  - **있어요** → 칸 다른-날로 간다.
  - **없어요** → 이 칸의 아래 줄을 이어 읽는다.
- **어른** 『탐험대 이야기』: 이름 반쪽이나 설명 반쪽이 다르면, 맞는 반쪽과 한 장만 바꿔요.
- **쉼**: 아이가 바꿀 때까지 기다린다.
- 고르기 (다음 칸)
  - **첫째 아들을 아직 확인하지 않았어요** → 칸 3으로 간다.
  - **첫째 아들도 확인했어요** → 칸 5로 간다.

### 칸 다른-날 · 다른 장면: 요셉이라는 이름 (창 30:22–24)

- 보이는 것: 편 다른 날 카드 (아기를 안은 라헬, 멀리서 작게)
- **어른** 『탐험대 이야기』: '아들을 하나 더 주시기를 바란다'는 반쪽을 들고 다른 날 카드를 펴요. 타임머신이 훨씬 앞의 날로 갔어요.
- (어른 도움말: 칸 5에서 왔으면 '다른 날' 자리의 두 반쪽을 들고 온다)
- **최온**: 여기도 아기가 있어! 누가 이름을 붙이는 거지?
- **어른**: 창세기 30장 가운데쯤을 펴 봐요. 이 말을 하며 이름을 붙인 사람은 누구이고, 붙인 이름은 무엇인가요? (어른 도움말: 22–24절. 라헬이 아들에게 '요셉'이라는 이름을 붙였다)
- **쉼**: 아이가 '라헬'과 '요셉'을 찾을 때까지 기다린다. (어른 도움말: 23절의 '부끄러움'은 이 판에서 풀지 않는다)
- **어른**: 요셉이 자기 아들에게 붙인 이름인가요?
- **쉼**: 아이가 아니라고 말할 때까지 기다린다.
- **어른** 『탐험대 이야기』: 이 반쪽과 '요셉' 이름 반쪽은 '다른 날' 자리에 짝지어 둬요. 애굽으로 돌아가요.
- → 온 칸으로 돌아간다: 칸 3에서 왔으면 칸 3, 칸 4에서 왔으면 칸 4, 칸 5에서 왔으면 칸 5의 '요셉은 첫째 아들 이름에' 줄.

### 칸 5 · 짝판 확인 (창 41:51–52, 30:24)

- 보이는 것: 반쪽이 다 놓인 짝판
- **어른** 『탐험대 이야기』: 자리마다 이름 반쪽 하나와 설명 반쪽 하나가 있나요? '다른 날' 자리에는 요셉과 그 설명이 있나요?
- **어른** 『탐험대 이야기』: '다른 날' 자리의 짝은 아직 성경으로 확인하지 않았나요? 그러면 그 두 반쪽을 들고 다른 날 카드를 펴요.
- 고르기
  - **아직 확인하지 않았어요** → 칸 다른-날로 간다.
  - **다른 날 카드를 다녀왔어요** → 이 칸의 아래 줄을 이어 읽는다.
- **어른**: 요셉은 첫째 아들 이름에 무엇을 잊게 하셨다는 말을 담았나요? 둘째 아들 이름에는요?
- **어른** 『탐험대 이야기』: 짝판을 보고 말해 봐요.
- **쉼**: 아이가 짝판을 보고 말할 때까지 기다린다.
- **최온**: 첫째는 '잊게 하셨다', 둘째는 '잘되게 하셨다'! 요셉은 둘 다 하나님이 하셨다고 했어.
- → 칸 6으로 간다.

### 칸 6 · 기록

- 보이는 것: 탐험 일지, 짝판
- **어른** 『탐험대 이야기』: 일지에 두 이름과 덧붙인 말을 옮겨 적어요. 먼저 확인한 아들도 적어요.
- 일지에 적을 것
  - 먼저 확인한 아들: **첫째** 또는 **둘째**
  - 두 아들이 태어난 때 · 창세기 41장 50절 · 흉년이 오기 전
  - **첫째 므낫세** · 창세기 41장 51절 · 아버지 집의 일도 고생도 하나님이 잊게 하셨다
  - **둘째 에브라임** · 창세기 41장 52절 · 하나님이 고생하며 일한 땅에서 잘되게 하셨다
  - 다른 날 카드를 다녀왔으면: **요셉** · 창세기 30장 24절 · 라헬이 붙인 이름, 아들을 하나 더 주시기를 바란다
- (원하면) 한 문장 기도: 어려운 날에도 함께하시는 하나님, 고맙습니다.
- 끝.

## 아이용 요약

풍년이 든 일곱 해 동안, 남는 곡식은 요셉이 모아 두었어요. 요셉에게 두 아들이 태어난 것은 흉년이 오기 전이에요(창세기 41장). 첫째 아들의 이름은 므낫세예요. 아버지 집의 일도 고생도 하나님이 잊게 하셨다는 말을 이름에 담았어요. 둘째 아들의 이름은 에브라임이에요. 고생하며 일한 땅에서 하나님이 잘되게 하셨다는 말을 담았어요(창세기 41장).

| ㉢ | 고생하며 일한 땅에서 하나님이 잘되게 하셨다는 말을 하며 붙인 이름 |

### 다른 날 카드 (한 장, 글이 안쪽으로 가게 접는다)

『탐험대 이야기』 **다른 날** · 창세기 30장 · [그림 자리: 아기를 안은 라헬, 멀리서 작게]

## 진행자용 정답과 근거

| 자리 | 이름 반쪽 | 설명 반쪽 | 근거 | 헷갈릴 만한 까닭 |
|---|---|---|---|---|
| 요셉의 첫째 아들 | ★ 므낫세 | ㉡ 아버지 집의 일도 고생도 잊게 | 창 41:51 | |
| 요셉의 둘째 아들 | ● 에브라임 | ㉢ 고생한 땅에서 잘되게 | 창 41:52 | ㉠ '아들을 하나 더'와 섞이기 쉽다(둘 다 자녀와 잘됨의 이야기) |
| 다른 날 | ▲ 요셉 | ㉠ 아들을 하나 더 주시기를 바란다 | 창 30:24 (붙인 사람은 라헬, 30:22–23) | '요셉'이 이 판의 주인공이라 첫째 아들로 고르기 쉽다 |

- 두 길의 차이: ㉠은 첫째 아들(41:51)을 먼저 확인하고 둘째(41:52)로 간다. ㉡은 둘째부터 확인한다. 두 길 모두 칸 5에서 같은 짝판이 된다.
- 되돌리는 방법: 자리마다 반쪽 한 장만 바꾸기, ㉠ 반쪽이 아들 자리에 있으면 다른 날을 다녀오기. 처음부터 '다른 날' 자리에 맞게 놓았어도 칸 5에서 다른 날 카드를 펴 30:24로 확인한다(먼저 놓은 짝은 모두 성경으로 확인한다, 공통 규칙서 4.1).
- 모양: 반쪽은 모두 같은 네모로 자르고 글만 다르다. 지그재그로 자르면 모양으로 짝이 드러나서 쓰지 않았다.
- 41:51의 '고난'(요셉이 형들에게 팔리고 애굽에서 겪은 일, 37–40장)은 풀어 말하지 않는다. 아이가 물으면 "요셉이 애굽에서 겪은 어려운 일들이에요. 앞의 이야기에 나와요."라고만 답한다.
- 30:22–24의 다른 장면에서는 24절의 이름 이야기만 다룬다. 23절의 '부끄러움'과 29:31–35(레아의 아들들)는 다루지 않는다.
- '번성하게'는 '잘되게'로 풀었다. 개역개정 각주의 이름 뜻은 쓰지 않는다(C05와 달리 이 판은 덧붙인 말로 짝을 짓는다).
- 성경 인물의 말은 간접 화법으로만 옮겼다. 인물의 속마음을 덧붙이지 않았다. 개역개정과 대조한 방법은 아래 '원고 자체 점검'에 적는다.
- 그림 주의: 짝판에는 그림을 넣지 않는다. 다른 날 카드의 그림은 아기를 안은 라헬만 멀리서 작게 그린다. 하나님의 모습·손·그림자를 그리지 않는다. 탐험대 가운데 이 판에 나오는 아이는 최온이다.

## 플레이 시험 기록 (2026-11-23)

혼자 두 역할(어른과 아이)로 원고 줄만 따라 두 첫 선택을 끝까지 갔다. 칸 2의 '먼저 놓기'는 아이가 짐작할 만한 것으로 놓아 봤다. 실제 아이가 한 것은 아직 없다.

| 첫 선택 | 칸 2에서 먼저 놓은 짝 (첫째 / 둘째 / 다른 날) | 지나간 칸과 바꾼 것 | 끝 |
|---|---|---|---|
| ㉠ 첫째 아들부터 | 요셉+㉡ / 므낫세+㉠ / 에브라임+㉢ ('요셉'을 주인공이라 첫째로 짐작) | 칸 3: 51절의 므낫세 → 이름 반쪽 요셉↔므낫세 바꿈, ㉡은 맞음 → '㉠이 있나요?' 없어요. 칸 4: 52절의 에브라임 → 이름 반쪽 므낫세↔에브라임 바꿈(둘째 자리에 에브라임), 설명은 ㉠ → '㉠이 있나요?' 있어요 → 칸 다른-날(30:24, 라헬이 붙인 요셉) → ㉠과 요셉을 다른 날 자리로 → 칸 4: ㉢을 둘째 자리로 | 칸 5: 다른 날 카드를 다녀왔어요 → 짝판 확인. 일지 첫 줄 '첫째' |
| ㉡ 둘째 아들부터 | 므낫세+㉡ / 에브라임+㉢ / 요셉+㉠ (짐작이 다 맞음) | 칸 4: 바뀐 것 없음. 칸 3: 바뀐 것 없음 | 칸 5: '다른 날 짝을 아직 확인하지 않았어요' → 칸 다른-날(30:24) → 칸 5 → 짝판 확인. 일지 첫 줄 '둘째' |
| ㉡, ㉠을 둘째 자리에 놓은 경우 | 므낫세+㉡ / 에브라임+㉠ / 요셉+㉢ | 칸 4: '㉠이 있나요?' 있어요 → 칸 다른-날 → ㉠은 다른 날 자리로, ㉢은 둘째 자리로 | 같은 짝판 |

- 두 첫 선택 모두 칸 5에서 같은 짝판(첫째 므낫세+㉡, 둘째 에브라임+㉢, 다른 날 요셉+㉠)에 닿았다. 처음부터 맞게 놓아도 칸 5에서 다른 날 카드를 펴 30:24로 확인한다.
- 시험하며 고친 것: 처음 원고는 짐작이 다 맞으면 다른 날 자리의 짝을 성경으로 확인하지 않고 끝났다. 칸 5에 '다른 날 자리의 짝을 아직 확인하지 않았나요?' 고르기를 넣었다.
- ⚠️ 8살 아이가 ㉠과 ㉢을 '자녀와 잘됨'의 비슷한 말로 헷갈리는지는 실제로 해 보지 않았다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 칸 이동 | 스크립트로 '→ 칸' 줄을 따라가 봤다. 칸 7개. 칸 3과 칸 4는 서로를 거쳐 칸 5로 가고, 칸 다른-날은 온 칸(3, 4, 5)으로 돌아간다. 출구 없는 칸, 없는 칸으로 가는 줄, 닿지 않는 칸이 없다 |
| 고르기 먼저 | 반쪽 여섯 장을 성경을 펴기 전에 짝지어 놓는다(공통 규칙서 4.1). 첫 선택은 확인할 차례다. 칸 2에서 어른은 반쪽을 인쇄한 차례대로 읽는다 |
| 되돌리는 방법 | 자리마다 반쪽 한 장만 바꾸기, ㉠ 반쪽은 다른 날을 다녀와 다른 날 자리로, 칸 5에서 다른 날 짝 확인 |
| 아이 앞에 답이 보이는지 | 짝판에는 자리 이름만 있다. 반쪽은 같은 네모라 모양으로 짝이 드러나지 않는다. 이름 반쪽(● 에브라임, ▲ 요셉, ★ 므낫세)과 설명 반쪽(㉠ 다른 날, ㉡ 첫째, ㉢ 둘째)은 정답 차례가 아니게 섞었다 |
| 개역개정과 겹치는 말 | 원고 전체를 창 41:45–53, 30:22–24와 세 가지 방법(낱말 첫소리, 글자 9자, 낱말 차례)으로 대조하고, 한 절을 낱말만 바꿔 따른 줄을 눈으로 다시 봤다. 처음 원고의 41:51 덧붙인 말(설명 반쪽 ㉡, 요약, 일지), 41:48과 41:50 줄이 본문과 같은 차례였다. 차례를 바꿨다('아버지 집의 일도, 겪은 고생도 하나님이 다 잊게 하셨다', '두 아들이 태어난 것은 흉년이 오기 전'). 어절 단위 걸림은 0이다 |
| 본문에 없는 말 | 요셉의 속마음을 덧붙이지 않았다. 덧붙인 말은 요셉이 이름을 붙이며 한 말(41:51–52)만 옮겼다. '고난'의 내용(37–40장)은 풀지 않는다 |
| 성경 찾기 안내 | 아이에게 하는 말은 장과 '41장 끝 무렵', '바로 뒤', '30장 가운데쯤'까지다 |
| 한 화면의 글 | 어른과 최온의 줄은 한 줄에 한두 문장이다(스크립트로 셈) |
| 『탐험대 이야기』 표시 | 짝판, 반쪽, 다른 날 카드를 다루는 줄과 최온의 카드 줄에 붙였다 |
