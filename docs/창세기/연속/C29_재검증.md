# C29 수정판 · 두 우회 경로 재검증

2026-11-26. Codex가 검토한 대상은 dc23936의 아이 판 1쪽과 답지 2쪽, E59·E60 원고다. 대한성서공회 개역개정 해당 절과 대조했다. 아래는 화면에 실제 PDF를 펼쳐 확인한 결과다. 이용 대상은 목회자와 성인 검토자다.

| 첫 선택 / 둘째 선택 | 읽는 칸 순서 | 우회에서 일지로 옮기는 항목 |
|---|---|---|
| 베냐민 / 모두 내보냄 | 1 → 3 → 5 | 없음 |
| 시므온 / 모두 내보냄 | 1 → 2 → 1 → 3 → 5 | 창 43:23 |
| 베냐민 / 안방 | 1 → 3 → 4 → 3 → 5 | 창 43:30–31 |
| 시므온 / 안방 | 1 → 2 → 1 → 3 → 4 → 3 → 5 | 두 항목 |

**시므온.** 시작할 때 2~5칸을 덮었다. 시므온을 고른 뒤 2칸만 열었다. 창 43:23의 마지막에서 돌아간 상대를 찾고, 답지대로 어른이 그들이 형들이라고 알려 준다. 1칸의 지난 일에서 종으로 남을 사람의 조건을 찾는다(창 44:12, 17). 성경을 덮고 1칸에서 다시 고른다. 같은 카드를 다시 고르면 어른은 시므온이 누구에게로 나왔는지만 묻는다. 베냐민을 고르면 3칸을 열고 44:32–34에서 유다가 아버지에게 한 약속과 대신 남겠다는 청을 구별해 적는다. 14절 위 소제목도 가리도록 답지에 적혀 있다. [창세기 43장](https://bible.bskorea.or.kr/bible/NKRV/GEN.43) · [44장](https://bible.bskorea.or.kr/bible/NKRV/GEN.44)

**안방.** 44장을 덮고 3칸 아래에서 고른다. 안방을 고른 뒤 4칸을 열고 창 43:30–31에서 장소와 음식을 차리라는 말을 순서대로 찾는다. 아이 면의 셋째 물음에는 ‘음식’이 미리 인쇄되지 않았다. 둘째 답을 쓴 뒤에만 어른이 식사한 날과 유다가 말한 때의 앞뒤를 묻는다. 성경을 덮고 3칸으로 돌아간다. 같은 카드를 고르면 어른은 무엇을 차리라고 했는지만 묻는다. 모두 내보냈다는 카드를 고른 뒤 5칸과 창 45:1–3을 연다. 4절부터는 덮는다. 어느 경로로 와도 공통 일지는 44:32, 44:33, 45:1·3 세 항목이다. [창세기 43장](https://bible.bskorea.or.kr/bible/NKRV/GEN.43) · [45장](https://bible.bskorea.or.kr/bible/NKRV/GEN.45)

**덮개.** A4 실제 크기 덮개 PDF에서 따온 190 mm 너비와 45·70·55·40 mm 높이로 각 칸의 테두리 가운데에 맞췄다. 한번 연 칸을 그대로 두고 네 경로에서 생기는 서로 다른 열림 상태 10가지를 렌더링했다. 매 상태에서 닫힌 칸 안의 글자가 모두 가려지고 열린 칸 안의 글자가 전부 남는지 원본 좌표와 대조했다. 이 배치에서는 다음 칸 답이 새지 않았다. 1칸에는 두 이름이 보기로 있고 지난 일로 답을 추론할 수 있다. 열린 다른 날 카드의 빈칸과 먼저 읽은 단서는 계속 보인다.

**판정.** 두 우회에서 원래 선택으로 돌아와 같은 일지에 도달했다. 디지털 검증 통과. 실물 출력의 축척·불투명도·종이 미끄러짐, 성경 판형에 따른 절 창과 맞은쪽 가림, 어린이의 이해도는 미확인이다. 목회자 감수 전 상태다.
