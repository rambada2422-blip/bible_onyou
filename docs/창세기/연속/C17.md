# C17 · 아이 화면으로 건네기 (C01·C02 화면판과 답지)

가장 잘 작동한 새 판 두 개(C01 하란에서 세겜으로, C02 밤의 돌, 아침의 돌)를 놀이 1 화면판 형식(`../놀이/놀이1_화면판.md`)에 맞춰 나눴다. 놀이 1 화면판은 이름을 누르면 안쪽 글이 펼쳐지는 칸으로 되어 있고, 답이 있는 어른 원고는 따로 둔다. 같은 방식으로 판마다 **아이와 같이 보는 화면판**과 **어른만 보는 답지**를 따로 저장했다. 처음 열었을 때 보이는 쪽에 결말이나 정답이 없는지는 휴대폰 크기 화면으로 확인했다.

## 두 판을 고른 까닭

⚠️ 실제 아이와 해 본 C 판은 아직 없다. 그래서 '잘 작동한 판'은 아래 세 가지로 골랐다. (1) 작성 과정을 보지 않은 별도 검증에서 고쳐야 한 필수 지적이 적다. (2) 혼자 두 역할로 해 본 두 길이 막힘 없이 끝났다. (3) 감수를 기다리지 않아도 된다(3.5 해당 없음). 화면판은 놀이 1과 같은 8~10세 판에서 골랐다.

| 판 | 별도 검증 필수 | 3.5 감수 | 종이 장치를 펼치는 칸으로 옮길 수 있나 | 고름 |
|---|---|---|---|---|
| C01 하란에서 세겜으로 | 0건 | 해당 없음 | 봉투 둘, 뒤로 접은 확인 줄 → 펼치는 칸 셋 | ✅ (C13 판 A의 바탕으로도 다시 썼다) |
| C02 밤의 돌, 아침의 돌 | 2건 | 해당 없음 | 뒤집기 판 두 면, 가린 돌 뒷면, 엎어 둔 다른 날 카드 → 펼치는 칸 다섯 | ✅ (공통 규칙서 4.2의 다른 장면도 있다) |
| C07 두 꿈, 한 기록 | 2건 | 해당 가능 | 두 창 → 옮길 수 있다 | 감수 전이라 뺐다 |
| C03 나란히 놓인 옷 | 3건 | 해당 없음 | 보관함 칸 → 옮길 수 있다 | 다음 후보 |
| C10 남겠다고 한 사람 | 3건 | 해당 없음 | 펴고 접는 판 → 옮길 수 있다 | 다음 후보 (판 짜임을 바꿔 새로 쓴 판이다) |
| C04~C06, C08, C09 | 4~8건 | | | 지적이 더 많았다 |

C11~C16은 놀이 방식을 바꾼 판(11세 이상, 2인판, 1인판)이라 이번 후보에서 뺐다. C16은 이미 따로 화면판(`C16.html`)이 있다.

## 종이판에서 화면판으로 바꾼 것

| 종이판 (C01·C02) | 화면판 (C17) |
|---|---|
| 접어 붙인 봉투(단서 카드) | 봉투 이름을 누르면 펼쳐지는 칸 |
| 뒤로 접은 확인 줄 | '확인 줄' 칸. 쪽지 세 장을 놓고 봉투 둘을 다 연 뒤에 누른다 |
| 접이 지도의 지도 줄 | 화면의 '지도의 세 자리' 목록. 아이는 종이에 ①, ②, ③ 세 칸을 그려 쪽지를 놓는다 |
| 장소 쪽지, 돌 조각, 기름 조각 | 종이 조각에 써서 화면 앞이나 옆에 놓는다 |
| 뒤집기 판의 두 면 | '밤 면', '아침 면' 칸. 판을 뒤집는 것은 보던 면을 닫고 다른 면을 누르는 것이다 |
| 돌 조각 뒷면의 가림 쪽지 | '뒷면' 칸 둘. 종이 조각의 뒷면에는 아무것도 쓰지 않는다 |
| 엎어 둔 다른 날 카드 | '다른 날 카드' 칸. 칸 이름에 장 번호를 쓰지 않는다 |
| 쓰임 칸의 동그라미 | 일지에 친다 |
| 그림 자리 | 그림 없이 한 줄 글. C01·C02의 그림 주의는 답지에 옮겼다 |
| 칸 8·9의 발견과 일지 | '마지막' 칸에는 찾을 물음과 적을 항목만 둔다. 답은 답지에만 둔다 |

## 처음 보는 쪽 점검 (2026-11-23)

화면판을 GitHub에서 보이는 모양(펼치는 칸은 닫힌 채)으로 그린 뒤, 휴대폰 크기(390×664)에서 아무 칸도 누르지 않은 상태로 보이는 글 전체를 뽑았다. 그 글에서 정답과 결말을 알려 주는 낱말을 찾았다.

| 판 | 닫혀 있는 칸 | 찾아본 낱말 | 보인 것 | 사진 |
|---|---|---|---|---|
| 가 | 4칸 모두 | 일흔다섯, 나타나셨, 살림과 사람들, 나무가 있는 곳, 산에 장막, 거기에서도, 서쪽, 12장 4·6·8, 그리고 자리 줄(①②③)에 곳 이름이 붙었는지 | 없음 | `docs/인계/사진/C17_가_첫화면.png` |
| 나 | 6칸 모두 | 28장의 돌, 29장의 돌, 29장, 베개, 기둥, 우물 덮개, 우물가, 베고, 기름을 부, 같은 돌, 벧엘, 루스 | 없음 | `docs/인계/사진/C17_나_첫화면.png` |

- 가 판의 장소 쪽지는 정답 차례가 아니게 놓았다(벧엘 동쪽의 산, 하란, 세겜 · 모레 상수리나무).
- 두 판 모두 가로로 넘치는 곳이 없다(화면 너비 390).
- 점검하며 고친 것: 나 판 '다른 날 카드'의 칸 이름에 있던 '29장'이 큰 돌의 장을 미리 알려 줄 수 있어 '돌의 뒷면이 판과 다른 장이면 눌러요'로 바꿨다.
- ⚠️ 실제 휴대폰의 GitHub 앱이나 Claude 앱에서 펼치는 칸이 되는지는 열어 보지 않았다. 놀이 1 화면판과 같은 방식이다. 펼쳐지지 않는 화면이면 화면판 맨 위의 안내대로 종이판(C01·C02)으로 한다.

## 플레이 시험 기록 (2026-11-23)

그린 화면에서 칸을 차례대로 눌러 가며, 혼자 두 역할(어른과 아이)로 두 판을 판마다 두 길씩 끝까지 갔다. 어른은 답지의 줄만 따라 읽었다. 실제 아이가 한 것은 아직 없다.

| 판 · 길 | 누른 차례 | 화면과 성경에서 알게 되는 것 | 끝 |
|---|---|---|---|
| 가 · 가 봉투 먼저 | 봉투 가 → 봉투 나 → 확인 줄 → 마지막 | 가: ①은 하란. 12장에서 '가나안 땅에 들어가서 닿은 곳'으로 세겜을 찾고 ②·③ 가운데 짐작해 놓음 → 나: '나타나신 곳에 제단, 그 뒤에 산'으로 ②·③ 차례를 맞춤 → 확인 줄로 세 자리 확인 → 12장에서 세 곳과 산 양쪽의 벧엘·아이 | 하란 → 세겜 → 벧엘 동쪽의 산. 일지 첫 줄은 '하란을 떠난 날' |
| 가 · 나 봉투 먼저 | 봉투 나 → 봉투 가 → 확인 줄 → 마지막 | 나: 12장에서 '나타나신 곳'으로 세겜을 찾고, '그 뒤에 산'으로 ②·③을 놓음. ①은 남은 하란 → 가: ①과 세겜을 맞춤 → 확인 줄 → 12장 | 같은 길. 일지 첫 줄은 '여호와께서 나타나신 곳' |
| 나 · 밤 면 먼저 | 밤 면 → (돌 ㉮를 눕힘) ㉮ 뒷면 → 밤 면을 닫고 아침 면 → (같은 조각을 세우고 기름) → 마지막 | ㉮ 뒷면 '28장의 돌' → 28장에서 베개(11절) → 아침 면에서 세운 돌이 베개로 삼았던 돌(18절), 기둥, 기름 → 곳의 이름 벧엘(19절) | 아침 자리에 세운 ㉮와 기름, 쓰임 베개·기둥 |
| 나 · 아침 면 먼저, 큰 돌을 고름 | 아침 면 → (큰 돌을 세움) ㉯ 뒷면 → 다른 날 카드 → 아침 면으로 돌아와 그 칸만 ㉮로 → ㉮ 뒷면 → 아침 면을 닫고 밤 면 → 마지막 | ㉯ 뒷면 '29장의 돌' → 다른 날 카드에서 29장의 우물 아귀를 찾고 우물 덮개 → 아침 면에서 18절로 '베개로 삼았던 돌' → 밤 면에서 11절 베개 | 같은 모습. 일지에 큰 돌 줄도 적음 |

- 화면판으로 해 보며 고친 것
  - 종이 조각 뒷면에 장 번호를 쓰면 아이가 놓기 전에 뒤집어 볼 수 있다. 뒷면은 화면의 '뒷면' 칸으로 옮기고, 종이 조각의 뒷면은 비웠다.
  - 다른 날 카드의 칸 이름에서 '29장'을 지웠다(위 '처음 보는 쪽 점검').
  - 화면에는 쓰임 칸에 동그라미를 칠 곳이 없다. 일지에 치게 하고, 답지 준비에 '밤의 쓰임', '아침의 쓰임' 두 줄을 미리 만들어 두라고 적었다.
  - 큰 돌을 놓을 '우물 입구'가 화면 밖에 없다. '야곱의 판 자리에서 빼서 화면 옆에 따로 놓아요'로 바꿨다.
- 펼치는 칸은 아이가 언제든 누를 수 있다. 차례를 지키는 것은 규칙 세 줄과 어른의 진행에 맡긴다(놀이 1 화면판과 같다).
- 마지막 칸에 정답을 넣지 않았다. 아이가 먼저 눌러도 '찾아봐요'와 '적어요'만 보인다.
- ⚠️ 종이 조각을 실제로 잘라 화면 앞에 놓아 보지는 않았다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 아이 화면과 답의 분리 | 정답, 절 번호, 어른 도움말, 일지 예시 답은 답지에만 있다. 화면판의 장절은 '창세기 12장'처럼 장까지만 있다 |
| 처음 보는 쪽 | 위 점검대로 결말과 정답이 보이지 않는다 |
| 한 화면의 글 | 화면판의 문단과 목록 줄마다 문장을 셌다. 두 문장을 넘는 곳이 없다(어른 안내 문단은 빼고 셈). 처음에 세 문장이던 나 판 두 곳(아침 면 돌 자리, 다른 날 카드)은 나눴다 |
| 칸 이동 | 화면판에는 펼치는 칸만 있고 칸 사이 이동 줄이 없다. 답지의 차례(가: 1–4 → 5-가·6-가 또는 5-나·6-나 → 7 → 8 / 나: 1–3 → 4-밤·5-밤·6-밤 또는 4-아침·5-아침 → 7 → 8, 다른 날 카드는 온 곳으로 돌아감)는 C01·C02의 칸 이동과 같다 |
| 개역개정과 겹치는 말 | 가 판 두 파일은 창 12:1–9, 13:1–4, 28:19와, 나 판 두 파일은 창 28:10–22, 29:1–10과 세 가지 방법(낱말 첫소리, 글자 9자, 낱말 차례)으로 대조했다. 새로 쓴 '곁에 양 세 떼가 누워 있어요'가 29:2와 다섯 어절 같아 '우물 가까이에 양 떼 셋이 있어요'로 고쳤다. 나머지 걸린 곳은 별도 검증을 마친 C01·C02의 줄이거나 세 어절 이하다('여호와께서 아브람에게 나타나', 12:7) |
| 새로 쓴 줄 | 이야기 줄은 C01·C02에서 그대로 가져왔다. 새로 쓴 것은 화면판의 안내와 규칙(해요체로 바꿈), 그림 대신 쓴 한 줄(해가 진 한 곳이에요. 야곱이 누워 잠들어 있어요 / 아침이에요. 야곱이 일어나 서 있어요 / 들판의 우물가예요. 우물 가까이에 양 떼 셋이 있어요), 화면을 누르고 조각을 놓는 줄이다 |
| 『탐험대 이야기』 표시 | 지도, 쪽지, 봉투, 확인 줄, 판의 면, 조각, 다른 날 카드, 일지를 말하는 줄에 붙였다 |
| 이름 | 가 판은 아브람·사래만 쓴다(이름이 바뀌는 것은 창 17장) |
| 말투 | 화면판에서 아이가 읽는 줄은 해요체다. 화면판 맨 위의 어른 안내와 답지의 설명은 '-ㄴ다'로 쓴다 |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다. 고칠 때는 "맞바꿔요", "그 한 칸만 고쳐요"라고만 한다 |
