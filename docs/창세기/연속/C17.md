# C17 · 아이 화면으로 건네기 (C01·C02 화면판과 답지)

가장 잘 작동한 새 판 두 개(C01 하란에서 세겜으로, C02 밤의 돌, 아침의 돌)를 놀이 1 화면판 형식(`../놀이/놀이1_화면판.md`)에 맞춰 나눴다. 놀이 1 화면판은 이름을 누르면 안쪽 글이 펼쳐지는 칸으로 되어 있고, 답이 있는 어른 원고는 따로 둔다. 같은 방식으로 판마다 **아이와 같이 보는 화면판**과 **어른만 보는 답지**를 따로 저장했다. 처음 열었을 때 보이는 쪽에 결말이나 정답이 없는지는 휴대폰 크기 화면으로 확인했다.

## 두 판을 고른 까닭

⚠️ 실제 아이와 해 본 C 판은 아직 없다. 그래서 '잘 작동한 판'은 아래 세 가지로 골랐다. (1) 작성 과정을 보지 않은 별도 검증에서 고쳐야 한 필수 지적이 적다. (2) 혼자 두 역할로 해 본 두 길이 막힘 없이 끝났다. (3) 감수를 기다리지 않아도 된다(3.5 해당 없음). 화면판은 놀이 1과 같은 8~10세 판에서 골랐다.

| 판 | 별도 검증 필수 | 3.5 감수 | 종이 장치를 펼치는 칸으로 옮길 수 있나 | 고름 |
|---|---|---|---|---|
| C01 하란에서 세겜으로 | 0건 | 해당 없음 | 봉투 둘, 뒤로 접은 확인 줄 → 펼치는 칸 셋 | ✅ (C13 판 A의 바탕으로도 다시 썼다) |
| C02 밤의 돌, 아침의 돌 | 2건 | 해당 없음 | 뒤집기 판 두 면, 가린 돌 뒷면, 엎어 둔 다른 날 카드 → 펼치는 칸 다섯 | ✅ (공통 규칙서 4.2의 다른 장면도 있다) |
| C11 고센의 두 심부름 | 2건 | 해당 없음 | 지도 수첩 → 옮길 수 있다 | C16에서 이미 화면판(`C16.html`, 1인판)으로 만들었다 |
| C07 두 꿈, 한 기록 | 2건 | 해당 가능 | 두 창 → 옮길 수 있다 | 감수 전이라 뺐다 |
| C03 나란히 놓인 옷 | 3건 | 해당 없음 | 보관함 칸 → 옮길 수 있다 | 다음 후보 |
| C10 남겠다고 한 사람 | 3건 | 해당 없음 | 펴고 접는 판 → 옮길 수 있다 | 다음 후보 (판 짜임을 바꿔 새로 쓴 판이다) |
| C04~C06, C08, C09, C12 | 4~8건 | | | 지적이 더 많았다(C12는 필수 6건, 판 짜임을 바꿔 새로 씀) |

C13~C16은 나이나 사람 수를 바꾼 판(C13 11~13세, C14 14~17세, C15 2인판, C16 1인판)이라 이번 후보에서 뺐다. C11과 C12는 8~10세 판이라 표에 넣었다.

## 종이판에서 화면판으로 바꾼 것

| 종이판 (C01·C02) | 화면판 (C17) |
|---|---|
| 접어 붙인 봉투(단서 카드) | 봉투 이름을 누르면 펼쳐지는 칸 |
| 뒤로 접은 확인 줄 | '확인 줄' 칸. 쪽지 세 장을 놓고 봉투 둘을 다 연 뒤에 누른다 |
| 접이 지도의 지도 줄 | 화면의 '지도의 세 자리' 목록. 아이는 종이에 ①, ②, ③ 세 칸을 그려 쪽지를 놓는다 |
| 장소 쪽지, 돌 조각, 기름 조각 | 종이 조각에 써서 화면 앞이나 옆에 놓는다 |
| 뒤집기 판의 두 면 | '밤 면', '아침 면' 칸. 판을 뒤집는 것은 보던 면을 닫고 다른 면을 누르는 것이다 |
| 돌 조각 뒷면의 가림 쪽지 | '뒷면' 칸 둘. 종이 조각의 뒷면에는 아무것도 쓰지 않는다 |
| 엎어 둔 다른 날 카드 | '다른 날 카드' 칸. 칸 이름에 장 번호를 쓰지 않는다 |
| 쓰임 칸의 동그라미 | 일지에 '밤의 쓰임', '아침의 쓰임', '다른 날의 쓰임' 세 줄을 미리 만들고, 줄마다 적어 둔 '베개 · 기둥 · 우물 덮개' 가운데 하나에 동그라미를 친다 |
| 단서 카드와 판의 긴 글 | 펼친 칸 하나를 한 화면으로 보고 칸마다 3문장 이하(물음 줄은 따로)로 줄였다. 뺀 이야기 줄(사래와 롯, 땅의 약속)은 답지의 어른 줄로 옮겼다 |
| C02 칸 7의 두 번 뒤집어 보기 | 같은 돌을 눕히고 세우는 일이라 답이 드러난다. 화면판에 넣지 않고 답지 7의 어른 줄에만 둔다 |
| 그림 자리 | 그림 없이 한 줄 글. C01·C02의 그림 주의는 답지에 옮겼다 |
| 칸 8·9의 발견과 일지 | '마지막' 칸에는 찾을 물음과 적을 항목만 둔다. 칸 이름에 '…뒤에 눌러요'를 붙였다. 답은 답지에만 둔다 |
| 판의 제목 | 아이 화면의 제목은 종이판의 판 이름(아브람의 접이 지도, 야곱의 뒤집기 판)으로 한다. C01·C02 문서의 제목(하란에서 세겜으로, 밤의 돌 아침의 돌)은 결말을 담고 있어 쓰지 않는다 |

## 플레이 시험 기록 (2026-11-23)

그린 화면에서 칸을 차례대로 눌러 가며, 혼자 두 역할(어른과 아이)로 두 판을 판마다 두 길씩 끝까지 갔다. 어른은 답지의 줄만 따라 읽었다. 실제 아이가 한 것은 아직 없다.

| 판 · 길 | 누른 차례 | 화면과 성경에서 알게 되는 것 | 끝 |
|---|---|---|---|
| 가 · 가 봉투 먼저 | 봉투 가 → 봉투 나 → 확인 줄 → 마지막 | 가: ①은 하란. 12장에서 '가나안 땅에 들어가서 닿은 곳'으로 세겜을 찾고 ②·③ 가운데 짐작해 놓음 → 나: '나타나신 곳에 제단, 그 뒤에 산'으로 ②·③ 차례를 맞춤 → 확인 줄로 세 자리 확인 → 12장에서 세 곳과 산 양쪽의 벧엘·아이 | 하란 → 세겜 → 벧엘 동쪽의 산. 일지 첫 줄은 '하란을 떠난 날' |
| 가 · 나 봉투 먼저 | 봉투 나 → 봉투 가 → 확인 줄 → 마지막 | 나: 12장에서 '나타나신 곳'으로 세겜을 찾고, '그 뒤에 산'으로 ②·③을 놓음. ①은 남은 하란 → 가: ①과 세겜을 맞춤 → 확인 줄 → 12장 | 같은 길. 일지 첫 줄은 '여호와께서 나타나신 곳' |
| 나 · 밤 면 먼저 | 밤 면 → (돌 ㉮를 눕힘) ㉮ 뒷면 열고 닫기 → 밤 면을 닫고 아침 면 → (같은 조각을 세움) ㉮ 뒷면 다시 열고 닫기 → (기름) → 답지 7의 두 번 뒤집기 → 마지막 | ㉮ 뒷면 '28장의 돌' → 28장에서 베개(11절) → 아침 면에서 세운 돌이 베개로 삼았던 돌(18절), 기둥, 기름 → 곳의 이름 벧엘(19절) | 아침 자리에 세운 ㉮와 기름, 쓰임 베개·기둥 |
| 나 · 아침 면 먼저, 큰 돌을 고름 | 아침 면 → (큰 돌을 세움) ㉯ 뒷면 열고 닫기 → 다른 날 카드 열고 닫기 → 아침 면으로 돌아와 그 칸만 ㉮로 → ㉮ 뒷면 열고 닫기 → 아침 면을 닫고 밤 면 → 밤 면을 닫고 아침 면 → 답지 7의 두 번 뒤집기 → 마지막 | ㉯ 뒷면 '29장의 돌' → 다른 날 카드에서 29장의 우물 아귀를 찾고 우물 덮개 → 아침 면에서 18절로 '베개로 삼았던 돌' → 밤 면에서 11절 베개 | 같은 모습. 일지에 큰 돌 줄도 적음 |

- 화면판으로 해 보며 고친 것
  - 종이 조각 뒷면에 장 번호를 쓰면 아이가 놓기 전에 뒤집어 볼 수 있다. 뒷면은 화면의 '뒷면' 칸으로 옮기고, 종이 조각의 뒷면은 비웠다.
  - 다른 날 카드의 칸 이름에서 '29장'을 지웠다(위 '처음 보는 쪽 점검').
  - 화면에는 쓰임 칸에 동그라미를 칠 곳이 없다. 일지에 '밤의 쓰임', '아침의 쓰임', '다른 날의 쓰임' 세 줄과 보기 세 낱말을 미리 써 두고 동그라미를 치게 했다(화면판 맨 위 안내와 답지 준비).
  - 큰 돌을 놓을 '우물 입구'가 화면 밖에 없다. '판 자리에서 빼서 화면 옆에 따로 놓아요'로 바꿨다.
- 펼치는 칸은 아이가 언제든 누를 수 있다. 차례를 지키는 것은 규칙 세 줄과 어른의 진행에 맡긴다(놀이 1 화면판과 같다).
- 마지막 칸에는 찾을 물음과 적을 항목만 있다. 처음 원고의 나 판 마지막 칸에는 두 번 뒤집기 지시(같은 돌이라는 답)가 있었다. 별도 검증 필수 2로 답지 7로 옮겼다.
- 뒷면 칸을 연 채로 두면 다음에 '뒷면을 눌러 봐요'에서 칸이 닫힌다. 규칙과 답지에 '보았으면 뒷면 칸을 다시 닫아요'를 넣었고, 시험에서 열고 닫기를 차례대로 해 봤다(두 길 모두 칸이 제대로 열리고 닫혔다).
- ⚠️ 종이 조각을 실제로 잘라 화면 앞에 놓아 보지는 않았다.

## 별도 내용 검증 (2026-11-23)

작성 과정을 보지 않은 검증자가 네 파일을 C01·C02, 놀이 1 화면판, 공통 규칙서, 창 12·13·28·29장과 대조하고, 화면판과 답지만으로 두 판을 판마다 두 길(큰 돌을 4-밤, 6-밤, 4-아침에서 고르는 경우 포함) 끝까지 가 봤다. 결과는 필수 3건, 권장 12건이었다. 정답·근거·차례는 C01·C02와 같고, 네 어절 겹침 0, 두 판 모두 끝까지 갈 수 있었다. 모두 반영했다.
