# C16 · 혼자서도 한 판 (고센의 두 심부름 1인판)

C11(고센의 두 심부름)을 어른 없이 혼자 하는 판으로 고쳤다. 아이는 번호가 붙은 칸을 하나씩 읽고, 칸 끝에 적힌 번호로 간다. 고르기가 있는 칸에서는 고른 보기에 적힌 번호로 간다. 고르기는 47장을 펴기 전에 한다. 정답은 아이가 답을 적은 뒤에 가는 **확인 칸**에만 있다. 화면판(`C16.html`)은 한 번에 한 칸만 보여 주고, 위의 '수첩 모양' 단추로 답이 없는 수첩 빈칸을 보여 준다. 인쇄판은 확인 칸을 따로 떼어 봉투에 넣고, 나머지 칸은 한 쪽에 하나씩 인쇄한다. 첫 화면에는 첫 행동(창세기 46장 31절을 펴서 34절까지 읽기)이 바로 보인다.

## 카드 정보

| 항목 | 내용 |
|---|---|
| 카드 번호 | C16 (바탕: C11. 별도 검증을 반영한 C11을 혼자 읽는 말로 바꿨다) |
| 근거 장절 | 창 46:28, 31–34, 47:1–17, 27, 42:3, 6 |
| 나이 단계 | 11~13세 (혼자 읽는다. 칸마다 장절을 알려 주고 스스로 찾게 한다. 한 화면 2~4문장. 공통 규칙서 5절) |
| 사람 수 | 한 사람 |
| 걸리는 때 | ⚠️ 추정 두 쪽 모두 20분, 한 쪽만 12분 (혼자 시험한 것이라 실제 아이와 잰 시간이 아니다) |
| 질문과 보기 | (먼저 풀 물음, 맞고 틀림 없음) 누구를 만나러 갔나? / 무엇을 받았나? (● 쪽) 그 앞에 간 형은 몇 명이었을까요? 열 명(창 42:3, 곡식을 사러 온 날) / 다섯 명(창 47:2) (▲ 쪽) 먹을 것은 무엇에 맞춰 주었을까요? 가축 수에 맞춰(창 47:16–17, 애굽 백성의 일) / 식구 수에 맞춰(창 47:12). 두 고르기 모두 47장을 펴기 전에 먼저 고른다(공통 규칙서 4.1) |
| 정답 근거 | C11과 같다. ● 바로(47:1), 차례 요셉 → 형 다섯 명 → 아버지 야곱(47:1, 2, 7), 바로의 물음 생업(47:3), 형들이 말한 선조(46:34, 47:3) / ▲ 라암셋(47:11), 바로의 말에도 고센(46:34, 47:6), 식구 수대로(47:12) |
| 성경 찾기 안내 | 11~13세 기준대로 칸마다 장절을 알려 준다. 아이가 스스로 펴서 찾는다 |
| 다른 장면 | C11과 같다. 곡식을 사러 온 날(창 42:3, 6), 돈이 떨어진 때(창 47:13–17). 고르기에서 앞의 보기를 고르면 그 칸으로 가서 사람을 찾고, 다시 고르러 돌아온다. 찾은 사람이 맞는지는 확인 칸에서 본다 |
| 준비물 | 성경책, 아래 '수첩 빈칸'을 옮겨 그린 종이(화면판은 '수첩 모양' 단추), 탐험 일지(종이), 연필. 화면판으로 하면 휴대폰이나 컴퓨터 하나. 인쇄판은 봉투 하나 |
| 참고 출처 | 성경 본문만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음. C11처럼, 칸 15(47:13–17)를 평가 없이 '누가 왔는가'만 찾게 한 처리는 감수 때 함께 봐 주기를 권한다 |
| 감수 상태 | 미감수 |

## 인쇄와 화면

- **화면판**: 같은 폴더의 `C16.html`을 휴대폰이나 컴퓨터의 브라우저로 연다. 인터넷이 없어도 열린다. 한 화면에 한 칸만 보이고, 칸 끝의 단추를 누르면 그 칸으로 간다. 위의 '수첩 모양' 단추는 답이 없는 수첩 빈칸을, '처음으로' 단추는 첫 칸을 보여 준다. 화면판의 글은 아래 '1인판 원고'와 '수첩 빈칸'에서 스크립트로 만든다(원고를 고치면 다시 만든다).
- **인쇄판**: 확인 칸(8, 9, 9나, 9다, 13, 13나, 13다)은 따로 인쇄해 봉투에 넣어 두고, 원고가 그 칸으로 가라고 할 때만 꺼낸다. 나머지 칸은 한 쪽에 하나씩, 앞면만 인쇄해 번호 차례로 묶는다. 칸 번호는 띄엄띄엄 있다. 없는 번호는 빠진 쪽이 아니다. 수첩 빈칸은 첫 쪽 앞에 둔다.
- **접지 않는다**: C11처럼 메모지로 쪽을 덮지 않는다. 확인 칸에 가기 전에는 정답이 보이지 않는다.

## 수첩 빈칸 (답 없음)

- 『탐험대 이야기』 **겉 면**: 가나안 땅 → 고센 땅 · ● (　　　) 앞, 그 앞에 선 형 (　) 명 · ▲ (　　　) 땅 · 칸의 자리는 실제 거리나 방향이 아니에요.
- **고센 쪽 · 창세기 46장**: 심부름 ① 가족이 왔다고 알리러 갈 사람 (　　) · 심부름 ② 하는 일을 물으면 대답할 사람들 (　　) · 요셉이 말한, 가족이 살 땅 (　　) 땅
- **● 쪽 · 창세기 47장**: (　　　) 앞 · 만난 차례: 첫째 (　　) → 둘째 (　　) → 셋째 (　　) · 바로의 물음 (　　) · 형들의 대답에서, 자기들 말고 그 일을 했다는 사람 (　　)
- **▲ 쪽 · 창세기 47장**: (　　　) 땅 · 받은 것: 살 곳 (　　), 먹을 것 (　　) · 확인: 고센 쪽에 적은 땅 이름이 바로의 말에도 나오나요? (나온다 / 안 나온다)

## 1인판 원고 (화면과 인쇄 공용)

### 칸 1 · 시작

- 『탐험대 이야기』 오늘은 혼자 하는 탐험이에요. 지도 수첩이 없으면, 위의 '수첩 모양'을 보고 종이에 그려요.
- **첫 행동**: 성경에서 창세기 46장 31절을 펴서, 34절까지 읽어요.
- 다 읽었으면 → 칸 1나로 가요.

### 칸 1나 · 고센 쪽 채우기

- 요셉이 가족에게 할 일 두 가지를 말했어요. 『탐험대 이야기』 이 판에서는 그 두 가지를 '심부름'이라고 불러요.
- 『탐험대 이야기』 수첩의 고센 쪽에 적어요. 심부름 ①을 할 사람, 심부름 ②를 할 사람들, 요셉이 말한 가족이 살 땅이에요.
- 고센 쪽을 다 적었으면 → 칸 8로 가요. (인쇄판은 봉투에서 칸 8을 꺼내요)

### 칸 3 · ● 쪽: 먼저 고르기

- 47장에서 요셉은 두 심부름을 하러 가요. 형들 가운데 몇 사람만 골라 데려가요.
- 47장을 펴기 전에 먼저 골라요. 데려간 형은 몇 명이었을까요?
- **열 명** → 칸 12로 가요.
- **다섯 명** → 칸 7로 가요.

### 칸 7 · 47장 처음 읽기

- 『탐험대 이야기』 이제 47장을 펴요. 1절에서 요셉은 누구에게 갔나요? 46장 31절의 사람과 같은지도 봐요.
- 『탐험대 이야기』 ● 쪽 맨 위, 겉의 ● 칸, 만난 차례의 첫째 칸(요셉)을 채워요.
- 다 적었으면 → 칸 7나로 가요.

### 칸 7나 · 형들과 바로의 물음

- 47장 2절에서, 그 앞에 간 형의 수를 확인해요. 『탐험대 이야기』 만난 차례의 둘째 칸과 겉의 ● 칸 옆에 적어요.
- 3절에서, 형들에게 바로가 무엇을 물었는지 찾아 '바로의 물음'에 적어요. ('생업'은 하는 일이에요.)
- 다 적었으면 → 칸 7다로 가요.

### 칸 7다 · 형들의 대답과 마지막 사람

- 3절에서, 형들은 자기들 말고 또 누가 그 일을 했다고 대답했나요? 46장 34절 요셉의 말에도 같은 낱말이 있어요.
- '우리'와 '종들'은 형들 자신이니, 자기들 말고 그 일을 한 사람을 찾아 적어요.
- 7절에서, 마지막으로 바로 앞에 선 사람을 찾아 만난 차례의 셋째 칸에 적어요.
- 다 적었으면 → 칸 9로 가요. (인쇄판은 봉투에서 칸 9를 꺼내요)

### 칸 8 · 고센 쪽 확인

- 내 답과 견줘 봐요. ①은 요셉, ②는 형들이에요(형들과 아버지의 가족도 맞아요).
- '당신들'이라고 적었다면 31절에서 요셉이 누구에게 말했는지 봐요. 가족이 살 땅은 고센이에요(46장 34절).
- 다른 곳은 다시 읽고 고쳐요. → 칸 8나로 가요.

### 칸 8나 · 먼저 풀 물음 고르기

- 이제 먼저 풀 물음을 하나 골라요. 맞고 틀림은 없어요.
- **누구를 만나러 갔나?** → 칸 3으로 가요.
- **무엇을 받았나?** → 칸 11로 가요.

### 칸 9 · ● 쪽 확인

- 내 답과 견줘 봐요. 요셉이 간 사람은 바로예요(47장 1절). 만난 차례는 요셉 → 형 다섯 명 → 아버지 야곱이에요(47장 1, 2, 7절).
- 다른 곳은 다시 읽고 고쳐요. → 칸 9나로 가요.

### 칸 9나 · ● 쪽 확인 (이어서)

- 바로가 물은 것은 생업, 곧 하는 일이에요(3절). 형들이 말한 사람은 '선조'예요(46장 34절, 47장 3절).
- '우리', '종들'은 형들 자신이라 답이 아니에요.
- 다른 곳은 다시 읽고 고쳐요. → 칸 9다로 가요.

### 칸 9다 · ● 쪽 마무리

- 칸 12를 다녀왔다면, 형들이 엎드린 사람은 요셉이고 그날 온 형은 열 명이에요(42장 3, 6절). 바로 앞에 간 다섯 명과 다른 날이에요.
- 『탐험대 이야기』 일지에 적어요. '바로를 만난 차례 · 47장 1, 2, 7절 · 요셉 → 형 다섯 명 → 아버지 야곱'.
- **▲ 쪽도 지금 해요** → 칸 11로 가요.
- **두 쪽을 다 했거나, 오늘은 여기까지** → 칸 16으로 가요.

### 칸 10 · 47장 11–12절 읽기

- 『탐험대 이야기』 이제 47장을 펴요. 11절에서 요셉이 가족에게 준 땅의 이름을 찾아, ▲ 쪽 맨 위와 겉의 ▲ 칸, 받은 것의 살 곳에 적어요.
- 바로 다음 12절에서, 먹을 것을 무엇에 맞춰 주었는지 찾아 받은 것의 먹을 것에 적어요.
- 다 적었으면 → 칸 10나로 가요.

### 칸 10나 · 바로의 말

- 47장 6절을 읽어요. 고센 쪽에 적은 땅 이름이 바로의 말에도 나오나요?
- 『탐험대 이야기』 ▲ 쪽 확인 칸에 '나온다' 또는 '안 나온다'를 적어요.
- 다 적었으면 → 칸 13으로 가요. (인쇄판은 봉투에서 칸 13을 꺼내요)

### 칸 11 · ▲ 쪽: 먼저 고르기

- 『탐험대 이야기』 ▲ 쪽은 '무엇을 받았나'예요. 요셉은 가족에게 먹을 것도 주었어요.
- 47장을 펴기 전에 먼저 골라요. 먹을 것은 무엇에 맞춰 주었을까요?
- **가축 수에 맞춰** → 칸 15로 가요.
- **식구 수에 맞춰** → 칸 10으로 가요.

### 칸 12 · 다른 때: 곡식을 사러 온 날

- 『탐험대 이야기』 다른 때로 가 봐요. 형들이 처음 곡식을 사러 애굽에 온 날이에요.
- 42장 6절: 형들이 그 앞에 엎드린 사람은 누구인가요? 42장 3절: 이날 온 형은 몇 명인가요?
- 찾았으면, 다시 고르러 → 칸 3으로 돌아가요.

### 칸 13 · ▲ 쪽 확인

- 내 답과 견줘 봐요. 요셉이 준 땅은 라암셋이에요(47장 11절). 먹을 것은 식구 수대로 주었어요(12절). 고센은 바로의 말에도 나와요(6절).
- 다른 곳은 다시 읽고 고쳐요. → 칸 13나로 가요.

### 칸 13나 · ▲ 쪽 확인 (이어서)

- 고센과 라암셋이 어떤 사이인지 이곳에서 성경은 말하지 않아요. 같은 장 27절에는 가족이 고센 땅에 살았다고 적혀 있어요.
- 칸 15를 다녀왔다면, 가축을 끌고 온 사람들은 애굽 백성이에요(47장 15–17절). 요셉의 가족과 다른 사람들이에요.
- 다 읽었으면 → 칸 13다로 가요.

### 칸 13다 · ▲ 쪽 마무리

- 『탐험대 이야기』 일지에 적어요. '가족이 받은 것 · 47장 11–12절 · 살 곳 라암셋 땅, 먹을 것 식구 수대로'.
- **● 쪽도 지금 해요** → 칸 3으로 가요.
- **두 쪽을 다 했거나, 오늘은 여기까지** → 칸 16으로 가요.

### 칸 15 · 다른 때: 돈이 떨어진 때

- 『탐험대 이야기』 다른 때로 가 봐요. 흉년이 더 심해져 돈이 떨어진 때예요.
- 47장 15–17절에서, 돈이 떨어져 요셉에게 온 사람들을 찾아봐요. 18절부터는 읽지 않아도 돼요.
- 찾았으면, 다시 고르러 → 칸 11로 돌아가요.

### 칸 16 · 수첩 닫기

- 『탐험대 이야기』 수첩 겉의 지도를 봐요. 빈칸을 몇 개 채웠나요? 남은 빈칸이 있으면, 다음에 칸 8나에서 남은 물음을 골라요.
- (원하면) 한 문장 기도: 우리 가족에게 살 곳과 먹을 것을 주시는 하나님, 고맙습니다.
- 끝.

## 진행자용 정답과 근거

정답과 근거는 C11의 '진행자용 정답과 근거'와 같다. 이 판에서 바뀐 것만 적는다.

| 바뀐 것 | 까닭 |
|---|---|
| 어른 줄을 혼자 읽는 말(해요체)로 바꾸고, 쉼은 '다 적었으면'으로 바꿨다 | 진행자가 없다 |
| 칸마다 장절을 알려 준다 | 혼자 찾으려면 장만으로는 어렵다. 11~13세 기준(장절 안내 후 스스로 찾기)에 맞췄다 |
| 두 고르기(칸 3, 11)를 47장을 펴기 전에 둔다 | 47:1과 47:11은 문장이 다음 절로 이어져, 47장을 먼저 펴면 '다섯 명'(47:2)과 '식구를 따라'(47:12)를 고르기 전에 읽게 된다(별도 검증 필수 3) |
| 정답은 확인 칸(8, 9, 9나, 9다, 13, 13나, 13다)에만 둔다. 다른 때 칸에서 찾은 사람도 확인 칸에서 본다 | 어른이 확인해 주던 일을 확인 칸이 맡는다. 화면판은 한 칸만 보이고, 인쇄판은 확인 칸을 봉투에 따로 둔다 |
| 수첩 빈칸을 이 문서와 화면판에 직접 실었다 | C11 문서는 답이 적혀 있어 아이가 열면 안 된다. 겉 면의 ● 칸은 '그 앞에 선 형'으로 적어 바로라는 이름을 미리 보이지 않게 했다 |
| 긴 칸을 '나', '다'로 나눴다 | 11~13세 기준(한 화면 2~4문장)에 맞췄다 |
| 칸 번호를 흩어 두었다 | 인쇄판에서 번호 차례로 묶어도 확인 칸은 봉투에 있으므로 넘기는 쪽에 정답이 없다 |

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 칸 이동 | 칸 20개. 칸 1에서 끝 칸까지 가는 길 18가지를 모두 셌다. 막힌 칸, 없는 칸으로 가는 줄, 닿을 수 없는 칸이 없다 |
| 해답이 다음 쪽에 비치지 않는지 | 정답은 확인 칸에만 있다. 화면판은 한 칸만 보인다. 인쇄판은 확인 칸을 봉투에 따로 두고, 나머지는 한 쪽에 한 칸, 뒷면은 비운다. 칸 제목에 정답이 없다(칸 7은 '47장 처음 읽기') |
| 접지 않고 완주 | 메모지나 접는 덮개 없이, 번호만 따라 끝까지 간다 |
| 첫 화면의 첫 행동 | 칸 1에 '첫 행동: 창세기 46장 31절을 펴서, 34절까지 읽어요'가 굵게 있다 |
| 한 화면의 글 | 화면판의 모든 칸에서 문장을 셌다. 4문장을 넘는 칸이 없다(11~13세 기준 2~4문장). 처음에 넘던 칸 7, 8, 9, 13, 15, 1나, 7다는 줄이거나 9다, 13다로 나눴다 |
| 개역개정과 겹치는 말 | 창 46:28–34, 47:1–27, 42:3–8과 세 가지 방법(낱말 첫소리, 글자 9자, 낱말 차례)으로 대조했다. 네 어절 넘게 이어지는 곳이 없다. 가장 긴 곳은 '형들과 아버지의 가족'(46:31, 세 어절)이다 |
| 말투 | 모두 해요체다. 칸 이동 줄도 '→ 칸 N로 가요'로 쓴다 |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다. 확인 칸은 '내 답과 견줘 봐요', '다른 곳은 다시 읽고 고쳐요'로 쓴다 |

## 별도 내용 검증 (2026-11-23)

작성 과정을 보지 않은 검증자가 C16.md, C16.html, 첫 화면 사진을 C11과 46–47장, 42장으로 대조하고 화면판을 끝까지 눌러 봤다. 필수 7건, 권장 7건이 나왔고 모두 반영했다. 1인판 원고를 새로 쓰고 화면판을 다시 만들었다.
