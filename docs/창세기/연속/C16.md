# C16 · 혼자서도 한 판 (고센의 두 심부름 1인판)

C11(고센의 두 심부름)을 어른 없이 혼자 하는 판으로 고쳤다. 아이는 번호가 붙은 칸을 하나씩 읽고, 칸 끝에 적힌 번호로 간다. 고르기가 있는 칸에서는 고른 보기에 적힌 번호로 간다. 정답은 아이가 답을 적은 뒤에 가는 **확인 칸**에만 있다. 화면판(`C16.html`)은 한 번에 한 칸만 보여 주어 다음 칸의 정답이 보이지 않는다. 인쇄판은 한 쪽에 한 칸만 놓고 뒷면을 비워, 다음 쪽의 정답이 비치지 않게 한다. 첫 화면에는 첫 행동(창세기 46장 31절을 펴고 고센 쪽을 채우기)이 바로 보인다.

## 카드 정보

| 항목 | 내용 |
|---|---|
| 카드 번호 | C16 (바탕: C11. 별도 검증을 반영한 C11의 칸 2~13을 혼자 읽는 말로 바꿨다) |
| 근거 장절 | 창 46:31–34, 47:1–17, 42:3, 6 |
| 나이 단계 | 11~13세 (혼자 읽는다. 아이에게 장절을 알려 주고 스스로 찾게 한다. 공통 규칙서 5절) |
| 사람 수 | 한 사람 |
| 걸리는 때 | ⚠️ 추정 두 쪽 모두 20분, 한 쪽만 12분 (혼자 시험한 것이라 실제 아이와 잰 시간이 아니다) |
| 질문과 보기 | (먼저 풀 물음, 맞고 틀림 없음) 누구를 만나러 갔나? / 무엇을 받았나? (● 쪽) 바로 앞에 간 형은 몇 명이었을까요? 열 명(창 42:3, 곡식을 사러 온 날) / 다섯 명(창 47:2) (▲ 쪽) 먹을 것은 무엇에 맞춰 주었을까요? 가축 수에 맞춰(창 47:16–17, 애굽 백성의 일) / 식구 수에 맞춰(창 47:12). 두 고르기 모두 성경을 덮고 먼저 고른다(공통 규칙서 4.1) |
| 정답 근거 | C11과 같다. ● 바로(47:1), 차례 요셉 → 형 다섯 명 → 아버지 야곱(47:1, 2, 7), 바로의 물음 생업(47:3), 형들이 말한 선조(46:34, 47:3) / ▲ 라암셋(47:11), 바로의 말에도 고센(46:34, 47:6), 식구 수대로(47:12) |
| 성경 찾기 안내 | 11~13세 기준대로 칸마다 장절을 알려 준다. 아이가 스스로 펴서 찾는다 |
| 다른 장면 | C11과 같다. 곡식을 사러 온 날(창 42:3, 6), 돈이 떨어진 때(창 47:13–17). 고르기에서 앞의 보기를 고르면 그 칸으로 가서 사람이 다른 것을 찾고 돌아온다 |
| 준비물 | 성경책, 지도 수첩(C11의 '인쇄용 수첩과 카드'를 쓰거나, 종이 한 장에 겉 면·고센 쪽·● 쪽·▲ 쪽을 그린다), 탐험 일지(종이), 연필. 화면판으로 하면 휴대폰이나 컴퓨터 하나 |
| 참고 출처 | 성경 본문만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음. C11처럼, 칸 15(47:13–17)를 평가 없이 '누가 왔는가'만 찾게 한 처리는 감수 때 함께 봐 주기를 권한다 |
| 감수 상태 | 미감수 |

## 인쇄와 화면

- **화면판**: 같은 폴더의 `C16.html`을 휴대폰이나 컴퓨터의 브라우저로 연다. 인터넷이 없어도 열린다. 한 화면에 한 칸만 보이고, 칸 끝의 단추를 누르면 그 번호의 칸으로 간다. '처음으로' 단추로 첫 칸에 돌아간다. 화면판의 글은 아래 '1인판 원고'에서 스크립트로 만든다(원고를 고치면 다시 만든다).
- **인쇄판**: 아래 '1인판 원고'의 칸을 한 쪽에 하나씩 인쇄한다. 앞면만 인쇄하고 뒷면은 비운다. 칸 번호 차례대로 묶는다. 칸 번호는 흩어 두어서, 묻는 칸 바로 다음 쪽에 그 확인 칸이 오지 않는다. 확인 칸(8, 9, 13)은 묻는 칸(1, 7, 10)과 붙어 있지 않다.
- **접지 않는다**: 이 판은 C11처럼 메모지로 쪽을 덮을 필요가 없다. 확인 칸에 가기 전에는 정답이 보이지 않는다.

## 1인판 원고 (화면과 인쇄 공용)

### 칸 1 · 시작

- 『탐험대 이야기』 지도 수첩을 펴요. 오늘은 혼자 하는 탐험이에요. 한 칸을 다 하면, 끝에 적힌 번호의 칸으로 가요.
- 야곱의 온 가족이 가나안 땅을 떠나 애굽의 고센 땅에 와 있어요.
- **첫 행동**: 성경에서 창세기 46장 31절을 펴요. 요셉이 가족에게 할 일 두 가지를 말해요. 34절까지 읽어요.
- 수첩의 고센 쪽에 적어요. 심부름 ① 가족이 왔다고 알리러 갈 사람은 누구인가요? 심부름 ② 하는 일을 물으면 대답할 사람들은 누구인가요? 요셉이 말한, 가족이 살 땅은 어디인가요?
- 34절 끝의 애굽 사람들과 목축 이야기는 읽어도 되지만, 까닭은 성경이 자세히 말하지 않아요.
- 고센 쪽을 다 적었으면 → 칸 8로 간다.

### 칸 3 · ● 쪽: 만나러 간 사람

- 창세기 47장 1절을 펴요. 요셉은 누구에게 갔나요? 46장 31절에서 요셉이 알리러 가겠다고 한 사람과 같은지도 봐요.
- 『탐험대 이야기』 ● 쪽 맨 위와 수첩 겉의 ● 칸에 그 이름을 적어요. 만난 차례의 첫째 칸에는 '요셉'을 적어요.
- 아버지와 형들이 와 있다는 것을, 요셉이 그 사람에게 알렸어요. 첫째 심부름이에요.
- 다 적었으면 → 칸 5로 간다.

### 칸 4 · 고르기: 먹을 것

- 먹을 것도 요셉이 가족에게 주었어요.
- 이번에는 성경을 덮고 먼저 골라요. 요셉은 먹을 것을 무엇에 맞춰 주었을까요?
- **가축 수에 맞춰** → 칸 15로 간다.
- **식구 수에 맞춰** → 칸 10으로 간다.

### 칸 5 · 고르기: 형은 몇 명

- 다음에는 요셉이 형들을 바로 앞에 데려갔어요. 형들 가운데 몇 사람만 골라서요.
- 이번에는 성경을 덮고 먼저 골라요. 바로 앞에 간 형은 몇 명이었을까요?
- **열 명** → 칸 12로 간다.
- **다섯 명** → 칸 7로 간다.

### 칸 7 · 형 다섯 명과 둘째 심부름

- 창세기 47장 2절을 펴서, 바로 앞에 간 형의 수를 확인해요. 만난 차례의 둘째 칸에 '형 (　) 명'을 적어요. 수첩 겉의 ● 칸 아래에도 그 수를 적어요.
- 47장 3절을 읽어요. 형들에게 바로가 무엇을 물었나요?
- 형들은 자기들 말고 또 누가 그 일을 했다고 대답했나요? 46장 34절 요셉의 말에도 같은 낱말이 있어요. 형들의 대답 칸에 적어요. ('우리'나 '종들'도 두 곳에 다 있지만, 사람을 가리키는 낱말을 찾아요.)
- 47장 7절을 읽어요. 마지막으로 바로 앞에 선 사람은 누구인가요? 만난 차례의 셋째 칸에 적어요.
- 다 적었으면 → 칸 9로 간다.

### 칸 8 · 고센 쪽 확인

- 내 답과 견줘 봐요. 심부름 ①은 요셉이에요. 심부름 ②는 형들이에요('형들과 아버지의 가족'도 맞아요). 요셉이 말한 땅은 고센이에요(46장 34절).
- 다른 곳이 있으면 46장 31–34절을 다시 읽고 고쳐요.
- 이제 먼저 풀 물음을 하나 골라요. 맞고 틀림은 없어요.
- **누구를 만나러 갔나?** → 칸 3으로 간다.
- **무엇을 받았나?** → 칸 11로 간다.

### 칸 9 · ● 쪽 확인

- 내 답과 견줘 봐요. 요셉이 간 사람은 바로예요(47장 1절). 만난 차례는 요셉 → 형 다섯 명 → 아버지 야곱이에요(47장 1, 2, 7절). 바로가 물은 것은 생업, 곧 하는 일이에요(47장 3절). 같은 낱말은 '선조'예요(46장 34절, 47장 3절).
- 다른 곳이 있으면 그 절을 다시 읽고 고쳐요.
- 『탐험대 이야기』 일지에 적어요. ● 바로를 만난 차례(창세기 47장 1, 2, 7절), 두 심부름(창세기 46장 31–34절, 47장 1–3절), 다른 때 칸을 다녀왔으면 곡식을 사러 온 날(창세기 42장 3, 6절).
- ▲ 쪽을 아직 안 했으면 지금 할 수도 있고, 다음에 해도 돼요.
- **▲ 쪽을 지금 한다** → 칸 11로 간다.
- **오늘은 여기까지** → 칸 16으로 간다.

### 칸 10 · 먹을 것 확인하기

- 창세기 47장 12절을 펴요. 라암셋이 나온 절 바로 다음이에요.
- 요셉은 먹을 것을 무엇에 맞춰 주었나요? ▲ 쪽 '먹을 것' 칸에 적어요.
- 다 적었으면 → 칸 13으로 간다.

### 칸 11 · ▲ 쪽: 받은 땅

- 창세기 47장 11절을 펴요. 요셉이 가족에게 준 땅의 이름은 무엇인가요?
- 『탐험대 이야기』 ▲ 쪽 맨 위와 수첩 겉의 ▲ 칸에 그 이름을 적어요. 받은 것의 살 곳 칸에도 적어요.
- '고센'이 떠올랐나요? 고센은 47장 6절에서 바로가 말한 땅이에요. 요셉이 준 곳을 적은 11절에는 다른 이름이 나와요. 성경은 여기서 두 이름이 어떤 사이인지 말하지 않아요.
- 47장 6절을 읽어요. 고센 쪽에 적은 땅 이름이 바로의 말에도 나오나요? ▲ 쪽 확인 칸에 '나온다' 또는 '안 나온다'를 적어요.
- 다 적었으면 → 칸 4로 간다.

### 칸 12 · 다른 때: 곡식을 사러 온 날

- 『탐험대 이야기』 다른 때로 가 봐요. 형들이 처음 곡식을 사러 애굽에 온 날이에요.
- 창세기 42장 6절을 펴요. 형들이 그 앞에 엎드린 사람은 누구인가요? ● 쪽 맨 위에 적은 사람과 같은가요?
- 42장 3절도 읽어요. 이날 곡식을 사러 온 형은 몇 명이었나요?
- 열 명은 곡식을 사러 온 날의 형들이에요. 바로 앞에 간 형의 수는 47장에 있어요.
- 다시 고르러 → 칸 5로 돌아간다.

### 칸 13 · ▲ 쪽 확인

- 내 답과 견줘 봐요. 요셉이 준 땅은 라암셋이에요(47장 11절). 고센은 바로의 말에도 나와요(47장 6절). 먹을 것은 식구 수대로 주었어요(47장 12절).
- 다른 곳이 있으면 그 절을 다시 읽고 고쳐요.
- 『탐험대 이야기』 일지에 적어요. ▲ 가족이 받은 것(창세기 47장 11–12절), 요셉이 말한 땅과 바로의 말(창세기 46장 34절, 47장 6절), 다른 때 칸을 다녀왔으면 돈이 떨어진 때(창세기 47장 15–17절).
- ● 쪽을 아직 안 했으면 지금 할 수도 있고, 다음에 해도 돼요.
- **● 쪽을 지금 한다** → 칸 3으로 간다.
- **오늘은 여기까지** → 칸 16으로 간다.

### 칸 15 · 다른 때: 돈이 떨어진 때

- 『탐험대 이야기』 다른 때로 가 봐요. 흉년이 더 심해져 돈이 떨어진 때예요.
- 창세기 47장 13–17절을 펴요. 돈이 떨어져 요셉에게 온 사람들은 누구인가요? ▲ 쪽에서 먹을 것을 받은 사람들과 같은가요?
- 가축과 바꾸어 먹을 것을 받은 일은 애굽 백성에게 있었던 일이에요. 18절부터의 일은 이 판에서 읽지 않아도 돼요.
- 다시 고르러 → 칸 4로 돌아간다.

### 칸 16 · 수첩 닫기

- 『탐험대 이야기』 수첩 겉의 지도를 봐요. 빈칸을 몇 개 채웠나요? 남은 빈칸이 있으면, 다음에 칸 8에서 남은 물음을 골라 그 쪽을 열어요.
- (원하면) 한 문장 기도: 우리 가족에게 살 곳과 먹을 것을 주시는 하나님, 고맙습니다.
- 끝.

## 진행자용 정답과 근거

정답과 근거는 C11의 '진행자용 정답과 근거'와 같다. 이 판에서 바뀐 것만 적는다.

| 바뀐 것 | 까닭 |
|---|---|
| 어른 줄을 혼자 읽는 말로 바꾸고, 쉼은 '다 적었으면'으로 바꿨다 | 진행자가 없다 |
| 칸마다 장절을 알려 준다 | 혼자 찾으려면 장만으로는 어렵다. 11~13세 기준(장절 안내 후 스스로 찾기)에 맞췄다 |
| 정답은 확인 칸(8, 9, 13)에만 둔다 | 어른이 확인해 주던 일을 확인 칸이 맡는다. 화면판은 한 칸만 보이고, 인쇄판은 한 쪽에 한 칸이다 |
| 칸 번호를 흩어 두었다(2, 6, 14는 없다) | 인쇄판에서 묻는 칸 바로 다음 쪽에 확인 칸이 오지 않게 했다 |
| C11의 칸 6, 11의 '● 쪽(▲ 쪽)과 같은가요?'를 그대로 두었다 | 다른 때 칸에서 사람이 다른 것을 아이가 스스로 견주게 한다 |
| 다른 때 칸의 마지막 줄 '열 명은 곡식을 사러 온 날의 형들', '애굽 백성에게 있었던 일' | 진행자가 없어 어긋남의 뜻을 글로 맺는다. 아이가 사람을 찾은 뒤의 줄이다 |

| ▲ 먼저, ● 쪽도 이어서 | 1 → 8 → 11 → 4 → 10 → 13 → 3 → 5 → 7 → 9 → 16 | 끝 칸에 닿았다. 칸 13에서 '오늘은 여기까지'를 누르면 ▲ 쪽만 하고 칸 16으로 간다 |
| 정답이 미리 보이는지 | 묻는 칸 1, 3, 4, 5, 11 | 화면판에서 묻는 칸의 글에 그 칸의 정답('요셉이에요', '고센이에요', '형 다섯 명', '식구 수대로', '바로예요', '라암셋이에요')이 없는 것을 스크립트로 확인했다 |

- 화면판은 '1인판 원고'에서 스크립트로 만들었다(세션 임시 폴더의 스크립트, 저장소에는 없음). 원고를 고치면 다시 만든다.
- ⚠️ 실제 아이가 혼자 해 보지는 않았다. ⚠️ 인쇄판을 실물로 인쇄해 비침을 보지는 않았다. ⚠️ 컴퓨터 화면과 다른 휴대폰 브라우저에서는 열어 보지 않았다(시험한 것은 세션의 크로미움 하나)

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 칸 이동 | 스크립트로 '→ 칸' 줄을 따라가 봤다. 출구 없는 칸, 없는 칸으로 가는 줄, 닿지 않는 칸이 없다. 화면판에서도 단추로 두 길을 끝까지 갔다 |
| 해답이 다음 쪽에 비치지 않는지 | 정답은 확인 칸에만 있다. 화면판은 한 칸만 보인다. 인쇄판은 한 쪽에 한 칸, 뒷면은 비운다. 묻는 칸과 확인 칸의 번호가 붙어 있지 않다 |
| 접지 않고 완주 | 메모지나 접는 덮개 없이, 번호만 따라 끝까지 간다 |
| 첫 화면의 첫 행동 | 칸 1에 '첫 행동: 창세기 46장 31절을 펴요'가 굵게 있다 |
| 개역개정과 겹치는 말 | 1인판 원고를 46:28–34, 47:1–17, 42:3–8과 세 가지로 대조했다: 어절 단위(첫 음절의 첫소리·가운뎃소리까지, 네 어절), 글자 단위(띄어쓰기 무시, 8자), 한 문장의 낱말이 사이에 말이 끼어도 본문과 같은 차례로 네 개 넘게 이어지는지(문장 낱말의 6할 이상). 첫 원고는 칸 4의 '요셉은 가족에게 먹을 것도 주었어요'가 걸려 C11의 고친 말로 바꿨다. 남은 걸림은 받아 주는 답 '형들과 아버지의 가족'(세 어절)이다 |
| 말투 | 모두 존댓말(해요체)이다 |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다. 확인 칸은 '내 답과 견줘 봐요', '다른 곳이 있으면 고쳐요'로 쓴다 |
