# C22 · 장막 앞의 물건판 (손님 대신 음식과 일손을 본다)

창세기 18:1–8에서 아브라함이 세 손님을 맞은 날을 **물건판**으로 본다. 본문은 이 손님들 가운데 여호와께서 계셨다고 한다(18:1). 그래서 탐험대는 손님을 그리지 않고, 손님을 위해 **준비한 음식**과 그 일을 한 **일손**만 판에 모은다. 판에는 '손님 앞에 차린 것' 자리와 일손 세 칸(아브라함, 사라, 하인)이 있다. 아이는 성경을 펴기 전에 **음식 카드**와 **일손 카드**를 모두 내 생각대로 놓고, 둘 가운데 무엇부터 18장으로 확인할지 고른다. 염소 새끼 카드를 상에 놓으면 다른 날(창 27:9)을 다녀와 그 한 장만 고친다. 바탕은 G12(창 18:1–8, 별도 검증 끝)다.

## 카드 정보

| 항목 | 내용 |

| 근거 장절 | 창 18:1–8, 27:9 (다른 장면) |
| 나이 단계 | 8~10세 (어른과 함께) |
| 사람 수 | 두 사람 (어른 한 명은 진행, 아이 한 명은 카드를 놓는다) |
| 걸리는 때 | ⚠️ 추정 10~12분 (잰 시간이 아니다) |

| 성경 찾기 안내 | 아이에게는 책과 장(창세기 18장, 27장)과 '18장 처음', '바로 뒤'까지 안내한다. 절은 어른 도움말로만 둔다 (공통 규칙서 5절). 일지에는 장절을 함께 적는다 |
| 다른 장면 | 리브가가 염소 새끼로 별미를 만들려던 날 (창 27:9) 한 곳. 염소 새끼 카드를 상에 놓으면 다녀온다(G12와 같은 장면) |
| 준비물 | 아래 '인쇄용 물건판과 카드'(인쇄하거나 손으로 옮겨 쓴다), 아이의 성경책, 탐험 일지(종이)와 연필, 접은 종이 한 장(다른 날 카드). 자르지 않으려면 판 칸에 카드 번호를 연필로 쓴다 |
| 참고 출처 | 성경 본문과 G12 원고만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음. 확인 권함(G12와 같다): 본문은 이 손님들 가운데 여호와께서 계셨다고 한다(18:1, 13, 22). 그래서 판과 그림에 손님을 그리지 않고, 손님의 말(18:5, 9–15)도 쓰지 않는다 |
| 감수 상태 | 미감수 |

이 판은 이 때의 이름 '아브라함'과 '사라'를 쓴다(이름이 바뀐 것은 창 17장).

읽는 법
- **어른**은 어른이 읽는 줄이고, **최온**은 아이가 읽는 줄이다(최온은 탐험대의 10살 아이). 한 줄이 한 화면이다.
- **쉼**에서는 다음 줄로 넘어가지 말고 아이를 기다린다.
- 『탐험대 이야기』가 붙은 줄은 성경 본문이 아니다. 물건판, 음식 카드, 일손 카드, 다른 날 카드, 탐험 일지는 탐험대가 만든 종이 도구다.
- 괄호 안의 장절과 '어른 도움말'은 소리 내어 읽지 않는다.
- 이 문서에는 답이 적혀 있어서 어른만 본다. 아이 앞에는 인쇄한 판과 카드만 둔다.

## 놀이 준비 (⚠️ 추정 3분)

1. 어른이 아래 '인쇄용 물건판과 카드'를 인쇄한다. 이 문서의 다른 쪽에는 답이 있으니 어른이 갖는다.
2. 음식 카드 네 장과 일손 카드 네 장을 잘라, 종류마다 따로 섞어 판 옆에 글이 보이게 펼친다. 자르지 않을 때는 카드 목록을 판 옆에 두고, 칸마다 카드 번호를 연필로 쓴다.
3. 다른 날 카드는 글이 안쪽으로 가게 접어 둔다.
4. 아이의 성경은 덮어 둔다. 카드를 다 놓은 뒤에 편다.

## 아이에게 알려 줄 규칙 (세 줄)

- 성경을 펴기 전에 카드 여덟 장을 **내 생각대로** 놓는다.
- 음식 카드와 일손 카드 가운데 **무엇부터** 18장으로 확인할지 고른다.
- 성경과 다르면 **그 한 장만** 옮긴다.

## 플레이 원고

### 칸 1 · 도착 (창 18:1–2)

- 보이는 것: 마주 놓인 물건판(손님 앞에 차린 것 자리, 일손 세 칸), 마므레의 상수리나무들과 장막, 장막 문에 앉은 아브라함 (손님은 그리지 않는다)
- **어른** 『탐험대 이야기』: 타임머신이 마므레의 상수리나무들이 있는 곳에 왔어요.
- **최온**: 날이 정말 뜨거워!
- **어른**: 날이 뜨거운 때예요. 아브라함이 장막 문에 앉아 있어요.
- **어른**: 성경은 이때 여호와께서 아브라함에게 나타나셨다고 말해요.
- **어른**: 아브라함 맞은편에 세 사람이 와 있었어요. 아브라함은 얼른 달려가 맞이하고 몸을 굽혀 인사했어요.
- → 칸 2로 간다.

### 칸 2 · 물건판 (창 18:3–5)

- 보이는 것: 물건판, 음식 카드 네 장, 일손 카드 네 장
- **어른**: 아브라함은 손님들에게 발을 씻고 나무 아래에서 쉬시라고 했어요. 먹을 것을 조금 가져오겠다고 했어요. (어른 도움말: 4–5절)
- **어른** 『탐험대 이야기』: 탐험대는 손님을 그리지 않아요. 대신 손님을 위해 준비한 것과 그 일을 한 사람을 이 판에 모아요.
- **어른** 『탐험대 이야기』: 위쪽은 손님 앞에 차린 것을 놓는 자리예요. 아래쪽 세 칸은 아브라함, 사라, 하인의 칸이에요.
- **어른**: 카드를 같이 읽어요. 음식 카드는 송아지, 엉긴 젖, 우유, 염소 새끼예요. (일손 카드 네 장도 차례대로 읽어 준다)
- **어른** 『탐험대 이야기』: 성경을 펴기 전에 먼저 놓아요. 손님 앞에 차렸을 것 같은 음식 카드는 위쪽 자리에, 아닐 것 같은 카드는 판 옆에 둬요.
- **어른** 『탐험대 이야기』: 일손 카드는 누구의 일일지 내 생각대로 아래 세 칸에 놓아요.
- **쉼**: 아이가 여덟 장을 다 정할 때까지 기다린다.
- **어른** 『탐험대 이야기』: 이제 18장을 펴요. 음식 카드와 일손 카드 가운데 무엇부터 확인할까요?
- **쉼**: 아이가 고를 때까지 기다린다.
- 고르기
  - **㉠ 음식 카드부터** → 칸 3으로 간다.
  - **㉡ 일손 카드부터** → 칸 4로 간다.

### 칸 3 · 음식 카드 (창 18:7–8)

- 보이는 것: 놓아 둔 음식 카드 네 장 (송아지, 엉긴 젖, 우유, 염소 새끼)
- 칸 다른-날에서 돌아왔으면 '18장에서' 줄부터 다시 읽는다.
- **어른**: 18장에서, 아브라함이 손님 앞에 차린 것을 찾아봐요. 18장 처음에서 조금 내려가요. (어른 도움말: 8절. 엉긴 젖, 우유, 하인이 요리한 송아지)
- **쉼**: 아이가 세 가지를 찾을 때까지 기다린다. (어른 도움말: 아이가 6절의 떡을 말하면 "떡은 사라에게 만들어 달라고 한 것이에요. 이 카드 네 장 가운데에는 없어요."라고만 답한다)
- **어른** 『탐험대 이야기』: 찾은 것과 다른 카드가 있으면 한 장씩 옮겨요.
- 고르기
  - **위쪽에 송아지, 엉긴 젖, 우유를 놓았어요** → 이 칸의 아래 줄을 이어 읽는다.
  - **위쪽에 염소 새끼를 놓았어요** → 칸 다른-날로 간다.
- 고르기 (다음 칸)
  - **일손 카드를 아직 확인하지 않았어요** → 칸 4로 간다.
  - **일손 카드도 확인했어요** → 칸 5로 간다.

### 칸 4 · 일손 카드 (창 18:6–8)

- 보이는 것: 일손 세 칸 (아브라함, 사라, 하인)에 놓아 둔 일손 카드 네 장
- **어른**: 18장에서, 아브라함이 장막으로 간 대목부터 읽어 봐요. (어른 도움말: 6–8절)
- **어른** 『탐험대 이야기』: 카드의 일이 나오는 곳을 손가락으로 짚어요. 그 일을 한 사람, 또는 그 말을 들은 사람의 이름을 찾아봐요.
- **쉼**: 아이가 네 장을 다 짚을 때까지 기다린다. (어른 도움말: 6절은 사라가 들은 말, 7절의 '그가'는 바로 앞의 하인, 7절 처음과 8절 처음은 아브라함)
- **어른** 『탐험대 이야기』: 짚은 것과 다른 카드가 있으면 한 장씩 옮겨요.
- 고르기
  - **음식 카드를 아직 확인하지 않았어요** → 칸 3으로 간다.
  - **음식 카드도 확인했어요** → 칸 5로 간다.

### 칸 다른-날 · 다른 장면: 리브가의 별미 (창 27:9)

- 보이는 것: 편 다른 날 카드 (염소 떼와 새끼 둘, 리브가와 야곱)
- **어른** 『탐험대 이야기』: 염소 새끼 카드를 들고 다른 날 카드를 펴요. 타임머신이 훨씬 뒤의 날로 갔어요.
- **어른**: 이삭의 아내 리브가가 아들 야곱에게 염소 떼에서 좋은 새끼 두 마리를 가져오라고 했어요.
- **어른**: 남편 이삭이 즐겨 먹는 별미를 만들려는 것이었어요.
- **최온**: 여기서는 염소 새끼야!
- **어른**: 창세기 27장을 펴 봐요. 리브가가 가져오라고 한 것은 무엇인가요? (어른 도움말: 9절)
- **쉼**: 아이가 '염소 새끼'를 찾을 때까지 기다린다.
- **어른**: 염소 새끼는 리브가가 별미를 만들 때 쓰려던 것이에요. 아브라함이 손님에게 차린 것이 아니에요.
- **어른** 『탐험대 이야기』: 염소 새끼 카드는 다른 날 카드 위에 둬요. 아브라함의 장막으로 돌아가요.
- → 칸 3으로 돌아간다.

### 칸 5 · 판 확인 (창 18:6–8)

- 보이는 것: 카드가 다 놓인 물건판
- **어른** 『탐험대 이야기』: 위쪽 자리에 세 장, 아브라함 칸에 두 장, 사라 칸에 한 장, 하인 칸에 한 장인가요?
- **어른** 『탐험대 이야기』: 수가 다르면, 많은 칸의 카드를 한 장씩 18장에서 다시 짚어 봐요. 맞지 않는 한 장만 옮겨요.
- **쉼**: 칸마다 수가 맞을 때까지 기다린다.
- **어른**: 찾았어요. 아브라함은 가축들이 있는 곳으로 뛰어가 송아지를 골랐어요.
- **어른**: 무엇을 보니 알 수 있었나요? 18장에 아브라함이 송아지를 골라 하인에게 맡겼고, 하인이 서둘러 요리했다고 나와요.
- **어른**: 손님들 앞에 차린 것은 엉긴 젖과 우유, 그리고 요리한 송아지였어요.
- **최온**: 아브라함은 뛰고, 사라는 떡을, 하인은 요리를! 모두 서둘렀어!
- → 칸 6으로 간다.

### 칸 6 · 기록

- 보이는 것: 탐험 일지, 물건판
- **어른** 『탐험대 이야기』: 일지에 손님 앞에 차린 것과 일손을 적어요. 먼저 확인한 카드도 적어요.
- 일지에 적을 것
  - 먼저 확인한 카드: **음식** 또는 **일손**
  - 손님 앞에 차린 것: **송아지, 엉긴 젖, 우유** · 창세기 18장 8절
  - **아브라함** · 창세기 18장 7–8절 · 송아지를 고름, 음식을 가져다 손님 앞에 놓음
  - **사라** · 창세기 18장 6절 · 떡을 만들어 달라는 말을 들음
  - **하인** · 창세기 18장 7절 · 송아지를 서둘러 요리함
  - 다른 날 카드를 다녀왔으면: **염소 새끼** · 창세기 27장 9절 · 리브가가 별미를 만들려던 것
- (원하면) 한 문장 기도: 아브라함처럼 찾아온 손님을 정성껏 맞게 해 주세요.
- 끝.

## 아이용 요약

날이 뜨거울 때 아브라함의 장막 맞은편에 세 사람이 왔어요(창세기 18장). 아브라함은 달려가 맞이했어요. 장막의 사라에게는 떡을 만들어 달라고 했어요. 아브라함은 가축들이 있는 곳으로 뛰어가 송아지를 골라 하인에게 맡겼고, 하인이 서둘러 요리했어요. 손님들 앞에 차린 것은 엉긴 젖과 우유, 그리고 요리한 송아지였어요(창세기 18장).

| 3 | 떡을 만들어 달라는 말을 들었어요. |
| 4 | 가축들이 있는 곳으로 뛰어가 송아지를 골랐어요. |

### 다른 날 카드 (한 장, 글이 안쪽으로 가게 접는다)

『탐험대 이야기』 **다른 날** · 창세기 27장 · [그림 자리: 염소 떼와 새끼 둘, 리브가와 야곱] · 염소 새끼 카드를 이 위에 둬요.

## 진행자용 정답과 근거

| 카드 | 놓을 곳 | 근거 | 헷갈릴 만한 까닭 |
|---|---|---|---|
| 송아지, 엉긴 젖, 우유 | 손님 앞에 차린 것 | 창 18:8 | |
| 염소 새끼 | 판 옆 (다른 날 카드) | 창 27:9 | 고기라서 송아지와 섞이기 쉽다 |
| 일손 1 음식을 가져다 손님들 앞에 놓았어요 | 아브라함 | 창 18:8 | 요리한 하인이 가져온 것으로 짐작하기 쉽다. 8절 처음의 이름이 아브라함이다 |
| 일손 2 송아지를 받아 서둘러 요리했어요 | 하인 | 창 18:7 | 7절의 '그가'는 바로 앞의 하인이다 |
| 일손 3 떡을 만들어 달라는 말을 들었어요 | 사라 | 창 18:6 | 말한 사람은 아브라함, 들은 사람이 사라다 |
| 일손 4 가축들이 있는 곳으로 뛰어가 송아지를 골랐어요 | 아브라함 | 창 18:7 | 송아지를 요리한 하인과 섞이기 쉽다 |

- 두 길의 차이: ㉠은 음식 카드(18:8)를 먼저 확인하고 일손 카드(18:6–8)로 간다. ㉡은 일손 카드를 먼저 확인하고 음식 카드로 간다. 두 길 모두 칸 5에서 같은 판(위쪽 3, 아브라함 2, 사라 1, 하인 1)이 되고, 일지의 첫 줄만 다르다.
- 되돌리는 방법: 확인할 때마다 '한 장씩 옮겨요', 칸 5의 수 세기(많은 칸을 다시 짚음), 염소 새끼는 다른 날을 다녀와 그 한 장만 판 옆으로.
- 떡: 아브라함은 손님에게 떡을 조금 가져오겠다고 했고(18:5) 사라에게 떡을 만들라고 했다(18:6). 18:8의 차린 목록에는 떡이 없다. 이 판은 떡을 음식 카드에 넣지 않고 일손 카드 3(사라)에만 두었다. 떡이 상에 올랐는지는 본문이 말하지 않으므로 다루지 않는다(아이가 물을 때의 답은 칸 3 도움말).
- 사라: 6절은 아브라함이 사라에게 떡을 만들라고 '말한' 것만 적는다. 그래서 일손 카드 3은 '떡을 만들어 달라는 말을 들었어요'로 썼다. 사라가 만들었다고 하지 않는다.
- '엉긴 젖'은 아이가 성경에서 찾을 음식 이름이라 그대로 둔다(G12와 같다).
- 줄 가운데 G12에서 그대로 가져온 것: 칸 1의 다섯 줄, 칸 2의 18:3–5 줄, 칸 다른-날의 이야기 줄, 칸 5의 두 줄, 기도. G12 칸 6의 '엉긴 젖과 우유와 요리한 송아지를 … 차렸어요'는 18:8과 낱말 차례가 거의 같아(대조 도구에 걸림) '손님들 앞에 차린 것은 …였어요'로 바꿨다. 새로 쓴 것: 칸 2·3·4·5의 판을 다루는 줄, 카드 글, 일지, 요약의 차례.
- 세 손님의 대사(18:5 뒷부분, 18:9–15)는 쓰지 않았다. 아브라함의 말(18:3–6)은 간접 화법으로 옮겼다.
- 그림 주의: 손님을 그리지 않는다. 하나님의 모습·손·그림자와 천사를 그리지 않는다. 물건판에는 그림을 넣지 않는다. 다른 날 카드의 그림은 G12 칸 5와 같다. 탐험대 가운데 이 판에 나오는 아이는 최온이다.

## 플레이 시험 기록 (2026-11-23)

혼자 두 역할(어른과 아이)로 원고 줄만 따라 두 첫 선택을 끝까지 갔다. 칸 2의 '먼저 놓기'는 아이가 짐작할 만한 것으로 놓아 봤다. 실제 아이가 한 것은 아직 없다.

| 첫 선택 | 칸 2에서 먼저 놓은 것 | 확인하며 옮긴 것 | 칸 5 | 끝 |
|---|---|---|---|---|
| ㉠ 음식 카드부터 | 위쪽: 송아지, 염소 새끼, 우유 / 판 옆: 엉긴 젖 · 아브라함 4 / 사라 3 / 하인 1·2 | 칸 3: 염소 새끼 → 칸 다른-날(27:9) → 판 옆으로, 엉긴 젖을 위쪽으로(8절). 칸 4: 1을 하인에서 아브라함으로(8절 처음) | 3 / 2 / 1 / 1 | 일지 첫 줄 '음식' |
| ㉡ 일손 카드부터 | 위쪽: 송아지, 엉긴 젖, 우유 / 판 옆: 염소 새끼 · 아브라함 1·4 / 사라 3 / 하인 2 | 칸 4: 바뀐 것 없음. 칸 3: 바뀐 것 없음 | 3 / 2 / 1 / 1 | 일지 첫 줄 '일손' |
| ㉡, 4를 하인 칸에 놓은 경우 | 아브라함 1 / 사라 3 / 하인 2·4 | 칸 4: 4를 7절 처음에서 짚어 아브라함으로 | 3 / 2 / 1 / 1 | 같은 판 |

- 두 첫 선택 모두 칸 5에서 같은 판(위쪽 3, 아브라함 2, 사라 1, 하인 1)에 닿았다.
- 시험하며 고친 것: 첫 원고는 고른 종류의 카드만 먼저 놓게 해서, ㉠ 길에서는 아이가 18:8을 읽은 뒤에 일손 카드를 놓게 됐다(8절에 '하인이 요리한', '가져다가'가 있다). 카드 여덟 장을 모두 성경을 펴기 전에 놓고, 확인할 차례만 고르게 바꿨다(공통 규칙서 4.1).
- ⚠️ 8살 아이가 7절의 '그가'를 하인과 잇는지, 일손 카드 3을 '말을 들은 사람'으로 사라에게 놓는지는 실제로 해 보지 않았다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 칸 이동 | 칸 7개(1, 2, 3, 4, 다른-날, 5, 6). 칸 3과 칸 4는 서로를 거쳐 칸 5로 가고, 칸 다른-날은 칸 3으로 돌아온다. 없는 칸으로 가는 줄이 없다 |
| 고르기 먼저 | 카드 여덟 장을 18장을 펴기 전에 놓는다. 첫 선택은 확인할 차례다 |
| 되돌리는 방법 | 확인할 때 한 장씩 옮기기, 칸 5의 수 세기, 염소 새끼는 다른 날을 다녀와 판 옆으로 |
| 아이 앞에 답이 보이는지 | 판에는 자리 이름만 있다. 음식 카드와 일손 카드는 정답 차례가 아니게 섞었다(일손: 아브라함, 하인, 사라, 아브라함) |
| 개역개정과 겹치는 말 | 원고 전체를 창 18:1–15, 27:1–10과 세 가지 방법(낱말 첫소리, 글자 9자, 낱말 차례)으로 대조했다. 걸린 18:8 줄(G12에서 가져온 줄과 요약)과 그림 자리의 27:9 말을 고쳤다. 남은 걸림은 G12의 검증된 줄('가축들이 있는 곳으로 뛰어가 송아지를 골랐어요')과 찾을 음식 이름, 세 어절 이하다 |
| 본문에 없는 말 | 사라가 떡을 만들었다고 하지 않는다(6절은 말만 적는다). 떡이 상에 올랐는지 말하지 않는다 |
| 성경 찾기 안내 | 아이에게 하는 말은 장과 '18장 처음', '바로 뒤'까지다 |
| 한 화면의 글 | 어른과 최온의 줄은 한 줄에 한두 문장이다(스크립트로 셈) |
| 말투와 쓰지 않은 말 | 어른의 줄은 존댓말이다. "틀렸어요", 감점, 실패 표현이 없다 |
| 감수 | 3.5 해당 없음. G12와 같은 확인 권함(손님 가운데 여호와) |
