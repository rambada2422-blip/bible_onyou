# C18 · 가정용 인쇄 두 판 (C17 두 판의 A4 인쇄본)

C17의 두 판(가 · 아브람의 접이 지도, 나 · 야곱의 뒤집기 판)을 집에서 A4로 인쇄해 **가위 없이** 쓰는 인쇄본이다. 자르는 대신 접고(석 장 접기, 반 접기), 쪽지는 연필로 쓰고, 조각은 붙임쪽지로 한다. 판마다 아이 앞에 둘 **판 PDF**와 어른만 보는 **답지 PDF**를 따로 만들었다. 만든 PDF를 열어 빈 면, 잘린 장절, 접었을 때 바깥에 답이 보이는지 확인했다. 실물 인쇄는 하지 않았다(아래 '실물 인쇄 여부').

판 PDF는 인쇄해 접은 종이로만 아이 앞에 둔다. 파일을 화면으로 보여 주지 않는다(펴진 쪽에는 봉투와 카드의 안쪽 글이 보인다).

## 자르지 않고 쓰는 방법

- **인쇄**: A4에 실제 크기(100%)로, 한 면만 찍는다. 확대나 축소를 하면 접는 선이 칸의 경계와 어긋난다. 아이가 보기 전에 인쇄하고 접는다.
- **봉투, 확인 줄 카드, 다른 날 카드(석 장 접기)**: 한 쪽이 위 칸(겉), 가운데 칸(안쪽 글), 아래 칸(비침 막이 무늬)으로 나뉘어 있다. ① 아래 무늬 칸을 위로 접어 가운데 칸을 덮는다. ② 접은 두 칸을 함께 위 칸 뒤로 접는다. 겉에는 위 칸(카드 이름)만 보이고, 뒤에는 무늬 칸의 빈 뒷면만 보인다. 안쪽 글은 앞에서 보면 종이 두 겹 뒤에, 뒤에서 보면 무늬 뒤에 있다. 테이프는 쓰지 않아도 된다.
- **나 판의 뒤집기 판**: 2쪽을 가운데 점선에서 뒤로 접는다. 앞은 밤 면, 뒤는 아침 면이다. 판을 뒤집을 때는 위아래로 뒤집는다(좌우로 뒤집으면 글이 거꾸로 보인다, C02와 같다). 이 말은 밤 면 아래에도 찍혀 있다.
- **쪽지와 조각**: 가 판은 장소 쪽지를 자르지 않고 지도 칸에 곳의 이름을 연필로 쓴다. 맞바꿀 때는 두 칸을 지우고 바꿔 쓴다. 나 판의 돌 조각과 기름 조각은 붙임쪽지로 한다(아래 '인쇄본으로 할 때 · 나 판'의 준비).

## 인쇄본으로 할 때 · 가 판

이 절은 `C18_가_답지.pdf` 맨 위에도 찍혀 있다. 답지의 진행 줄은 화면판(C17) 말로 쓰여 있어서, 인쇄본으로 할 때는 아래처럼 바꿔 읽는다.

준비 (⚠️ 추정 5분)

1. `C18_가_판.pdf` 4쪽을 실제 크기로 한 면만 인쇄한다. 아이가 보기 전에 2쪽과 3쪽(봉투), 4쪽(확인 줄 카드)을 석 장 접기로 접는다. 접는 법은 종이에 찍혀 있다.
2. 1쪽 지도판을 책상에 놓고, 봉투 두 개와 확인 줄 카드를 그 옆에 둔다. 연필과 지우개, 아이의 성경책, 탐험 일지를 둔다.
3. 아래 답지 안의 '준비'는 화면판으로 할 때의 준비다. 인쇄본으로 할 때는 이 절의 준비를 따른다.

| 답지(화면판)의 말 | 인쇄본에서 |
|---|---|
| 화면 맨 위 두 문단 | 1쪽 제목 아래 두 문단 |
| 화면의 규칙 세 줄 | 1쪽 규칙 세 줄 |
| 장소 쪽지 세 장을 손에 든다, 쪽지를 지도에 놓아요 | 1쪽의 '곳의 이름 세 개'를 같이 읽고, 지도 칸에 이름을 연필로 써요 |
| 두 쪽지를 맞바꿔요 | 두 칸의 이름을 지우고 맞바꿔 써요 |
| 봉투 가(나)를 누른다, 봉투 칸 | 봉투 가(나)를 편다(접은 것을 풀고 무늬 칸을 든다), 봉투 |
| 확인 줄을 누른다 | 확인 줄 카드를 펴서 지도 아래에 놓는다 |
| 마지막을 누른다 | 종이에는 마지막 칸이 없다. 답지 8의 줄을 어른이 읽어 준다 |

## 인쇄본으로 할 때 · 나 판

이 절은 `C18_나_답지.pdf` 맨 위에도 찍혀 있다. 답지의 진행 줄은 화면판(C17) 말로 쓰여 있어서, 인쇄본으로 할 때는 아래처럼 바꿔 읽는다.

준비 (⚠️ 추정 5분)

1. `C18_나_판.pdf` 3쪽을 실제 크기로 한 면만 인쇄한다. 아이가 보기 전에 2쪽(뒤집기 판)을 가운데 점선에서 뒤로 접고, 3쪽을 석 장 접기로 다른 날 카드로 만든다. 1쪽(시작 쪽)은 그대로 둔다.
2. 돌 조각 두 개는 가로로 긴 붙임쪽지(약 75×25mm) 두 장씩으로 만든다. 없으면 정사각 붙임쪽지(약 75×75mm)를 끈끈한 띠가 안쪽에 오게 가로로 세 번 접어 띠를 만든다. 두 조각은 같은 크기로 한다(크기로 답을 알 수 없게). 판의 돌 자리(가로 80×30mm, 세로 30×80mm)에 들어간다.
3. 조각마다 두 장을 등을 맞대어 붙여 하나로 만든다. ㉮는 앞 장에 '돌', 뒤 장에 '창세기 28장의 돌'을 쓴다. ㉯는 앞 장에 '큰 돌', 뒤 장에 '창세기 29장의 돌'을 쓴다. 두 장을 겹치는 것은 뒤의 글이 앞으로 비치지 않게 하려는 것이다.
4. 뒤의 장 번호 위에는 작은 붙임쪽지를 덮개로 붙인다(C02의 가림 쪽지와 같다). 아이는 조각을 돌 자리에 놓은 다음에 덮개를 들춰 본다. 놓기 전에는 조각을 뒤집지 않는다고 말해 준다.
5. 기름 조각은 작은 붙임쪽지 한 장에 '기름'을 써서 만든다. 아침 면의 '기름 자리'(돌 자리 위의 작은 칸)에 놓는다.
6. 이것들은 아이가 보지 않을 때 만들고, 조각은 앞면이 위로 오게 놓는다.
7. 1쪽(시작 쪽)을 아이 앞에 둔다. 판은 아이가 아무 면도 보지 않게 세워 들고 있다가, 아이가 고른 면이 위로 오게 내려놓는다. 다른 날 카드는 접은 채 옆에 둔다.
8. 아래 답지 안의 '준비'는 화면판으로 할 때의 준비다(종이 조각의 뒷면을 비워 두라는 말도 화면판용이다). 인쇄본으로 할 때는 이 절의 준비를 따른다.

| 답지(화면판)의 말 | 인쇄본에서 |
|---|---|
| 화면 맨 위 두 문단, 조각 세 개 | 1쪽(시작 쪽)의 두 문단과 조각 세 개 |
| 화면의 규칙 세 줄 | 1쪽의 규칙 네 줄(넷째 줄 '놓기 전에는 조각을 뒤집지 않아요'가 더 있다) |
| 밤 면(아침 면)을 누른다 | 판의 밤 면(아침 면)이 위로 오게 놓는다 |
| 보던 면을 닫고 다른 면을 눌러요 (판 뒤집기) | 판을 위아래로 뒤집어요 |
| 화면 앞에 가로로 눕혀(세로로 세워) 놓아요 | 판의 돌 자리에 가로로 눕혀(세로로 세워) 놓아요 |
| 놓은 조각의 뒷면을 눌러 봐요 / 뒷면 칸을 다시 닫아요 | 놓은 조각을 들어 뒷면 덮개를 들춰 봐요 / 덮개를 다시 덮고 앞면이 위로 오게 놓아요 |
| 다른 날 카드를 누른다 / 닫는다 | 다른 날 카드를 편다 / 편 채로 옆에 둔다 |
| 화면 옆에 따로 놓아요 | 다른 날 카드의 '우물 입구' 자리에 놓아요 |
| 일지의 '밤의 쓰임'('아침의 쓰임', '다른 날의 쓰임') 줄에 동그라미를 쳐요 | 판(다른 날 카드)의 쓰임 칸에 동그라미를 쳐요. 답지 7의 '일지의 쓰임 두 줄'도 판의 쓰임 칸 두 곳으로 읽는다. 일지에는 마지막에 옮겨 적는다 |
| 마지막을 누른다 | 종이에는 마지막 칸이 없다. 답지 8의 줄을 어른이 읽어 준다 |

## 실물 인쇄 여부

⚠️ 실물로 인쇄하고 접어 보지 않았다. 이 작업 환경에는 프린터가 없다. 그래서 종이의 비침, 집 프린터의 여백과 크기 맞춤, 접은 봉투가 저절로 펴지는지는 확인하지 못했다. 대표가 인쇄해 보면 아래 칸을 채운다.

## 플레이 시험 기록 (2026-11-23)

종이로 인쇄하지 않고, 판 PDF의 쪽 그림과 답지 PDF를 나란히 두고 혼자 두 역할(어른과 아이)로 판마다 두 길을 끝까지 따라갔다. 접기와 펴기, 연필로 쓰고 지우기, 붙임쪽지를 놓고 드는 일은 머릿속으로 했다. 실제 아이가 한 것은 아직 없다.

|---|---|---|
| 가 · 봉투 가 먼저 | 1쪽 제목 아래 두 문단 → 지도의 세 자리 → 곳의 이름 세 개 → 규칙 → 봉투 가를 편다(12장에서 세겜) → ①에 하란, ②·③ 가운데 하나에 세겜, 남은 칸에 벧엘 동쪽의 산을 연필로 쓴다 → 봉투 나를 편다(제단 뒤에 산) → 필요하면 두 칸을 지우고 맞바꿔 쓴다 → 확인 줄 카드를 펴서 지도 아래에 놓는다 → 답지 8을 어른이 읽는다 | 하란 → 세겜 → 벧엘 동쪽의 산. 일지 첫 줄 '하란을 떠난 날' |
| 가 · 봉투 나 먼저 | 봉투 나를 편다(12장에서 세겜, 그 뒤에 산) → ②에 세겜, ③에 벧엘 동쪽의 산, 남은 ①에 하란 → 봉투 가를 편다(①과 세겜 맞춤) → 확인 줄 카드 → 답지 8 | 같은 길. 일지 첫 줄 '여호와께서 나타나신 곳' |
| 나 · 밤 면 먼저 | 1쪽(시작 쪽)의 두 문단, 조각 세 개, 규칙 네 줄 → 판의 밤 면이 위로 → '돌' 조각을 ㉠에 가로로 놓고 뒷면 덮개를 들춰 봄(창세기 28장의 돌) → 28장에서 베개, ㉡에 동그라미 → 조각을 손에 들고 판을 위아래로 뒤집는다 → ㉢에 같은 조각을 세로로, 덮개 확인, 18절로 기둥과 기름, 기름 조각은 기름 자리에, ㉣에 동그라미 → 답지 7(두 번 뒤집기) → 답지 8 | 아침 면에 세운 ㉮와 기름, 쓰임 베개·기둥 |
| 나 · 아침 면 먼저, 큰 돌을 고름 | 1쪽 → 아침 면이 위로 → '큰 돌'을 ㉢에 세우고 덮개를 들춰 봄(창세기 29장의 돌) → 다른 날 카드를 펴서 큰 돌을 우물 입구 자리에 놓고, 29장에서 우물 아귀를 찾아 카드의 쓰임 칸에 동그라미 → 카드는 편 채로 옆에 → ㉢만 '돌'로 바꾸고 덮개 확인 → 18절 → 판을 뒤집어 밤 면 ㉠에 같은 조각, 11절, ㉡ → 다시 뒤집어 아침 자리에 세우고 기름 → 답지 7 → 답지 8 | 같은 모습. 일지에 큰 돌 줄도 적음 |

- 해 보며 고친 것
  - 답지 안의 '준비'(C17 화면판용)는 종이 조각 뒷면을 비워 두라고 한다. 인쇄본에서는 붙임쪽지 뒷면에 장을 써야 하므로, '인쇄본으로 할 때' 절에 '답지 안의 준비는 화면판용'이라는 줄을 넣었다.
  - 답지 7의 '일지의 쓰임 두 줄'이 인쇄본에서는 판의 쓰임 칸이라, 바꿔 읽는 표에 적었다.
- 바꿔 읽는 표: 답지의 진행 줄은 화면판(C17) 말이다. 인쇄본으로 할 때 어른이 바꿔 읽어야 하는 말은 판마다 6~8가지이고, 답지 PDF 맨 위 표에 모았다. ⚠️ 어른이 표를 보며 바꿔 읽는 것이 번거로운지는 해 보지 않았다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 아이 쪽과 답의 분리 | 정답, 절 번호, 어른 도움말, 일지 예시 답, 붙임쪽지 뒷면에 쓸 장 번호는 답지 PDF에만 있다. 판 PDF의 장절은 장까지만 있다. 돌 조각 뒷면의 장 번호는 덮개로 가리고, 놓은 다음에 들춰 본다 |
| 가위 | 판 PDF 어디에도 자르는 선이 없다. 접는 선(가 판 6곳: 봉투 둘과 확인 줄 카드에 2곳씩, 나 판 3곳: 뒤집기 판 1곳과 다른 날 카드 2곳)과 연필, 붙임쪽지만 쓴다 |
| 판 PDF의 글 | 이야기 줄은 C17 화면판과 같다. 『탐험대 이야기』 표시는 C17처럼 지도의 세 자리, 돌 자리, 쓰임 줄마다 붙였다. 새로 쓴 것은 나 판 1쪽의 '뒷면 덮개를 들춰 봐요', '놓기 전에는 조각을 뒤집지 않아요', 가 판 1쪽의 '곳의 이름이 섞여 버렸어요', '지도 칸에 이름을 써 봐요', 연필로 쓰고 지우는 규칙과 확인 줄 아래 줄, 봉투 겉의 '봉투 두 개 가운데 하나를 골라 먼저 열어요', 다른 날 카드의 '판에서 빼서 여기에 놓아요', 접는 선과 접는 법 줄이다 |
| 개역개정과 겹치는 말 | 판 PDF에서 뽑은 글을 창 12:1–9, 13:1–4 / 28:10–22, 29:1–10과 어절 단위·낱말 차례로 대조했다. 어절 단위 걸림은 0이다. 낱말 차례로 걸린 두 줄('여호와께서 하신 말씀대로 하란을 떠났어요', '여호와께서 아브람에게 나타나신 곳은')은 별도 검증을 마친 C01 봉투의 줄이다 |
| 한 쪽의 글 | 봉투 안쪽과 다른 날 카드 안쪽은 C17처럼 3문장 이하(물음 줄 따로)다. 판의 줄은 한 줄에 두 문장 이하다 |
| 『탐험대 이야기』 표시 | 판 이름, 봉투 이름, 다른 날 카드, 곳의 이름 목록, 규칙, 탐험대 줄에 붙였다. 본문 내용 줄('그림 대신: …')에는 장을 붙였다 |
| 말투 | 판에서 아이가 읽는 줄은 해요체다. 이 문서와 답지의 설명은 '-ㄴ다'로 쓴다 |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다 |
| 다시 만들기 | 판 PDF는 이 세션의 임시 스크립트(HTML을 짜서 브라우저로 PDF 인쇄)로 만들었다. 저장소에는 스크립트가 없다. 글을 고치면 같은 방법으로 다시 만들어야 한다 |

## 별도 내용 검증 (2026-11-23)

작성 과정을 보지 않은 검증자가 PDF 네 개를 직접 열어(쪽 그림, 낱말 자리), C17·C01·C02, 공통 규칙서와 대조하고 판마다 두 길을 따라갔다. 결과는 필수 5건, 권장 6건이었다. 쪽 수와 빈 면, 접는 선 위치, 석 장 접기의 겉과 뒤, 뒤집기 판, 판 PDF에 절 번호와 정답이 없는 것, 가 판 두 길의 완주는 문제없었다. 모두 반영하고 PDF를 다시 만들었다.

| 지적 | 고친 것 |
|---|---|
| 필수 1: 나 판에 C17 화면판의 첫 두 문단, 조각 세 개, 규칙이 없어 답지 1·3을 종이로 할 수 없음 | 나 판 1쪽에 시작 쪽(판 이름, 두 문단, 조각 세 개, 규칙 네 줄)을 더했다(나 판 2쪽 → 3쪽). 바꿔 읽는 표에 두 줄을 더했다 |
| 필수 2: 붙임쪽지 뒷면의 장 번호가 가려지지 않아, 조각을 집으면 답이 보임 | C02처럼 장 번호 위에 작은 붙임쪽지 덮개를 붙이고, 놓은 다음에 들추게 했다. 시작 쪽 규칙과 준비에 '놓기 전에는 조각을 뒤집지 않아요'를 넣었다 |
| 필수 3: 붙임쪽지의 모양과 크기가 없어 눕히기·세우기가 안 되고 돌 자리에 맞지 않음, 기름 조각이 돌을 덮음 | 가로로 긴 붙임쪽지(약 75×25mm, 없으면 정사각을 세 번 접음)로 정했다. 돌 자리를 가로 80×30mm, 세로 30×80mm, 우물 입구 80×30mm로 맞추고, 기름은 작은 붙임쪽지로 돌 자리 위의 따로 된 '기름 자리'에 놓게 했다 |
| 필수 4: 가 판 확인 줄을 뒤로 접으면 글이 판 뒷면 바깥을 향해 정답표가 됨 | 확인 줄을 1쪽에서 빼서 4쪽의 석 장 접기 카드로 만들었다(가 판 3쪽 → 4쪽). 확인할 때 펴서 지도 아래에 놓는다 |
| 필수 5: 답지 표에서 장절과 낱말이 줄바꿈으로 갈림, 점검표는 '없음'이라 적음 | 장절과 낱말을 줄바꿈하지 않게 묶고, 표 머리줄이 쪽마다 다시 나오게 했다. 점검표를 다시 적었다 |
| 권장 1: 놀이 중에 읽을 안내가 접는 선에 걸쳐 접으면 갈림 | 접는 선 글씨를 모두 선 위쪽으로 올렸다. '판을 뒤집을 때는 위아래로 뒤집어요'는 밤 면 아래에 따로 찍었다 |
| 권장 2: 무늬 칸의 흰 이름표가 막이에 구멍을 냄 | 이름표를 ① 접는 선 바로 아래로 옮겼다. 접으면 가운데 칸의 빈 아랫부분에 겹친다 |
| 권장 3: 나 답지 준비에 '아이가 보기 전에'가 없음, 판 PDF를 화면으로 보여 주면 안쪽이 보임 | 준비 1에 넣었다. '만든 파일' 아래에 '인쇄해 접은 종이로만 아이 앞에 둔다. 파일을 화면으로 보여 주지 않는다'를 적었다 |
| 권장 4: 답지 PDF의 쪽 표시·제목 정보·쪽 나눔 | 쪽마다 머리말('어른만 보는 쪽 · 정답 있음 · 파일 이름')과 쪽 번호, PDF 제목 정보를 넣었다. 제목만 쪽 끝에 남지 않게 했다 |
| 권장 5: 『탐험대 이야기』 표시가 C17보다 줄었음 | 지도의 세 자리, 돌 자리, 쓰임, 다른 날 카드의 돌 자리 줄마다 붙였다 |
| 권장 6: 기록과 답지 문구(접는 선 수, 가장자리 기준 5pt, 답지 PDF 안의 자기 가리킴, '자르지 않고 쓰는 방법'의 요점, '1쪽 맨 위 두 줄') | 접는 선 수를 고치고, 가장자리 기준을 6mm로 다시 점검했다. 답지 PDF에서 자기 가리킴 문장을 빼고, '자르지 않고 쓰는 방법' 절을 답지 PDF에 넣었다. 표를 '1쪽 제목 아래 두 문단'으로 고치고 '규칙' 줄을 더했다 |
