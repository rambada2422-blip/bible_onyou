# G16 · 요셉의 채색옷

## 카드 정보

| 항목 | 내용 |
|---|---|
| 장면 번호 | G16 |
| 근거 장절 | 창 37:1–4, 23–24, 41:42 (다른 장면) |
| 나이 단계 | 8~10세 (어른과 함께) |
| 질문과 보기 | 아버지 이스라엘이 요셉에게 지어 준 옷은 무엇일까요? 채색옷(창 37:3) / 세마포 옷(창 41:42, 오랜 뒤 바로가 입혀 준 옷) |
| 정답 근거 | 채색옷 · 창 37:3 |
| 성경 찾기 안내 | 아이에게는 책과 장(창세기 37장, 41장)까지 안내한다. 절은 어른 도움말로만 둔다 (공통 규칙서 5절) |
| 다른 장면 | 오랜 뒤 애굽에서 바로가 요셉에게 세마포 옷을 입힌 날 (창 41:42) 한 곳 |
| 준비물 | 아이의 성경책, 탐험 일지(종이)와 연필, 고르기 카드 두 장 |
| 참고 출처 | 성경 본문만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음. 형들이 요셉을 해치려 한 의논과 판 일(37:18–28)은 이 편에서 다루지 않았다 |
| 감수 상태 | 미감수 |

읽는 법
- **어른**은 어른이 읽는 줄이고, **최온**은 아이가 읽는 줄이다(최온은 탐험대의 10살 아이). 한 줄이 한 화면이다.
- **쉼**에서는 다음 줄로 넘어가지 말고 아이를 기다린다.
- 『탐험대 이야기』가 붙은 줄은 성경 본문이 아니다. 타임머신과 탐험 일지는 탐험대의 도구다. 과거의 장면에는 아무것도 남기지 않는다.
- 괄호 안의 장절과 '어른 도움말'은 소리 내어 읽지 않는다.

## 플레이 원고

### 칸 1 · 도착 (창 37:2–3)

- 보이는 것: 타임머신, 가나안의 야곱의 집, 양을 치는 젊은 요셉과 형들
- **어른** 『탐험대 이야기』: 타임머신이 가나안에 있는 야곱의 집에 왔어요.
- **최온**: 양을 치는 오빠들이 있어!
- **어른**: 열일곱 살 요셉도 형들과 같이 양을 돌봐요.
- → 칸 2로 간다.

### 칸 2 · 목격 (창 37:3)

- 보이는 것: 요셉에게 옷을 지어 주는 아버지
- **어른**: 아버지 이스라엘은 늘그막에 얻은 요셉을 다른 아들들보다 더 사랑했어요.
- **어른**: 그래서 요셉에게 옷을 지어 주었어요.
- → 칸 3으로 간다.

### 칸 3 · 목격 (창 37:4)

- 보이는 것: 요셉을 바라보는 형들
- **어른**: 아버지는 형들보다 요셉을 더 아꼈어요. 형들은 그 때문에 요셉을 미워했어요.
- **어른**: 형들은 요셉에게 다정하게 말을 걸지 못했어요.
- → 칸 4로 간다.

### 칸 4 · 고르기

- 보이는 것: 고르기 카드 두 장 (채색옷 / 세마포 옷)
- 칸 5에서 돌아왔으면 이 칸을 처음부터 다시 읽는다 (원래 장을 다시 편다).
- **어른**: 창세기 37장을 펴 볼까요? 아버지가 지어 준 옷의 이름을 찾아봐요. (어른 도움말: 3절)
- **쉼**: 아이가 옷의 이름을 찾을 때까지 기다린다.
- **어른**: 아버지 이스라엘이 요셉에게 지어 준 옷은 무엇일까요? 채색옷일까요, 세마포 옷일까요?
- 고르기
  - **채색옷** (창 37:3) → 칸 6으로 간다.
  - **세마포 옷** (창 41:42, 오랜 뒤 바로가 입혀 준 옷) → 칸 5로 간다.

### 칸 5 · 다른 장면: 바로가 입혀 준 옷 (창 41:42)

- 보이는 것: 애굽 바로의 궁, 세마포 옷을 입은 어른 요셉, 도장 반지, 금 사슬
- **어른** 『탐험대 이야기』: 타임머신이 오랜 뒤의 날, 애굽 바로의 궁으로 갔어요.
- **어른**: 바로는 요셉에게 자기 도장 반지를 주었어요. 세마포 옷을 입히고 금 사슬도 걸어 주었어요.
- **최온**: 이건 왕이 입혀 준 옷이야!
- **어른**: 창세기 41장을 펴 봐요. 바로가 요셉에게 입힌 옷은 무엇인가요? (어른 도움말: 42절)
- **쉼**: 아이가 '세마포 옷'을 찾을 때까지 기다린다.
- **어른**: 세마포 옷은 오랜 뒤 바로가 입혀 준 옷이에요. 아버지가 지어 준 옷이 아니에요.
- **어른** 『탐험대 이야기』: 가나안의 야곱의 집으로 돌아가요.
- → 칸 4로 돌아간다.

### 칸 6 · 발견 (창 37:3)

- 보이는 것: 채색옷을 입은 젊은 요셉
- **어른**: 찾았어요. 아버지가 지어 준 옷은 채색옷이에요.
- **어른**: 무엇을 보니 알 수 있었나요? 37장에 이스라엘이 요셉을 위해 채색옷을 지었다고 나와요.
- → 칸 7로 간다.

### 칸 7 · 목격 (창 37:23–24)

- 보이는 것: 물이 없는 빈 구덩이 (요셉이 다치는 모습은 그리지 않는다)
- **어른**: 나중에 요셉이 형들에게 갔어요. 형들은 요셉에게서 채색옷을 벗겨 냈어요.
- **어른**: 그리고 요셉을 물이 없는 빈 구덩이에 던졌어요.
- **최온**: 아버지가 지어 준 옷을 벗겨 버렸어.
- → 칸 8로 간다.

### 칸 8 · 기록

- 보이는 것: 탐험 일지
- **어른** 『탐험대 이야기』: 일지에 요셉의 옷을 차례대로 적어요.
- 칸 5에 가 보지 않았다면, 먼저 어른이 아이와 함께 창세기 41장을 펴서 바로가 요셉에게 입힌 옷을 찾는다. (어른 도움말: 42절)
- 일지에 적을 것
  - 아버지가 지어 준 옷: **채색옷** · 창세기 37장 3절
  - 형들이 벗겨 낸 옷 · 창세기 37장 23절 · 형들은 요셉에게서 채색옷을 벗겨 냈어요.
  - 오랜 뒤 바로가 입혀 준 옷: **세마포 옷** · 창세기 41장 42절
- (원하면) 한 문장 기도: 가족이 서로 미워하지 않고 아끼게 해 주세요.
- 끝.

## 아이용 요약

아버지 이스라엘은 요셉을 더 사랑해서 채색옷을 지어 주었어요. 형들은 요셉을 미워했고, 나중에 그 채색옷을 벗겼어요(창세기 37장). 세마포 옷은 오랜 뒤 애굽에서 바로가 요셉에게 입혀 준 옷이에요(창세기 41장).

## 녹음용 읽기 원고

한 줄이 한 칸이다. 줄 앞 번호와 괄호 안은 읽지 않는다. 각 줄은 어른 목소리로 시작한다. (최온)과 (어른)은 목소리를 바꾸는 자리다.

1. 타임머신이 가나안에 있는 야곱의 집에 왔어요. (최온) 양을 치는 오빠들이 있어! (어른) 열일곱 살 요셉도 형들과 같이 양을 돌봐요.
2. 아버지 이스라엘은 늘그막에 얻은 요셉을 다른 아들들보다 더 사랑했어요. 그래서 요셉에게 옷을 지어 주었어요.
3. 아버지는 형들보다 요셉을 더 아꼈어요. 형들은 그 때문에 요셉을 미워했어요. 형들은 요셉에게 다정하게 말을 걸지 못했어요.
4. 창세기 37장을 펴 볼까요? 아버지가 지어 준 옷의 이름을 찾아봐요. (쉼) 아버지 이스라엘이 요셉에게 지어 준 옷은 무엇일까요? 채색옷일까요, 세마포 옷일까요?
5. 타임머신이 오랜 뒤의 날, 애굽 바로의 궁으로 갔어요. 바로는 요셉에게 자기 도장 반지를 주었어요. 세마포 옷을 입히고 금 사슬도 걸어 주었어요. (최온) 이건 왕이 입혀 준 옷이야! (어른) 창세기 41장을 펴 봐요. 바로가 요셉에게 입힌 옷은 무엇인가요? (쉼) 세마포 옷은 오랜 뒤 바로가 입혀 준 옷이에요. 아버지가 지어 준 옷이 아니에요. 가나안의 야곱의 집으로 돌아가요.
6. 찾았어요. 아버지가 지어 준 옷은 채색옷이에요. 무엇을 보니 알 수 있었나요? 37장에 이스라엘이 요셉을 위해 채색옷을 지었다고 나와요.
7. 나중에 요셉이 형들에게 갔어요. 형들은 요셉에게서 채색옷을 벗겨 냈어요. 그리고 요셉을 물이 없는 빈 구덩이에 던졌어요. (최온) 아버지가 지어 준 옷을 벗겨 버렸어.
8. 일지에 요셉의 옷을 차례대로 적어요. 아버지가 지어 준 옷 채색옷, 창세기 37장 3절. 형들이 벗겨 낸 옷, 창세기 37장 23절, 형들은 요셉에게서 채색옷을 벗겨 냈어요. 오랜 뒤 바로가 입혀 준 옷 세마포 옷, 창세기 41장 42절.

## 작업자용 근거

| 원고의 내용 | 근거 |
|---|---|
| 요셉은 열일곱 살로 형들과 양을 침 (칸 1) | 창 37:2 |
| 이스라엘이 늘그막에 얻은 요셉을 더 사랑하여 채색옷을 지음 (칸 2·6) | 창 37:3 |
| 형들이 그것을 보고 요셉을 미워하여 다정하게 말하지 못함 (칸 3) | 창 37:4 |
| 형들에게 온 요셉에게서 채색옷을 벗겨 냄 (칸 7) | 창 37:23 |
| 요셉을 물 없는 빈 구덩이에 넣음 (칸 7) | 창 37:24 |
| 바로가 반지·세마포 옷·금 사슬을 줌 (칸 5) | 창 41:42 |

- 고르기 보기의 근거: 채색옷은 창 37:3, 세마포 옷은 창 41:42. 본문에 없는 보기는 쓰지 않았다.
- 칸 5의 차이 한 가지: 세마포 옷은 오랜 뒤 애굽에서 바로가 입혀 준 옷이다.
- 최온의 '색깔 있는 옷'은 '채색옷'을 아이 말로 옮긴 것이다. 옷의 무늬나 색은 본문이 밝히지 않으므로 그림에서 지나치게 꾸미지 않는다.
- 37:24대로 "던졌어요"로 옮겼다. 다치는 모습은 그리지 않는다.
- 개역개정 문장을 옮기지 않고 풀어 썼다(공통 규칙서 7절). 작업자용 근거 표도 요점만 적었다.
- 그림 주의: 하나님의 모습·손·그림자와 천사를 그리지 않는다. 탐험대 가운데 이 편에 나오는 아이는 최온이다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 채색옷을 고른 경로: 칸 1 → 2 → 3 → 4 → 6 → 7 → 8 | 칸 8에서 41장을 함께 펴고, 일지에 채색옷(37:3) → 벗긴 일(37:23) → 세마포 옷(41:42)이 차례대로 적힌다 |
| 세마포 옷을 고른 경로: 칸 1 → 2 → 3 → 4 → 5 → 4 → 6 → 7 → 8 | 바로가 입혀 준 옷과의 차이를 찾고, 칸 4에서 37장을 다시 편 뒤 같은 일지에 닿는다 |
| 한 화면의 글 | 어른과 최온의 줄은 한 줄에 한두 문장이다 |
| 말투 | 어른의 줄은 모두 존댓말이다 |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다 |

## 별도 내용 검증 (2026-11-23)

작성 과정을 보지 않은 검증자가 개역개정 원문과 공통 규칙서로 대조했다. 경로, 녹음 원고, 요약의 장 표기, 『탐험대 이야기』 표시는 문제 없음. 반영한 고침: 본문에 없는 '한 벌', '고운', '들'을 뺐다. 10살 여자아이 최온이 '형'이 아니라 '오빠'라고 부르게 했다. 37:2, 4, 23과 41:42의 문장 틀을 풀어 썼다. 37:24대로 '던졌어요'로 옮겼다. 근거 장절에 37:1을 더했다. 첫 칸을 최온의 관찰로 열었다.
