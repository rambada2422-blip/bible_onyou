# G01 · 빛과 땅

## 카드 정보

| 항목 | 내용 |
|---|---|
| 장면 번호 | G01 |
| 근거 장절 | 창 1:1–5, 9–13 |
| 나이 단계 | 8~10세 (어른과 함께) |
| 준비물 | 아이의 성경책, 일지 종이와 연필. 종이로 할 때는 '낮'·'밤' 이름표 두 장을 만들어 둔다 |
| 하는 방법 | 어른이 칸을 읽는다. 아이는 최온의 줄을 읽고, 고른 다음 적힌 칸으로 간다. 그림이 없어도 '보이는 것'의 물건 이름으로 진행한다 |
| 다른 장면 | 셋째 날 (창 1:9–13) 한 곳 |
| 참고 출처 | 성경 본문만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음. 다만 '창조의 날을 타임머신 창으로 본다'는 틀은 감수 때 한 번 확인받기를 권함 |
| 감수 상태 | 미감수 |

읽는 사람 표시: **어른**은 어른이 읽는 줄이다. **최온**은 아이가 읽는 줄이다(최온은 탐험대의 10살 아이). **쉼**에서는 다음 줄로 넘어가지 말고 아이를 기다린다. 『탐험대 이야기』는 성경 본문이 아닌 부분이다.

## 플레이 원고

### 칸 1 · 도착 『탐험대 이야기』

- 보이는 것: 타임머신 창, 캄캄함, 깊은 물
- **어른**: 타임머신이 아주 먼 처음으로 왔어요. 창밖이 온통 캄캄해요.
- **최온**: 아무것도 안 보여. 깊은 물만 있는 것 같아.
- **어른**: 창세기 1장 2절도 어둠과 깊은 물을 말해요.
- → 칸 2로 간다.

### 칸 2 · 목격 (창 1:3–4)

- 보이는 것: 빛 (하나님의 모습·손·그림자는 그리지 않는다. 빛만 보인다)
- **어른**: 하나님이 말씀하시자 빛이 생겼어요. 하나님은 빛과 어둠을 나누셨어요.
- **최온**: 와, 환해졌어!
- → 칸 3으로 간다.

### 칸 3 · 목격 (창 1:5)

- 보이는 것: 빛, 어둠, 이름표 두 장 ('낮', '밤')
- **어른**: 하나님은 빛과 어둠에 이름을 붙이셨어요. 저녁이 되고 아침이 되었어요. 첫째 날이에요.
- **최온**: 밝을 때와 어두울 때, 이름이 달라!
- → 칸 4로 간다.

### 칸 4 · 고르기

- 보이는 것: 이름표 '낮', 빛, 풀이 난 땅
- **어른**: 창세기 1장 5절을 펴 볼까? 빛에 붙은 이름을 찾아보자.
- **쉼**: 아이가 1장 5절을 찾을 때까지 기다린다.
- **어른**: '낮' 이름표는 어디에 붙여야 할까요?
- 고르기
  - **빛** (창 1:5) → 칸 6으로 간다.
  - **풀이 난 땅** (창 1:11–12, 셋째 날) → 칸 5로 간다.

### 칸 5 · 다른 장면: 셋째 날 (창 1:9–13)

- 보이는 것: 한 곳에 모인 물(바다), 마른 땅, 풀과 채소와 열매 맺는 나무
- **어른**: 타임머신이 셋째 날로 왔어요. 물이 한 곳에 모이고 마른 땅이 드러났어요.
- **어른**: 땅에서 풀과 채소와 나무가 났어요.
- **최온**: 여기는 풀이 있어! 그런데 이 땅에도 이름이 붙어 있을까?
- **어른**: 창세기 1장 10절을 펴 보자. 하나님이 마른 땅을 무엇이라고 부르셨지?
- **쉼**: 아이가 10절에서 '땅'과 '바다'를 찾을 때까지 기다린다.
- **어른**: 셋째 날에 붙은 이름은 '땅'과 '바다'예요. '낮'이라는 이름은 여기 없어요.
- **어른**: '낮'이 붙은 날로 돌아가요. 창세기 1장 5절을 다시 펴요.
- → 칸 4로 돌아간다.

### 칸 6 · 발견 (창 1:5)

- 보이는 것: '낮' 이름표가 붙은 빛, 어둠
- **어른**: 찾았어요. 하나님은 빛을 '낮'이라고 부르셨어요.
- **어른**: 무엇을 보니 알 수 있었나요? 창세기 1장 5절에 빛에 붙은 이름이 적혀 있었어요.
- **어른**: 그러면 '밤' 이름표는 어디에 붙일까요?
- **최온**: 어둠!
- **어른**: 맞아요. 하나님은 어둠을 '밤'이라고 부르셨어요. 같은 5절에 있어요.
- → 칸 7로 간다.

### 칸 7 · 기록

- 보이는 것: 탐험 일지
- **어른**: 일지에 오늘 찾은 것을 적어요.
- 일지에 적을 것
  - 물건 이름: **빛**
  - 장절: 창세기 1장 3~5절
  - 한 줄: 하나님이 빛을 '낮', 어둠을 '밤'이라고 부르셨어요.
- (원하면) 한 문장 기도: 빛을 지으신 하나님, 고맙습니다.
- 끝.

## 아이용 요약

첫째 날 하나님이 말씀하시자 빛이 생겼어요. 하나님은 빛을 '낮', 어둠을 '밤'이라고 부르셨어요(창세기 1장 3~5절). 풀과 나무가 난 것은 셋째 날이에요(창세기 1장 11~13절).

## 녹음용 읽기 원고

칸 번호와 장절 기호를 소리 내지 않도록 한 줄씩 적었다. 괄호 안은 읽지 않는다.

1. 타임머신이 아주 먼 처음으로 왔어요. 창밖이 온통 캄캄해요. (최온) 아무것도 안 보여. 깊은 물만 있는 것 같아. 창세기 1장 2절도 어둠과 깊은 물을 말해요.
2. 하나님이 말씀하시자 빛이 생겼어요. 하나님은 빛과 어둠을 나누셨어요. (최온) 와, 환해졌어!
3. 하나님은 빛과 어둠에 이름을 붙이셨어요. 저녁이 되고 아침이 되었어요. 첫째 날이에요. (최온) 밝을 때와 어두울 때, 이름이 달라!
4. 창세기 1장 5절을 펴 볼까? 빛에 붙은 이름을 찾아보자. (쉼) 낮 이름표는 어디에 붙여야 할까요? 빛일까요, 풀이 난 땅일까요?
5. 타임머신이 셋째 날로 왔어요. 물이 한 곳에 모이고 마른 땅이 드러났어요. 땅에서 풀과 채소와 나무가 났어요. (최온) 여기는 풀이 있어! 그런데 이 땅에도 이름이 붙어 있을까? 창세기 1장 10절을 펴 보자. 하나님이 마른 땅을 무엇이라고 부르셨지? (쉼) 셋째 날에 붙은 이름은 땅과 바다예요. 낮이라는 이름은 여기 없어요. 낮이 붙은 날로 돌아가요. 창세기 1장 5절을 다시 펴요.
6. 찾았어요. 하나님은 빛을 낮이라고 부르셨어요. 창세기 1장 5절에 빛에 붙은 이름이 적혀 있었어요. 그러면 밤 이름표는 어디에 붙일까요? (최온) 어둠! 맞아요. 하나님은 어둠을 밤이라고 부르셨어요.
7. 일지에 오늘 찾은 것을 적어요. 빛. 창세기 1장 3절에서 5절. 하나님이 빛을 낮, 어둠을 밤이라고 부르셨어요.

## 작업자용 근거

| 원고의 내용 | 근거 |
|---|---|
| 처음에 어둠과 깊은 물이 있었다 (칸 1) | 창 1:2 (흑암이 깊음 위에, 수면) |
| 하나님이 말씀하시자 빛이 생겼고, 빛과 어둠을 나누셨다 (칸 2) | 창 1:3–4 |
| 빛을 낮, 어둠을 밤이라고 부르셨다. 저녁과 아침, 첫째 날 (칸 3·6) | 창 1:5 |
| 물이 한 곳으로 모이고 마른 땅이 드러났다 (칸 5) | 창 1:9 |
| 마른 땅을 땅, 모인 물을 바다라고 부르셨다 (칸 5) | 창 1:10 |
| 땅이 풀과 채소와 열매 맺는 나무를 냈다. 셋째 날 (칸 5) | 창 1:11–13 |

- 고르기 보기의 근거: '빛'은 창 1:5, '풀이 난 땅'은 창 1:11–12(셋째 날). 본문에 없는 보기는 쓰지 않았다.
- 첫째 날과 셋째 날을 섞지 않는다: 풀이 난 땅은 칸 5(셋째 날)에만 나온다. 칸 1~3에는 풀과 땅을 두지 않는다.
- 성경 인물의 대사는 없다. 하나님의 말씀은 "말씀하시자"로만 전하고, 개역개정 문장을 옮기지 않았다(공통 규칙서 7절).
- 그림 주의: 하나님의 모습·손·그림자와 천사를 그리지 않는다. 칸 1의 타임머신과 세 아이는 『탐험대 이야기』다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 빛을 고른 경로: 칸 1 → 2 → 3 → 4 → 6 → 7 | 일지 '빛'에 닿는다 |
| 풀이 난 땅을 고른 경로: 칸 1 → 2 → 3 → 4 → 5 → 4 → 6 → 7 | 셋째 날에서 '땅'·'바다' 이름의 차이를 찾고, 창 1:5를 편 뒤 칸 4로 돌아와 일지 '빛'에 닿는다 |
| 한 화면의 글 | 어른과 최온의 줄은 한 줄에 한두 문장이다 (한 줄이 한 화면) |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다 |
| 인물의 속마음과 지어낸 대사 | 없다 |
