# G01 · 빛과 땅

## 카드 정보

| 항목 | 내용 |
|---|---|
| 장면 번호 | G01 |
| 근거 장절 | 창 1:1–5, 9–13 |
| 나이 단계 | 8~10세 (어른과 함께) |
| 질문과 보기 | 탐험 일지의 빛 사진에 붙일 이름표는 '낮'일까요? 빛 사진(창 1:5) / 풀이 난 땅 사진(창 1:11–12, 셋째 날) |
| 정답 근거 | 빛 · 창 1:5 |
| 성경 찾기 안내 | 아이에게는 책과 장(창세기 1장)까지 안내한다. 절은 어른 도움말로만 둔다 (공통 규칙서 5절) |
| 다른 장면 | 셋째 날 (창 1:9–13) 한 곳 |
| 준비물 | 아이의 성경책, 탐험 일지(종이)와 연필, 이름표 두 장('낮', '밤') |
| 참고 출처 | 성경 본문만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음. 다만 '창조의 날을 타임머신 창으로 본다'는 틀은 감수 때 한 번 확인받기를 권함 |
| 감수 상태 | 미감수 |

읽는 법
- **어른**은 어른이 읽는 줄이고, **최온**은 아이가 읽는 줄이다(최온은 탐험대의 10살 아이). 한 줄이 한 화면이다.
- **쉼**에서는 다음 줄로 넘어가지 말고 아이를 기다린다.
- 『탐험대 이야기』가 붙은 줄은 성경 본문이 아니다. 타임머신, 이름표, 탐험 일지는 탐험대의 도구다. 과거의 장면에는 아무것도 붙이거나 남기지 않는다.
- 괄호 안의 장절과 '어른 도움말'은 소리 내어 읽지 않는다.

## 플레이 원고

### 칸 1 · 도착 (창 1:2)

- 보이는 것: 타임머신 창, 캄캄함, 깊은 물
- **어른** 『탐험대 이야기』: 타임머신이 아주 먼 처음으로 왔어요. 창밖이 온통 캄캄해요.
- **최온**: 아무것도 안 보여. 깊은 물만 있는 것 같아.
- **어른**: 성경도 처음에 어둠과 깊은 물이 있었다고 말해요.
- → 칸 2로 간다.

### 칸 2 · 목격 (창 1:3–4)

- 보이는 것: 빛 (하나님의 모습·손·그림자는 그리지 않는다. 빛만 보인다)
- **어른**: 하나님이 말씀하시자 빛이 생겼어요. 하나님은 빛과 어둠을 나누셨어요.
- **최온**: 와, 환해졌어!
- → 칸 3으로 간다.

### 칸 3 · 목격 (창 1:5)

- 보이는 것: 빛, 어둠
- **어른**: 하나님은 빛과 어둠에 이름을 붙여 부르셨어요.
- **어른**: 저녁이 지나고 아침이 왔어요. 첫째 날이에요.
- **최온**: 밝을 때와 어두울 때, 이름이 달라!
- **어른** 『탐험대 이야기』: 빛과 어둠을 일지에 사진으로 담아 두어요.
- → 칸 4로 간다.

### 칸 4 · 고르기

- 보이는 것: 탐험 일지, 이름표 '낮', 고르기 카드 두 장 (빛 사진 / 풀이 난 땅 사진)
- 칸 5에서 돌아왔으면 이 칸을 처음부터 다시 읽는다 (원래 장을 다시 편다).
- **어른**: 창세기 1장을 펴 볼까요? 빛에 붙은 이름을 찾아봐요. (어른 도움말: 5절)
- **쉼**: 아이가 빛에 붙은 이름을 찾을 때까지 기다린다.
- **어른** 『탐험대 이야기』: '낮' 이름표는 어느 사진에 붙일까요? 빛일까요, 풀이 난 땅일까요?
- 고르기
  - **빛 사진** (창 1:5) → 칸 6으로 간다.
  - **풀이 난 땅 사진** (창 1:11–12, 셋째 날) → 칸 5로 간다.

### 칸 5 · 다른 장면: 셋째 날 (창 1:9–13)

- 보이는 것: 한데 모인 물(바다), 마른 땅, 풀과 채소와 열매가 열리는 나무
- **어른** 『탐험대 이야기』: 타임머신이 셋째 날로 왔어요.
- **어른**: 물이 한데 모이자 마른 땅이 나타났어요. 땅에서 풀과 채소와 나무가 자랐어요.
- **최온**: 여기는 풀이 있어! 이 땅에도 이름이 있을까?
- **어른**: 창세기 1장에서 셋째 날을 찾아봐요. 하나님이 마른 땅을 무엇이라고 부르셨나요? (어른 도움말: 10절)
- **쉼**: 아이가 '땅'과 '바다'를 찾을 때까지 기다린다.
- **어른**: 셋째 날에 붙은 이름은 '땅'과 '바다'예요. '낮'이라는 이름은 여기 없어요.
- **어른** 『탐험대 이야기』: '낮'이 붙은 첫째 날로 돌아가요.
- → 칸 4로 돌아간다.

### 칸 6 · 발견 (창 1:5)

- 보이는 것: 탐험 일지의 빛 사진과 '낮' 이름표
- **어른**: 찾았어요. 하나님은 빛을 '낮'이라고 부르셨어요.
- **어른**: 무엇을 보니 알 수 있었나요? 첫째 날 이야기에 빛에 붙은 이름이 적혀 있었어요.
- **어른** 『탐험대 이야기』: 그러면 '밤' 이름표는 어느 사진에 붙일까요?
- **최온**: 어둠!
- **어른**: 맞아요. 하나님은 어둠을 '밤'이라고 부르셨어요.
- → 칸 7로 간다.

### 칸 7 · 기록

- 보이는 것: 탐험 일지
- **어른** 『탐험대 이야기』: 일지에 오늘 찾은 것을 적어요.
- 일지에 적을 것
  - 물건 이름: **빛**
  - 장절: 창세기 1장 3~5절
  - 한 줄: 하나님이 빛을 '낮', 어둠을 '밤'이라고 부르셨어요.
- (원하면) 한 문장 기도: 빛을 지으신 하나님, 고맙습니다.
- 끝.

## 아이용 요약

첫째 날 하나님이 말씀하시자 빛이 생겼어요. 하나님은 빛을 '낮', 어둠을 '밤'이라고 부르셨어요(창세기 1장). 풀과 나무가 자란 것은 셋째 날이에요(창세기 1장).

## 녹음용 읽기 원고

한 줄이 한 칸이다. 줄 앞 번호와 괄호 안은 읽지 않는다. 각 줄은 어른 목소리로 시작한다. (최온)과 (어른)은 목소리를 바꾸는 자리다.

1. 타임머신이 아주 먼 처음으로 왔어요. 창밖이 온통 캄캄해요. (최온) 아무것도 안 보여. 깊은 물만 있는 것 같아. (어른) 성경도 처음에 어둠과 깊은 물이 있었다고 말해요.
2. 하나님이 말씀하시자 빛이 생겼어요. 하나님은 빛과 어둠을 나누셨어요. (최온) 와, 환해졌어!
3. 하나님은 빛과 어둠에 이름을 붙여 부르셨어요. 저녁이 지나고 아침이 왔어요. 첫째 날이에요. (최온) 밝을 때와 어두울 때, 이름이 달라! (어른) 빛과 어둠을 일지에 사진으로 담아 두어요.
4. 창세기 1장을 펴 볼까요? 빛에 붙은 이름을 찾아봐요. (쉼) '낮' 이름표는 어느 사진에 붙일까요? 빛일까요, 풀이 난 땅일까요?
5. 타임머신이 셋째 날로 왔어요. 물이 한데 모이자 마른 땅이 나타났어요. 땅에서 풀과 채소와 나무가 자랐어요. (최온) 여기는 풀이 있어! 이 땅에도 이름이 있을까? (어른) 창세기 1장에서 셋째 날을 찾아봐요. 하나님이 마른 땅을 무엇이라고 부르셨나요? (쉼) 셋째 날에 붙은 이름은 '땅'과 '바다'예요. '낮'이라는 이름은 여기 없어요. '낮'이 붙은 첫째 날로 돌아가요.
6. 찾았어요. 하나님은 빛을 '낮'이라고 부르셨어요. 무엇을 보니 알 수 있었나요? 첫째 날 이야기에 빛에 붙은 이름이 적혀 있었어요. 그러면 '밤' 이름표는 어느 사진에 붙일까요? (최온) 어둠! (어른) 맞아요. 하나님은 어둠을 '밤'이라고 부르셨어요.
7. 일지에 오늘 찾은 것을 적어요. 빛. 창세기 1장 3절에서 5절. 하나님이 빛을 '낮', 어둠을 '밤'이라고 부르셨어요.

## 작업자용 근거

| 원고의 내용 | 근거 |
|---|---|
| 처음에 어둠과 깊은 물이 있었다 (칸 1) | 창 1:2 |
| 하나님이 말씀하시자 빛이 생겼고, 빛과 어둠을 나누셨다 (칸 2) | 창 1:3–4 |
| 빛과 어둠에 낮과 밤이라는 이름을 붙이셨다. 저녁과 아침, 첫째 날 (칸 3·6) | 창 1:5 |
| 물이 한데 모이고 마른 땅이 나타났다 (칸 5) | 창 1:9 |
| 마른 땅은 땅, 모인 물은 바다라고 부르셨다 (칸 5) | 창 1:10 |
| 땅에서 풀과 채소와 열매가 열리는 나무가 자랐다. 셋째 날 (칸 5) | 창 1:11–13 |

- 고르기 보기의 근거: 빛 사진은 창 1:5, 풀이 난 땅 사진은 창 1:11–12(셋째 날). 본문에 없는 보기는 쓰지 않았다.
- 첫째 날과 셋째 날을 섞지 않는다: 풀이 난 땅은 칸 5(셋째 날)와 고르기 카드에만 나온다. 칸 1~3의 장면에는 풀과 땅을 두지 않는다.
- 이름표는 탐험대의 일지 도구다. 아이는 과거의 빛에 이름표를 붙이지 않고 일지 사진에 붙인다(공통 규칙서 3.3, 12절).
- 성경 인물의 대사는 없다. 하나님의 말씀은 "말씀하시자"로만 전한다. 개역개정 문장을 옮기지 않고 풀어 썼다(공통 규칙서 7절).
- 그림 주의: 하나님의 모습·손·그림자와 천사를 그리지 않는다. 탐험대 가운데 이 편에 나오는 아이는 최온이다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 빛 사진을 고른 경로: 칸 1 → 2 → 3 → 4 → 6 → 7 | 일지 '빛'에 닿는다 |
| 풀이 난 땅 사진을 고른 경로: 칸 1 → 2 → 3 → 4 → 5 → 4 → 6 → 7 | 셋째 날의 이름 '땅'·'바다'로 차이를 찾고, 칸 4의 물음으로 돌아와 일지 '빛'에 닿는다 |
| 한 화면의 글 | 어른과 최온의 줄은 한 줄에 한두 문장이다 |
| 말투 | 어른의 줄은 모두 존댓말이다 |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다 |
| 인물의 속마음과 지어낸 대사 | 없다 |

## 별도 내용 검증 (2026-11-23)

작성 과정을 보지 않은 검증자가 창 1장 원문과 공통 규칙서로 첫 원고를 대조했다.

- 사실과 장절: 문제 없음.
- 반영한 고침
  - 개역개정 어구를 그대로 옮긴 곳(저녁과 아침, 물이 모이고 땅이 드러남, 열매 맺는 나무)을 풀어 썼다.
  - 이름표를 과거의 장면이 아니라 일지 사진에 붙이게 했다.
  - 타임머신이 움직이는 줄에 『탐험대 이야기』 표시를 달았다.
  - 고르기 화면에서 풀이 난 땅을 장면이 아닌 고르기 카드로 바꿨다.
  - 돌아왔을 때 다시 읽을 곳을 적었다.
  - 한 줄 세 문장을 나눴고, 어른의 말투를 존댓말로 맞췄다.
  - 녹음 원고에 목소리 바꿈 표시를 넣었다.
  - 카드 정보에 질문과 보기, 정답 근거를 더했다.
- 규칙서와 지시서의 차이: 지시서 예시는 8~10세에게 절까지 알려 주지만, 공통 규칙서 5절은 '책 이름과 장까지 안내'다. 규칙서를 따르고, 절은 어른 도움말로 두었다. 인계에 보고했다.
