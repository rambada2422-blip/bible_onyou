# G13 · 이삭이 태어난 날

## 카드 정보

| 항목 | 내용 |
|---|---|
| 장면 번호 | G13 |
| 근거 장절 | 창 21:1–7, 25:24–26 (다른 장면) |
| 나이 단계 | 8~10세 (어른과 함께) |
| 질문과 보기 | 아브라함이 사라가 낳은 아들에게 지어 준 이름은 무엇일까요? 이삭(창 21:3) / 에서(창 25:25, 이삭의 쌍둥이 아들) |
| 정답 근거 | 이삭 · 창 21:3 |
| 성경 찾기 안내 | 아이에게는 책과 장(창세기 21장, 25장)까지 안내한다. 절은 어른 도움말로만 둔다 (공통 규칙서 5절) |
| 다른 장면 | 리브가가 쌍둥이 에서와 야곱을 낳은 날 (창 25:24–26) 한 곳 |
| 준비물 | 아이의 성경책, 탐험 일지(종이)와 연필, 고르기 카드 두 장 |
| 참고 출처 | 성경 본문만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음. 이삭이라는 이름의 뜻은 본문이 이 자리에서 풀지 않으므로 쓰지 않았다 |
| 감수 상태 | 미감수 |

읽는 법
- **어른**은 어른이 읽는 줄이고, **최온**은 아이가 읽는 줄이다(최온은 탐험대의 10살 아이). 한 줄이 한 화면이다.
- **쉼**에서는 다음 줄로 넘어가지 말고 아이를 기다린다.
- 『탐험대 이야기』가 붙은 줄은 성경 본문이 아니다. 타임머신과 탐험 일지는 탐험대의 도구다. 과거의 장면에는 아무것도 남기지 않는다.
- 괄호 안의 장절과 '어른 도움말'은 소리 내어 읽지 않는다.

## 플레이 원고

### 칸 1 · 도착 (창 21:1–2)

- 보이는 것: 타임머신, 아브라함과 사라가 사는 곳, 갓난아기
- **어른** 『탐험대 이야기』: 타임머신이 아브라함과 사라가 사는 곳에 왔어요.
- **최온**: 아기가 있어!
- **어른**: 여호와께서는 사라에게 하신 약속을 지키셨어요.
- **어른**: 하나님이 정하신 때가 되자 사라가 아들을 낳았어요.
- **어른**: 아브라함은 나이가 아주 많았어요.
- → 칸 2로 간다.

### 칸 2 · 목격 (창 21:5)

- 보이는 것: 아브라함과 갓난아기
- **어른**: 아들이 태어났을 때 아브라함은 백 살이었어요.
- **최온**: 백 살에 아기를 얻었어!
- → 칸 3으로 간다.

### 칸 3 · 고르기

- 보이는 것: 고르기 카드 두 장 (이삭 / 에서)
- 칸 4에서 돌아왔으면 이 칸을 처음부터 다시 읽는다 (원래 장을 다시 편다).
- **어른**: 창세기 21장을 펴 볼까요? 아브라함이 아들에게 지어 준 이름을 찾아봐요. (어른 도움말: 3절)
- **쉼**: 아이가 아들의 이름을 찾을 때까지 기다린다.
- **어른**: 아브라함이 사라가 낳은 아들에게 지어 준 이름은 무엇일까요? 이삭일까요, 에서일까요?
- 고르기
  - **이삭** (창 21:3) → 칸 5로 간다.
  - **에서** (창 25:25, 이삭의 쌍둥이 아들) → 칸 4로 간다.

### 칸 4 · 다른 장면: 쌍둥이가 태어난 날 (창 25:24–26)

- 보이는 것: 갓난 쌍둥이, 리브가와 이삭
- **어른** 『탐험대 이야기』: 타임머신이 훨씬 뒤의 날로 갔어요.
- **어른**: 이삭의 아내 리브가가 쌍둥이를 낳았어요. 먼저 태어난 형의 이름은 에서예요.
- **어른**: 에서는 몸이 붉고 털이 많았어요.
- **어른**: 동생은 형의 발뒤꿈치를 붙잡고 나와서 야곱이라고 불렀어요.
- **최온**: 여기는 쌍둥이 아기야!
- **어른**: 창세기 25장을 펴 봐요. 먼저 나온 아이의 이름은 무엇인가요? (어른 도움말: 25절)
- **쉼**: 아이가 '에서'를 찾을 때까지 기다린다.
- **어른**: 에서는 이삭의 아들이에요. 아브라함과 사라가 얻은 아들의 이름이 아니에요.
- **어른** 『탐험대 이야기』: 아브라함과 사라가 사는 곳으로 돌아가요.
- → 칸 3으로 돌아간다.

### 칸 5 · 발견 (창 21:3, 6–7)

- 보이는 것: 아기 이삭, 웃는 사라
- **어른**: 찾았어요. 아브라함은 아들의 이름을 이삭이라고 지었어요.
- **어른**: 무엇을 보니 알 수 있었나요? 21장에 아브라함이 사라가 낳은 아들을 이삭이라 불렀다고 나와요.
- **어른**: 사라는 하나님이 자기를 웃게 하셨다고 말했어요. 이 소식을 듣는 사람도 다 함께 웃을 것이라고 했어요.
- **최온**: 아기 때문에 모두 웃게 되는구나!
- → 칸 6으로 간다.

### 칸 6 · 기록

- 보이는 것: 탐험 일지
- **어른** 『탐험대 이야기』: 일지에 오늘 찾은 것을 적어요.
- 일지에 적을 것
  - 사람: **이삭** · 창세기 21장 3절, 5절 · 아브라함이 백 살에 얻은 아들이에요.
  - 사라의 말 · 창세기 21장 6절 · 하나님이 자기를 웃게 하셨다고 했어요.
- (원하면) 한 문장 기도: 약속하신 대로 이루시는 하나님, 고맙습니다.
- 끝.

## 아이용 요약

여호와께서 약속을 지키셔서 사라가 아들을 낳았어요. 아브라함은 백 살이었고, 아들의 이름을 이삭이라고 지었어요. 사라는 하나님이 자기를 웃게 하셨다고 말했어요(창세기 21장). 에서는 그 뒤 이삭이 얻은 쌍둥이 아들이에요(창세기 25장).

## 녹음용 읽기 원고

한 줄이 한 칸이다. 줄 앞 번호와 괄호 안은 읽지 않는다. 각 줄은 어른 목소리로 시작한다. (최온)과 (어른)은 목소리를 바꾸는 자리다.

1. 타임머신이 아브라함과 사라가 사는 곳에 왔어요. (최온) 아기가 있어! (어른) 여호와께서는 사라에게 하신 약속을 지키셨어요. 하나님이 정하신 때가 되자 사라가 아들을 낳았어요. 아브라함은 나이가 아주 많았어요.
2. 아들이 태어났을 때 아브라함은 백 살이었어요. (최온) 백 살에 아기를 얻었어!
3. 창세기 21장을 펴 볼까요? 아브라함이 아들에게 지어 준 이름을 찾아봐요. (쉼) 아브라함이 사라가 낳은 아들에게 지어 준 이름은 무엇일까요? 이삭일까요, 에서일까요?
4. 타임머신이 훨씬 뒤의 날로 갔어요. 이삭의 아내 리브가가 쌍둥이를 낳았어요. 먼저 태어난 형의 이름은 에서예요. 에서는 몸이 붉고 털이 많았어요. 동생은 형의 발뒤꿈치를 붙잡고 나와서 야곱이라고 불렀어요. (최온) 여기는 쌍둥이 아기야! (어른) 창세기 25장을 펴 봐요. 먼저 나온 아이의 이름은 무엇인가요? (쉼) 에서는 이삭의 아들이에요. 아브라함과 사라가 얻은 아들의 이름이 아니에요. 아브라함과 사라가 사는 곳으로 돌아가요.
5. 찾았어요. 아브라함은 아들의 이름을 이삭이라고 지었어요. 무엇을 보니 알 수 있었나요? 21장에 아브라함이 사라가 낳은 아들을 이삭이라 불렀다고 나와요. 사라는 하나님이 자기를 웃게 하셨다고 말했어요. 이 소식을 듣는 사람도 다 함께 웃을 것이라고 했어요. (최온) 아기 때문에 모두 웃게 되는구나!
6. 일지에 오늘 찾은 것을 적어요. 이삭, 창세기 21장 3절, 5절, 아브라함이 백 살에 얻은 아들이에요. 사라의 말, 창세기 21장 6절, 하나님이 자기를 웃게 하셨다고 했어요.

## 작업자용 근거

| 원고의 내용 | 근거 |
|---|---|
| 약속대로 사라를 돌보심 (칸 1) | 창 21:1 |
| 정하신 때에 사라가 아들을 낳음. 아브라함은 나이가 많음 (칸 1) | 창 21:2 |
| 아브라함이 그 아들을 이삭이라 부름 (칸 5) | 창 21:3 |
| 이삭이 태어날 때 아브라함은 백 살 (칸 2) | 창 21:5 |
| 사라의 말: 하나님이 자기를 웃게 하셨고, 듣는 이도 함께 웃으리라 (칸 5) | 창 21:6 |
| 리브가가 쌍둥이를 낳음. 먼저 나온 아이는 붉고 털이 많아 에서, 동생은 발뒤꿈치를 잡아 야곱 (칸 4) | 창 25:24–26 |

- 고르기 보기의 근거: 이삭은 창 21:3, 에서는 창 25:25. 본문에 없는 보기는 쓰지 않았다.
- 칸 4의 차이 한 가지: 에서는 이삭이 얻은 아들이다(다른 세대).
- 21:4(여드레 만의 할례)는 8~10세 원고에서 다루지 않았다.
- 개역개정 문장을 옮기지 않고 풀어 썼다(공통 규칙서 7절). 작업자용 근거 표도 요점만 적었다.
- 그림 주의: 하나님의 모습·손·그림자와 천사를 그리지 않는다. 탐험대 가운데 이 편에 나오는 아이는 최온이다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 이삭을 고른 경로: 칸 1 → 2 → 3 → 5 → 6 | 일지에 이삭(21:3, 5)과 사라의 말(21:6)이 적힌다 |
| 에서를 고른 경로: 칸 1 → 2 → 3 → 4 → 3 → 5 → 6 | 다른 세대의 아들이라는 차이를 찾고, 칸 3에서 21장을 다시 편 뒤 같은 일지에 닿는다 |
| 한 화면의 글 | 어른과 최온의 줄은 한 줄에 한두 문장이다 |
| 말투 | 어른의 줄은 모두 존댓말이다 |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다 |

## 별도 내용 검증 (2026-11-23)

작성 과정을 보지 않은 검증자가 개역개정 원문과 공통 규칙서로 대조했다. 경로, 녹음 원고, 요약의 장 표기, 『탐험대 이야기』 표시는 문제 없음. 반영한 고침: 21:1–2, 25:25의 문장 틀을 풀어 썼다. 21:1–7에 나오지 않는 '장막'과 '아기를 안은'을 뺐다. 사라의 말은 간접 화법('자기를')으로 고쳤다.
