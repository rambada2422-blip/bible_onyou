# G11 · 노아의 방주

## 카드 정보

| 항목 | 내용 |
|---|---|
| 장면 번호 | G11 |
| 근거 장절 | 창 6:14–16, 22, 11:3–4 (다른 장면) |
| 나이 단계 | 8~10세 (어른과 함께) |
| 질문과 보기 | 노아가 방주를 만든 재료는 무엇일까요? 고페르 나무(창 6:14) / 구운 벽돌(창 11:3, 사람들이 탑을 쌓던 날) |
| 정답 근거 | 고페르 나무 · 창 6:14 |
| 성경 찾기 안내 | 아이에게는 책과 장(창세기 6장, 11장)까지 안내한다. 절은 어른 도움말로만 둔다 (공통 규칙서 5절) |
| 다른 장면 | 사람들이 구운 벽돌로 성과 탑을 쌓던 날 (창 11:3–4) 한 곳 |
| 준비물 | 아이의 성경책, 탐험 일지(종이)와 연필, 고르기 카드 두 장 |
| 참고 출처 | 성경 본문만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음. 방주를 만든 까닭인 홍수 심판(6:13, 17)은 이 편에서 풀지 않았다. 감수 때 까닭을 말할지 확인받기를 권함 |
| 감수 상태 | 미감수 |

읽는 법
- **어른**은 어른이 읽는 줄이고, **최온**은 아이가 읽는 줄이다(최온은 탐험대의 10살 아이). 한 줄이 한 화면이다.
- **쉼**에서는 다음 줄로 넘어가지 말고 아이를 기다린다.
- 『탐험대 이야기』가 붙은 줄은 성경 본문이 아니다. 타임머신과 탐험 일지는 탐험대의 도구다. 과거의 장면에는 아무것도 남기지 않는다.
- 괄호 안의 장절과 '어른 도움말'은 소리 내어 읽지 않는다.

## 플레이 원고

### 칸 1 · 도착 (창 6:14)

- 보이는 것: 타임머신, 노아, 쌓아 둔 나무
- **어른** 『탐험대 이야기』: 타임머신이 노아가 살던 때로 왔어요.
- **최온**: 나무가 잔뜩 있어. 아주 큰 걸 만드나 봐!
- → 칸 2로 간다.

### 칸 2 · 목격 (창 6:14)

- 보이는 것: 노아 (하나님의 모습은 그리지 않는다)
- **어른**: 하나님은 노아에게 방주라는 큰 배를 만들라고 말씀하셨어요.
- **어른**: 안에는 방을 여러 칸 만들고, 안팎에는 역청이라는 검은 칠을 하라고 하셨어요.
- → 칸 3으로 간다.

### 칸 3 · 목격 (창 6:15–16)

- 보이는 것: 길고 높은 방주, 창, 옆으로 난 문, 세 층
- **어른**: 방주는 아주 길고 넓고 높게 짓게 하셨어요.
- **어른**: 위쪽에 창을 내고, 문은 옆쪽에 달고, 세 층으로 지으라고 하셨어요.
- **최온**: 문이 옆에 있대!
- → 칸 4로 간다.

### 칸 4 · 고르기

- 보이는 것: 고르기 카드 두 장 (고페르 나무 / 구운 벽돌)
- 칸 5에서 돌아왔으면 이 칸을 처음부터 다시 읽는다 (원래 장을 다시 편다).
- **어른**: 창세기 6장을 펴 볼까요? 방주를 만들 나무의 이름을 찾아봐요. (어른 도움말: 14절)
- **쉼**: 아이가 나무 이름을 찾을 때까지 기다린다.
- **어른**: 노아가 방주를 만든 재료는 무엇일까요? 고페르 나무일까요, 구운 벽돌일까요?
- 고르기
  - **고페르 나무** (창 6:14) → 칸 6으로 간다.
  - **구운 벽돌** (창 11:3, 사람들이 탑을 쌓던 날) → 칸 5로 간다.

### 칸 5 · 다른 장면: 벽돌로 쌓은 탑 (창 11:3–4)

- 보이는 것: 구운 벽돌 더미, 쌓아 올리는 탑과 성
- **어른** 『탐험대 이야기』: 타임머신이 훨씬 뒤의 날, 사람들이 탑을 쌓던 곳으로 갔어요.
- **어른**: 사람들은 돌 대신 단단히 구운 벽돌을 썼어요. 벽돌 사이는 역청으로 붙였어요.
- **어른**: 꼭대기가 하늘에 닿는 탑을 쌓아 이름을 내자고 했어요.
- **최온**: 여기서는 벽돌로 탑을 쌓고 있어!
- **어른**: 창세기 11장을 펴 봐요. 사람들은 무엇을 구워 돌 대신 썼나요? (어른 도움말: 3절)
- **쉼**: 아이가 '벽돌'을 찾을 때까지 기다린다.
- **어른**: 벽돌은 탑을 쌓을 때 쓴 재료예요. 방주의 재료가 아니에요.
- **어른** 『탐험대 이야기』: 노아가 방주를 만들던 때로 돌아가요.
- → 칸 4로 돌아간다.

### 칸 6 · 발견 (창 6:14)

- 보이는 것: 고페르 나무로 짓는 방주
- **어른**: 찾았어요. 방주는 고페르 나무로 만들었어요.
- **어른**: 무엇을 보니 알 수 있었나요? 6장에서 하나님이 고페르 나무로 방주를 만들라고 하셨어요.
- **최온**: 커다란 나무 배구나!
- → 칸 7로 간다.

### 칸 7 · 목격 (창 6:22)

- 보이는 것: 다 지어진 방주와 노아
- **어른**: 노아는 하나님이 시키신 대로 모두 그대로 했어요.
- → 칸 8로 간다.

### 칸 8 · 기록

- 보이는 것: 탐험 일지
- **어른** 『탐험대 이야기』: 일지에 방주에서 찾은 두 가지를 적어요.
- 일지에 적을 것
  - 재료: **고페르 나무** · 창세기 6장 14절 · 하나님이 이 나무로 방주를 만들라고 하셨어요.
  - 문: **옆쪽에 단 문** · 창세기 6장 16절 · 방주의 문은 옆에 냈어요.
- (원하면) 한 문장 기도: 노아처럼 하나님 말씀대로 하게 해 주세요.
- 끝.

## 아이용 요약

하나님은 노아에게 고페르 나무로 방주를 만들라고 하셨어요. 문은 옆에 내고 세 층으로 짓게 하셨어요(창세기 6장). 노아는 시키신 대로 모두 했어요. 구운 벽돌로 탑을 쌓은 것은 훨씬 뒤의 일이에요(창세기 11장).

## 녹음용 읽기 원고

한 줄이 한 칸이다. 줄 앞 번호와 괄호 안은 읽지 않는다. 각 줄은 어른 목소리로 시작한다. (최온)과 (어른)은 목소리를 바꾸는 자리다.

1. 타임머신이 노아가 살던 때로 왔어요. (최온) 나무가 잔뜩 있어. 아주 큰 걸 만드나 봐!
2. 하나님은 노아에게 방주라는 큰 배를 만들라고 말씀하셨어요. 안에는 방을 여러 칸 만들고, 안팎에는 역청이라는 검은 칠을 하라고 하셨어요.
3. 방주는 아주 길고 넓고 높게 짓게 하셨어요. 위쪽에 창을 내고, 문은 옆쪽에 달고, 세 층으로 지으라고 하셨어요. (최온) 문이 옆에 있대!
4. 창세기 6장을 펴 볼까요? 방주를 만들 나무의 이름을 찾아봐요. (쉼) 노아가 방주를 만든 재료는 무엇일까요? 고페르 나무일까요, 구운 벽돌일까요?
5. 타임머신이 훨씬 뒤의 날, 사람들이 탑을 쌓던 곳으로 갔어요. 사람들은 돌 대신 단단히 구운 벽돌을 썼어요. 벽돌 사이는 역청으로 붙였어요. 꼭대기가 하늘에 닿는 탑을 쌓아 이름을 내자고 했어요. (최온) 여기서는 벽돌로 탑을 쌓고 있어! (어른) 창세기 11장을 펴 봐요. 사람들은 무엇을 구워 돌 대신 썼나요? (쉼) 벽돌은 탑을 쌓을 때 쓴 재료예요. 방주의 재료가 아니에요. 노아가 방주를 만들던 때로 돌아가요.
6. 찾았어요. 방주는 고페르 나무로 만들었어요. 무엇을 보니 알 수 있었나요? 6장에서 하나님이 고페르 나무로 방주를 만들라고 하셨어요. (최온) 커다란 나무 배구나!
7. 노아는 하나님이 시키신 대로 모두 그대로 했어요.
8. 일지에 방주에서 찾은 두 가지를 적어요. 재료 고페르 나무, 창세기 6장 14절, 하나님이 이 나무로 방주를 만들라고 하셨어요. 문 옆쪽에 단 문, 창세기 6장 16절, 방주의 문은 옆에 냈어요.

## 작업자용 근거

| 원고의 내용 | 근거 |
|---|---|
| 고페르 나무로 방주를 만들고, 안에 칸을 막고, 안팎에 역청을 칠하라 하심 (칸 2·6) | 창 6:14 |
| 방주의 길이·너비·높이를 정해 주심 (칸 3) | 창 6:15 |
| 창을 내고, 문은 옆에, 세 층으로 (칸 3) | 창 6:16 |
| 노아가 하나님이 시키신 대로 다 함 (칸 7) | 창 6:22 |
| 사람들이 돌 대신 구운 벽돌, 진흙 대신 역청을 씀 (칸 5) | 창 11:3 |
| 꼭대기가 하늘에 닿는 탑을 쌓아 이름을 내자고 함 (칸 5) | 창 11:4 |

- 고르기 보기의 근거: 고페르 나무는 창 6:14, 구운 벽돌은 창 11:3. 본문에 없는 보기는 쓰지 않았다.
- 칸 5의 차이 한 가지: 11장의 벽돌은 탑을 쌓을 때의 재료다. 역청은 두 장면에 다 나오므로 차이로 쓰지 않았다.
- 방주의 크기(삼백·오십·삼십 규빗)는 8~10세 원고에서 숫자 대신 "아주 길고 넓고 높게"로만 옮겼다.
- 칸 1의 나무 더미는 방주를 짓는 장면을 보이려는 그림 설명이다. 본문은 노아가 시키신 대로 다 했다고만 한다(6:22).
- 개역개정 문장을 옮기지 않고 풀어 썼다(공통 규칙서 7절). 작업자용 근거 표도 요점만 적었다.
- 그림 주의: 하나님의 모습·손·그림자와 천사를 그리지 않는다. 탐험대 가운데 이 편에 나오는 아이는 최온이다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 고페르 나무를 고른 경로: 칸 1 → 2 → 3 → 4 → 6 → 7 → 8 | 일지에 고페르 나무(6:14)와 옆쪽 문(6:16)이 적힌다 |
| 구운 벽돌을 고른 경로: 칸 1 → 2 → 3 → 4 → 5 → 4 → 6 → 7 → 8 | 탑을 쌓은 재료와의 차이를 찾고, 칸 4에서 6장을 다시 편 뒤 같은 일지에 닿는다 |
| 한 화면의 글 | 어른과 최온의 줄은 한 줄에 한두 문장이다 |
| 말투 | 어른의 줄은 모두 존댓말이다 |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다 |
