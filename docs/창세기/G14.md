# G14 · 팥죽과 바꾼 것

## 카드 정보

| 항목 | 내용 |
|---|---|
| 장면 번호 | G14 |
| 근거 장절 | 창 25:27–34, 27:1, 26–27, 36 (다른 장면) |
| 나이 단계 | 8~10세 (어른과 함께) |
| 질문과 보기 | 에서가 팥죽을 받고 야곱에게 판 것은 무엇일까요? 장자의 명분(창 25:31–33) / 아버지의 축복(창 27:27, 다른 날 이삭이 야곱에게 빈 것) |
| 정답 근거 | 장자의 명분 · 창 25:33 |
| 낱말 풀이 | 장자의 명분: 맏아들이 받는 자리와 몫. 아이에게는 '맏아들의 자리'라고 풀어 준다 |
| 성경 찾기 안내 | 아이에게는 책과 장(창세기 25장, 27장)까지 안내한다. 절은 어른 도움말로만 둔다 (공통 규칙서 5절) |
| 다른 장면 | 나이 든 이삭이 야곱에게 복을 빌어 준 날 (창 27:27, 36) 한 곳 |
| 준비물 | 아이의 성경책, 탐험 일지(종이)와 연필, 고르기 카드 두 장 |
| 참고 출처 | 성경 본문만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음. 27장에서 야곱이 복을 받은 경위는 이 편에서 풀지 않았다 |
| 감수 상태 | 미감수 |

읽는 법
- **어른**은 어른이 읽는 줄이고, **최온**은 아이가 읽는 줄이다(최온은 탐험대의 10살 아이). 한 줄이 한 화면이다.
- **쉼**에서는 다음 줄로 넘어가지 말고 아이를 기다린다.
- 『탐험대 이야기』가 붙은 줄은 성경 본문이 아니다. 타임머신과 탐험 일지는 탐험대의 도구다. 과거의 장면에는 아무것도 남기지 않는다.
- 괄호 안의 장절과 '어른 도움말'은 소리 내어 읽지 않는다.

## 플레이 원고

### 칸 1 · 도착 (창 25:27)

- 보이는 것: 타임머신, 들과 장막, 사냥꾼 에서, 장막의 야곱
- **어른** 『탐험대 이야기』: 타임머신이 이삭의 장막이 있는 곳에 왔어요.
- **최온**: 들에 사냥꾼이 있어!
- **어른**: 이삭의 쌍둥이 아들들이 다 자랐어요. 형 에서는 들을 누비는 사냥꾼이 되었어요.
- **어른**: 동생 야곱은 말수가 적은 사람이었어요. 야곱은 장막에 머물렀어요.
- → 칸 2로 간다.

### 칸 2 · 목격 (창 25:29–30)

- 보이는 것: 붉은 죽이 끓는 솥, 지친 에서
- **어른**: 야곱이 죽을 끓이고 있었어요. 그때 에서가 몹시 지쳐서 들에서 돌아왔어요.
- **어른**: 에서는 야곱에게 그 붉은 죽을 달라고 했어요.
- **최온**: 붉은 죽이야!
- → 칸 3으로 간다.

### 칸 3 · 목격 (창 25:31–33)

- 보이는 것: 에서와 야곱
- **어른**: 야곱은 죽을 주기 전에 형의 장자의 명분을 넘겨 달라고 했어요. 장자의 명분은 맏아들이 받는 자리와 몫이에요.
- **어른**: 에서는 자기가 죽게 되었는데 그것이 무슨 소용이냐고 했어요.
- → 칸 4로 간다.

### 칸 4 · 고르기

- 보이는 것: 고르기 카드 두 장 (장자의 명분 / 아버지의 축복)
- 칸 5에서 돌아왔으면 이 칸을 처음부터 다시 읽는다 (원래 장을 다시 편다).
- **어른**: 창세기 25장을 펴 볼까요? 에서가 무엇을 팔았는지 찾아봐요. (어른 도움말: 33절)
- **쉼**: 아이가 에서가 판 것을 찾을 때까지 기다린다.
- **어른**: 에서가 팥죽을 받고 야곱에게 판 것은 무엇일까요? 장자의 명분일까요, 아버지의 축복일까요?
- 고르기
  - **장자의 명분** (창 25:31–33) → 칸 6으로 간다.
  - **아버지의 축복** (창 27:27, 다른 날) → 칸 5로 간다.

### 칸 5 · 다른 장면: 이삭의 축복 (창 27:1, 27, 36)

- 보이는 것: 나이 들어 눈이 어두운 이삭, 이삭 앞에 선 야곱
- **어른** 『탐험대 이야기』: 타임머신이 뒤의 날로 갔어요.
- **어른**: 이삭은 늙어서 앞을 잘 보지 못했어요. 야곱이 가까이 가서 이삭에게 입을 맞추었어요.
- **어른**: 이삭은 야곱에게 복을 빌어 주었어요.
- **어른**: 나중에 에서는 동생이 장자의 명분에 이어 이제는 복까지 가져갔다고 말했어요.
- **최온**: 여기는 팥죽을 먹던 날이 아니야!
- **어른**: 창세기 27장을 펴 봐요. 이삭이 야곱에게 해 준 것은 무엇인가요? (어른 도움말: 27절)
- **쉼**: 아이가 '축복'을 찾을 때까지 기다린다.
- **어른**: 축복은 다른 날 이삭이 빌어 준 것이에요. 에서가 팥죽을 받고 판 것이 아니에요.
- **어른** 『탐험대 이야기』: 죽이 끓던 날로 돌아가요.
- → 칸 4로 돌아간다.

### 칸 6 · 발견 (창 25:33–34)

- 보이는 것: 팥죽과 떡, 먹고 일어나는 에서
- **어른**: 찾았어요. 에서는 야곱에게 장자의 명분을 팔았어요.
- **어른**: 팔기 전에 맹세까지 했어요.
- **어른**: 무엇을 보니 알 수 있었나요? 25장에 에서가 맹세하고 그것을 팔았다고 나와요.
- **어른**: 에서는 야곱이 준 떡과 팥죽을 먹고 마셨어요. 그러고는 자리를 떠났어요.
- **어른**: 성경은 에서가 장자의 명분을 소중히 여기지 않았다고 말해요.
- **최온**: 팥죽을 먹으려고 맏아들의 자리를 팔았구나.
- → 칸 7로 간다.

### 칸 7 · 기록

- 보이는 것: 탐험 일지
- **어른** 『탐험대 이야기』: 일지에 오늘 찾은 것을 적어요.
- 일지에 적을 것
  - 판 것: **장자의 명분** · 창세기 25장 31~33절 · 맏아들의 자리와 몫이에요.
  - 받은 것: **떡과 팥죽** · 창세기 25장 34절
- (원하면) 한 문장 기도: 하나님이 주신 소중한 것을 가볍게 여기지 않게 해 주세요.
- 끝.

## 아이용 요약

에서가 지쳐서 들에서 돌아와 야곱이 끓인 붉은 죽을 달라고 했어요. 에서는 맹세하고 장자의 명분을 팔았고, 떡과 팥죽을 먹고 가 버렸어요(창세기 25장). 이삭이 야곱에게 복을 빌어 준 것은 뒤의 일이에요(창세기 27장).

## 녹음용 읽기 원고

한 줄이 한 칸이다. 줄 앞 번호와 괄호 안은 읽지 않는다. 각 줄은 어른 목소리로 시작한다. (최온)과 (어른)은 목소리를 바꾸는 자리다.

1. 타임머신이 이삭의 장막이 있는 곳에 왔어요. (최온) 들에 사냥꾼이 있어! (어른) 이삭의 쌍둥이 아들들이 다 자랐어요. 형 에서는 들을 누비는 사냥꾼이 되었어요. 동생 야곱은 말수가 적은 사람이었어요. 야곱은 장막에 머물렀어요.
2. 야곱이 죽을 끓이고 있었어요. 그때 에서가 몹시 지쳐서 들에서 돌아왔어요. 에서는 야곱에게 그 붉은 죽을 달라고 했어요. (최온) 붉은 죽이야!
3. 야곱은 죽을 주기 전에 형의 장자의 명분을 넘겨 달라고 했어요. 장자의 명분은 맏아들이 받는 자리와 몫이에요. 에서는 자기가 죽게 되었는데 그것이 무슨 소용이냐고 했어요.
4. 창세기 25장을 펴 볼까요? 에서가 무엇을 팔았는지 찾아봐요. (쉼) 에서가 팥죽을 받고 야곱에게 판 것은 무엇일까요? 장자의 명분일까요, 아버지의 축복일까요?
5. 타임머신이 뒤의 날로 갔어요. 이삭은 늙어서 앞을 잘 보지 못했어요. 야곱이 가까이 가서 이삭에게 입을 맞추었어요. 이삭은 야곱에게 복을 빌어 주었어요. 나중에 에서는 동생이 장자의 명분에 이어 이제는 복까지 가져갔다고 말했어요. (최온) 여기는 팥죽을 먹던 날이 아니야! (어른) 창세기 27장을 펴 봐요. 이삭이 야곱에게 해 준 것은 무엇인가요? (쉼) 축복은 다른 날 이삭이 빌어 준 것이에요. 에서가 팥죽을 받고 판 것이 아니에요. 죽이 끓던 날로 돌아가요.
6. 찾았어요. 에서는 야곱에게 장자의 명분을 팔았어요. 팔기 전에 맹세까지 했어요. 무엇을 보니 알 수 있었나요? 25장에 에서가 맹세하고 그것을 팔았다고 나와요. 에서는 야곱이 준 떡과 팥죽을 먹고 마셨어요. 그러고는 자리를 떠났어요. 성경은 에서가 장자의 명분을 소중히 여기지 않았다고 말해요. (최온) 팥죽을 먹으려고 맏아들의 자리를 팔았구나.
7. 일지에 오늘 찾은 것을 적어요. 판 것 장자의 명분, 창세기 25장 31절에서 33절, 맏아들의 자리와 몫이에요. 받은 것 떡과 팥죽, 창세기 25장 34절.

## 작업자용 근거

| 원고의 내용 | 근거 |
|---|---|
| 형은 들의 사냥꾼, 동생은 말수 적고 장막에 머묾 (칸 1) | 창 25:27 |
| 야곱이 죽을 끓였고, 몹시 지친 에서가 들에서 와서 붉은 것을 달라고 함 (칸 2) | 창 25:29–30 |
| 야곱이 명분을 넘기라 하고, 에서는 죽게 된 처지에 무슨 소용이냐고 함 (칸 3) | 창 25:31–32 |
| 맹세 후 명분을 넘김 (칸 6) | 창 25:33 |
| 에서가 떡과 팥죽을 먹고 마신 뒤 떠남. 명분을 소중히 여기지 않음 (칸 6) | 창 25:34 |
| 이삭이 늙어 잘 보지 못함. 야곱이 다가가 이삭에게 입 맞춤. 이삭이 야곱에게 복을 빎. 에서가 명분에 이어 복도 잃었다고 말함 (칸 5) | 창 27:1, 26–27, 36 |

- 고르기 보기의 근거: 장자의 명분은 창 25:31–33, 아버지의 축복은 창 27:27. 본문에 없는 보기는 쓰지 않았다.
- 칸 5의 차이 한 가지: 축복은 다른 날 이삭이 빌어 준 것이다. 27장의 경위(옷과 별미, 속임)는 8~10세 원고에서 다루지 않았다.
- '팥죽 한 그릇'이라는 말은 창세기에 없으므로 쓰지 않았다.
- '장자의 명분'은 아이가 성경에서 찾을 낱말이라 그대로 두고, 칸 3과 일지에서 '맏아들의 자리와 몫'으로 풀었다.
- 개역개정 문장을 옮기지 않고 풀어 썼다(공통 규칙서 7절). 작업자용 근거 표도 요점만 적었다.
- 그림 주의: 하나님의 모습·손·그림자와 천사를 그리지 않는다. 탐험대 가운데 이 편에 나오는 아이는 최온이다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 장자의 명분을 고른 경로: 칸 1 → 2 → 3 → 4 → 6 → 7 | 일지에 판 것(25:31–33)과 받은 것(25:34)이 적힌다 |
| 아버지의 축복을 고른 경로: 칸 1 → 2 → 3 → 4 → 5 → 4 → 6 → 7 | 다른 날의 축복과의 차이를 찾고, 칸 4에서 25장을 다시 편 뒤 같은 일지에 닿는다 |
| 한 화면의 글 | 어른과 최온의 줄은 한 줄에 한두 문장이다 |
| 말투 | 어른의 줄은 모두 존댓말이다 |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다 |

## 별도 내용 검증 (2026-11-23)

작성 과정을 보지 않은 검증자가 개역개정 원문과 공통 규칙서로 대조했다. 경로, 녹음 원고, 요약의 장 표기, 『탐험대 이야기』 표시는 문제 없음. 반영한 고침: [사실 바로잡음] 27:26–27에서 입을 맞춘 사람은 야곱이다. 25:27, 30, 31, 33, 34와 27:1의 문장 틀을 풀어 썼다. 근거 장절에 없던 '활'과 '훨씬'을 뺐다. 첫 칸을 최온의 관찰로 열었다.
