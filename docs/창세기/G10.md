# G10 · 이름을 지어 준 아담

## 카드 정보

| 항목 | 내용 |
|---|---|
| 장면 번호 | G10 |
| 근거 장절 | 창 2:19–20, 2:9·15 (곳의 근거), 7:8–9 (다른 장면) |
| 나이 단계 | 8~10세 (어른과 함께) |
| 질문과 보기 | 가축과 새와 들짐승에게 이름을 지어 준 사람은 누구일까요? 아담(창 2:19–20) / 노아(창 7:8–9, 동물들이 방주로 들어간 날) |
| 정답 근거 | 아담 · 창 2:19–20 |
| 성경 찾기 안내 | 아이에게는 책과 장(창세기 2장, 7장)까지 안내한다. 절은 어른 도움말로만 둔다 (공통 규칙서 5절) |
| 다른 장면 | 짐승과 새가 둘씩 노아에게 와서 방주로 들어간 날 (창 7:8–9) 한 곳 |
| 준비물 | 아이의 성경책, 탐험 일지(종이)와 연필, 고르기 카드 두 장 |
| 참고 출처 | 성경 본문만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음. 2:20 뒷부분(돕는 배필)은 이 편에서 다루지 않았다 |
| 감수 상태 | 미감수 |

읽는 법
- **어른**은 어른이 읽는 줄이고, **최온**은 아이가 읽는 줄이다(최온은 탐험대의 10살 아이). 한 줄이 한 화면이다.
- **쉼**에서는 다음 줄로 넘어가지 말고 아이를 기다린다.
- 『탐험대 이야기』가 붙은 줄은 성경 본문이 아니다. 타임머신과 탐험 일지는 탐험대의 도구다. 과거의 장면에는 아무것도 남기지 않는다.
- 괄호 안의 장절과 '어른 도움말'은 소리 내어 읽지 않는다.

## 플레이 원고

### 칸 1 · 도착 (창 2:19)

- 보이는 것: 타임머신, 나무가 있는 동산, 여러 짐승과 새
- **어른** 『탐험대 이야기』: 타임머신이 처음 사람이 살던 아주 먼 옛날로 왔어요.
- **최온**: 짐승이랑 새가 정말 많아!
- → 칸 2로 간다.

### 칸 2 · 목격 (창 2:19)

- 보이는 것: 아담 앞으로 오는 짐승과 새 (하나님의 모습은 그리지 않는다)
- **어른**: 여호와 하나님은 들짐승과 새도 흙으로 만드셨어요.
- **어른**: 하나님은 그것들을 아담에게 데려가셨어요. 아담이 어떤 이름을 붙이는지 보시려고요.
- → 칸 3으로 간다.

### 칸 3 · 목격 (창 2:19 끝)

- 보이는 것: 짐승과 새의 이름을 부르는 아담
- **어른**: 아담이 부른 그대로 그 생물의 이름이 되었어요.
- **최온**: 아담이 부르는 대로 이름이 생겼어!
- → 칸 4로 간다.

### 칸 4 · 고르기

- 보이는 것: 고르기 카드 두 장 (아담 / 노아)
- 칸 5에서 돌아왔으면 이 칸을 처음부터 다시 읽는다 (원래 장을 다시 편다).
- **어른**: 창세기 2장을 펴 볼까요? 동물들에게 이름을 지어 준 사람을 찾아봐요. (어른 도움말: 19~20절)
- **쉼**: 아이가 이름을 지어 준 사람을 찾을 때까지 기다린다.
- **어른**: 가축과 새와 들짐승에게 이름을 지어 준 사람은 누구일까요? 아담일까요, 노아일까요?
- 고르기
  - **아담** (창 2:19–20) → 칸 6으로 간다.
  - **노아** (창 7:8–9, 동물들이 방주로 들어간 날) → 칸 5로 간다.

### 칸 5 · 다른 장면: 방주로 들어가는 동물들 (창 7:8–9)

- 보이는 것: 큰 방주, 둘씩 짝지어 들어가는 짐승과 새, 노아
- **어른** 『탐험대 이야기』: 타임머신이 훨씬 뒤의 날, 노아의 방주 앞으로 갔어요.
- **어른**: 짐승과 새가 암컷과 수컷 둘씩 노아에게 와서 방주로 들어갔어요.
- **최온**: 여기서는 동물들이 방주로 들어가고 있어!
- **어른**: 창세기 7장을 펴 봐요. 노아에게 온 동물들은 어디로 들어갔나요? (어른 도움말: 9절)
- **쉼**: 아이가 '방주'를 찾을 때까지 기다린다.
- **어른**: 노아의 때에는 동물들이 방주로 들어갔어요. 이름을 지어 준 날이 아니에요.
- **어른** 『탐험대 이야기』: 처음 사람이 살던 때로 돌아가요.
- → 칸 4로 돌아간다.

### 칸 6 · 발견 (창 2:20)

- 보이는 것: 여러 짐승과 새, 아담
- **어른**: 찾았어요. 동물마다 이름을 지어 준 사람은 아담이에요.
- **어른**: 무엇을 보니 알 수 있었나요? 2장에 아담이 가축과 새와 들짐승의 이름을 지었다고 나와요.
- **최온**: 동물 이름을 처음 지은 사람이 아담이었구나!
- → 칸 7로 간다.

### 칸 7 · 기록

- 보이는 것: 탐험 일지
- **어른** 『탐험대 이야기』: 일지에 오늘 찾은 것을 적어요.
- 일지에 적을 것
  - 사람: **아담** · 창세기 2장 19~20절 · 가축과 새와 들짐승에게 이름을 지어 주었어요.
- (원하면) 한 문장 기도: 모든 생물을 지으신 하나님, 고맙습니다.
- 끝.

## 아이용 요약

여호와 하나님이 들짐승과 새를 지으시고 아담에게 데려가셨어요. 아담은 가축과 새와 들짐승에게 이름을 지어 주었어요(창세기 2장). 동물들이 둘씩 방주로 들어간 것은 훨씬 뒤 노아의 때예요(창세기 7장).

## 녹음용 읽기 원고

한 줄이 한 칸이다. 줄 앞 번호와 괄호 안은 읽지 않는다. 각 줄은 어른 목소리로 시작한다. (최온)과 (어른)은 목소리를 바꾸는 자리다.

1. 타임머신이 처음 사람이 살던 아주 먼 옛날로 왔어요. (최온) 짐승이랑 새가 정말 많아!
2. 여호와 하나님은 들짐승과 새도 흙으로 만드셨어요. 하나님은 그것들을 아담에게 데려가셨어요. 아담이 어떤 이름을 붙이는지 보시려고요.
3. 아담이 부른 그대로 그 생물의 이름이 되었어요. (최온) 아담이 부르는 대로 이름이 생겼어!
4. 창세기 2장을 펴 볼까요? 동물들에게 이름을 지어 준 사람을 찾아봐요. (쉼) 가축과 새와 들짐승에게 이름을 지어 준 사람은 누구일까요? 아담일까요, 노아일까요?
5. 타임머신이 훨씬 뒤의 날, 노아의 방주 앞으로 갔어요. 짐승과 새가 암컷과 수컷 둘씩 노아에게 와서 방주로 들어갔어요. (최온) 여기서는 동물들이 방주로 들어가고 있어! (어른) 창세기 7장을 펴 봐요. 노아에게 온 동물들은 어디로 들어갔나요? (쉼) 노아의 때에는 동물들이 방주로 들어갔어요. 이름을 지어 준 날이 아니에요. 처음 사람이 살던 때로 돌아가요.
6. 찾았어요. 동물마다 이름을 지어 준 사람은 아담이에요. 무엇을 보니 알 수 있었나요? 2장에 아담이 가축과 새와 들짐승의 이름을 지었다고 나와요. (최온) 동물 이름을 처음 지은 사람이 아담이었구나!
7. 일지에 오늘 찾은 것을 적어요. 아담, 창세기 2장 19절에서 20절, 가축과 새와 들짐승에게 이름을 지어 주었어요.

## 작업자용 근거

| 원고의 내용 | 근거 |
|---|---|
| 하나님이 흙으로 들짐승과 새를 지으시고 아담에게 데려가심. 아담이 무엇이라 부르는지 보시려 함 (칸 2) | 창 2:19 |
| 아담이 부른 것이 그 생물의 이름이 됨 (칸 3) | 창 2:19 |
| 아담이 가축과 새와 들짐승의 이름을 지음 (칸 6) | 창 2:20 |
| 하나님 말씀대로 짐승과 새가 수컷·암컷 둘씩 와서 방주에 들어감 (칸 5) | 창 7:8–9 |

- 고르기 보기의 근거: 아담은 창 2:19–20, 노아는 창 7:8–9. 본문에 없는 보기는 쓰지 않았다.
- 칸 5의 차이 한 가지: 노아의 때 동물들은 방주로 들어갔다. 이름을 지은 일이 아니다.
- 칸 1의 동산은 2:15의 에덴 동산이다. 동산의 모습은 2:9(보기 좋은 나무)에 근거한 것만 둔다.
- 개역개정 문장을 옮기지 않고 풀어 썼다(공통 규칙서 7절). 작업자용 근거 표도 요점만 적었다.
- 그림 주의: 하나님의 모습·손·그림자와 천사를 그리지 않는다. 탐험대 가운데 이 편에 나오는 아이는 최온이다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 아담을 고른 경로: 칸 1 → 2 → 3 → 4 → 6 → 7 | 일지에 아담(2:19–20)이 적힌다 |
| 노아를 고른 경로: 칸 1 → 2 → 3 → 4 → 5 → 4 → 6 → 7 | 방주로 들어간 날과의 차이를 찾고, 칸 4에서 2장을 다시 편 뒤 같은 일지에 닿는다 |
| 한 화면의 글 | 어른과 최온의 줄은 한 줄에 한두 문장이다 |
| 말투 | 어른의 줄은 모두 존댓말이다 |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다 |

## 별도 내용 검증 (2026-11-23)

작성 과정을 보지 않은 검증자가 개역개정 원문과 공통 규칙서로 대조했다. 경로, 녹음 원고, 요약의 장 표기, 『탐험대 이야기』 표시는 문제 없음. 반영한 고침: 개역개정과 다섯 낱말이 겹치던 근거 표 줄(7:9)과 2:19의 문장 틀을 풀어 썼다. 본문에 없는 '풀'과 '바라보는'을 뺐다. 근거 장절에 2:9, 15를 더했다.
