# G04 · 우물가의 리브가

## 카드 정보

| 항목 | 내용 |
|---|---|
| 장면 번호 | G04 |
| 근거 장절 | 창 24:10–21 (중심 24:15–20), 29:9–10 (다른 장면), 25:21–26 (때의 근거) |
| 나이 단계 | 8~10세 (어른과 함께) |
| 질문과 보기 | 아브라함의 종이 물을 다 마신 뒤, 리브가가 또 누구를 위해 물을 길었을까요? 낙타들(창 24:19–20) / 양 떼(창 29:9–10, 다른 날의 라헬) |
| 정답 근거 | 낙타들 · 창 24:19–20 |
| 성경 찾기 안내 | 아이에게는 책과 장(창세기 24장, 29장)까지 안내한다. 절은 어른 도움말로만 둔다 (공통 규칙서 5절) |

| 참고 출처 | 성경 본문만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음 |
| 감수 상태 | 미감수 |

읽는 법
- **어른**은 어른이 읽는 줄이고, **최온**은 아이가 읽는 줄이다(최온은 탐험대의 10살 아이). 한 줄이 한 화면이다.
- **쉼**에서는 다음 줄로 넘어가지 말고 아이를 기다린다.
- 『탐험대 이야기』가 붙은 줄은 성경 본문이 아니다. 타임머신과 탐험 일지는 탐험대의 도구다. 과거의 장면에는 아무것도 남기지 않는다.
- 괄호 안의 장절과 '어른 도움말'은 소리 내어 읽지 않는다.

## 플레이 원고

### 칸 1 · 도착 (창 24:10–11)

- 보이는 것: 타임머신, 성 밖의 우물, 무릎을 꿇고 앉은 낙타 열 마리, 아브라함의 종
- **어른** 『탐험대 이야기』: 타임머신이 성 밖 우물가에 왔어요.
- **어른**: 저녁 무렵이에요. 아브라함의 종이 낙타 열 마리를 우물 곁에 쉬게 했어요.
- **최온**: 낙타가 무릎을 꿇고 앉았어!
- → 칸 2로 간다.

### 칸 2 · 목격 (창 24:12–14)

- 보이는 것: 우물 곁에 선 종
- **어른**: 종은 하나님께 기도했어요. 낙타에게도 물을 주겠다고 하는 소녀를 만나게 해 달라고 했어요.
- **어른**: 그 소녀가 주인의 아들 이삭의 아내가 될 사람인 줄 알게 해 달라고 했어요.
- → 칸 3으로 간다.

### 칸 3 · 목격 (창 24:15–16)

- 보이는 것: 물동이를 어깨에 진 소녀, 우물
- **어른**: 종의 기도가 끝나기도 전에, 어깨에 물동이를 얹은 소녀가 나왔어요.
- **어른**: 소녀는 우물로 내려가 물동이에 물을 채워 올라왔어요.
- **최온**: 물동이를 든 사람이 왔어! 누구지?
- **어른**: 창세기 24장을 펴 봐요. 물동이를 얹고 나온 소녀의 이름을 찾아봐요. (어른 도움말: 15절)
- **쉼**: 아이가 '리브가'를 찾을 때까지 기다린다.
- **어른**: 리브가예요.
- → 칸 4로 간다.

### 칸 4 · 목격 (창 24:17–18)

- 보이는 것: 달려가는 종, 물동이를 손에 내린 리브가
- **어른**: 종이 달려가 물을 조금 마시게 해 달라고 했어요.
- **어른**: 리브가는 얼른 물동이를 내려 종에게 마시게 했어요.
- → 칸 5로 간다.

### 칸 5 · 고르기

- 보이는 것: 고르기 카드 두 장 (낙타들 / 양 떼)
- 칸 6에서 돌아왔으면 이 칸을 처음부터 다시 읽는다 (원래 장을 다시 편다).
- **어른**: 창세기 24장을 다시 펴 볼까요? 종이 다 마신 다음을 읽어 봐요. (어른 도움말: 19~20절)
- **쉼**: 아이가 종이 다 마신 뒤 리브가가 한 일을 찾을 때까지 기다린다.
- **어른**: 종이 물을 다 마신 뒤, 리브가는 또 누구를 위해 물을 길었을까요? 낙타들일까요, 양 떼일까요?
- 고르기
  - **낙타들** (창 24:19–20) → 칸 7로 간다.
  - **양 떼** (창 29:9–10, 다른 날) → 칸 6으로 간다.

### 칸 6 · 다른 장면: 양 떼를 몰고 온 라헬 (창 29:9–10)

- 보이는 것: 들판의 우물, 양 떼, 양 떼를 몰고 오는 라헬, 야곱
- **어른** 『탐험대 이야기』: 타임머신이 다른 날, 들판의 우물가로 왔어요.
- **어른**: 여러 해 뒤의 일이에요. 라헬이 아버지의 양 떼를 몰고 우물로 왔어요.
- **어른**: 야곱이 라헬이 데려온 양들에게 물을 주었어요.
- **최온**: 여기는 낙타가 아니라 양 떼야!
- **어른**: 창세기 29장을 펴 봐요. 라헬이 몰고 온 것은 무엇인가요? (어른 도움말: 9절)
- **쉼**: 아이가 '양'을 찾을 때까지 기다린다.
- **어른**: 라헬이 데려온 것은 낙타가 아니라 양 떼예요.
- **어른** 『탐험대 이야기』: 리브가가 있는 저녁의 우물로 돌아가요.
- → 칸 5로 돌아간다.

### 칸 7 · 발견 (창 24:19–20)

- 보이는 것: 구유, 다시 우물로 달려가는 리브가, 물을 마시는 낙타들
- **어른**: 찾았어요. 리브가는 낙타들에게도 물을 떠다 주었어요.
- **어른**: 무엇을 보니 알 수 있었나요? 24장에 종이 다 마시자 리브가가 낙타들도 배불리 마시게 하겠다고 말한 것이 나와요.
- **어른**: 리브가는 구유에 물을 쏟았어요. 또 우물로 뛰어가 낙타들이 마실 물을 떠 왔어요.
- **최온**: 낙타가 열 마리나 되는데!
- → 칸 8로 간다.

### 칸 8 · 목격 (창 24:21)

- 보이는 것: 조용히 지켜보는 종
- **어른**: 종은 아무 말 없이 리브가를 지켜보았어요.
- **어른**: 여호와께서 이 길을 잘 열어 주셨는지 알고 싶었기 때문이에요.
- → 칸 9로 간다.

### 칸 9 · 기록

- 보이는 것: 탐험 일지
- **어른** 『탐험대 이야기』: 일지에 오늘 찾은 것을 적어요.
- 일지에 적을 것
  - 사람: **리브가** · 창세기 24장 15절 · 물동이를 들고 우물로 나왔어요.
  - 동물: **낙타** · 창세기 24장 19~20절 · 리브가는 종이 마신 뒤 낙타들에게도 물을 떠다 주었어요.
- (원하면) 한 문장 기도: 리브가처럼 얼른 돕는 사람이 되게 해 주세요.
- 끝.

## 아이용 요약

아브라함의 종이 성 밖 우물가에서 기도했어요. 리브가가 물동이를 들고 나와 종에게 물을 마시게 했어요. 그리고 종의 낙타들에게도 물을 떠다 주었어요(창세기 24장). 라헬이 양 떼를 몰고 온 것은 여러 해 뒤의 일이에요(창세기 29장).

## 녹음용 읽기 원고

한 줄이 한 칸이다. 줄 앞 번호와 괄호 안은 읽지 않는다. 각 줄은 어른 목소리로 시작한다. (최온)과 (어른)은 목소리를 바꾸는 자리다.

1. 타임머신이 성 밖 우물가에 왔어요. 저녁 무렵이에요. 아브라함의 종이 낙타 열 마리를 우물 곁에 쉬게 했어요. (최온) 낙타가 무릎을 꿇고 앉았어!
2. 종은 하나님께 기도했어요. 낙타에게도 물을 주겠다고 하는 소녀를 만나게 해 달라고 했어요. 그 소녀가 주인의 아들 이삭의 아내가 될 사람인 줄 알게 해 달라고 했어요.
3. 종의 기도가 끝나기도 전에, 어깨에 물동이를 얹은 소녀가 나왔어요. 소녀는 우물로 내려가 물동이에 물을 채워 올라왔어요. (최온) 물동이를 든 사람이 왔어! 누구지? (어른) 창세기 24장을 펴 봐요. 물동이를 얹고 나온 소녀의 이름을 찾아봐요. (쉼) 리브가예요.
4. 종이 달려가 물을 조금 마시게 해 달라고 했어요. 리브가는 얼른 물동이를 내려 종에게 마시게 했어요.
5. 창세기 24장을 다시 펴 볼까요? 종이 다 마신 다음을 읽어 봐요. (쉼) 종이 물을 다 마신 뒤, 리브가는 또 누구를 위해 물을 길었을까요? 낙타들일까요, 양 떼일까요?
6. 타임머신이 다른 날, 들판의 우물가로 왔어요. 여러 해 뒤의 일이에요. 라헬이 아버지의 양 떼를 몰고 우물로 왔어요. 야곱이 라헬이 데려온 양들에게 물을 주었어요. (최온) 여기는 낙타가 아니라 양 떼야! (어른) 창세기 29장을 펴 봐요. 라헬이 몰고 온 것은 무엇인가요? (쉼) 라헬이 데려온 것은 낙타가 아니라 양 떼예요. 리브가가 있는 저녁의 우물로 돌아가요.
7. 찾았어요. 리브가는 낙타들에게도 물을 떠다 주었어요. 무엇을 보니 알 수 있었나요? 24장에 종이 다 마시자 리브가가 낙타들도 배불리 마시게 하겠다고 말한 것이 나와요. 리브가는 구유에 물을 쏟았어요. 또 우물로 뛰어가 낙타들이 마실 물을 떠 왔어요. (최온) 낙타가 열 마리나 되는데!
8. 종은 아무 말 없이 리브가를 지켜보았어요. 여호와께서 이 길을 잘 열어 주셨는지 알고 싶었기 때문이에요.
9. 일지에 오늘 찾은 것을 적어요. 리브가, 창세기 24장 15절, 물동이를 들고 우물로 나왔어요. 낙타, 창세기 24장 19절에서 20절, 리브가는 종이 마신 뒤 낙타들에게도 물을 떠다 주었어요.

## 작업자용 근거

| 원고의 내용 | 근거 |
|---|---|
| 종이 낙타 열 마리를 데리고 왔다 (칸 1) | 창 24:10 |
| 저녁 무렵, 종이 낙타를 성 밖 우물가에 쉬게 함 (칸 1) | 창 24:11 |
| 종의 기도: 낙타에게도 물을 주겠다는 소녀가 이삭을 위해 정하신 사람이게 해 달라 (칸 2) | 창 24:12–14 |
| 기도가 끝나기 전에 리브가가 물동이를 들고 와서 우물물을 채움 (칸 3) | 창 24:15–16 |
| 종이 달려가 물을 청했고, 리브가가 물동이를 내려 마시게 했다 (칸 4) | 창 24:17–18 |
| 낙타들도 실컷 마시게 하겠다고 말하고, 구유에 물을 쏟고 다시 뛰어가 낙타들이 마실 물을 떠 옴 (칸 7) | 창 24:19–20 |
| 종이 말없이 지켜봄. 여호와께서 길을 잘 열어 주셨는지 알려는 뜻 (칸 8) | 창 24:21 |
| 라헬이 아버지의 양 떼를 몰고 왔고, 야곱이 그 양들에게 물을 주었다 (칸 6) | 창 29:9–10 |
| 라헬의 장면은 리브가의 장면보다 여러 해 뒤다 (칸 6) | 야곱은 리브가의 아들이다 (창 25:21–26) |

- 고르기 보기의 근거: 낙타들은 창 24:19–20, 양 떼는 창 29:9–10. 본문에 없는 보기는 쓰지 않았다.
- 칸 6의 차이 한 가지: 라헬의 우물가에서 물을 먹인 것은 낙타가 아니라 양 떼다. 우물 입구의 돌은 G05에서 쓰므로 이 편에서는 꺼내지 않았다. 두 우물이 서로 다른 우물이라고는 쓰지 않았다(본문이 말하지 않음).
- 종의 이름은 24장에 나오지 않는다. '아브라함의 종'으로만 부른다.
- 종의 기도(24:12–14)와 말(24:17), 리브가의 말(24:18–19)은 간접 화법으로 풀어 썼다. 칸 8의 "알고 싶었기 때문"은 24:21이 말한 종의 뜻 그대로다. 그 밖의 속마음은 넣지 않았다.
- 최온의 "낙타가 열 마리나 되는데!"는 24:10의 수를 떠올린 아이의 말이다.
- 개역개정 문장을 옮기지 않고 풀어 썼다(공통 규칙서 7절). 24:16의 외모 묘사는 쓰지 않았다.
- 그림 주의: 하나님의 모습·손·그림자를 그리지 않는다. 탐험대 가운데 이 편에 나오는 아이는 최온이다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 낙타들을 고른 경로: 칸 1 → 2 → 3 → 4 → 5 → 7 → 8 → 9 | 일지에 리브가(24:15)와 낙타(24:19–20)가 놓인다 |
| 양 떼를 고른 경로: 칸 1 → 2 → 3 → 4 → 5 → 6 → 5 → 7 → 8 → 9 | 라헬의 양 떼(29:9–10)로 차이를 찾고 칸 5의 물음으로 돌아와 같은 일지에 닿는다 |
| 지시서의 마치는 기준 | 아이가 24장 19~20절에서 낙타를 찾는다. 다른 단서는 창 29:9–10의 라헬과 양 떼로 이어진다 |
| 한 화면의 글 | 어른과 최온의 줄은 한 줄에 한두 문장이다 |
| 말투 | 어른의 줄은 모두 존댓말이다 |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다 |

## 별도 내용 검증 (2026-11-23)

작성 과정을 보지 않은 검증자가 창 24·29장 원문과 공통 규칙서로 대조했다.

- 사실, 순서, 수(낙타 열 마리), 지명: 문제 없음.
- 반영한 고침
  - 24:15, 19–20과 문장 틀이 같은 줄을 풀어 썼다. 작업자용 근거 표도 요점만 적는 말로 바꿨다.
  - 기도 문장의 '기쁘게'를 '얼른'으로 바꿨다(본문은 '급히'라고만 한다).
  - 칸 6의 차이를 한 가지(양 떼)로 줄였고, '다른 우물'이라고 단정하지 않았다.
  - 형식 맞추기
    - 돌아오면 칸 5를 처음부터 읽어 24장을 다시 펴게 했다.
    - 쉼에서 찾을 것을 적었다.
    - 일지의 낙타를 '동물'로 적었다.
    - 녹음 원고를 다시 만들었다.
    - 아이용 요약에는 장까지만 적었다.

### 수정본 재검증 (2026-11-23)

작성 과정을 보지 않은 다른 검증자가 고친 곳만 다시 대조했다. 경로, 녹음 원고, 요약의 장 표기는 문제 없음. 새로 찾은 것을 반영했다: 29:3과 겹치던 '양 떼에게 물을 먹였다'를 '양들에게 물을 주었다'로 바꿨다. 근거 장절에 25:21–26을 더했다.
