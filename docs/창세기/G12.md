# G12 · 장막 앞의 세 손님

## 카드 정보

| 항목 | 내용 |
|---|---|
| 장면 번호 | G12 |
| 근거 장절 | 창 18:1–8, 27:9 (다른 장면) |
| 나이 단계 | 8~10세 (어른과 함께) |
| 질문과 보기 | 아브라함이 손님을 위해 골라 요리하게 한 것은 무엇일까요? 송아지(창 18:7) / 염소 새끼(창 27:9, 리브가가 별미를 만들던 날) |
| 정답 근거 | 송아지 · 창 18:7 |
| 성경 찾기 안내 | 아이에게는 책과 장(창세기 18장, 27장)까지 안내한다. 절은 어른 도움말로만 둔다 (공통 규칙서 5절) |
| 다른 장면 | 리브가가 염소 새끼로 별미를 만들려던 날 (창 27:9) 한 곳 |
| 준비물 | 아이의 성경책, 탐험 일지(종이)와 연필, 고르기 카드 두 장 |
| 참고 출처 | 성경 본문만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음. 다만 확인받기를 권함: 본문은 이 손님들 가운데 여호와께서 계셨다고 한다(18:1, 13, 22). 그래서 그림에 세 손님을 그리지 않고, 아브라함과 음식과 나무만 그린다 |
| 감수 상태 | 미감수 |

읽는 법
- **어른**은 어른이 읽는 줄이고, **최온**은 아이가 읽는 줄이다(최온은 탐험대의 10살 아이). 한 줄이 한 화면이다.
- **쉼**에서는 다음 줄로 넘어가지 말고 아이를 기다린다.
- 『탐험대 이야기』가 붙은 줄은 성경 본문이 아니다. 타임머신과 탐험 일지는 탐험대의 도구다. 과거의 장면에는 아무것도 남기지 않는다.
- 괄호 안의 장절과 '어른 도움말'은 소리 내어 읽지 않는다.

## 플레이 원고

### 칸 1 · 도착 (창 18:1)

- 보이는 것: 타임머신, 마므레의 상수리나무들, 장막, 장막 문에 앉은 아브라함
- **어른** 『탐험대 이야기』: 타임머신이 마므레의 상수리나무들이 있는 곳에 왔어요.
- **어른**: 한낮이라 날이 뜨거워요. 아브라함이 장막 문에 앉아 있어요.
- **최온**: 햇볕이 엄청 뜨거워!
- → 칸 2로 간다.

### 칸 2 · 목격 (창 18:1–2)

- 보이는 것: 달려 나가 몸을 굽히는 아브라함 (세 손님은 그리지 않는다)
- **어른**: 성경은 이때 여호와께서 아브라함에게 나타나셨다고 말해요.
- **어른**: 아브라함 맞은편에 세 사람이 와 있었어요. 아브라함은 얼른 달려가 맞이하고 몸을 굽혀 인사했어요.
- → 칸 3으로 간다.

### 칸 3 · 목격 (창 18:3–6)

- 보이는 것: 물 그릇, 나무 그늘, 장막 안으로 서둘러 가는 아브라함
- **어른**: 아브라함은 손님들에게 발을 씻고 나무 아래에서 쉬시라고 했어요. 먹을 것을 조금 가져오겠다고 했어요.
- **어른**: 아브라함은 서둘러 장막으로 가서, 사라에게 고운 가루로 떡을 만들어 달라고 했어요.
- **최온**: 아브라함이 정말 바쁘게 움직여!
- → 칸 4로 간다.

### 칸 4 · 고르기

- 보이는 것: 고르기 카드 두 장 (송아지 / 염소 새끼)
- 칸 5에서 돌아왔으면 이 칸을 처음부터 다시 읽는다 (원래 장을 다시 편다).
- **어른**: 창세기 18장을 펴 볼까요? 아브라함이 가축 떼에서 무엇을 골랐는지 찾아봐요. (어른 도움말: 7절)
- **쉼**: 아이가 아브라함이 고른 짐승을 찾을 때까지 기다린다.
- **어른**: 아브라함이 손님을 위해 골라 요리하게 한 것은 무엇일까요? 송아지일까요, 염소 새끼일까요?
- 고르기
  - **송아지** (창 18:7) → 칸 6으로 간다.
  - **염소 새끼** (창 27:9, 리브가가 별미를 만들던 날) → 칸 5로 간다.

### 칸 5 · 다른 장면: 리브가의 별미 (창 27:9)

- 보이는 것: 염소 떼, 좋은 염소 새끼 두 마리, 리브가와 야곱
- **어른** 『탐험대 이야기』: 타임머신이 훨씬 뒤의 날로 갔어요.
- **어른**: 이삭의 아내 리브가가 아들 야곱에게 염소 떼에서 좋은 새끼 두 마리를 가져오라고 했어요.
- **어른**: 남편 이삭이 즐겨 먹는 별미를 만들려는 것이었어요.
- **최온**: 여기서는 염소 새끼야!
- **어른**: 창세기 27장을 펴 봐요. 리브가가 가져오라고 한 것은 무엇인가요? (어른 도움말: 9절)
- **쉼**: 아이가 '염소 새끼'를 찾을 때까지 기다린다.
- **어른**: 염소 새끼는 리브가가 별미를 만들 때 쓰려던 것이에요. 아브라함이 손님에게 차린 것이 아니에요.
- **어른** 『탐험대 이야기』: 아브라함의 장막으로 돌아가요.
- → 칸 4로 돌아간다.

### 칸 6 · 발견 (창 18:7–8)

- 보이는 것: 송아지 요리, 떡, 엉긴 젖과 우유, 나무 곁에 선 아브라함
- **어른**: 찾았어요. 아브라함은 가축 떼로 달려가 살지고 좋은 송아지를 골랐어요.
- **어른**: 무엇을 보니 알 수 있었나요? 18장에 아브라함이 송아지를 골라 하인에게 맡겼고, 하인이 서둘러 요리했다고 나와요.
- **어른**: 아브라함은 떡과 송아지 요리, 엉긴 젖과 우유를 손님들 앞에 차렸어요.
- **어른**: 손님들이 먹는 동안 아브라함은 나무 아래 곁에 서 있었어요.
- **최온**: 손님을 반갑게 맞고 서둘러 대접했어!
- → 칸 7로 간다.

### 칸 7 · 기록

- 보이는 것: 탐험 일지
- **어른** 『탐험대 이야기』: 일지에 아브라함이 차린 음식을 적어요.
- 일지에 적을 것
  - 고기: **송아지** · 창세기 18장 7절 · 아브라함이 골라 하인에게 요리하게 했어요.
  - 그 밖의 음식: **떡, 엉긴 젖, 우유** · 창세기 18장 6절, 8절
- (원하면) 한 문장 기도: 아브라함처럼 손님을 반갑게 맞게 해 주세요.
- 끝.

## 아이용 요약

한낮에 아브라함의 장막 앞에 세 사람이 왔어요. 아브라함은 달려가 맞이하고, 송아지를 골라 요리하게 해서 떡과 엉긴 젖과 우유와 함께 대접했어요(창세기 18장). 염소 새끼로 별미를 만들려 한 사람은 훨씬 뒤의 리브가예요(창세기 27장).

## 녹음용 읽기 원고

한 줄이 한 칸이다. 줄 앞 번호와 괄호 안은 읽지 않는다. 각 줄은 어른 목소리로 시작한다. (최온)과 (어른)은 목소리를 바꾸는 자리다.

1. 타임머신이 마므레의 상수리나무들이 있는 곳에 왔어요. 한낮이라 날이 뜨거워요. 아브라함이 장막 문에 앉아 있어요. (최온) 햇볕이 엄청 뜨거워!
2. 성경은 이때 여호와께서 아브라함에게 나타나셨다고 말해요. 아브라함 맞은편에 세 사람이 와 있었어요. 아브라함은 얼른 달려가 맞이하고 몸을 굽혀 인사했어요.
3. 아브라함은 손님들에게 발을 씻고 나무 아래에서 쉬시라고 했어요. 먹을 것을 조금 가져오겠다고 했어요. 아브라함은 서둘러 장막으로 가서, 사라에게 고운 가루로 떡을 만들어 달라고 했어요. (최온) 아브라함이 정말 바쁘게 움직여!
4. 창세기 18장을 펴 볼까요? 아브라함이 가축 떼에서 무엇을 골랐는지 찾아봐요. (쉼) 아브라함이 손님을 위해 골라 요리하게 한 것은 무엇일까요? 송아지일까요, 염소 새끼일까요?
5. 타임머신이 훨씬 뒤의 날로 갔어요. 이삭의 아내 리브가가 아들 야곱에게 염소 떼에서 좋은 새끼 두 마리를 가져오라고 했어요. 남편 이삭이 즐겨 먹는 별미를 만들려는 것이었어요. (최온) 여기서는 염소 새끼야! (어른) 창세기 27장을 펴 봐요. 리브가가 가져오라고 한 것은 무엇인가요? (쉼) 염소 새끼는 리브가가 별미를 만들 때 쓰려던 것이에요. 아브라함이 손님에게 차린 것이 아니에요. 아브라함의 장막으로 돌아가요.
6. 찾았어요. 아브라함은 가축 떼로 달려가 살지고 좋은 송아지를 골랐어요. 무엇을 보니 알 수 있었나요? 18장에 아브라함이 송아지를 골라 하인에게 맡겼고, 하인이 서둘러 요리했다고 나와요. 아브라함은 떡과 송아지 요리, 엉긴 젖과 우유를 손님들 앞에 차렸어요. 손님들이 먹는 동안 아브라함은 나무 아래 곁에 서 있었어요. (최온) 손님을 반갑게 맞고 서둘러 대접했어!
7. 일지에 아브라함이 차린 음식을 적어요. 고기 송아지, 창세기 18장 7절, 아브라함이 골라 하인에게 요리하게 했어요. 그 밖의 음식 떡, 엉긴 젖, 우유, 창세기 18장 6절, 8절.

## 작업자용 근거

| 원고의 내용 | 근거 |
|---|---|
| 마므레 상수리나무들 곁, 한낮에 아브라함이 장막 문에 앉아 있었음. 여호와께서 나타나심 (칸 1·2) | 창 18:1 |
| 맞은편에 선 세 사람을 보고 달려가 맞이하고 몸을 굽힘 (칸 2) | 창 18:2 |
| 발을 씻고 나무 아래 쉬시라, 떡을 조금 가져오겠다 (칸 3) | 창 18:3–5 |
| 장막으로 가서 사라에게 고운 가루로 떡을 만들라 함 (칸 3) | 창 18:6 |
| 가축 떼로 달려가 좋은 송아지를 골라 하인에게 주었고, 하인이 서둘러 요리함 (칸 6) | 창 18:7 |
| 엉긴 젖과 우유와 송아지 요리를 차리고, 먹는 동안 나무 아래 곁에 섬 (칸 6) | 창 18:8 |
| 리브가가 야곱에게 좋은 염소 새끼 둘을 가져오게 해 이삭이 즐기는 별미를 만들려 함 (칸 5) | 창 27:9 |

- 고르기 보기의 근거: 송아지는 창 18:7, 염소 새끼는 창 27:9. 본문에 없는 보기는 쓰지 않았다.
- 칸 5의 차이 한 가지: 염소 새끼는 리브가가 이삭의 별미를 만들려던 것이다. 27장의 뒷일(야곱이 복을 받은 일)은 이 편에서 다루지 않았다.
- 세 손님의 대사는 쓰지 않았다(18:5, 9–15는 이 편의 범위 밖). 아브라함의 말(18:3–6)은 간접 화법으로 옮겼다.
- '엉긴 젖'은 아이가 성경에서 찾을 음식 이름이라 그대로 둔다.
- 개역개정 문장을 옮기지 않고 풀어 썼다(공통 규칙서 7절). 작업자용 근거 표도 요점만 적었다.
- 그림 주의: 하나님의 모습·손·그림자와 천사를 그리지 않는다. 탐험대 가운데 이 편에 나오는 아이는 최온이다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| 송아지를 고른 경로: 칸 1 → 2 → 3 → 4 → 6 → 7 | 일지에 송아지(18:7)와 떡·엉긴 젖·우유(18:6, 8)가 적힌다 |
| 염소 새끼를 고른 경로: 칸 1 → 2 → 3 → 4 → 5 → 4 → 6 → 7 | 리브가의 별미와의 차이를 찾고, 칸 4에서 18장을 다시 편 뒤 같은 일지에 닿는다 |
| 한 화면의 글 | 어른과 최온의 줄은 한 줄에 한두 문장이다 |
| 말투 | 어른의 줄은 모두 존댓말이다 |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다 |
