# E24 · 장막에서 들은 아들의 소식 (창세기 18:1–15)

창세기 본편 24회. 아이는 E23 일지의 단서(아들 이삭이 태어날 때: 내년 이 시기)와 칸 7 끝의 예고(장막에 찾아온 손님들)에서 시작한다. 손님이 온 날의 일을 어른이 먼저 말로 잇고, 18장을 펴기 전에 **아브라함이 가축 떼에서 골라 하인에게 맡긴 것**을 먼저 고른다. 그다음 18장에서 손님상에 오른 것과 사라가 들은 약속을 찾아 **장막 앞 판**(다섯 칸)에 적는다. 바탕은 G12의 손님맞이(18:1–8)이고, 고르기와 다른 장면(27:9 염소 새끼)도 G12의 것을 본편으로 옮겼다.

## 회차 연결

| 항목 | 내용 |
|---|---|
| 앞 회에서 남은 일 | E23 일지의 '다음 탐험의 단서'에 '아들 이삭이 태어날 때: 내년 이 시기'(창 17:21)가 있다. E23 칸 7 끝에서 '다음 탐험에서는 아브라함의 장막에 찾아온 손님들을 본다'고 했다 |
| 이번 사건 | 여호와께서 나타나신 날 장막 맞은편에 온 세 사람과 아브라함의 맞이(창 18:1–6, 어른이 말로 잇는다), 아브라함이 고른 송아지와 손님 앞에 차린 음식(창 18:7–8), 사라에 대한 물음과 아들의 약속(창 18:9–10), 사라의 웃음과 여호와께서 하신 물음(창 18:11–15) |
| 그 결과로 달라진 점 | 사라도 아들의 약속을 직접 들었다. 손님 가운데 한 분은 사라가 아들을 낳게 된다고 했고, 그때는 내년 이맘때라고 했다(18:10). 여호와께서는 사라가 웃은 것을 아셨고, 아브라함에게 한 가지를 물으셨다(18:14) |
| 다음 회 첫 장면의 단서 | 일어나 소돔 쪽으로 향한 손님들(18:16). 다음 회(E25, 창 18:16–33)는 아브라함이 손님들을 배웅하고 소돔을 두고 여호와께 여쭙는 장면이다. 칸 6 끝에서 아이가 18:16을 찾고, '다음 탐험에서는 손님들이 떠난 길과 아브라함이 여호와께 여쭌 일을 본다'고 말한다 |
| 아이가 직접 확인할 단서 | 18:7의 '송아지'. 칸 3에서 고르고 칸 5에서 확인한다 |
| 되돌아볼 장절 | 창 17:21 (E23 일지의 '내년 이 시기'). 칸 6에서 18:10의 '내년 이맘때'와 같은 때인지 견준다. 창 17:17 (E23 칸 6에서 아브라함도 웃었다). 칸 6에서 어른이 떠올려 준다 |

## 카드 정보

| 항목 | 내용 |
|---|---|
| 장면 번호 | E24 (본편 24회, 바탕 원고 G12) |
| 근거 장절 | 창 18:1–16 (18:11–12와 18:15는 어른이 짧게 잇고, 아이가 물을 때의 답만 도움말에 둠), 17:17, 21 (되돌아보기), 27:9 (다른 장면) |
| 나이 단계 | 8~10세 (어른과 함께) |
| 질문과 보기 | 아브라함이 가축 떼에서 골라 하인에게 맡긴 것은 무엇이었을까요? 송아지(창 18:7) / 염소 새끼(창 27:9, 리브가가 별미를 만들려던 날). 18장을 펴기 전에 먼저 고르고, 성경을 펴서 확인한다(공통 규칙서 4.1) |
| 정답 근거 | 송아지 · 창 18:7 |
| 성경 찾기 안내 | 아이에게는 책과 장(창세기 18장, 27장)과 '18장 앞부분', '바로 뒤', '27장 앞부분'까지 안내한다. 절은 어른 도움말로만 둔다 (공통 규칙서 5절). 17:21은 E23 일지로 되돌아본다. 일지에는 장절을 함께 적는다 |
| 다른 장면 | 리브가가 염소 새끼로 별미를 만들려던 날 (창 27:9) 한 곳 (G12와 같은 장면) |
| 준비물 | 아이의 성경책, E23까지 쓴 탐험 일지, 연필, 장막 앞 판(종이에 다섯 칸: ① 아브라함이 골라 하인에게 맡긴 것 (　) ② 함께 차린 두 가지 (　), (　) ③ 사라가 약속을 들은 곳: 장막 (　) ④ 아들이 있으리라고 한 때 (　) ⑤ 여호와께서 하신 물음에 내가 하는 대답 (　)). 판은 엎어 두었다가 칸을 적을 때만 편다. 고르기 카드 두 장(송아지 / 염소 새끼) |
| 참고 출처 | 성경 본문과 G12 원고만 썼다 |
| 감수 필수 여부 | 3.5 주제에 해당하지 않음. 확인 권함: 손님 가운데 여호와께서 계셨다는 것(18:1, 13)을 어른이 '성경은 이때 아브라함에게 여호와께서 나타나셨다고 말해요'로만 읽고, 아이가 물을 때 목사님께 여쭙게 한 것, 18:10의 손님의 말을 높임말로 옮긴 것, 18:11을 소리 내어 읽지 않은 것, 18:12와 18:15의 사라의 말을 평가하지 않은 것, 18:14의 물음을 '여호와께서는 무엇이든 하실 수 있다'는 뜻으로 받은 것, 기도 문장 |
| 감수 상태 | 미감수 |

읽는 법
- **어른**은 어른이 읽는 줄이고, **최온**은 아이가 읽는 줄이다(최온은 탐험대의 10살 아이). 한 줄이 한 화면이다.
- **쉼**에서는 다음 줄로 넘어가지 말고 아이를 기다린다.
- 『탐험대 이야기』가 붙은 줄은 성경 본문이 아니다. 타임머신, 탐험 일지, 장막 앞 판, 고르기 카드는 탐험대의 도구다. 탐험대는 사건에 끼어들지 않고 지켜보기만 한다.
- 괄호 안의 장절과 '어른 도움말'은 소리 내어 읽지 않는다.

## 플레이 원고

### 칸 1 · 도착 (앞 회에서 남은 일)

- 보이는 것: 마므레의 상수리나무들과 장막, 장막 입구의 아브라함 (멀리서 작게. 손님은 그리지 않는다)
- **어른** 『탐험대 이야기』: 타임머신이 아브라함의 장막 가까이에 왔어요.
- **최온**: 나무가 많다! 해가 아주 뜨거워.
- **어른**: 지난 일지에서 다음 탐험의 단서를 펴 봐요. 이삭이 태어날 때는 언제라고 하셨나요? (어른 도움말: E23 일지, 17:21)
- **쉼**: 아이가 '내년 이 시기'를 찾을 때까지 기다린다.
- → 칸 2로 간다.

### 칸 2 · 손님이 온 날 (창 18:1–6)

- 보이는 것: 장막과 나무 (멀리서 작게. 손님은 그리지 않는다)
- **어른**: 성경은 이때 아브라함에게 여호와께서 나타나셨다고 말해요. 날이 뜨거운 때였어요. (어른 도움말: 18:1. 아이는 아직 18장을 펴지 않는다. 아이가 '손님이 여호와예요?'라고 물으면 "성경은 여호와께서 나타나셨다고 말해요. 더 궁금한 것은 목사님께 함께 여쭤봐요."라고만 답한다)
- **어른**: 장막 맞은편에 손님 세 사람이 보였어요. 아브라함은 손님들에게 몸을 굽혀 인사했어요. 그보다 먼저, 손님들을 보자마자 맞으러 나갔어요. (어른 도움말: 2절)
- **어른**: 아브라함은 손님들에게 쉬어 가라고 청했어요. 발 씻을 물과 먹을 것을 조금 내오겠다고 했어요. (어른 도움말: 3–5절)
- **어른**: 사라에게는 떡을 만들어 달라고 부탁했어요. (어른 도움말: 6절)
- **어른** 『탐험대 이야기』: 아브라함은 가축 떼 쪽으로도 갔어요. 거기서 무엇을 골라 하인에게 맡겼을까요?
- → 칸 3으로 간다.

### 칸 3 · 고르기 (18장을 펴기 전)

- 보이는 것: 고르기 카드 두 장 (송아지 / 염소 새끼)
- 칸 4에서 돌아왔으면 이 칸을 처음부터 다시 읽는다.
- **어른**: 이번에도 성경을 펴기 전에 먼저 골라요. 고른 다음에 18장을 펴서 확인해요.
- **어른** 『탐험대 이야기』: 송아지일까요, 염소 새끼일까요?
- 고르기
  - **염소 새끼** → 칸 4로 간다.
  - **송아지** → 칸 5로 간다.

### 칸 4 · 다른 장면: 리브가의 별미 (창 27:9)

- 보이는 것: 염소 떼와 두 사람 (멀리서 작게)
- **어른** 『탐험대 이야기』: 타임머신이 다른 곳에 잠깐 내렸어요.
- **최온**: 저기 염소 떼가 있어!
- **어른**: 창세기 27장 앞부분을 펴 봐요. 염소 새끼를 가져오라고 한 사람은 누구이고, 누구에게 말했나요? (어른 도움말: 9절. 리브가가 아들 야곱에게 말했다. 6절에 두 이름이 나온다)
- **쉼**: 아이가 '리브가'와 '야곱'을 찾을 때까지 기다린다. (어른 도움말: 아이가 그날의 다른 일을 물으면 "그 이야기는 나중 탐험에서 만나요. 이 장면에서는 누가 염소 새끼를 가져오라고 했는지만 봐요."라고만 답한다)
- **어른**: 아브라함이 손님을 맞은 날인가요?
- **쉼**: 아이가 아니라고 말할 때까지 기다린다.
- **어른** 『탐험대 이야기』: 성경을 덮어요. 아브라함의 장막으로 돌아가서 다시 골라 봐요.
- → 칸 3으로 돌아간다.

### 칸 5 · 손님상 (창 18:6–8)

- 보이는 것: 장막과 나무 (멀리서 작게. 손님은 그리지 않는다)
- **어른**: 이제 18장을 펴요. 아브라함이 직접 달려가 고른 것을 18장 앞부분에서 찾아봐요. (어른 도움말: 7절)
- **쉼**: 아이가 '송아지'를 찾을 때까지 기다린다.
- **어른** 『탐험대 이야기』: 장막 앞 판 첫째 칸에 적어요.
- **어른**: 골라서 맡긴 사람은 아브라함이고, 요리는 하인이 서둘러 했어요. (어른 도움말: 7절)
- **어른**: 송아지 말고 손님들 앞에 함께 놓인 두 가지를 바로 뒤에서 찾아봐요. (어른 도움말: 8절)
- **쉼**: 아이가 '엉긴 젖'과 '우유'를 찾을 때까지 기다린다. (어른 도움말: 아이가 떡을 말하면 "떡은 사라에게 부탁한 것이에요. 차린 것을 적은 줄을 다시 봐요."라고만 답한다)
- **어른** 『탐험대 이야기』: 둘째 칸에 두 가지를 적어요.
- **최온**: 아브라함은 뛰어다니면서 손님을 대접했구나!
- → 칸 6으로 간다.

### 칸 6 · 사라가 들은 약속 (창 18:9–16, 되돌아보기 17:17, 21)

- 보이는 것: 장막 문 (멀리서 작게. 사람은 그리지 않는다)
- **어른**: 손님들은 아브라함에게 사라에 대해 물었어요. 그다음 손님 가운데 한 분이 사라가 아들을 낳게 된다고 하셨어요. (어른 도움말: 9–10절)
- **어른**: 그 말을 사라는 어디에서 들었나요? 바로 뒤에서 찾아봐요. (어른 도움말: 10절 끝)
- **쉼**: 아이가 '장막 문'을 찾을 때까지 기다린다.
- **어른** 『탐험대 이야기』: 셋째 칸에 적어요.
- **어른**: 손님은 언제라고 하셨는지 같은 절에서 찾아봐요. (어른 도움말: 10절)
- **쉼**: 아이가 '내년 이맘때'를 찾을 때까지 기다린다.
- **어른** 『탐험대 이야기』: 넷째 칸에 적어요. 지난 일지의 '내년 이 시기'와 같은 때인가요?
- **쉼**: 아이가 같은 때라고 말할 때까지 기다린다. (어른 도움말: E23 일지, 17:21. 낱말은 달라도 같은 때를 말한다)
- **어른**: 사라가 속으로 웃었어요. 장막 문에서 그 말을 들었거든요. (어른 도움말: 11–12절. 11절은 소리 내어 읽지 않는다. 아이가 물으면 "사라가 아이를 낳을 나이가 지났다는 말이에요."라고만 답한다. 12절의 속말은 나이 이야기라고만 가리킨다. E23 칸 6에서 아브라함도 웃었다)
- **어른**: 사라가 웃은 것을 여호와께서 아셨어요. 그리고 아브라함에게 한 가지를 물으셨어요. (어른 도움말: 13–14절)
- **어른**: 여러분은 어떻게 생각해요? 여호와께 못 하실 일이 있을까요?
- **쉼**: 아이가 제 생각을 말할 때까지 기다린다.
- **어른**: 이제 '여호와께'로 시작하는 물음을 14절 앞부분에서 찾아 읽어 봐요. (어른 도움말: 14절)
- **쉼**: 아이가 그 물음을 찾아 읽을 때까지 기다린다. (어른 도움말: 이 물음은 여호와께서는 무엇이든 하실 수 있다는 뜻이다)
- **어른** 『탐험대 이야기』: 다섯째 칸에 그 물음에 대한 내 대답을 적어요.
- **어른**: 사라는 웃지 않았다고 했어요. 성경은 그때 사라가 두려웠다고 적고, 여호와께서는 사라가 웃었다고 하셨어요. (어른 도움말: 15절. 사라의 말을 거짓말이라고 평가하지 않는다. 아이가 물으면 "성경은 있었던 일을 적어요. 이 판에서는 사라가 들은 약속을 봐요."라고만 답한다)
- **어른**: 바로 뒤를 봐요. 손님들은 일어나 어느 쪽으로 향했나요? (어른 도움말: 16절)
- **쉼**: 아이가 '소돔'을 찾을 때까지 기다린다.
- **최온**: 사라도 아들의 약속을 직접 들었어!
- **어른** 『탐험대 이야기』: 다음 탐험에서는 손님들이 떠난 길과 아브라함이 여호와께 여쭌 일을 봐요.
- → 칸 7로 간다.

### 칸 7 · 기록

- 보이는 것: 탐험 일지, 장막 앞 판
- **어른** 『탐험대 이야기』: 일지에 장막 앞 판을 옮겨 적어요.
- 일지에 적을 것
  - **아브라함이 고른 것** · 창세기 18장 7절 · 송아지 (요리는 하인)
  - **함께 차린 것** · 창세기 18장 8절 · 엉긴 젖, 우유
  - **사라가 약속을 들은 곳** · 창세기 18장 10절 · 장막 문
  - **아들이 있으리라고 한 때** · 창세기 18장 10절 · 내년 이맘때 (17:21의 '내년 이 시기'와 같은 때)
  - **여호와께서 하신 물음** · 창세기 18장 14절 · 내 대답: (아이가 판에 적은 말)
  - **다음 탐험의 단서** · 창세기 18장 16절 · 소돔 쪽으로 향한 손님들
  - 다른 장면을 다녀왔으면: **염소 새끼** · 창세기 27장 9절 · 리브가가 별미를 만들려던 것
- (원하면) 한 문장 기도: 무엇이든 하실 수 있는 하나님, 약속을 지키시니 고맙습니다.

## 아이용 요약

손님 세 사람이 찾아온 것은 날이 뜨거운 때였어요(창세기 18장). 아브라함은 손님들을 맞으러 나가, 쉬어 가라고 청했어요. 사라에게는 떡을 부탁했고, 송아지는 아브라함이 직접 골랐어요. 함께 차린 것은 엉긴 젖과 우유였어요. 손님 가운데 한 분은 사라가 아들을 낳게 된다고 하셨어요. 내년 이맘때라고요. 사라가 속으로 웃었어요. 장막 문에서 그 말을 들었거든요. 아브라함은 여호와께 한 가지 물음을 들었어요. 그 물음에는, 여호와께서 무엇이든 하실 수 있다는 뜻이 담겨 있어요(창세기 18장).

## 녹음용 읽기 원고

한 줄이 한 칸이다. 줄 앞 번호와 괄호 안은 읽지 않는다. 각 줄은 어른 목소리로 시작한다. (최온)과 (어른)은 목소리를 바꾸는 자리다.

1. 타임머신이 아브라함의 장막 가까이에 왔어요. (최온) 나무가 많다! 해가 아주 뜨거워. (어른) 지난 일지에서 다음 탐험의 단서를 펴 봐요. 이삭이 태어날 때는 언제라고 하셨나요?
2. 성경은 이때 아브라함에게 여호와께서 나타나셨다고 말해요. 날이 뜨거운 때였어요. 장막 맞은편에 손님 세 사람이 보였어요. 아브라함은 손님들에게 몸을 굽혀 인사했어요. 그보다 먼저, 손님들을 보자마자 맞으러 나갔어요. 아브라함은 손님들에게 쉬어 가라고 청했어요. 발 씻을 물과 먹을 것을 조금 내오겠다고 했어요. 사라에게는 떡을 만들어 달라고 부탁했어요. 아브라함은 가축 떼 쪽으로도 갔어요. 거기서 무엇을 골라 하인에게 맡겼을까요?
3. 이번에도 성경을 펴기 전에 먼저 골라요. 고른 다음에 18장을 펴서 확인해요. 송아지일까요, 염소 새끼일까요?
4. 타임머신이 다른 곳에 잠깐 내렸어요. (최온) 저기 염소 떼가 있어! (어른) 창세기 27장 앞부분을 펴 봐요. 염소 새끼를 가져오라고 한 사람은 누구이고, 누구에게 말했나요? (쉼) 아브라함이 손님을 맞은 날인가요? (쉼) 성경을 덮어요. 아브라함의 장막으로 돌아가서 다시 골라 봐요.
5. 이제 18장을 펴요. 아브라함이 직접 달려가 고른 것을 18장 앞부분에서 찾아봐요. (쉼) 장막 앞 판 첫째 칸에 적어요. 골라서 맡긴 사람은 아브라함이고, 요리는 하인이 서둘러 했어요. 송아지 말고 손님들 앞에 함께 놓인 두 가지를 바로 뒤에서 찾아봐요. (쉼) 둘째 칸에 두 가지를 적어요. (최온) 아브라함은 뛰어다니면서 손님을 대접했구나!
6. 손님들은 아브라함에게 사라에 대해 물었어요. 그다음 손님 가운데 한 분이 사라가 아들을 낳게 된다고 하셨어요. 그 말을 사라는 어디에서 들었나요? 바로 뒤에서 찾아봐요. (쉼) 셋째 칸에 적어요. 손님은 언제라고 하셨는지 같은 절에서 찾아봐요. (쉼) 넷째 칸에 적어요. 지난 일지의 '내년 이 시기'와 같은 때인가요? (쉼) 사라가 속으로 웃었어요. 장막 문에서 그 말을 들었거든요. 사라가 웃은 것을 여호와께서 아셨어요. 그리고 아브라함에게 한 가지를 물으셨어요. 여러분은 어떻게 생각해요? 여호와께 못 하실 일이 있을까요? (쉼) 이제 '여호와께'로 시작하는 물음을 14절 앞부분에서 찾아 읽어 봐요. (쉼) 다섯째 칸에 그 물음에 대한 내 대답을 적어요. 사라는 웃지 않았다고 했어요. 성경은 그때 사라가 두려웠다고 적고, 여호와께서는 사라가 웃었다고 하셨어요. 바로 뒤를 봐요. 손님들은 일어나 어느 쪽으로 향했나요? (쉼) (최온) 사라도 아들의 약속을 직접 들었어! (어른) 다음 탐험에서는 손님들이 떠난 길과 아브라함이 여호와께 여쭌 일을 봐요.
7. 일지에 장막 앞 판을 옮겨 적어요. 아브라함이 고른 것, 창세기 18장 7절, 송아지. 함께 차린 것, 창세기 18장 8절, 엉긴 젖과 우유. 사라가 약속을 들은 곳, 창세기 18장 10절, 장막 문. 아들이 있으리라고 한 때, 창세기 18장 10절, 내년 이맘때. 여호와께서 하신 물음, 창세기 18장 14절, 그 물음에 내가 한 대답. 다음 탐험의 단서, 창세기 18장 16절, 소돔 쪽으로 향한 손님들.

## 작업자용 근거

| 원고의 내용 | 근거 |
|---|---|
| 내년 이 시기에 태어날 이삭 (칸 1, 6 되돌아보기) | 창 17:21 |
| 여호와께서 나타나심, 날이 뜨거운 때, 장막 입구의 아브라함 (칸 1, 2, 요약) | 창 18:1 |
| 맞은편의 세 사람, 맞으러 나가 몸을 굽힘 (칸 2, 요약) | 창 18:2 |

- 고르기 보기의 근거: 송아지는 18:7, 염소 새끼는 27:9(G12와 같다). 음식을 만들려고 짐승을 고르는 다른 날이라 짐작하기 쉬운 보기다. 칸 4에서 아이는 염소 새끼를 가져오라고 한 사람과 들은 사람(리브가, 야곱)을 찾아, 이 장면이 아브라함이 손님을 맞은 날이 아니라는 것(사람이 어긋남)을 말한다. 27:9에는 떡이나 송아지가 나오지 않는다. 처음 원고의 '떡 / 팥죽'은 25:34에 떡이 함께 있고 E20이 이미 쓴 장면이라 바꿨다.
- 고르기는 18장을 펴기 전(칸 3)에 한다. 18:7에 답이 있어서, 칸 2의 18:1–6 내용은 어른이 말로만 잇고 송아지를 말하지 않는다. 칸 2에서 말하는 떡(18:6)은 이 회의 고르기와 판의 답이 아니다.
- 손님 가운데 여호와께서 계셨다는 것(18:1, 13)은 G12처럼 어른이 '성경은 이때 아브라함에게 여호와께서 나타나셨다고 말해요'로 소리 내어 읽고, 그 이상은 풀지 않는다. 18:10의 손님의 말은 높임말로 옮겨, 18:13–14의 여호와의 말과 같은 분의 말로 들리게 했다. 손님을 그리지 않는다(감수 확인 권함).
- 18:11의 말은 소리 내어 읽지 않는다. 18:12의 사라의 속말은 '나이 이야기'라고만 가리킨다. 18:15의 사라의 말은 거짓말이라고 평가하지 않는다.
- 18:14의 물음은 아이가 먼저 '못 하실 일이 있을까요?'에 제 생각을 말한 뒤, 14절의 물음을 찾아 읽고 판에 내 대답을 적게 한다. 어른은 '무엇이든 하실 수 있다'는 뜻으로 받는다(감수 확인 권함). 본문의 물음을 그대로 옮기지 않는다.
- 27:9의 다른 장면에서는 누가 누구에게 염소 새끼를 가져오라고 했는지만 본다. 그날의 다른 일(27:1–40)은 풀지 않는다.
- G12에서 가져온 것: 18:1–8의 차례, 손님을 그리지 않는 처리, 18:1을 어른이 소리 내어 읽는 줄, 고르기(송아지 / 염소 새끼)와 다른 장면 27:9. G12와 C22에서 별도 검증이 낱말 바꿈으로 짚은 18:1, 2, 4, 7, 8 줄은 가져오지 않고 새로 썼다.
- 성경 인물의 말은 간접 화법으로만 옮겼다(18:3–6 아브라함, 18:9–10 손님, 18:13–15 여호와와 사라, 27:9 리브가). 개역개정과 대조한 방법은 아래 '원고 자체 점검'에 적었다.
- 그림 주의: 손님, 하나님의 모습·빛을 그리지 않는다. 칸 1은 상수리나무들과 장막과 장막 입구의 아브라함만, 칸 2·5는 장막과 나무만(나무가 어디 있는지는 정하지 않는다), 칸 4는 염소 떼와 두 사람만, 칸 6은 장막 문만 멀리서 작게 그린다. 탐험대 가운데 이 회에 나오는 아이는 최온이다.

## 별도 내용 검증 (2026-11-23)

작성 과정을 보지 않은 검증자가 창 17·18·19·25·27장, 회차표, E20·E23, G12·C22, 공통 규칙서, 인계의 교훈과 대조하고 두 경로를 원고 줄대로 따라가 봤다. 결과는 필수 5건, 권장 10건이었다. 장절과 낱말, 18:11·12·15의 처리, 3.5 해당 없음 판단, 칸 이동, 다른 장면에서 차이를 먼저 말하지 않는 것, 녹음 원고, 다음 회 예고는 문제없었다. 모두 반영했다. 고르기와 다른 장면을 바꿔서 원고를 거의 다시 썼다.

| 지적 | 고친 것 |

| 필수 1: 칸 2가 고르기의 답 '떡'을 먼저 말함 | 고르기를 '송아지 / 염소 새끼'(G12와 같음)로 바꿨다. 칸 2는 송아지를 말하지 않고, 18:5는 '먹을 것'으로 썼다 |
| 필수 2: 다른 장면 25:34에 정답 '떡'이 같이 있고, E20이 이미 쓴 장면이며 장자의 명분을 앞당김 | 다른 장면을 27:9(리브가가 야곱에게 염소 새끼를 가져오라고 한 날)로 바꿨다. 27:9에는 떡과 송아지가 없다 |
| 필수 3: 17:21의 낱말은 '내년 이 시기에'인데 '내년 이맘때'로 적음 | 칸 1, 회차 연결, 근거표를 '내년 이 시기'로 고치고, 칸 6에서 18:10의 '내년 이맘때'와 같은 때인지 견주게 했다. E23도 같은 날 고쳤다 |
| 필수 4: '손님 가운데 여호와'를 G12와 같다고 했지만 도움말에만 둠, 18:10을 높임 없이 옮김, 아이가 물을 때의 답이 없음 | 칸 2에서 어른이 '성경은 이때 아브라함에게 여호와께서 나타나셨다고 말해요'를 소리 내어 읽게 했다. 18:10은 '손님 가운데 한 분이 … 하셨어요'로 높이고, 물을 때의 답 문장을 두었다. 카드 정보와 근거 메모를 실제 처리대로 고쳤다 |
| 필수 5: 18:6, 18:9, 18:2, 18:10–12를 낱말만 바꿔 차례대로 옮긴 줄 | 18:2는 '몸을 굽혀 인사했어요. 그보다 먼저 … 맞으러 나갔어요'로 뒤집고, 18:9는 '사라에 대해 물었어요'로 줄였다. 18:10–12는 '사라가 속으로 웃었어요. 장막 문에서 그 말을 들었거든요.'로 바꿨다 |
| 권장 1: 18:14를 판이 먼저 보여 주고 어른이 '없다'를 불러 줌, 문구가 본문 차례를 따름 | 아이가 먼저 '여호와께 못 하실 일이 있을까요?'에 제 생각을 말하고, 14절 앞부분의 '여호와께'로 시작하는 물음을 찾아 읽은 뒤, 판 ⑤ '내 대답'에 적게 했다. 뜻은 '여호와께서는 무엇이든 하실 수 있다'로 받는다 |
| 권장 2: 판의 '사라가 있던 곳: 장막'이 앞에서 이미 나옴 | 판 ③을 '사라가 약속을 들은 곳: 장막 (　)'(답 '문')으로 바꿨다 |
| 권장 3: 카드 정보의 17:17 되돌아보기, '18장 가운데쯤' | 17:17은 'E23 칸 6에서 본 일'로 고치고, 쓰지 않는 안내말을 뺐다 |
| 권장 4: 일지의 18:16 단서를 아이가 찾은 적이 없음 | 칸 6 끝에 '바로 뒤를 봐요. 손님들은 일어나 어느 쪽으로 향했나요?'를 넣었다 |
| 권장 5: 일지의 '18장 10, 14절 · 내년 이맘때' | 10절만 적었다 |
| 권장 6: 본문에 없는 그림(솥, 나무 그늘)과 최온의 '여기도' | 다른 장면 그림을 '염소 떼와 두 사람'으로, 최온 줄을 '저기 염소 떼가 있어!'로, 나무는 자리를 정하지 않고 '장막과 나무'로 고쳤다 |
| 권장 7: 『탐험대 이야기』 표시가 본문 내용 줄에 붙음 | 본문 줄(18:6, 18:7)에서 표시를 떼고, 탐험대 물음 줄만 표시했다 |
| 권장 8: 칸 5에 떡에 대한 답 줄이 없음 | '떡은 사라에게 부탁한 것이에요…'를 도움말에 두었다 |
| 권장 9: 요약 첫 문장이 아브라함이 맞은편에 있던 것처럼 읽힘 | '손님 세 사람이 찾아온 것은 날이 뜨거운 때였어요.'로 바꿨다 |
| 권장 10: 근거표·도움말·회차 연결의 본문 낱말 묶음, 자체 점검의 '어절 0건' 표현 | 근거표 줄을 요점으로 바꾸고, 도움말의 '고운 가루 세 스아', '가축 떼 있는 곳'을 뺐다. 자체 점검을 네 가지 방법으로 다시 돌린 결과로 고쳤다 |
