# E50 · 돌아오지 않은 요셉과 아버지에게 간 옷 (창세기 37:12–36)

창세기 본편 50회. 아이는 E49 일지의 단서(아버지가 지어 준 채색옷, 37:3)와 칸 7 끝의 예고(형들을 찾아 나선 요셉)에서 시작한다. 37장을 펴기 전에 **요셉이 형들을 만난 곳**(도단 / 세겜)을 먼저 고르고, 37장에서 확인한다. 그다음 **두 줄 판**에 쪽지를 놓는다. 윗줄은 '요셉의 길'(헤브론 골짜기, 세겜, 도단, 구덩이, 애굽)이고, 아랫줄은 '아버지에게 간 것'(피를 묻힌 채색옷, 아버지가 한 말, 아버지의 애통)이다. 마지막에 두 줄을 견주어, 아버지가 한 말과 성경이 적은 요셉의 길이 다르다는 것을 본문으로 확인한다. 바탕 원고는 없다(G16의 37:23–24와 사실을 맞췄다).

**감수 필수 (죽음에 닿는 말과 가족 사이의 폭력. 공통 규칙서 3.5 '하나님의 주권과 사람의 책임'에 닿는다). 감수 전에는 확정하지 않고, 아이에게 쓰지 않는다.** 이 대목에는 형들이 동생을 죽이려고 꾀한 일(37:18–20), 사람을 판 일(37:28), 피를 묻힌 옷을 아버지에게 보낸 일(37:31–32), 아버지의 긴 애통과 '스올'이라는 말(37:34–35)이 있다. 37장에는 하나님의 이름이 한 번도 나오지 않는다. 원고는 일어난 일을 서술자가 적은 만큼만 옮기고, 형들을 평가하지 않으며, 이 일의 뜻을 풀지 않는다(뒤의 장에서 요셉이 이 일을 두고 하는 말은 쓰지 않는다). 아래 '연령별 읽기 안내'와 '어른이 고를 수 있는 도움말'을 두었다. 이 처리와 답 문장을 목회자가 확인해야 한다.

**연령별 읽기 안내 (E26의 방식).** 이 원고는 8~10세 판이다. 11~13세와 14~19세 판은 따로 쓰지 않았고, 쓸 때 이 표를 따른다.

| 대목 | 8~10세 (이 원고) | 11~13세 | 14~19세 |
|---|---|---|---|
| 37:12–17 (형들을 찾아가는 길) | 아이와 읽는다 | 같은 처리 | 같은 처리 |
| 37:18–22 (죽이려고 꾀함, 르우벤의 말) | 덮어 두고 읽지 않는다. 어른이 '형들은 요셉을 죽이려고 꾀했다', '르우벤은 죽이지 말고 구덩이에 던지자고 했다', '성경은 르우벤이 요셉을 구해 아버지에게 돌려보내려 했다고 적는다'까지만 말한다. 20절의 꾸민 말은 말하지 않는다 | 아이 성경은 덮고 어른이 읽어 준다 | 함께 읽는다 |
| 37:23–24 (옷을 벗기고 구덩이에 던짐) | 아이와 읽는다. 그리지 않는다 | 같은 처리 | 같은 처리 |

| 37:36 (보디발) | 어른이 한 줄로 말한다 | 아이와 읽는다 | 같은 처리 |

## 어른이 고를 수 있는 도움말 (감수 필수)

따옴표 안의 문장은 감수 전의 초안이다. 죽음과 슬픔에 관한 물음에는 E31의 도움말 표에서 같은 줄을 쓴다.

| 이런 때 | 어른이 고를 수 있는 것 | 근거 |
|---|---|---|
| 시작하기 전 | 어른이 원고를 먼저 끝까지 읽고 오늘 할지 정한다. 형들이 동생을 죽이려고 꾀하고 파는 대목이다. 형제나 또래에게 맞거나 따돌림을 당한 아이, 가족과 떨어져 지내는 아이라면 미루는 쪽을 먼저 생각한다. 교사는 아이의 형편을 아이에게 묻지 말고 보호자에게 미리 확인한다 | 본문 밖 (진행 안내) |
| 어른이 이 회를 하지 않기로 했다 | "형들은 요셉을 미워해서 먼 나라로 가는 상인들에게 넘겼어요. 요셉은 애굽으로 갔어요."라고 말하고, 일지에 '요셉이 간 곳 · 창세기 37장 28절 · 애굽'과 '다음 탐험의 단서 · 창세기 37장 26절 · 요셉의 형 유다'를 적을지 어른이 고른다 | 창 37:26–28 |
| 아이가 자기가 겪은 일(맞음, 따돌림, 형제의 괴롭힘)을 꺼낸다 | 놀이를 멈추고 끝까지 들어 준다. 캐묻지 않는다. "말해 줘서 고마워. 네 잘못이 아니야."라고 말한다. 그다음의 일은 E46의 '어른이 먼저 읽을 것'을 따른다 | 본문 밖 (감수 필수. 대표 확인) |
| '요셉은 죽었어요?' | "아니에요. 성경은 상인들이 요셉을 애굽으로 데리고 갔다고 적어요." | 창 37:28, 36 |
| '요셉은 무서웠어요? 울었어요?' | "37장은 요셉의 마음과 말을 적지 않아요." | 창 37:23–28 |
| 아이가 더 하기 어려워한다 | 칸 6 끝(요셉의 길 줄을 다 놓은 뒤)에서 멈출 수 있다. 일지에 길 줄만 옮겨 적고 기도 한 문장으로 마친다. 다음에 칸 7부터 잇는다 | 창 37:28 |

## 아이가 물을 때의 답 (감수 필수)

아이가 물을 때만 쓴다. 어른이 먼저 꺼내지 않는다. 칸 1~2에서는 성경을 펴지 않는다. 가림 종이 밑을 읽고 물으면 "그 부분은 더 크면 어른과 함께 읽어요."라고 답한다.

| 물음 | 답 | 근거 절 |
|---|---|---|
| (13–14절) 아버지는 왜 요셉을 보냈어요? | "돌아와서 알려 달라고 했어요. 형들과 양 떼가 잘 있는지를요." | 창 37:14 |
| (15–17절) 길에서 만난 '어떤 사람'은 누구예요? | "성경은 '어떤 사람'이라고만 적어요. 형들이 도단으로 간다고 하는 말을 들었다고 요셉에게 알려 주었어요." | 창 37:15–17 |
| 형들은 왜 요셉을 죽이려고 했어요? | "성경은 형들이 요셉을 미워했다고 앞에서 적었어요. 여기서는 형들이 요셉을 '꿈 꾸는 자'라고 불렀다고 적어요." | 창 37:4, 8, 19 |
| 르우벤은 착한 형이에요? | "성경은 르우벤이 요셉을 구해서 아버지에게 돌려보내려 했다고 적어요. 착하다 나쁘다는 말하지 않아요." | 창 37:21–22 |
| (24절) 구덩이는 얼마나 깊어요? 요셉은 다쳤어요? | "성경은 구덩이가 비어 있었고 물이 없었다고만 적어요." | 창 37:24 |
| (25절) 형들은 어떻게 밥을 먹을 수 있어요? | "성경은 형들이 앉아 음식을 먹었다고만 적어요. 마음은 적지 않아요." | 창 37:25 |
| 유다는 요셉을 살려 준 거예요? | "유다는 죽이지 말고 팔자고 했어요. 성경은 그 말을 그대로 적고, 옳다 그르다는 말하지 않아요." | 창 37:26–27 |
| (25, 28, 36절) 이스마엘 사람이에요, 미디안 사람이에요? | "성경은 두 이름을 다 써요. 왜 그런지는 풀어 주지 않아요." | 창 37:25, 27–28, 36 |
| (28절) '은 이십'은 얼마예요? 사람을 팔아도 돼요? | "얼마만큼인지는 적혀 있지 않아요.", "사람을 파는 것은 해서는 안 되는 일이에요. 성경은 형들이 그렇게 했다고 적어요." | 창 37:28 ('해서는 안 되는 일'은 본문 밖의 말. 감수 필수) |
| (29–30절) 르우벤은 어디 갔다 왔어요? 왜 옷을 찢었어요? | "어디에 있었는지는 적혀 있지 않아요. 돌아와서 요셉이 없는 것을 보고 옷을 찢었다고 적어요. 옷을 찢는 것은 몹시 슬플 때 하던 일이에요." | 창 37:29–30. 풀이는 본문 밖 |
| 형들은 아버지에게 거짓말을 했어요? | "형들은 옷을 보내며 '이것을 발견했다'고 말했어요. 성경은 그 옷에 피를 묻힌 사람이 형들이라고 적어요." | 창 37:31–32 |
| 아버지는 속은 거예요? | "아버지는 옷을 보고, 악한 짐승이 요셉을 잡아먹었다고 말했어요. 성경은 요셉이 애굽으로 갔다고 적어요." | 창 37:28, 33 |
| (34절) '굵은 베'가 뭐예요? | "거친 천이에요. 몹시 슬플 때 허리에 둘렀어요." | 낱말 풀이는 본문 밖. 창 37:34 |
| (35절) '스올'이 뭐예요? | "야곱이 슬퍼하며 한 말이에요. 더 깊은 뜻은 목사님께 함께 여쭤봐요." | 창 37:35 |
| 형들은 벌을 받아요? | "37장은 그 뒤의 일을 적지 않아요." | 창 37장 |
| 하나님은 왜 막지 않으셨어요? 이 장에 하나님이 나와요? | "37장에는 하나님의 이름이 나오지 않아요. 왜 그런지, 하나님이 어디 계셨는지는 목사님께 함께 여쭤봐요." | 창 37장 |
| (36절) '바로', '친위대장', '보디발'이 뭐예요? | "바로는 애굽의 왕이에요. 친위대장은 왕을 지키는 군인들의 우두머리이고, 보디발은 그 사람의 이름이에요." | 낱말 풀이는 본문 밖. 창 37:36 |
| (다른 장면) 세겜은 지난번에 무서운 일이 있던 곳이에요? | "네, 34장의 일이 있던 성읍이에요. 오늘은 요셉이 형들을 만난 곳을 찾아요." | 창 33:18, 34장 |

## 회차 연결

| 항목 | 내용 |
|---|---|
| 앞 회에서 남은 일 | E49 일지의 '다음 탐험의 단서'에 '아버지가 지어 준 채색옷'(창 37:3)이 있다. E49 칸 7 끝에서 '다음 탐험에서는 형들을 찾아 나선 요셉을 본다'고 했다. 형들은 요셉을 미워하고 시기했다(창 37:4, 8, 11) |
| 이번 사건 | 세겜으로 양을 치러 간 형들(창 37:12), 아버지의 심부름으로 헤브론 골짜기를 떠난 요셉(창 37:13–14), 세겜에서 도단으로(창 37:15–17), 형들이 죽이려고 꾀함(창 37:18–20), 르우벤의 말(창 37:21–22), 채색옷을 벗기고 구덩이에 던짐(창 37:23–24), 상인들과 유다의 말(창 37:25–27), 은 이십에 팔려 애굽으로(창 37:28), 르우벤이 돌아옴(창 37:29–30), 피를 묻힌 옷과 아버지의 말(창 37:31–33), 아버지의 애통(창 37:34–35), 애굽에서 보디발에게 팔림(창 37:36) |
| 그 결과로 달라진 점 | 요셉은 가나안의 아버지 집을 떠나 애굽에 있다. 아버지는 요셉이 짐승에게 잡아먹혔다고 말하며 오래도록 애통했다 |
| 다음 회 첫 장면의 단서 | '요셉의 형 유다'(창 37:26). 다음 회(E51, 창 38장)는 유다의 집의 일이다. 칸 8 끝에서 '다음 탐험에서는 요셉의 형 유다의 집을 본다'고만 말한다. 38장은 소제목까지 가림 종이로 덮는다 |
| 아이가 직접 확인할 단서 | 37:17에서 요셉이 형들을 만난 곳. 칸 2에서 고르고 칸 4에서 확인한다 |
| 되돌아볼 장절 | 창 37:3 (E49 일지, 채색옷), 35:27 (E47 일지, 헤브론), 33:18 (E45 일지, 세겜 성읍. 다른 장면). 칸 1, 3, 4, 5에서 되돌아본다 |

| 성경 찾기 안내 | 아이에게는 책과 장(창세기 37장)과 '가림 종이 아래 첫머리', '조금 뒤', '바로 뒤', '가림 종이 사이의 두 절', '가림 종이 사이의 한 절'까지 안내한다. 어른이 성경을 펴고 손가락으로 절을 짚어 준다. 절은 어른 도움말로만 둔다 (공통 규칙서 5절). 다른 장면은 창을 낸 종이로 33장의 한 절만 보여 준다. 칸 7은 성경을 덮은 채 어른의 말을 듣는다. 지난 일지가 없어도 할 수 있다. 칸 1과 칸 9의 단서는 어른이 말로 알려 준다. 일지에는 아이가 눈으로 읽은 절에만 절 번호를 적는다 |
| 다른 장면 | 야곱이 세겜 성읍에 이른 일 (창 33:18) 한 곳 |
| 준비물 | 아이의 성경책, 가림 종이 넉 장(37장에서 한 장은 12절 위쪽을, 한 장은 18–22절을, 한 장은 25–27절을, 한 장은 29절부터 38장까지를 덮는다. 단이 둘인 성경이면 옆 단과 맞은쪽까지 덮는다. 좁게 덮기 어려우면 어른이 23–24절과 28절을 손가락으로 짚어 줄 때만 종이를 조금 내린다. 시작하기 전에 어른이 미리 끼워 두고, 다른 장면을 다녀온 뒤에 종이가 빠지지 않았는지 다시 본다), 창을 낸 종이 한 장(성경 한 쪽을 다 덮는 종이에 한 절 크기의 창을 낸 것. 다른 장면에서 33:18만 보이게 얹는다. 33장 끝 아래에 있는 34장이 보이지 않게 한다)과 맞은쪽을 다 덮는 종이 한 장, 지금까지 쓴 탐험 일지(있으면), 연필, 두 줄 판(윗줄 '요셉의 길'에 다섯 자리, 아랫줄 '아버지에게 간 것'에 세 자리), 길 쪽지 다섯 장(① '일 · 아버지가 보낸 곳: (　) 골짜기' ② '일 · 형들을 찾으러 간 곳: 세겜' ③ '일 · 형들을 만난 곳: (　)' ④ '일 · 형들이 던져 넣은 곳: 물 없는 (　)' ⑤ '일 · 상인들이 데리고 간 곳: (　)'. ②는 미리 적혀 있다), 아버지 쪽지 석 장(㉮ '일 · 형들이 아버지에게 보낸 것: 피를 묻힌 (　)' ㉯ '말(아버지) · 악한 짐승이 요셉을 잡아먹었다' ㉰ '일 · 아버지는 아들을 위해 오래도록 슬퍼함'. ㉯와 ㉰는 미리 적혀 있다). 쪽지는 엎어 두었다가 한 장씩 편다. 고르기 카드 두 장(도단 / 세겜. 낱말 카드) |
| 고르기 카드 | 곳의 이름이라 낱말 카드로 둔다. 8~10세의 그림 고르기와 다르다(총괄 확인) |
| 성경의 소제목 | 개역개정 37장 12절 위의 소제목에는 요셉이 가게 되는 곳(칸 6의 답)이 적혀 있어 덮는다. 38장의 소제목은 다음 회의 것이라 덮는다. 회 제목에는 고르기의 답이 없다 |
| 그림 | 사건 그림을 두지 않는다. 타임머신, 고르기 카드, 두 줄 판과 쪽지만 보인다. 사람, 구덩이 속, 피를 그리지 않는다(G16은 빈 구덩이를 그리지만 본편은 그리지 않는다. 총괄 확인) |
| 참고 출처 | 성경 본문만 썼다 |
| 감수 필수 여부 | **해당함.** 함께 확인받을 것: 연령별 읽기 안내와 가림 처리 전체, 8~10세에게 이 회를 하게 할지와 '하지 않기로 했을 때'의 말, 37:18을 '죽이려고 꾀했어요'로 말한 것, 37:20의 꾸민 말을 말하지 않은 것, 르우벤(37:21–22)과 유다(37:26–27)의 말을 평가 없이 옮긴 것, 사람을 판 일을 '팔았어요'로 말한 것과 값을 말해 주는 것, 37:31–32를 '옷에 숫염소의 피를 묻혀 보냈다'로 옮기고 원고가 '속였다'고 하지 않은 것, 37:33의 아버지의 말을 '말(아버지)'로 적어 요셉의 길과 견주게 한 것, 37:35의 '스올'을 말하지 않은 것, 37장에 하나님의 이름이 없다는 답, 이 일의 뜻을 풀지 않은 것(창 45장과 50장의 요셉의 말은 쓰지 않았다), '어른이 고를 수 있는 도움말' 표와 본문 밖의 말 전체, 최온의 줄, 아이용 요약, '아이가 물을 때의 답' 표 전체, 기도 문장 |
| 감수 상태 | 미감수 (감수 전에는 확정하지 않는다) |

읽는 법
- **어른**은 어른이 읽는 줄이고, **최온**은 아이가 읽는 줄이다(최온은 탐험대의 10살 아이). 한 줄이 한 화면이다.
- **쉼**에서는 다음 줄로 넘어가지 말고 아이를 기다린다.
- 『탐험대 이야기』가 붙은 줄은 성경 본문이 아니다. 타임머신, 탐험 일지, 두 줄 판, 쪽지, 고르기 카드, 가림 종이는 탐험대의 도구다. 탐험대는 사건에 끼어들지 않는다. 이 회에서 타임머신은 멀리 떨어진 곳에 머물고, 탐험대는 성경이 적은 것을 읽고 듣기만 한다.
- 괄호 안의 장절과 '어른 도움말'은 소리 내어 읽지 않는다. 칸의 이름(제목)은 어른이 보는 말이고 아이 화면에는 띄우지 않는다.

## 플레이 원고

### 칸 1 · 도착 (앞 회에서 남은 일, 창 37:12–14)

- 보이는 것: 타임머신 (탐험대의 도구. 성경 속 사람은 그리지 않는다)
- **어른** 『탐험대 이야기』: 타임머신이 야곱의 집에서 멀리 떨어진 언덕에 내렸어요. (어른 도움말: 칸 1~2에서는 성경을 펴지 않는다. 37장은 칸 4에서 처음 편다)
- **최온**: 지난번 단서를 다시 읽어 보자.
- **어른**: 지난 일지에서 다음 탐험의 단서를 읽어 봐요. (어른 도움말: E49 일지의 '아버지가 지어 준 채색옷', 37:3. 지난 일지가 없으면 "야곱에게는 요셉이라는 아들이 있어요. 아버지는 요셉에게 채색옷을 지어 주었고, 형들은 요셉을 미워했어요."라고 말로 알려 주고 다음 쉼은 건너뛴다)
- **쉼**: 아이가 단서를 읽을 때까지 기다린다.
- **어른**: 형들은 양을 치러 세겜으로 갔어요. 아버지는 형들이 잘 있는지 보고 오라고 요셉을 보냈어요. (어른 도움말: 12–14절)
- → 칸 2로 간다.

### 칸 2 · 고르기 (37장을 펴기 전)

- 보이는 것: 고르기 카드 두 장 (도단 / 세겜)
- 칸 3에서 돌아왔으면 이 칸을 처음부터 다시 읽는다.
- **어른**: 요셉은 형들을 찾아 길을 떠났어요. (어른 도움말: 14–17절. 어디에서 만났는지는 말하지 않는다)
- **어른**: 이번에도 성경을 펴기 전에 먼저 골라요. 고른 다음에 37장에서 확인해요. (어른 도움말: 칸 3을 다녀온 아이에게는 이 줄 대신 "이번에는 성경을 덮은 채로 다시 골라요."라고 말한다. 같은 카드를 또 고르면 '그 절에서 그 성읍에 이른 사람은 누구였나요?'라고만 묻고 다시 고르게 한다. 탐험이 처음인 아이에게는 '이번에도'를 빼고 읽는다)
- **어른** 『탐험대 이야기』: 요셉이 형들을 만난 곳은 어디일까요? 도단일까요, 세겜일까요?
- 고르기
  - **세겜** → 칸 3으로 간다.
  - **도단** → 칸 4로 간다.

### 칸 3 · 다른 장면: 세겜 성읍에 이른 사람 (창 33:18)

- 보이는 것: 타임머신 (탐험대의 도구. 성경 속 사람은 그리지 않는다)
- **어른** 『탐험대 이야기』: 타임머신이 다른 때에 잠깐 내렸어요.
- **최온**: 여기는 언제일까?
- **어른**: 창을 낸 종이 사이로 보이는 절을 봐요. 세겜 성읍에 이른 사람은 누구인가요? (어른 도움말: 33:18. 야곱. 어른이 33장을 펴서 창을 낸 종이를 얹어 18절만 보이게 하고, 맞은쪽은 다른 종이로 다 덮는다. 바로 아래의 34장이 보이지 않게 한다)
- **쉼**: 아이가 '야곱'을 찾을 때까지 기다린다.
- **어른**: 오늘 우리가 찾는 것은 누가 누구를 만난 곳이었나요?
- **쉼**: 아이가 요셉이 형들을 만난 곳이라고 말할 때까지 기다린다. (어른 도움말: 33:18은 아버지 야곱이 세겜 성읍에 이른 일이다. 오늘은 요셉이 형들을 만난 곳을 찾는다. 아이가 스스로 말하게 둔다. E45 일지가 있으면 '세겜 성읍' 줄을 함께 본다)
- **어른** 『탐험대 이야기』: 일지에 찾은 것을 적어 둬요. (어른 도움말: '세겜 성읍에 이른 사람 · 창세기 33장 18절 · 야곱')
- **어른** 『탐험대 이야기』: 성경을 덮어요. 요셉의 길로 돌아가서 다시 골라 봐요.
- → 칸 2로 돌아간다.

### 칸 4 · 형들을 찾아가는 길 (창 37:12–17)

- 보이는 것: 두 줄 판 (탐험대의 도구. 편 쪽지까지만 보인다. 성경 속 사람은 그리지 않는다)
- **어른**: 이제 창세기 37장을 봐요. 가림 종이 아래 첫머리에서, 아버지가 요셉을 어느 골짜기에서 보냈는지 찾아봐요. (어른 도움말: 14절. 헤브론 골짜기. 가림 종이를 미리 끼워 둔 37장을 어른이 편다. 12절 위쪽과 18–22절, 25–27절, 29절부터가 덮여 있어야 한다)
- **쉼**: 아이가 '헤브론'을 찾을 때까지 기다린다.
- **어른** 『탐험대 이야기』: 길 쪽지 첫 장에 적고, 둘째 장과 함께 윗줄에 놓아요. (어른 도움말: ① 헤브론, ② 세겜. 14절. 쪽지를 적을 때마다 어른이 절 번호를 불러 주고 아이가 작은 칸에 적는다)
- **어른**: 세겜에 간 요셉은 들에서 형들을 찾아다녔어요. 요셉이 형들을 만난 곳을 조금 뒤에서 찾아봐요. (어른 도움말: 17절. 도단. 15–16절에서 어떤 사람이 요셉에게 길을 알려 준다)
- **쉼**: 아이가 '도단'을 찾을 때까지 기다린다.
- **어른** 『탐험대 이야기』: 셋째 장에 적고 놓아요. 아까 고른 카드와도 견주어 봐요. (어른 도움말: ③ 도단. 17절)
- → 칸 5로 간다.

### 칸 5 · 옷과 구덩이 (창 37:18–24)

- 보이는 것: 두 줄 판 (탐험대의 도구. 사건은 그리지 않는다)
- **어른**: 형들은 멀리서 오는 요셉을 보았어요. 형들은 요셉을 죽이려고 꾀했어요. (어른 도움말: 18절. 이 말 그대로만 읽고 더 풀지 않는다. 18–22절은 덮어 둔 채로 어른이 말한다)
- **어른**: 맏형 르우벤은 죽이지 말고 구덩이에 던지자고 했어요. 성경은 르우벤이 요셉을 구해서 아버지에게 돌려보내려 했다고 적어요. (어른 도움말: 21–22절. 앞 문장은 르우벤의 말, 뒤 문장은 서술자가 적은 까닭이다)
- **어른**: 요셉이 오자 형들은 요셉의 옷을 벗겼어요. 무슨 옷이었는지 가림 종이 사이의 두 절에서 찾아봐요. (어른 도움말: 23절. 채색옷. 어른이 23–24절을 짚어 준다)
- **쉼**: 아이가 '채색옷'을 찾을 때까지 기다린다.
- **최온**: 지난 단서에 있던 그 옷이야.
- **어른**: 형들이 요셉을 던져 넣은 곳도 바로 뒤에서 찾아봐요. (어른 도움말: 24절. 구덩이. 비어 있었고 물이 없었다)
- **쉼**: 아이가 '구덩이'를 찾을 때까지 기다린다.
- **어른** 『탐험대 이야기』: 넷째 장에 적고 놓아요. (어른 도움말: ④ 구덩이. 24절)
- → 칸 6으로 간다.

### 칸 6 · 애굽으로 (창 37:25–28)

- 보이는 것: 두 줄 판 (탐험대의 도구. 사건은 그리지 않는다)
- **어른**: 그때 애굽으로 가는 상인들이 지나갔어요. 유다는 요셉을 죽이지 말고 그 상인들에게 팔자고 했어요. (어른 도움말: 25–27절. 덮어 둔 채로 어른이 말한다. 지나간 것은 서술자가 적은 일, 팔자는 것은 유다의 말이다)
- **어른**: 형들은 유다의 말을 따랐어요. 구덩이에 있던 요셉을 꺼내어, 은 이십을 받고 팔았어요. (어른 도움말: 27–28절)
- **어른**: 상인들이 요셉을 어디로 데리고 갔는지 가림 종이 사이의 한 절에서 찾아봐요. (어른 도움말: 28절 끝. 애굽. 어른이 28절을 짚어 준다)
- **쉼**: 아이가 '애굽'을 찾을 때까지 기다린다.
- **어른** 『탐험대 이야기』: 다섯째 장에 적고 놓아요. 윗줄이 다 찼어요. (어른 도움말: ⑤ 애굽. 28절. 여기서 멈출 수 있다)
- → 칸 7로 간다.

### 칸 7 · 아버지에게 간 것 (창 37:31–35, 성경을 덮은 채)

- 보이는 것: 두 줄 판 (탐험대의 도구. 사건은 그리지 않는다)
- **어른** 『탐험대 이야기』: 성경을 덮어요. 여기서부터는 성경이 적은 것을 듣기만 해요.
- **어른**: 형들은 요셉의 옷에 숫염소의 피를 묻혔어요. 그 옷을 아버지에게 보내어, 아들의 옷인지 보라고 했어요. (어른 도움말: 31–32절. 피를 묻힌 것은 서술자가 적은 일, 보라고 한 것은 형들의 말이다)
- **어른** 『탐험대 이야기』: 아버지에게 간 옷은 무슨 옷이었나요? 아랫줄의 첫 쪽지에 적어요. (어른 도움말: ㉮ 쪽지. 채색옷. 32절. 칸 5에서 찾은 그 옷이다)
- **쉼**: 아이가 '채색옷'이라고 말하고 적을 때까지 기다린다.
- **어른**: 아버지는 그 옷을 알아보았어요. 그리고 악한 짐승이 요셉을 잡아먹었다고 말했어요. (어른 도움말: 33절. 아버지가 한 말이다. ㉯ 쪽지를 어른이 아랫줄에 놓는다. 쪽지 머리의 '말(아버지)'를 함께 읽는다)
- **어른**: 아버지는 아들을 위해 오래도록 슬퍼했어요. 자녀들이 위로해도 받지 않았어요. (어른 도움말: 34–35절. 서술자가 적은 일이다. ㉰ 쪽지를 어른이 놓는다. 35절의 아버지의 말은 말하지 않는다)
- → 칸 8로 간다.

### 칸 8 · 두 줄 견주기 (창 37:36)

- 보이는 것: 탐험 일지, 두 줄 판 (쪽지 여덟 장이 다 놓여 있다)

## 아이용 요약

어른과 함께 읽는다.

요셉은 아버지의 심부름으로 헤브론 골짜기를 떠났어요(창세기 37장). 형들이 잘 있는지 보고 오는 길이었어요. 요셉은 세겜을 지나 도단에서 형들을 만났어요. 형들은 요셉을 죽이려고 꾀했어요. 르우벤은 죽이지 말고 구덩이에 던지자고 했어요. 형들은 요셉의 채색옷을 벗기고, 물 없는 구덩이에 요셉을 던져 넣었어요. 유다는 요셉을 상인들에게 팔자고 했고, 형들은 은 이십에 요셉을 팔았어요. 요셉은 상인들을 따라 애굽으로 가게 되었어요. 형들은 요셉의 옷에 숫염소의 피를 묻혀 아버지에게 보냈어요. 아버지는 악한 짐승이 요셉을 잡아먹었다고 말했고, 오래도록 슬퍼했어요. 성경은 요셉이 애굽에서 보디발이라는 사람에게 팔렸다고 적어요.

## 녹음용 읽기 원고

한 줄이 한 칸이다. 줄 앞 번호와 괄호 안은 읽지 않는다. 각 줄은 어른 목소리로 시작한다. (최온)과 (어른)은 목소리를 바꾸는 자리다.

1. 타임머신이 야곱의 집에서 멀리 떨어진 언덕에 내렸어요. (최온) 지난번 단서를 다시 읽어 보자. (어른) 지난 일지에서 다음 탐험의 단서를 읽어 봐요. (쉼) 형들은 양을 치러 세겜으로 갔어요. 아버지는 형들이 잘 있는지 보고 오라고 요셉을 보냈어요.
2. 요셉은 형들을 찾아 길을 떠났어요. 이번에도 성경을 펴기 전에 먼저 골라요. 고른 다음에 37장에서 확인해요. 요셉이 형들을 만난 곳은 어디일까요? 도단일까요, 세겜일까요?
3. 타임머신이 다른 때에 잠깐 내렸어요. (최온) 여기는 언제일까? (어른) 창을 낸 종이 사이로 보이는 절을 봐요. 세겜 성읍에 이른 사람은 누구인가요? (쉼) 오늘 우리가 찾는 것은 누가 누구를 만난 곳이었나요? (쉼) 일지에 찾은 것을 적어 둬요. 성경을 덮어요. 요셉의 길로 돌아가서 다시 골라 봐요.
4. 이제 창세기 37장을 봐요. 가림 종이 아래 첫머리에서, 아버지가 요셉을 어느 골짜기에서 보냈는지 찾아봐요. (쉼) 길 쪽지 첫 장에 적고, 둘째 장과 함께 윗줄에 놓아요. 세겜에 간 요셉은 들에서 형들을 찾아다녔어요. 요셉이 형들을 만난 곳을 조금 뒤에서 찾아봐요. (쉼) 셋째 장에 적고 놓아요. 아까 고른 카드와도 견주어 봐요.
5. 형들은 멀리서 오는 요셉을 보았어요. 형들은 요셉을 죽이려고 꾀했어요. 맏형 르우벤은 죽이지 말고 구덩이에 던지자고 했어요. 성경은 르우벤이 요셉을 구해서 아버지에게 돌려보내려 했다고 적어요. 요셉이 오자 형들은 요셉의 옷을 벗겼어요. 무슨 옷이었는지 가림 종이 사이의 두 절에서 찾아봐요. (쉼) (최온) 지난 단서에 있던 그 옷이야. (어른) 형들이 요셉을 던져 넣은 곳도 바로 뒤에서 찾아봐요. (쉼) 넷째 장에 적고 놓아요.
6. 그때 애굽으로 가는 상인들이 지나갔어요. 유다는 요셉을 죽이지 말고 그 상인들에게 팔자고 했어요. 형들은 유다의 말을 따랐어요. 구덩이에 있던 요셉을 꺼내어, 은 이십을 받고 팔았어요. 상인들이 요셉을 어디로 데리고 갔는지 가림 종이 사이의 한 절에서 찾아봐요. (쉼) 다섯째 장에 적고 놓아요. 윗줄이 다 찼어요.
7. 성경을 덮어요. 여기서부터는 성경이 적은 것을 듣기만 해요. 형들은 요셉의 옷에 숫염소의 피를 묻혔어요. 그 옷을 아버지에게 보내어, 아들의 옷인지 보라고 했어요. 아버지에게 간 옷은 무슨 옷이었나요? 아랫줄의 첫 쪽지에 적어요. (쉼) 아버지는 그 옷을 알아보았어요. 그리고 악한 짐승이 요셉을 잡아먹었다고 말했어요. 아버지는 아들을 위해 오래도록 슬퍼했어요. 자녀들이 위로해도 받지 않았어요.
8. 아랫줄의 가운데 쪽지를 읽어 봐요. 아버지는 요셉이 어떻게 되었다고 말했나요? (쉼) 이번에는 윗줄의 마지막 쪽지를 읽어 봐요. 성경은 요셉이 어디로 갔다고 적나요? (쉼) (최온) 아버지는 짐승이 요셉을 잡아먹었다고 말했어. 성경은 상인들이 요셉을 애굽으로 데리고 갔다고 적어. (어른) 37장의 끝 절은 요셉이 애굽에서 보디발이라는 사람에게 팔렸다고 적어요. 다음 탐험에서는 요셉의 형 유다의 집을 봐요.
9. 일지에 윗줄의 다섯 곳을 놓인 차례대로 옮겨 적어요. 다음 탐험의 단서도 같이 적어요. 요셉의 길, 창세기 37장 14절과 17절과 24절과 28절, 헤브론 골짜기, 세겜, 도단, 물 없는 구덩이, 애굽의 차례. 형들이 벗긴 옷, 창세기 37장 23절, 채색옷. 아버지에게 간 것, 창세기 37장, 일은 피를 묻힌 채색옷, 아버지의 말은 악한 짐승이 요셉을 잡아먹었다, 일은 아버지는 오래도록 슬퍼함. 다음 탐험의 단서, 창세기 37장 26절, 요셉의 형 유다.

- 고르기 보기의 근거: '도단'은 37:17에서 요셉이 형들을 만난 곳이다. '세겜'은 형들이 양을 치러 갔다고 아버지가 말한 곳이고(37:13), 33:18에서 야곱이 이른 성읍이다(E45에서 아이가 단서로 적었다). 칸 1에서 어른이 '형들은 세겜으로 갔다'고 읽어 주므로 세겜이라고 짐작하기 쉽다. 본문에서 요셉은 세겜에 갔다가 형들을 만나지 못하고 도단으로 간다. 칸 3에서 아이는 33:18의 세겜에 이른 사람이 야곱이라는 것을 찾고, 오늘 찾는 것은 요셉이 형들을 만난 곳이라고 스스로 말한다(사람과 일이 어긋남).
- 사건의 폭력을 고르기로 두지 않은 까닭: E46의 방식대로, 죽이려 한 일이나 판 일을 두고 고르게 하지 않고 곳을 고르게 했다.
- 두 줄 판: 회차표 50행의 '구덩이에서 애굽으로 이어지는 요셉의 길과 야곱이 전해 받은 단서를 두 줄로 놓는다'에 맞췄다. 윗줄은 곳 다섯(37:14, 17, 24, 28), 아랫줄은 아버지에게 간 것 셋(37:31–34)이다. 칸 8에서 아랫줄의 아버지의 말(37:33)과 윗줄의 끝(37:28)을 견준다. 아버지의 말은 쪽지 머리에 '말(아버지)'로 적어 서술자가 적은 일과 가른다.
- 말과 일의 가름: 37:12, 14 끝, 15 앞, 17 끝, 18, 22 끝, 23–25 앞, 27 끝, 28–29, 31, 32 앞, 33 앞, 34, 35(위로와 울음), 36은 서술자가 적은 일이다. 37:13–14 앞은 아버지와 요셉의 말, 15 뒤–17 앞은 어떤 사람과 요셉의 말, 19–20은 형들의 말, 21–22 앞은 르우벤의 말, 26–27 앞은 유다의 말, 30은 르우벤의 말, 32 뒤는 형들의 말, 33 뒤와 35 가운데는 아버지의 말이다.
- 37:20(형들이 꾸미려던 말)과 37:33(아버지의 말): 형들은 20절에서 '악한 짐승이 잡아먹었다고 하자'고 말했고, 32절에서는 옷만 보이며 '발견했다'고 했다. 그 말은 33절에서 아버지가 스스로 한다. 8~10세 판에서는 20절을 말하지 않고, 33절을 아버지의 말로만 옮긴다.
- 원고는 '형들이 아버지를 속였다'고 쓰지 않는다. 본문이 적은 것(옷에 피를 묻힘, 보냄, 한 말)만 옮기고, 물을 때의 답에서 두 사실을 나란히 답한다.
- 르우벤과 유다: 두 사람의 말을 그대로 줄여 옮기고 평가하지 않는다. 르우벤의 속뜻(37:22 끝)은 서술자가 적은 것이라 '성경은 … 적어요'로 옮겼다. 유다의 말의 까닭(37:26–27의 '유익', '혈육')은 어른 줄에 넣지 않았다.
- 상인들: 본문은 이스마엘 사람들(37:25, 27, 28)과 미디안 사람 상인들(37:28, 36)을 함께 쓴다. 원고는 '상인들'이라고만 하고 풀지 않는다.
- 어른 줄에 넣지 않은 절: 37:15–16(어떤 사람과의 말), 37:19–20, 37:29–30, 37:35의 아버지의 말. 물을 때의 답을 두었다(20절과 35절의 낱말은 답에도 쓰지 않았다).
- 37장에는 하나님의 이름이 나오지 않는다(받아 둔 본문에서 낱말을 세어 확인했다). 이 일의 뜻을 말하는 뒤의 장(45장, 50장)은 쓰지 않았다.
- 덮어 둔 절(37:31–35)의 번호는 아이가 일지에 적지 않는다(E46의 방식).
- 다음 회 단서는 '요셉의 형 유다'(37:26)다. E51은 38:1에서 유다가 형제들에게서 떠나는 데서 시작한다. 예고는 '유다의 집'이라고만 한다.
- 이 회로 바로 온 아이: 칸 1에서 어른이 요셉과 채색옷과 형들의 미움을 말로 알려 주고, 칸 9의 단서는 어른이 불러 준다.
- 성경 인물의 말은 간접 화법으로 옮겼다. 개역개정과 대조한 방법은 아래 '원고 자체 점검'에 적었다.
- 그림 주의: 사건 그림을 두지 않는다. 성경 속 사람, 구덩이 속, 피, 옷을 벗기는 모습을 그리지 않는다. 칸 1과 칸 3은 타임머신, 칸 2는 고르기 카드(낱말 카드), 칸 4~9는 두 줄 판과 쪽지만 그린다. 탐험대 가운데 이 회에 나오는 아이는 최온이다.

## 원고 자체 점검

| 점검 | 결과 |
|---|---|
| '도단'을 고른 경로: 칸 1 → 2 → 4 → 5 → 6 → 7 → 8 → 9 | 칸 2에서 37장을 펴기 전에 고르고, 칸 4에서 떠난 골짜기(37:14)와 형들을 만난 곳(37:17)을, 칸 5에서 형들이 벗긴 옷(37:23)과 던져 넣은 곳(37:24)을, 칸 6에서 상인들이 데리고 간 곳(37:28)을 찾아 길 쪽지 다섯 장을 윗줄에 놓는다. 칸 7은 성경을 덮은 채 듣고 아랫줄에 쪽지 석 장을 놓는다. 칸 8에서 아버지의 말과 요셉의 길 끝을 차례로 읽어 견준다 |
| '세겜'을 고른 경로: 칸 1 → 2 → 3 → 2 → 4 → … → 9 | 창을 낸 종이로 보여 준 33:18에서 세겜 성읍에 이른 사람이 야곱이라는 것을 찾고, 오늘 찾는 것은 요셉이 형들을 만난 곳이라고 스스로 말한다. 일지에 적고 성경을 덮은 뒤 칸 2에서 다시 고르고 같은 일지에 닿는다 |
| 칸 이동 | 스크립트로 확인했다. 칸 9개, 막힌 칸·빠진 칸·닿지 않는 칸 없음. 두 경로 모두 칸 9에 닿는다 |
| 회차표의 일 | 구덩이에서 애굽으로 이어지는 요셉의 길(윗줄, 칸 4~6)과 야곱이 전해 받은 것(아랫줄, 칸 7)을 두 줄로 놓고 칸 8에서 견준다 |
| 아이가 눈으로 읽는 절 | 37:12–17, 23–24, 28과 다른 장면의 33:18이다. 37:18–22, 25–27, 29–36은 가림 종이로 덮고 어른이 짧게 잇는다. 덮어 둔 절의 번호는 일지에 적지 않는다 |
| 서술자의 말과 인물의 말 | 37:14 끝, 17 끝, 18, 22 끝, 23–24, 28, 31, 34–36은 '성경이 적은 일', 37:21–22 앞은 '르우벤의 말', 37:26–27 앞은 '유다의 말', 37:32 뒤는 '형들의 말', 37:33 뒤는 '아버지의 말'로 갈라 옮겼다. 아버지의 말(37:33)은 쪽지 머리에 '말(아버지)'로 적어 요셉의 길(서술)과 가른다. 근거 표의 셋째 칸에 적었다 |
| 찾기 지시가 답을 미리 말하는지 | 칸 2는 37장을 펴기 전에 고른다(칸 1~2는 성경을 펴지 않는다). 칸 1~2는 형들을 만난 곳을 말하지 않는다. 37장은 어른이 펴고, 12절 위의 소제목(칸 6의 답이 적혀 있다)을 덮는다. 다른 장면은 창을 낸 종이로 33:18만 보여 주고 맞은쪽과 아래의 34장도 덮는다. 쪽지는 엎어 두고 한 장씩 편다. 칸 이름은 아이 화면에 띄우지 않는다 |
| 물음마다 답이 하나인지 | 헤브론(37:14), 도단(37:17), 채색옷(37:23), 구덩이(37:24), 애굽(37:28), 다른 장면의 야곱(33:18)은 각각 본문에서 답이 정해진다. 칸 7의 물음(아버지에게 간 옷)과 칸 8의 두 물음은 판의 쪽지로 확인된다 |
| 본문에 없는 곳·물건·까닭·속마음 | 요셉의 마음과 말, 형들의 마음, 아버지가 요셉을 보낸 속뜻, 이 일의 뜻을 쓰지 않는다. 인물의 마음은 서술자가 적은 것(르우벤의 속뜻 37:22, 아버지의 슬픔 37:34–35)만 옮겼다. 형들과 르우벤과 유다를 평가하지 않는다. 본문 밖의 말은 그렇게 표시했다 |
| 수위 | 37:20의 꾸민 말, 37:33 끝의 낱말, 37:35의 '스올'을 어른 줄과 답에 쓰지 않았다. 죽이려 한 일과 판 일은 한 줄씩만 말하고 그리지 않는다. 하지 않는 길과 멈출 자리를 두었다 |
| 아이가 읽고 물을 수 있는 곳의 답 문장 | '아이가 물을 때의 답' 표에 열여덟 줄, '어른이 고를 수 있는 도움말' 표에 여섯 줄을 두고 줄마다 근거를 붙였다 |
| 감수 | 필수. 감수 전에는 아이에게 쓰지 않는다. 머리말과 카드 정보에 표시했다 |
| 본편 회차 항목 | 앞 회에서 남은 일, 이번 사건, 달라진 점, 다음 회 첫 장면의 단서(37:26), 아이가 확인할 단서(37:17), 되돌아볼 장절을 '회차 연결'에 적었다. E49 끝의 단서와 예고를 칸 1이 받는다 |
| 이 회로 바로 온 아이 | 칸 1에서 어른이 요셉과 채색옷과 형들의 미움을 말로 알려 주고, 칸 9의 단서는 어른이 불러 준다. 막히는 줄이 없는지 읽어 보았다 |
| 개역개정과 겹치는 말 | 창 37, 33, 34, 35, 36장 본문과 소제목, 난외주(대한성서공회 읽기 쪽에서 받은 것)를 스크립트로 문서 전체와 대조했다. 처음에는 9자 이상 겹침 8건, 느슨한 네 어절 겹침 5건이 나왔다(네 어절 겹침은 0건). 고친 뒤 세 가지 모두 0건이다 |
| 한 화면의 글 | 어른과 최온의 줄 38개 모두 괄호를 빼고 두 문장 이하다 |
| 길이 | 줄 38개, 쉼 11곳(도단 경로는 9곳), 칸 9개다. 플레이 원고 안에서만 스크립트로 세었다 |
| 녹음용 읽기 원고 | 플레이 원고에서 스크립트로 만든다. 어른 도움말과 기도는 빼고, 일지 항목은 읽는 말로 더한다. 감수 전에는 녹음하지 않는다 |
| 말투 | 어른의 줄은 모두 존댓말이다 |
| 쓰지 않은 말 | "틀렸어요", 감점, 실패 표현이 없다 |
| 인물의 속마음과 지어낸 대사 | 없다. 성경 인물의 말은 본문이 적은 말만 간접 화법으로 줄여 옮겼다 |
| ⚠️ 확인하지 못한 것 | 가림 종이 넉 장으로 18–22, 25–27, 29절부터를 덮고 23–24절과 28절만 보이게 하는 일은 실물 성경으로 해 보지 못했다(판형에 따라 어렵다). 실제 아이와 해 보지 못했다. 뒤의 장(39장부터)은 본문을 받지 않아 대조하지 못했다 |
